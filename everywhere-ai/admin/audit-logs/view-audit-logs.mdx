Audit logs record all operations performed in the cluster, tracking who performed each action, when it occurred, and which resources were affected. Use this page for troubleshooting, security investigations, and tracking configuration changes in Everywhere AI.

Navigate to **Audit Logs** > **Audit Logs** to view the event history.

![Audit Logs page showing event history with filters and table](/images/docs/everywhere-ai/admin/audit-logs/view-audit-logs/audit-logs-list.png)

The page displays a date range selector (default: one month) with custom date pickers, and filter dropdowns for **Actions**, **Resources**, **Projects**, and **Users**.

Each event row shows:

- **Date** — timestamp of the operation.
- **Action** — operation type. Common values include `create`, `update`, `delete`, `get`, and `list`.
- **Resource** — the type of object affected by the action — user, project, quota, or deployment.
- **Project** — project context, if applicable.
- **Event** — human-readable description of what happened.
- **Changed by** — username of who performed the action.
