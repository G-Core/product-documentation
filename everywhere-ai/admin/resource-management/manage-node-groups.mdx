---
title: "Manage node groups"
description: "Create and manage logical node groups in the Everywhere AI Admin Panel to organize infrastructure by purpose or hardware type."
---

Navigate to **Resources** > **Node Groups** to manage logical groupings of nodes.

![Node Groups page showing search, filters, and bulk delete controls](/images/docs/everywhere-ai/admin/resource-management/manage-node-groups/resource-management-node-groups.png)

A node group links cluster nodes to one or more projects. Workloads from those projects can run only on nodes assigned to the group. Groups can span multiple regions, and each node can belong to only one group at a time.

Common use cases include separating production and development workloads, dedicating GPU nodes to specific projects, and filtering nodes during workload relocation.

Search by group or node name, or filter by **Region** and **Project**. Each group that remains shows its projects, regions, and node count.

## Create a node group

A group needs a name and at least one project, because those projects are the ones whose workloads can run on its nodes. Set both in **Create Node Group**.

Nodes are chosen from **Available Nodes**. **Add** lists the chosen node under **Nodes in the Group**.

**Expose** is optional. After a node is added, each region keeps **Default gateway** unless **Select host** routes that region's containers through a custom gateway. An empty host keeps the default regional gateway.

Click **Create**.

## Change a node group

Click the group to open **Node Group Overview**.

**Edit Nodes** returns to the same node list and the optional **Expose** setting. **Edit Projects** changes which projects can use the group. **Save** applies the change.

## Delete a node group

Check the groups to remove. **Select all** checks every group on the page when the whole list should go. **Delete selected** opens the confirmation, and **Delete Node Groups** accepts it. The dialog states that the nodes move to public availability.

**Delete** in **Node Group Overview** removes that one group and states the same outcome.

Node group assignments are visible in the [Nodes](/everywhere-ai/admin/resource-management/manage-nodes) list and can be used to filter instances in [Instances](/everywhere-ai/admin/resource-management/manage-instances).
