Navigate to **Resources** > **Instances** to view all running workloads across the cluster. The page shows resource allocation per instance and lets administrators relocate individual workloads between nodes.

![Instances page showing workloads grouped by node group with resource allocation and filters](/images/docs/everywhere-ai/admin/resource-management/manage-instances/resource-management-instances-list.png)

Each entry shows the instance name, flavor, vCPU, RAM, GPU allocation, current node, and region. Use the **Region**, **Node Group**, **Node**, **GPU type**, and **Flavor** filters to narrow the list.

## Deschedule an instance

Click **Deschedule** on any instance to migrate it to another available node within the same node group. The workload is evicted from its current node and rescheduled automatically.


<Info>
If no node in the group has sufficient capacity, the instance is paused and queued until resources become available. It is not lost or terminated.
</Info>



<Warning>
Deschedule fails if no other node in the same node group can satisfy the workload's CPU, memory, or GPU requirements. To resolve this, free capacity on a compatible node in the group or move the node group assignment.
</Warning>


To evacuate all workloads from a specific node at once, run Drain on the [Nodes](/everywhere-ai/admin/resource-management/manage-nodes) page.
