Navigate to **Resources** > **Images** to view the OS images available across the cluster. Images define the operating system template used when creating new instances. They are provided and updated by Everywhere AI. Super Admins cannot upload custom images from this page.

![Images list showing image name, type, last updated date, status, and state columns with search and filter controls](/images/docs/everywhere-ai/admin/resource-management/manage-images/resource-management-images-list.png)

Each entry shows:

- **Image Name** — the OS identifier used when selecting an image during instance creation.
- **Type** — CPU-based or GPU-based, indicating which instance types the image is compatible with.
- **Last Updated** — when Everywhere AI last updated this image.
- **Status** — the current lifecycle status of the image (see below).
- **State** — whether the image is currently available for use (Active or Disabled).

## Status values

Status indicates the current availability of the image in Everywhere AI:

| Status | Meaning |
|--------|---------|
| Pending | Image is queued for import |
| Importing | Image is being imported and synced |
| Available | Image is ready for instance deployment |
| Failed | Import failed; the image cannot be used |
| Deprecated | Image has been superseded; not recommended for new deployments |

## Disable an image

To prevent an image from being used in new deployments, click the three-dot menu on the image row and select **Disable**. The image's State changes to **Disabled**. Disabled images can be re-enabled at any time using the same menu.

Disabling an image does not affect instances that are already running with that image.

Images define the operating system, while hardware resources (CPU, memory, GPU) are configured through [Flavors](/everywhere-ai/admin/capacity/manage-flavors).
