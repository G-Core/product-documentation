The Everywhere AI autoinstaller (`box-installer`) deploys Everywhere AI on Kubernetes using a GitOps approach: it bootstraps Gitea and Argo CD on the lead cluster, then deploys all components as Argo Applications. Secrets and configuration are stored in Kubernetes secrets and HashiCorp Vault. Each target cluster must have Cilium CNI installed, a default StorageClass configured, and a container registry with Everywhere AI images reachable from the cluster; the kubeconfig used for installation requires cluster-admin permissions.

## Node requirements

Each cluster requires the following node groups before installation:

**Control plane** — 3 nodes, each: 4 vCPU, 8 GiB RAM, 100 GiB disk.

**Worker infrastructure** — at least 3 nodes labeled `node-role.kubernetes.io/worker-infra`, with at least 42 GiB of allocatable memory across the group. Recommended per node: 8 vCPU, 16 GiB RAM, 200 GiB disk.

**Ingress** — at least 2 nodes labeled `node-role.kubernetes.io/ingress`, with at least 7 GiB of allocatable memory across the group. Recommended per node: 2 vCPU, 4 GiB RAM, 80 GiB disk.

## Configuration

The installer reads deployment parameters from `config.yaml`. A minimal single-cluster configuration:

```yaml
secrets: path/to/secrets.yaml
boxStackRegistry: registry.example.com

clusters:
  - name: my-cluster
    lead: true
    kubeconfig: path/to/kubeconfig.yaml
    platform:
      domain: box.example.com
```

Cluster name and domain are permanent after bootstrap. Naming constraints and secret keys are in [installer&nbsp;config](/everywhere-ai/admin/autoinstaller/configure-autoinstaller). The `secrets.yaml` format and available secret keys are also defined there.

## Installation sequence

<Steps>

<Step title="Verify requirements">

Check cluster readiness before proceeding:

```bash
box-installer --config config.yaml install check-requirements
```

For multi-cluster deployments, check all clusters:

```bash
box-installer --config config.yaml install check-requirements --all
```

</Step>

<Step title="Bootstrap the cluster">

Initialize Gitea, Argo CD, cert-manager, Vault, and External Secrets Operator:

For **Option B** (automated ACME), set `dnsProvider.gcore` in `config.yaml` before this command. The fields are in [DNS&nbsp;provider&nbsp;configuration](/everywhere-ai/admin/autoinstaller/configure-autoinstaller#dns-provider-per-cluster).

```bash
box-installer --config config.yaml install bootstrap
```

Bootstrap is idempotent: if interrupted and restarted, it compares the rendered templates against the existing repository. If they match, it resumes. If they differ, it stops and reports the conflict — use `--force-rewrite-repo` to recreate the repository from scratch.

cert-manager is installed automatically by bootstrap. No separate step is needed.

</Step>

<Step title="Provision TLS certificates">

Three certificates are required in the `envoy-gateway-system` namespace before infrastructure deployment: `*.<domain>` (wildcard), `api.<domain>`, and `*.caas.<domain>`. Select a provisioning method:

**Option A: Pre-issued certificates** — place certificate and key files in a directory and apply them:

```bash
box-installer --config config.yaml install certs-byoc --dir ./certs
```

**Option B: Automated issuance via DNS-01 (ACME)** — requires `dnsProvider.gcore` set in the cluster's `config.yaml` entry ([DNS&nbsp;provider&nbsp;configuration](/everywhere-ai/admin/autoinstaller/configure-autoinstaller#dns-provider-per-cluster)). Configure it before bootstrap, then run:

```bash
box-installer --config config.yaml install certs-acme
```

</Step>

<Step title="Deploy infrastructure">

```bash
box-installer --config config.yaml install infra
```

</Step>

<Step title="Deploy the box-stack">

```bash
box-installer --config config.yaml install box-stack
```

</Step>

<Step title="Activate GitOps synchronization">

```bash
box-installer --config config.yaml install commit
```

`commit` records the installed version and enables Argo CD sync. Argo CD begins converging at this point.

Once Argo CD has synced, verify the installation:

```bash
box-installer --config config.yaml check full
```

Each check prints `PASS`, `FAIL`, or `SKIP`. The command exits with code 1 if any check failed. Future updates are delivered through [release commands](/everywhere-ai/admin/autoinstaller/manage-releases) without repeating this sequence.

</Step>

</Steps>

## Multi-cluster deployments

Deploy and fully configure the lead cluster first, then add additional clusters one by one. Each additional cluster must be defined in `config.yaml` and meet the node requirements above before bootstrap.

Bootstrap each additional cluster:

```bash
box-installer --config config.yaml install bootstrap --cluster edge-cluster-1
```

Register the new cluster so all clusters know about it:

```bash
box-installer --config config.yaml install register --cluster edge-cluster-1
```

To register all clusters at once:

```bash
box-installer --config config.yaml install register --all
```

After adding a new cluster, update cross-cluster Keycloak federation so all clusters trust each other:

```bash
box-installer --config config.yaml install keycloak-federation
```

List clusters and check their status:

```bash
box-installer --config config.yaml install list-clusters
```

Once bootstrap, registration, and Keycloak federation are complete, provision TLS certificates for the new cluster using the same options as in the **Provision TLS certificates** step above:

```bash
# Option A: pre-issued certificates
box-installer --config config.yaml install certs-byoc --dir ./certs --cluster edge-cluster-1

# Option B: automated ACME (dnsProvider.gcore must be configured before bootstrap)
box-installer --config config.yaml install certs-acme --cluster edge-cluster-1
```

Then complete the deployment of the new cluster using the same `--cluster` targeting pattern:

```bash
box-installer --config config.yaml install infra --cluster edge-cluster-1
box-installer --config config.yaml install box-stack --cluster edge-cluster-1
box-installer --config config.yaml install commit --cluster edge-cluster-1
box-installer --config config.yaml install finalize --cluster edge-cluster-1
```
