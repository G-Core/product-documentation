# Quotas for Public Models

Quotas for Public Models control how many tokens and requests each user can consume per minute when accessing shared AI models via API. Rate limits are configured per API key and apply to specific models.

Navigate to **Public Models** > **Quotas for Public Models** to manage per-user rate limits.

![Quotas for Public Models page showing user list on the left and API key quotas on the right](/images/docs/everywhere-ai/admin/public-models/manage-public-model-quotas/quotas-public-models-user.png)

The left panel lists all users with a search box. Select a user to view their API keys on the right panel. Users without API keys display a message indicating quotas will appear once the first key is created.

Each row in the right panel displays:

- **API Key** — the key name.
- **Model** — the Public Model this key is scoped to, with a link to the model detail view.
- **Quotas Limits** — current **Tokens per min** and **Requests per min** values.

Use the **Models** and **API Keys** filters above the table to narrow the list.

## Update quotas

Click **Update quotas** next to an API key to modify its rate limits.

![Update quotas dialog with API Key, Model, Tokens per min and Requests per min fields](/images/docs/everywhere-ai/admin/public-models/manage-public-model-quotas/quotas-public-models-update.png)

The **API Key** and **Model** fields are read-only. Enter new values for **Tokens per min** and **Requests per min**, then click **Save**.


<Warning>
Quota changes take effect immediately. Reducing limits may cause active user sessions to receive rate limit errors.
</Warning>


Compute resource quotas (CPU, memory, GPU) for projects are configured separately in [Quotas](/everywhere-ai/admin/capacity/manage-quotas).
