One deployment serves every user. Each user calls it with an API key, and [Public&nbsp;model&nbsp;quotas](/everywhere-ai/admin/public-models/manage-public-model-quotas) caps that key.

The sidebar group **Public Models** contains the page **Public Models**.

![Public models list with Deploy Model and the Status column](/images/docs/everywhere-ai/admin/public-models/manage-public-models/public-models-list.png)

**Deploy Model** adds a deployment. The name in the **Model** column opens one that already exists. **Status** names the state of the row. A deployment that is not running is **Stopped**.

## Deploy a public model

A new deployment needs a model, a name, and at least one region. **Deploy Model** opens **Deploy Public Model**.

![Deploy Public Model form with Model, Inference Instance Name, and Regions](/images/docs/everywhere-ai/admin/public-models/manage-public-models/public-models-deploy.png)

The **Inference Instance Name** identifies this deployment of the selected **Model**.

**Regions** are the locations that will run the deployment. **Show out of stock** adds locations that currently have no free capacity.

Under **Performance**, the modules travel with the selected model, and a **Required** module cannot be turned off. **Expose**, in that same block, publishes the endpoint outside the cluster. A flavor appears under **TOPOLOGY & COMPUTE** only when a selected region has capacity. Otherwise the form shows **No flavors available with sufficient capacity**.

Open WebUI appears here only when the selected model includes that companion module.

Click **Create** to deploy. **Cancel** returns to the list without creating a deployment.

## Change a running deployment

Open the model name, then **Settings**. This tab changes where the deployment runs, whether the endpoint is exposed, and how large it is.

![Settings tab with Expose, Serving topology, Flavor, and Replicas](/images/docs/everywhere-ai/admin/public-models/manage-public-models/public-models-settings.png)

**Flavor** and the **Replicas** range, **Min** to **Max**, set how large each copy is. **Single node** keeps every replica on one node. **Runtime** is **Native** or **Dynamo**. Click **Save** to keep the edit.

**Modules** lists each component with its **Flavor** and a **Status** of **Enabled** or **Disabled**.

**Monitoring** shows **Resource usage**: **CPU Usage**, **Memory Usage**, **GPU Utilization**, and **GPU Memory Utilization**. A stopped deployment shows **No data for given period**.

## Delete a public model

**Delete** at the top right opens **Delete public model**. Type `Delete`, then click **Delete**.
