Account Admins manage users in Everywhere AI. This includes inviting new users by email, changing roles, configuring project access for Members, and removing users.


<Info>
Account Admins invite users and change their roles here. Admin Panel user management (Super Admin) is in [Manage&nbsp;users](/everywhere-ai/admin/access-management/manage-users). The full access hierarchy is described in [Access&nbsp;management](/everywhere-ai/admin/access-management/access-management).
</Info>


Navigate to **Users** in the sidebar to open the user list for the current account.

![Users page showing the user list with name, role columns, and the Invite User button](/images/docs/everywhere-ai/admin/access-management/manage-users-in-account/account-admin-users.png)

The table shows username, email, and role. Use the search box to filter by name. The **Roles** filter limits the list to Account Admin or Member users.

## Invite a user

Click **Invite User** to open the invitation dialog.

![Invite User dialog with Email field and role selection between Account Admin and Member](/images/docs/everywhere-ai/admin/access-management/manage-users-in-account/account-admin-invite-user.png)

1. Enter the **Email** of the person to invite (required).
2. Select the **Role**:
   - **Account Admin** — the user automatically receives Read/Write access to all current and future projects in the account.
   - **Member** — the user receives no project access by default. Projects can be optionally assigned immediately using the **Assign Project Access** toggle.

### Project access for Members

When **Member** is selected and the **Assign Project Access** toggle is enabled, a project selector appears.

![Invite User dialog with Member role selected, Assign Project Access toggle enabled, and project and permission dropdowns](/images/docs/everywhere-ai/admin/access-management/manage-users-in-account/invite-user-member-projects.png)

Select a project from the **Select project** dropdown and select **Read Only** or **Read/Write** permission. Click **+** to add more project assignments.


<Tip>
Members who are not assigned to any project can only access Public Models within the account. Assign projects immediately at invite time, or use [Edit&nbsp;access](#edit-user-access) later.
</Tip>


3. Click **Create** to send the invitation.

The invited user receives an email and can log in after completing account setup.

## Edit user access

To change a user's role or manage their project assignments, click the three-dot menu on the user's row and select **Edit access**.

![Edit User Access panel showing Account Admin and Member role options](/images/docs/everywhere-ai/admin/access-management/manage-users-in-account/user-edit-access.png)

The available roles are **Account Admin** and **Member**:

- Switching a Member to **Account Admin** grants immediate Read/Write access to all projects.
- Switching an Account Admin to **Member** removes their automatic project access. Assign specific projects after saving in [account&nbsp;projects](/everywhere-ai/admin/access-management/manage-projects-in-account).

Click **Save** to apply the change.

## Remove a user

Click the three-dot menu on the user's row and select **Delete** to remove the user from the account.


<Warning>
Removing a user revokes all their access to the account and its projects immediately. The user's data and resources created within projects are not deleted — only the access grant is removed.
</Warning>
