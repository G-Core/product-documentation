Projects are the resource and access boundary within an account — each compute instance, volume, and database belongs to one project, and user permissions are scoped per project. The Admin Panel's **Projects** page covers all projects across all accounts in one view; role definitions and the full access model are in the [access&nbsp;management&nbsp;overview](/everywhere-ai/admin/access-management/access-management).

Navigate to **Workspace settings** > **Projects** to manage projects.

![Projects list showing project names, accounts, user and group assignment counts, and creation dates](/images/docs/everywhere-ai/admin/access-management/manage-projects/projects-list.png)

The list displays project name and internal ID, the parent account (click the account name to open that account's detail page), assigned users count, assigned user groups count, and creation date. Use the search box to filter by project name, and the Accounts dropdown to filter by parent account.

## Create a project

Click **Create Project** to open the creation form.

![Create Project form with account selector, project name field, and access settings section](/images/docs/everywhere-ai/admin/access-management/manage-projects/project-create-form.png)

1. Select the **Account** that will own this project (required). The project will be visible only to users and groups that have access to that account.
2. Enter the **Project Name** (required).
3. Configure **Access Settings** — assign users and user groups after selecting an account. The section becomes active once an account is selected.
4. Click **Create**.

## Manage project access

Click the three-dot menu on a project row and select **Edit** to open the access management panel. The same Access Settings panel is used during project creation.

The **Access Settings** section has two tabs: **Assigned Users** and **Assigned User Groups**.

### Assigned Users

The tab shows [users](/everywhere-ai/admin/access-management/manage-users) assigned to this project and their individual permission levels.

![Project Edit form showing Assigned Users tab with user list and Read Only / Read Write permission buttons](/images/docs/everywhere-ai/admin/access-management/manage-projects/project-edit-users.png)

To add a user, select them from the **Select user** dropdown, select **Read Only** or **Read/Write** permission, and click **Add User**.

The user list shows username and email, role (**Account Admin** or **Member**), and the current access level. Account Admins always have Read/Write access and appear in the list when **Show Account Admins** is checked.

Members have configurable permissions — click **Read Only** or **Read/Write** on their row to change the level. Click the delete icon to remove a member from the project.

### Assigned User Groups

The tab shows [user&nbsp;groups](/everywhere-ai/admin/access-management/manage-user-groups) linked to this project and their permission levels.

![Project Edit form showing Assigned User Groups tab with my-user-group assigned as Member with Read/Write access](/images/docs/everywhere-ai/admin/access-management/manage-projects/project-edit-user-groups-assigned.png)

To add a user group, select it from the **Select user group** dropdown, select **Read Only** or **Read/Write**, and click **Add Group**.

The group list shows group name, role, and the current access level. Account Admin groups always have Read/Write access. Click **Read Only** or **Read/Write** on a row to change the permission level. Click the delete icon to remove a group from the project. Use the search box to filter by group name.

Click **Save** to apply all access changes.

## Delete a project

Click the three-dot menu on the project row and select **Delete**.


<Warning>
Deleting a project removes all resources created within it and all access assignments for that project. This action cannot be undone.
</Warning>
