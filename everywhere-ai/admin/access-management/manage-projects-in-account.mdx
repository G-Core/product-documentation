Account Admins manage projects from Everywhere AI. Projects are the working environments where resources (inference instances, volumes, databases) are created. Each project belongs to one account.


<Info>
Everywhere AI actions here are for Account Admins. Super Admin project management in the Admin Panel is in [Manage&nbsp;projects](/everywhere-ai/admin/access-management/manage-projects).
</Info>


Open **Projects** in the sidebar to list the projects of the current account.

![Projects list with Name, Users, Created At, and the Create project button](/images/docs/everywhere-ai/admin/access-management/manage-projects-in-account/account-admin-projects-list.png)

**Type to search...** matches the **Name** column. The id under that name, **Users**, and **Created At** stay on each matching row.

## Default project

When a Super Admin creates an account, a default project with the same name is created automatically.

## Create a project

To add an empty working environment in the current account, click **Create project**. **Create Project** opens.

![Create Project dialog with Project Name, Add Users, Email / Login, and Read Only](/images/docs/everywhere-ai/admin/access-management/manage-projects-in-account/create-project-form.png)

1. Enter the **Project Name** (required).
2. Turn on **Add Users** to assign Members while creating the project. Under **Email / Login**, select the user in **Select user**, then select **Read Only** or **Read / Write** under **Permissions**.
3. Click **Create**.

The project appears in the list. Leave **Add Users** off and the project still includes the Account Admin, with **Read / Write** access and no separate assignment. Invite Members and set their access in [Manage&nbsp;account&nbsp;users](/everywhere-ai/admin/access-management/manage-users-in-account).

## Manage project access

This panel assigns access to Members. The Account Admin row only displays access that already covers every project in the account.

Click the row menu and select **Edit access** to open **Edit Project Access**.

![Project row menu with Edit access, Edit details, and Delete](/images/docs/everywhere-ai/admin/access-management/manage-projects-in-account/project-3dot-menu.png)

![Edit Project Access panel with Select user, Read Only, Read / Write, and Show Account Admins](/images/docs/everywhere-ai/admin/access-management/manage-projects-in-account/project-edit-access.png)

**Select user** lists Members already added to the account. When the account has no other users, the list shows **No users**.

To add a Member:

1. Select the user in **Select user**.
2. Select **Read Only** or **Read / Write**.
3. Click **Add User**.

Assigned users appear under **Name**, **Role**, and **Access**. **Show Account Admins** is on when the panel opens, so Account Admins are listed. An Account Admin stays at **Read / Write** and has no project-level permission control on that row.

Click **Save** to apply the change.

### Permission levels

| Permission | Description |
|---|---|
| **Read Only** | The Member can view resources in the project but cannot create, modify, or delete them |
| **Read / Write** | The Member can create, modify, and delete resources in the project |

## Rename a project

**Edit details** opens **Edit Project Details** on the display name. **Project name** is the field that changes. Click **Save** to keep the new name.

## Delete a project

In the row menu, select **Delete**.


<Warning>
Deleting a project permanently removes the project and every resource created in it. This cannot be undone.
</Warning>


In **Delete Project**, type `Delete`, then click **Delete Project**.

## Navigation

### Switch between projects

The header shows **Project** and the name of the current project. Click that control to open the project list. **View all projects** opens the full list.

![Project switcher listing the account projects and View all projects](/images/docs/everywhere-ai/admin/access-management/manage-projects-in-account/project-switcher.png)

Select a project to change context. Resource pages then show resources from that project.

### Switch accounts

A user can be an Account Admin in one account and a Member in another. To change account, click the profile button in the top-right corner, then **Switch account**.

![Switch account list of the other accounts and the role on each row](/images/docs/everywhere-ai/admin/access-management/manage-projects-in-account/switch-account-list.png)

Each row is another account this user can open, with the role on that row. Click an account to switch to it.
