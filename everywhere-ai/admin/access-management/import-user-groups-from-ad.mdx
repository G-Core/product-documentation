If Active Directory is integrated with Everywhere AI, use **Copy User Groups from AD** to import AD groups as user groups without recreating them manually. Imported groups appear in the [User&nbsp;Groups](/everywhere-ai/admin/access-management/manage-user-groups) list with an **AD** badge.


<Info>
The **Copy User Groups from AD** button is available only when Active Directory integration is configured for Everywhere AI.
</Info>


Click **Copy User Groups from AD** on the User Groups page to open the import wizard.

## Step 1 — Select Groups

![Copy User Groups from AD wizard Step 1: list of AD groups with checkboxes, search, and Show selected only toggle](/images/docs/everywhere-ai/admin/access-management/import-user-groups-from-ad/user-groups-copy-ad-step1.png)

The list shows all groups available in the connected AD, including their names and IDs. Check one or more groups to import. Use the search box to filter by name, or enable **Show selected only** to review the current selection. Click **Next** to proceed.

## Step 2 — Assign Access

![Copy User Groups from AD wizard Step 2: Configure per group mode showing Access Level and Access Settings for a selected group](/images/docs/everywhere-ai/admin/access-management/import-user-groups-from-ad/user-groups-copy-ad-step2.png)

Configure account access for the imported groups. Two modes are available:

- **Configure per group** — select a group from the left panel and configure its access level and account/project assignments individually. Use this when different groups need different access.
- **Apply to all groups** — configure access once and apply the same settings to all selected groups.

The access form matches [new&nbsp;group](/everywhere-ai/admin/access-management/manage-user-groups): select **Custom access** to configure specific accounts and projects, or **Full access (Super Admin)** for unrestricted access.

Click **Create in Platform** to complete the import.

## After import

Imported groups appear in the User Groups list with an **AD** badge. Their names and membership are sourced from Active Directory, but access configuration — accounts, roles, and project permissions — is managed in the Admin Panel and can be edited at any time.
