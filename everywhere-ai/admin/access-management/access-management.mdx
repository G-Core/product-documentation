Access in Everywhere AI is organized around a three-level hierarchy: Accounts contain Projects, and access to resources is always scoped within a project. Users operate in one of three roles that define both what they can do and which interface they use to do it.

## Roles

| Role | Interface | Scope |
|---|---|---|
| **Super Admin** | Admin Panel | Full access to all accounts, projects, users, and Admin Panel settings |
| **Account Admin** | Everywhere AI | Full management access to one or more accounts and all projects within them |
| **Member** | Everywhere AI | Access to specific projects within an account, with Read Only or Read/Write permissions |

### Super Admin

Super Admin is a global role that grants unrestricted access to all accounts, projects, users, user groups, quota settings, and infrastructure resources. It is the only role with access to the Admin Panel and is configured as a separate access level — not as Custom access — on the [user record](/everywhere-ai/admin/access-management/manage-users).

### Account Admin

Account Admin is an account-level role that grants full Read/Write access to all current and future projects within the assigned account — no per-project configuration needed. On login to Everywhere AI, an account selector lists all accounts the user belongs to with their role in each; selecting one enters its project context.

![Everywhere AI login: account selector showing Account 3 and Account 2 as Member, Account 1 as Account Admin](/images/docs/everywhere-ai/admin/access-management/access-management/account-selector-login.png)

From Everywhere AI, Account Admins [manage users](/everywhere-ai/admin/access-management/manage-users-in-account) — inviting, changing roles, removing — and [manage projects](/everywhere-ai/admin/access-management/manage-projects-in-account) — creating, deleting, and assigning Members.

### Member

Member is a project-level role with access limited to explicitly assigned projects — granted by an Account Admin from Everywhere AI or by a Super Admin from the Admin Panel. Without project assignments, only the account's Public Models are accessible.

Member capabilities in Everywhere AI are covered in the user documentation.

## Quickstart

On first login as Super Admin, the Admin Panel is empty: no accounts, no users, no projects. The typical setup sequence is:

1. **Create accounts** — go to [Accounts](/everywhere-ai/admin/access-management/manage-accounts) and create the accounts that will organize resources. Each new account automatically gets a default project with the same name.
2. **Create users and assign roles** — go to [Users](/everywhere-ai/admin/access-management/manage-users) and create each user. In the **Manual Access** section of the creation form, select the accounts to grant access to and set the role (Account Admin or Member). For Member access, expand the account row to select specific projects and set permissions.
3. **Share credentials** — after creation, a one-time password is shown. Copy and share it securely. The user will be prompted to change it on first login.

The new user logs into Everywhere AI (not the Admin Panel) and sees an account selector listing only the accounts they were assigned to. Selecting an account enters its project context.

## Access channels

Access is configured through two independent channels in the Admin Panel: **Group Access** and **Manual Access**. This applies to Super Admin operations only — Account Admins use the Everywhere AI workflow described above.

### Group Access

Users inherit permissions from the [user groups](/everywhere-ai/admin/access-management/manage-user-groups) they belong to, where each group defines an access level (Account Admin or Member) per account with optional per-project permissions for Member-level groups. This is the recommended approach for teams where multiple users share the same access pattern.

### Manual Access

Permissions can be assigned directly on a user record, independent of any group. It is useful for individual cases that do not fit an existing group configuration.


<Tip>
When permissions from user groups conflict with manually assigned access, the highest level is applied.
</Tip>


When a user's effective permissions are unclear, check both the **Group Access** and **Manual Access** sections on the [user's edit form](/everywhere-ai/admin/access-management/configure-access) in the Admin Panel.
