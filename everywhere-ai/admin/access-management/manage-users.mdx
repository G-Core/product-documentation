User accounts are created and managed under **Workspace settings** > **Users** in the Admin Panel. Each user operates with one of two access levels: **Custom access** (permissions derived from user groups and manual assignments) or **Full access (Super Admin)** (unrestricted access to all accounts, projects, and Admin Panel settings). The [access&nbsp;management&nbsp;overview](/everywhere-ai/admin/access-management/access-management) describes the full role hierarchy.

![Users list showing user accounts with roles and project assignments](/images/docs/everywhere-ai/admin/access-management/manage-users/users-list.png)

The list displays username, email, role, user group memberships, access summary, last login date, and status. The Role column shows **Super Admin** for users with full access, **Account Admin** for users with full management access to assigned accounts, or **Member** for users with project-specific access. The Access column shows the count of accounts and projects the user can reach.

Use the search box to filter by username or email address. The **Roles** dropdown filters by role type. The **Accounts** dropdown filters by account association. Enable **Without account access only** to list users who have no account assignments.

## Create a user

Click **Create User** to add a new user.

![Create User form with name, email, and access level options](/images/docs/everywhere-ai/admin/access-management/manage-users/users-add-form.png)

1. Enter the **Email** address for the new user.
2. Enter the **User Name**.
3. Select **Access Level**: **Custom access** for group-based and manual permissions, or **Full access (Super Admin)** for complete access to all accounts, projects, and admin settings.
4. Optional: set access in [access&nbsp;during&nbsp;creation](#configure-access-during-creation).
5. Click **Create**.

After creation, a dialog displays the generated password. Copy it immediately — it is shown only once and cannot be retrieved later. Share it securely with the user. The user can log in with this password and is prompted to change it on first login.

### Configure access during creation

Access can be assigned in the same form when creating a user with **Custom access**.

![Create User form Manual Access section: Account 3 selected as Member with project expanded showing Read only selected, Account 2 as Member with Read/Write, Account 1 as Account Admin](/images/docs/everywhere-ai/admin/access-management/manage-users/create-user-manual-access-member.png)

**Group Access**: select one or more [user&nbsp;groups](/everywhere-ai/admin/access-management/manage-user-groups) to inherit their permissions.

**Manual Access**: assign direct access to specific accounts and projects.

1. Select one or more accounts from the list. Use the search box to filter by name or ID.
2. Select **Account Admin** or **Member** for each account.
3. For Member access, expand the account row and select individual projects.
4. Select **Read only** or **Read/Write** for each project.

## Edit user access

Click a username to open the edit panel. Email and User Name fields are read-only in this view.

![Edit User form showing group access and manual access sections](/images/docs/everywhere-ai/admin/access-management/manage-users/users-edit-form.png)

For users with Custom access, permissions are configured through two sections:

**Group Access**: select [user&nbsp;groups](/everywhere-ai/admin/access-management/manage-user-groups) to inherit their permissions. The dropdown shows available groups with an assigned/total counter.

**Manual Access**: assign direct access to specific accounts and projects.

1. Select one or more accounts from the list. Enable **Show selected accounts only** to view only already-assigned accounts.
2. Select **Account Admin** or **Member** for each account.
3. For Member access, expand the account row and select individual projects.
4. Select **Read only** or **Read/Write** for each project.


<Tip>
When permissions from user groups conflict with manually assigned access, the highest permission level is applied.
</Tip>


Click **Save** to apply changes.

## Delete a user

Click the three-dot menu on the user row and select **Delete**.


<Warning>
Deletion removes access immediately and terminates active sessions. This action cannot be undone.
</Warning>
