Use the **Access Settings** section on a user or user group to assign Account Admin or Member access. Access is configured per account, so the same user or group can have different roles in different accounts.

The conceptual model behind these roles is described in the [access&nbsp;management&nbsp;overview](/everywhere-ai/admin/access-management/access-management).

## Assign Account Admin

Account Admin grants full Read/Write access to all current and future projects in the selected account. No project-level configuration is required.

1. Set **Access Level** to **Custom access**.
2. Check the checkbox next to each account to manage.
3. Click **Account Admin** on the account row.

![Edit user group form showing Account Admin role with multiple accounts selected](/images/docs/everywhere-ai/admin/access-management/configure-access/account-admin-config.png)

The group summary shows the count of selected accounts.

## Assign Member

Member grants access at the project level. Projects become available for selection only after the parent account is selected.

1. Check the checkbox next to an account. The account row expands to show its projects.

![Member configuration with one account selected and no projects selected](/images/docs/everywhere-ai/admin/access-management/configure-access/member-account-no-project.png)

2. Expand the account row and check the checkbox next to each project to grant access. For each selected project, select the permission level:
   - **Read only** — the user can view resources in the project but cannot create or modify them.
   - **Read/Write** — the user has full access to create, modify, and delete resources.

![Member configuration with account and project selected, showing Read only and Read/Write permission options](/images/docs/everywhere-ai/admin/access-management/configure-access/member-project-permissions.png)

## Public Models access

Selecting an account without selecting any projects grants access to public models available within that account, without exposing any project resources. This is treated as Member access with zero project assignments.
