# Accounts

Accounts are the top-level containers in Everywhere AI. Each account contains one or more projects, its own users and user groups, and optional resource quota limits per region. Access roles and the account hierarchy are described in the [access management overview](/everywhere-ai/admin/access-management/access-management).

Navigate to **Workspace settings** > **Accounts** to manage accounts.

![Accounts list showing account names, emails, project counts, and creation dates](/images/docs/everywhere-ai/admin/access-management/manage-accounts/accounts-list.png)

## Create an account

Click **Create Account** to open the creation form.

![Create Account form with name, email, and description fields](/images/docs/everywhere-ai/admin/access-management/manage-accounts/account-create-form.png)

1. Enter the **Account Name** (required).
2. Enter the **Account Email** — the primary contact address for the account.
3. Enter an optional **Description**.
4. Click **Create**.


<Info>
Creating an account automatically creates a default project with the same name, visible on the **Projects** tab of the account detail page.
</Info>


## Account detail page

Click an account name to open its detail page. The page is organized into five tabs: **Projects**, **Assigned Users**, **Assigned User Groups**, **Account Quotas**, and **Delete**.

![Account detail page showing metadata, Actions button, and tab navigation](/images/docs/everywhere-ai/admin/access-management/manage-accounts/account-detail-header.png)

Click **Edit** in the header to update the account name, email, and description.

### Projects tab

Lists all projects in this account. Click **+ Create Project** to add a project directly under this account. Click a project name to open its edit panel.

### Assigned Users tab

Lists users who have access to this account, either through a user group or a manual assignment.

![Assigned Users tab showing users with their roles, project access counts, and status](/images/docs/everywhere-ai/admin/access-management/manage-accounts/account-assigned-users.png)

The **Projects Access** column shows **All** for Account Admins (they always have full access to every project) and a project count for Members.

Click **+ Add user** to open the assignment form.

![Add User form showing User selection and Role options: Account Admin and Member](/images/docs/everywhere-ai/admin/access-management/manage-accounts/account-add-user-form.png)

1. Select the **User** from the dropdown (required).
2. Select the **Role**:
   - **Account Admin** — the user automatically gets Read/Write access to all current and future projects in the account.
   - **Member** — a project selection table appears for assigning specific projects and setting a permission level per project.
3. Click **Add**.

The three-dot menu on each row provides edit and remove options.

### Assigned User Groups tab

Lists groups that have access to the account. Click **+ Add User Group** to attach a group. The assignment workflow is the same as for individual users.

### Account Quotas tab

Manages resource limits for this account per region. Quotas control how much compute capacity users in the account can consume.

![Account Quotas tab showing per-region quota limits for CPU, memory, and GPU types](/images/docs/everywhere-ai/admin/access-management/manage-accounts/account-quotas.png)

If no quotas are configured, resource usage is unlimited until limits are set.

When quotas are configured, select a region from the tab bar to filter the view. The table lists quota type, region, current usage, and an editable limit field.

After modifying quota values, click **Save changes** or **Discard changes**.

Enable **Multi-Regional Quota Editor** to apply changes across multiple regions at once, instead of editing each region separately.

### Delete tab

Permanently removes the account and all associated resources.

![Delete tab showing warning about permanent deletion of account and all associated resources](/images/docs/everywhere-ai/admin/access-management/manage-accounts/account-delete-tab.png)


<Warning>
Deleting an account permanently removes all projects, access settings, and quota configurations associated with it. This action cannot be undone.
</Warning>


Click **Delete Account**. In the confirmation dialog, type `Delete` in the text field and click **Delete** to proceed.
