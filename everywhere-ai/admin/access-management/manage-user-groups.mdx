User groups manage permissions for multiple users simultaneously. Instead of assigning accounts and projects to each user individually, create a group with the desired access level and add users to it.

The [access&nbsp;management&nbsp;overview](/everywhere-ai/admin/access-management/access-management) describes the full role hierarchy and how group permissions interact with manual assignments.


<Info>
User group management is available in the Admin Panel only.
</Info>


Navigate to **Workspace settings** > **User Groups** to manage groups.

![User Groups list showing groups with roles and access assignments](/images/docs/everywhere-ai/admin/access-management/manage-user-groups/user-groups-list.png)

The list displays group name, role, access scope, and creation date. A **Source** filter narrows the list to manually created groups or groups imported from Active Directory — imported groups are marked with an **AD** badge. The Role column shows one of the following values:

- **Super Admin**: full access to all accounts, projects, and admin settings
- **Account Admin**: all assigned accounts use the Account Admin role
- **Member**: all assigned accounts use the Member role
- **Mixed**: different accounts within the group have different roles (some Account Admin, some Member)
- **—**: no accounts are assigned to the group yet

The Access column shows **Full Access** for Super Admin groups or an account/project summary for other roles.

## Create a user group

Click **Create User Group** to open the creation form.

![Create User Group form with access level and role options](/images/docs/everywhere-ai/admin/access-management/manage-user-groups/user-groups-create.png)

**User Group Name**: Enter a unique name for the group.

**Assigned Users**: Select users to add to the group. Users can also be added later from the [Users](/everywhere-ai/admin/access-management/manage-users) page.

**Access Level**: two options are available:

- **Custom access**: configure access to specific accounts and projects
- **Full access (Super Admin)**: grants full access to all accounts, projects, and admin settings without additional configuration

### Configure account access

Visible when **Custom access** is selected. The section shows a list of all accounts. Use the search box to filter by account name or ID. Enable **Show selected accounts only** to view only accounts already assigned to the group.

To grant access to an account:

1. Check the checkbox next to the account. The row expands to show **Account Admin** and **Member** role buttons and a list of that account's projects.
2. Click **Account Admin** to grant full management access to the account and all its projects.
3. Click **Member** to configure project-specific access. Select individual projects from the list and set the permission level for each: **Read only** or **Read/Write**.

Each account can use a different role. Groups that mix Account Admin and Member assignments display **Mixed** in the Role column.

After configuring access, click **Create**.

## Edit a user group

Click a group name to open the edit panel. The form displays the same options as the creation form.


<Warning>
The group name cannot be changed after creation. To rename a group, delete it and create a new one with the desired name.
</Warning>


Modify the access level or account/project assignments as needed. Click **Save** to apply changes.


<Tip>
When permissions from user groups conflict with manually assigned access, the highest permission level is applied.
</Tip>


## Delete a user group

Click the three-dot menu on the group row and select **Delete**.

![Delete User Group confirmation dialog requiring typing Delete to confirm](/images/docs/everywhere-ai/admin/access-management/manage-user-groups/user-groups-delete.png)

A confirmation dialog appears. Type **Delete** in the input field to confirm, then click **Delete**.


<Warning>
Deleting a group removes access for all users who relied on that group membership. Users with direct assignments or membership in other groups retain access through those associations.
</Warning>


## Filter and search

Enter a name in the search box to filter by group name. The **Roles** dropdown filters by role type, and the **Accounts** dropdown filters by account association. The **Source** dropdown filters between manually created groups and groups from [Active&nbsp;Directory](/everywhere-ai/admin/access-management/import-user-groups-from-ad). Counters on each filter show how many items match the current selection.
