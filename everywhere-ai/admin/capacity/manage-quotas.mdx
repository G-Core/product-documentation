Quotas control how much CPU and GPU resources each account can consume, preventing any single account from monopolizing cluster capacity. Limits are configured per account and region. Memory limits are configurable per account only, not as a global default.

Navigate to **Capacity** > **Quotas** to manage quota configurations.

![Quotas page with the account list and the default quotas panel](/images/docs/everywhere-ai/admin/capacity/manage-quotas/quotas-overview.png)

The page opens with **Default Quotas** selected. The left panel lists all accounts with a search box. The right panel shows the quota table for the selected entry.

The quota table has two forms depending on what is selected:

| Selected | Columns | Quota types |
|----------|---------|-------------|
| Default Quotas | Quota, Region, Limit | cpu, nvidia.com/gpu, per-GPU-model |
| Account | Quota, Region, Usage, Limit | cpu, memory (GiB), nvidia.com/gpu, per-GPU-model |

For accounts, the **Usage** column shows current consumption as a value and percentage with a progress bar.

## Default quotas

**Default Quotas** is the first item in the left panel and is selected by default when the page loads. The table displays the limits that are copied to each new account automatically at the time of creation. Changing default quotas does not affect accounts that already exist.

Edit limit values directly using the **+** and **-** controls. Use **Multi-Regional Quota Editor** to apply changes across all regions at once.

Click **Delete Default Quotas** to remove the defaults. This does not affect quotas already configured for existing accounts.


<Warning>
When default quotas are not set, any new account starts without resource limits, allowing unrestricted resource consumption until quotas are configured manually.
</Warning>


## Account quotas

1. Select an account from the left panel.
2. Select a region tab, or enable **Multi-Regional Quota Editor** to edit all regions at once.
3. Adjust the **Limit** values using the **+** and **-** controls.


<Tip>
If a workload fails to deploy because the account has reached its quota, increase the corresponding limit for that account and region.
</Tip>


API rate limits for public AI models are configured separately in [public&nbsp;model&nbsp;quotas](/everywhere-ai/admin/public-models/manage-public-model-quotas).
