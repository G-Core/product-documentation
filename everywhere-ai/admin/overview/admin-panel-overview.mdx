title: "Admin panel overview"
description: "Overview of the Everywhere AI Admin Panel sections, navigation structure, and functional areas available to administrators."
---

The admin panel provides operational control over the cluster, monitoring health, managing infrastructure, and controlling user access. Access it via `/admin/dashboard` path (admin privileges required).

Each sidebar section corresponds to a functional area, from infrastructure monitoring to user management:

**Overview** contains the [Dashboard](/everywhere-ai/admin/dashboard/dashboard) with real-time health and utilization metrics across all regions.

**Resources** provides infrastructure management through [Resource&nbsp;management](/everywhere-ai/admin/resource-management/manage-nodes), covering node operations, node groups, workload relocation, and OS images.

**Managed Databases** displays database clusters across projects. The [Qdrant&nbsp;vector&nbsp;DB](/everywhere-ai/admin/qdrant/manage-qdrant) page shows all Qdrant clusters with status and configuration.

**Public Models** manages centralized AI model deployments. The [Public&nbsp;Models](/everywhere-ai/admin/public-models/manage-public-models) page covers model deployment and settings, while [public&nbsp;model&nbsp;quotas](/everywhere-ai/admin/public-models/manage-public-model-quotas) configures per-user API rate limits.

**Capacity** handles resource allocation. [Flavors](/everywhere-ai/admin/capacity/manage-flavors) defines hardware profiles, and [Quotas](/everywhere-ai/admin/capacity/manage-quotas) sets resource limits per project.

**Audit Logs** records all significant system activity for compliance and troubleshooting through the [Audit&nbsp;Logs](/everywhere-ai/admin/audit-logs/view-audit-logs) page.

**Workspace settings** manages access control across Everywhere AI. [Accounts](/everywhere-ai/admin/access-management/manage-accounts) organizes users and projects into top-level units with their own quota limits. [Projects](/everywhere-ai/admin/access-management/manage-projects) groups resources within an account and controls per-project access. The [Users](/everywhere-ai/admin/access-management/manage-users) page handles individual user access configuration. [User&nbsp;Groups](/everywhere-ai/admin/access-management/manage-user-groups) enables bulk permission management through shared role assignments.

## Daily operations

Start with the [Dashboard](/everywhere-ai/admin/dashboard/dashboard) to review global health metrics and identify nodes requiring attention. Use [Resource&nbsp;management](/everywhere-ai/admin/resource-management/manage-nodes) for maintenance operations: setting nodes to maintenance mode, draining workloads, and relocating instances. Monitor project resource limits in [Quotas](/everywhere-ai/admin/capacity/manage-quotas).

For user access issues, verify account and project assignments in [Users](/everywhere-ai/admin/access-management/manage-users). For bulk permission changes, manage membership through [User&nbsp;Groups](/everywhere-ai/admin/access-management/manage-user-groups). To review what accounts and projects exist, use [Accounts](/everywhere-ai/admin/access-management/manage-accounts) and [Projects](/everywhere-ai/admin/access-management/manage-projects).
