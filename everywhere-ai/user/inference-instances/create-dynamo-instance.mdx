---

A Dynamo graph places a Router in front of the workers. **Aggregated** keeps prefill and decode on one Decode worker, so the form shows the Router and that worker. **Disaggregated** runs prefill and decode in separate pools, and the form adds a Prefill worker.

Open **Inference**, then **Inference Instances**. On an empty list, click **Create Dynamo**. When the list already has instances, open **Create inference instance** and select **Dynamo by NVIDIA**.

![Empty inference list with Create Deployment, Create MultiNode, and Create Dynamo](/images/docs/everywhere-ai/user/inference-instances/create-dynamo-instance/create-entry-point.png)

<Steps>

<Step title="Select the inference architecture">

In the **General** section, enter an **Inference instance name**. The name appears in the instance list and forms part of the endpoint URL.

Selecting **SGLang**, **vLLM**, or **TRT-LLM** as the **Backend framework** changes the **Runtime image** list to images built for that engine. Enable **Use a custom image** to supply a different image.

![Backend framework section showing SGLang, vLLM, and TRT-LLM options](/images/docs/everywhere-ai/user/inference-instances/create-dynamo-instance/create-dynamo-backend.png)

Under **Graph topology**, select how prefill and decode are split:

- **Aggregated** — one worker runs both phases. The graph is a Router and a Decode worker.
- **Disaggregated** — prefill and decode scale as separate pools. A Prefill worker appears between the Router and the Decode worker.

![Runtime image selection and Graph topology section showing Aggregated and Disaggregated options](/images/docs/everywhere-ai/user/inference-instances/create-dynamo-instance/create-dynamo-runtime-topology.png)

</Step>

<Step title="Configure the inference graph">

Each component has its own **Flavor**, **Autoscaling**, and **Environment variables**. Under **Autoscaling**, **Global** applies the same minimum and maximum to every selected region. **Custom** sets those bounds separately for each region and shows **Select regions** until a region is selected.

One **Runtime image** is used for every component. **Executable command** on a worker pool is the container command that runs that image as prefill or decode. The field starts empty. The Router command is optional under **Set startup command**.

A volume can be attached only after a region is selected.

#### Router

The Router is the only component clients reach. **Container port** under **Expose** defaults to 8000. Raise **Read timeout** for long responses. Enable **Disable response buffering** for streaming. Attach **Storage** when the Router needs persistent files.

#### Prefill worker (Disaggregated only)

The Prefill worker processes the prompt and passes the KV cache to the Decode worker. The prefill pool scales independently of the decode pool, so a prefill-heavy workload can add Prefill replicas without adding Decode capacity. Enable **Spread this component across multiple nodes** to place that pool on separate nodes.

#### Decode worker

The Decode worker generates the response tokens. Enable **Spread this component across multiple nodes** to place that pool on separate nodes. Attach **Storage** when the worker needs persistent model weights.

![Graph components table showing Router, Prefill worker, and Decode worker rows](/images/docs/everywhere-ai/user/inference-instances/create-dynamo-instance/create-dynamo-components.png)

</Step>

<Step title="Deploy the graph">

Under **Regions**, each selected region shows available capacity as **Capacity: available/required**. Select at least one region.

Under **API keys**, select keys to enforce authentication. With at least one key attached, the endpoint rejects unauthenticated requests.

Click **Create inference instance**. **Deployment status** stays **Provisioning** until the instance is **Active**, when **Endpoint** on **Overview** opens the address for that region.

</Step>

</Steps>
