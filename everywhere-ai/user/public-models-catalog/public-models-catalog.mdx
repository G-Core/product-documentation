---
title: "Public Models Catalog"
description: "Access and query pre-deployed shared AI models from the Public Models Catalog using API keys, without configuring deployments or hardware."
---

The catalog provides access to AI models that administrators have already deployed as shared infrastructure. Each model exposes an API endpoint — generate a key and start sending requests without configuring deployments or hardware.

Public Models run on shared infrastructure managed by administrators. Unlike the [Application Catalog](/everywhere-ai/user/application-catalog/application-catalog) where each project deploys dedicated instances, Public Models are available across all projects without individual deployment or configuration.

| Aspect | Public Models | Application Catalog |
|--------|---------------|---------------------|
| Deployment | Pre-deployed by administrators | Deployed per-project |
| Infrastructure | Shared across projects | Dedicated per-instance |
| Configuration | Fixed (no hardware or scaling choices) | Configurable (flavor, pods, regions) |
| API access | Generate key and use | Deploy, then generate key |

Use Public Models for immediate access to a model without managing infrastructure. Use the Application Catalog for dedicated deployments with control over resources and scaling.

## Model catalog

Navigate to **Public Models** > **Public Models Catalog** in the sidebar. The catalog displays models as cards, organized by category.

![Public Models Catalog showing model cards with category filters and search](/images/docs/everywhere-ai/user/public-models-catalog/public-models-catalog/public-models-catalog.png)

Use the search box to find models by name. Click a category tab to filter the view — the number next to each category shows how many models are available. Categories may include:

- Text Large Language Model (LLM) for chat and text generation
- Text + Audio LLM (speech understanding and text)
- Automatic Speech Recognition (audio to text)
- Text-to-Speech (text to audio)
- Image Generation (text to image)
- Text Embedding (text to vectors)

Each card shows basic model information and an **API Endpoint** button.

## API access

Click **API Endpoint** on any model card to open the integration dialog with an API key form and a ready-to-use code sample.

![API endpoint dialog showing three steps: generate key, install SDK, and use code](/images/docs/everywhere-ai/user/public-models-catalog/public-models-catalog/public-models-api-endpoint-dialog.png)

### Step 1. Generate an API key

Click **Generate API key** in the dialog. A form appears with the following fields:

- **Name** (required): Enter a descriptive name for the key.
- **Description** (optional): Add context for future reference.
- **Expires at**: Choose **Never expire** or **Set an expiration date**.

![Generate API Key form with name, description, and expiration options](/images/docs/everywhere-ai/user/public-models-catalog/public-models-catalog/public-models-generate-key-form.png)

Click **Generate** to create the key. Generated keys appear in [API&nbsp;Keys](/everywhere-ai/user/public-models-api-keys/manage-public-models-api-keys) and can be rotated or revoked at any time.


<Warning>
Copy the key immediately — it appears only once and cannot be retrieved later.
</Warning>


### Step 2. Use the code sample

Public Models expose an OpenAI-compatible API. Install the OpenAI SDK for the target language and copy the example shown in the dialog. The example already contains the correct endpoint URL for the environment.


<Warning>
The endpoint URL varies by environment. Always copy the code sample from the integration dialog — URLs in documentation examples may not match the target environment.
</Warning>
