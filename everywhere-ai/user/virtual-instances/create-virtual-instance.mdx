---
title: "Create a Virtual Instance"
description: "Create a Virtual Instance in Everywhere AI by selecting a region, flavor, boot volume, network, and SSH keys."
---

A Virtual Instance requires a boot volume with an OS image and at least one network interface. A floating IP is optional for external access; SSH keys enable remote login.

Navigate to **Virtual Instances** and click **Create Virtual Instance**.

<Steps>

<Step title="Select a region and flavor">

Available images, volumes, and networks are region-specific — select the region closest to dependent services. Public images are not offered in every region; in that case, the image list is empty.

The flavor sets CPU and RAM. Use the **With GPU** / **Without GPU** toggle to filter options, then select the row that matches the workload. **With GPU** is disabled when the region has no GPU flavors.

![Create Virtual Instance form showing Region and Flavor sections](/images/docs/everywhere-ai/user/virtual-instances/create-virtual-instance/create-virtual-instance-form.png)


<Warning>
Flavor cannot be changed after creation. To change compute resources, create a new instance and migrate data.
</Warning>


</Step>

<Step title="Add a boot volume">

Click **Add Boot Volume** to create the OS disk required to start the instance. Select its image source:

<Tabs>

<Tab title="Public Images">

Pre-built Gcore OS images. Select the image from the list — each entry shows the OS name, version, architecture, compatibility, and minimum disk size. The volume size has to be at least that minimum.

![Add Boot Volume dialog showing Public Images tab with Debian 13 and Ubuntu 24.04 entries](/images/docs/everywhere-ai/user/virtual-instances/create-virtual-instance/add-boot-volume-public-images.png)

</Tab>

<Tab title="Custom Image">

Provide a direct HTTP(S) URL to a bootable OS image. Enter the URL in the **Image URL** field.

![Add Boot Volume dialog showing Custom Image tab with Image URL field](/images/docs/everywhere-ai/user/virtual-instances/create-virtual-instance/add-boot-volume-custom-image.png)

</Tab>

</Tabs>

Set the **Volume Name**, **Size**, and **Storage Class**, then click **Create & Add**.

</Step>

<Step title="Connect to a network">

Click **Add Interface**. A subnetwork is required. If no security group is attached, all traffic is allowed.

![Add Network Interface dialog with Use floating IP on, Create new selected, and the high-traffic warning](/images/docs/everywhere-ai/user/virtual-instances/create-virtual-instance/add-network-interface-dialog.png)

If no network exists yet, create one together with the required subnetwork. Click **Add new Network**, enter a name, and click **Create & Proceed**; **Static Routes** are optional. In the subnetwork dialog that opens, enter a name and private IPv4 CIDR block, then click **Create subnetwork**. The network can be managed later in [Networks](/everywhere-ai/user/networking/networks).

![Create Network dialog showing Network name field](/images/docs/everywhere-ai/user/virtual-instances/create-virtual-instance/create-network-dialog.png)

Enable **Use floating IP** to reach the instance from outside the private network. Select **Create new** to provision a fresh public IP, or **Use existing** to assign one already allocated to the project. A floating IP is not recommended for sustained high traffic, because that traffic can affect network stability. The guest OS may also need extra network configuration.

Without a floating IP, the instance is reachable only from within the same private network.

</Step>

<Step title="Configure SSH access">

Select existing keys from the **SSH Keys** dropdown, or click **Add new SSH Key** to upload a public key. To generate a new key pair, click **Generate SSH Key**, enter a name, and click **Generate SSH Key** — download the private key immediately because it cannot be retrieved later. Multiple keys can be added to allow access for multiple users.

**User data** is optional. It sets a password or applies other settings when the instance starts.

</Step>

<Step title="Set a name and create">

Enter a unique name for the instance.


<Warning>
The name cannot be changed after creation.
</Warning>


The side panel lists the selected region, flavor, and volumes. Click **Create Virtual Instance**.

The instance appears in the list with **Starting** [status](/everywhere-ai/user/virtual-instances/manage-virtual-instances#instance-statuses) while the OS boots, then transitions to **Running** when ready.

![Virtual Instances list showing instance with Starting status](/images/docs/everywhere-ai/user/virtual-instances/create-virtual-instance/vm-list-provisioning.png)

</Step>

<Step title="Connect via SSH">

Once the instance is **Running**, use its floating IP to connect from outside the private network, or its private address from a resource that can reach that network. The default username depends on the OS image. `ubuntu` and `debian` are common defaults for public images. The instance page shows the private address. The floating IP attached to the interface is listed in [Floating&nbsp;IPs](/everywhere-ai/user/networking/floating-ips). In the command, `<ip-address>` is one of those two addresses:

```bash
ssh <username>@<ip-address>
```

</Step>

</Steps>
