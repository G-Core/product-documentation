Everywhere AI provides infrastructure for deploying and managing AI workloads: inference instances, managed databases, training environments, persistent volumes, and container image registries.

Resources are organized into projects. Each project has isolated resources — inference instances, volumes, and registries in one project are not visible in other projects. Use the **Project** dropdown in the header to switch between projects.

![Projects list showing available projects with search and Create project button](/images/docs/everywhere-ai/user/overview/portal-overview/overview-projects-list.png)

## Inference

The **Inference** section in the sidebar handles model deployment and endpoint management.

![](/images/docs/everywhere-ai/user/overview/portal-overview/instances-black.svg)[Inference&nbsp;Instances](/everywhere-ai/user/inference-instances/manage-inference-instances) host containerized models as HTTP endpoints. Deploy custom containers or models from the Application Catalog, configure autoscaling, and monitor resource usage.

![](/images/docs/everywhere-ai/user/overview/portal-overview/catalog-black.svg)[Application&nbsp;Catalog](/everywhere-ai/user/application-catalog/application-catalog) provides 50 pre-configured models from Meta, Mistral, Qwen, and other providers. Select a model, choose resources, and deploy in minutes without configuring containers.

![](/images/docs/everywhere-ai/user/overview/portal-overview/api-keys-black.svg)[API&nbsp;Keys](/everywhere-ai/user/api-keys/manage-api-keys) authenticate requests to inference endpoints. Create keys, attach them to instances, and include in request headers to protect models from unauthorized access.

## Public Models

Administrators can pre-deploy AI models as shared infrastructure. The **Public Models** section provides access to these models without requiring individual deployment.

![](/images/docs/everywhere-ai/user/overview/portal-overview/public-models-black.svg)[Public&nbsp;Models&nbsp;Catalog](/everywhere-ai/user/public-models-catalog/public-models-catalog) lists available shared models. Browse models and get API integration code with the endpoint URL embedded.

![](/images/docs/everywhere-ai/user/overview/portal-overview/public-api-keys-black.svg)[Public&nbsp;API&nbsp;keys](/everywhere-ai/user/public-models-api-keys/manage-public-models-api-keys) authenticate requests to shared models. Generate a key and start sending requests without deploying dedicated instances.

## Managed Databases

Database infrastructure for AI workloads is available under **Managed Databases** in the sidebar.

![](/images/docs/everywhere-ai/user/overview/portal-overview/qdrant-logo.svg)[Qdrant&nbsp;vector&nbsp;DB](/everywhere-ai/user/qdrant/create-qdrant-cluster) stores high-dimensional embeddings and performs similarity search. Create clusters with configurable replication, connect from applications, and query vectors for retrieval-augmented generation (RAG) pipelines and semantic search.

## Training

Model development environments are available under **Training** in the sidebar.

![](/images/docs/everywhere-ai/user/overview/portal-overview/jupyter-lab.svg)[JupyterLab](/everywhere-ai/user/jupyterlab/create-jupyterlab-instance) provides interactive notebook workspaces with CPU or GPU resources. Explore datasets, prototype models, and run experiments with persistent storage.

![](/images/docs/everywhere-ai/user/overview/portal-overview/slurm-black.svg)[Slurm](/everywhere-ai/user/slurm/create-slurm-cluster) manages distributed computing jobs on cluster infrastructure. Create multi-node clusters, submit batch jobs, and scale worker count based on workload requirements.

## Volumes

Persistent storage for training data, model weights, and application files is managed in the **Volumes** section.

![](/images/docs/everywhere-ai/user/overview/portal-overview/volumes-black.svg)[Volumes](/everywhere-ai/user/volumes/manage-volumes) survive container restarts and can be attached to inference instances, JupyterLab notebooks, and Slurm clusters. Data stored on volumes remains available even after the attached resource is deleted.

## Images

Container image management is available under **Images** in the sidebar.

![](/images/docs/everywhere-ai/user/overview/portal-overview/registries-logo.svg)[Registries](/everywhere-ai/user/registries/manage-registries) store custom Docker images within the project. Push images from continuous integration and delivery (CI/CD) pipelines and pull them when creating inference instances.

![](/images/docs/everywhere-ai/user/overview/portal-overview/pull-secrets-black.svg)[Pull&nbsp;secrets](/everywhere-ai/user/pull-secrets/manage-pull-secrets) authenticate against external private registries. Configure credentials for Docker Hub, GitLab, GitHub, or self-hosted registries.
