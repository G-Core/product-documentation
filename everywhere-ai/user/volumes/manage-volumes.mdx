Volumes provide persistent storage for inference instances, JupyterLab notebooks, and Slurm clusters. Without a volume, any files created during a session are lost when the instance restarts, scales, or is deleted.

Typical use cases include model weights downloaded at runtime, datasets for notebooks or training jobs, checkpoints, caches, and logs that must persist beyond a single run.

Volumes are independent resources created and deleted separately from compute resources. After provisioning, a volume transitions to **Available** status. For a resource to access its contents, the volume must then be attached and mounted. Volumes are region-bound and can only attach to resources running in the same region.

![Volumes list showing existing volumes with name, regions, mode, capacity, and status](/images/docs/everywhere-ai/user/volumes/manage-volumes/volumes-list.png)

## Create a volume

Navigate to **Volumes** > **Volumes** and click **Create Volume**.

Fill in the dialog:

1. Select one or more **Regions** for the volume. Selecting multiple regions creates a separate volume in each selected region. The storage class options update based on the selected region.
2. Select the **Source Type**:

   | Type | Description |
   |------|-------------|
   | Persistent Storage | Regular disk storage with a storage class. Best for databases, file storage, and any data that needs to persist. |
   | Container Image | Mount an OCI container image as read-only storage. |

3. Select a **Storage Class**. Different classes offer different performance characteristics — SSD-based options provide lower latency than network-attached storage. Available options depend on the region.
4. Enter the **Capacity** in GiB.
5. Enter a unique **Name** for the volume.
6. Click **Create**.

![Create Volume dialog with Regions, Source Type, Storage Class, Capacity, and Name fields](/images/docs/everywhere-ai/user/volumes/manage-volumes/volumes-create-form.png)

The volume appears with **Pending** status while provisioning, then changes to **Available** when ready for use.


<Tip>
Capacity can be increased later but cannot be reduced.
</Tip>


## Volume management

### Mounting

When creating or editing an inference instance, [JupyterLab](/everywhere-ai/user/jupyterlab/create-jupyterlab-instance) notebook, or [Slurm](/everywhere-ai/user/slurm/create-slurm-cluster) cluster, select the volume from the **Volume name** dropdown and enter the mount path. The volume content appears at the specified path inside the container.

### Resize

To change the capacity of a volume:

1. Click the menu icon (three dots) next to the volume.
2. Select **Resize**.
3. Enter the new **Capacity**.
4. Click **Resize**.

![Resize Volume dialog with Capacity field](/images/docs/everywhere-ai/user/volumes/manage-volumes/volumes-resize-dialog.png)


<Info>
Capacity can only be increased — reductions require creating a new volume and migrating data.
</Info>


### Deletion

1. Click the menu icon (three dots) next to the volume.
2. Select **Delete**.
3. Confirm the deletion.


<Warning>
Deleting permanently removes all stored data. Detach from all instances before deletion.
</Warning>
