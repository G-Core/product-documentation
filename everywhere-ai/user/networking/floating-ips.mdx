title: "Floating IPs"
description: "Allocate and assign public IPv4 addresses to Virtual Instances in Everywhere AI."
---

Floating IPs are public IPv4 addresses that route external traffic to a specific network interface. Unlike an interface's private IP, a floating IP persists after an instance is stopped or deleted — it stays allocated to the project until explicitly removed.

Create and manage floating IPs under **Compute Instances** > **Networking** > **Floating IPs**.

![Floating IPs list showing two entries in region anx-2-k-box-dev-1, one with IP 78.111.108.123 and one unassigned](/images/docs/everywhere-ai/user/networking/floating-ips/floating-ips-list.png)

## Allocate a floating IP

Each floating IP belongs to one region and can only attach to interfaces in that region. Two paths are available when allocating.

![Floating IP creation form with Region dropdown and Assign to existing instance toggle](/images/docs/everywhere-ai/user/networking/floating-ips/floating-ips-create.png)

**To allocate and attach immediately:** enable the **Assign to existing instance** toggle, then select the target **Network Interface** from the same region before clicking **Create new floating IP**.

**To allocate unassigned:** leave the toggle off and click **Create new floating IP**. The IP appears in the list with a dash in the **Attached to** column and can be attached later.

To attach an unassigned IP, use the **Use existing** option in the **Use floating IP** field when [creating a Virtual Instance](/everywhere-ai/user/virtual-instances/create-virtual-instance) or when [adding a new network interface](/everywhere-ai/user/virtual-instances/manage-virtual-instances#network-interfaces) to an existing one. Attaching to a new interface detaches the IP from any interface it was previously assigned to — this cuts external connectivity for that interface.

## Delete a floating IP

After deletion, the same IP address cannot be recovered. If external systems reference this IP, update them before proceeding.

Click the menu icon (three dots) next to the IP, select **Delete**, and confirm.


<Warning>
Deleting a floating IP that is currently attached removes external access for the interface it was assigned to.
</Warning>
