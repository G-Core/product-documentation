The Streaming Admin Portal lists all Streaming customers, including those on trial and free tariff plans. Streaming appears in the Admin Portal only if the reseller has the Streaming product enabled.

## Activate Streaming

<Steps>
  <Step title="Open the Admin Portal">
  Open the [Admin Portal](https://admin.gcore.top/).
  </Step>
  <Step title="Open the Streaming section">
  Navigate to the **Streaming** section.
  </Step>
  <Step title="Open the customer account">
  Create a new customer account or open an existing one.
  </Step>
  <Step title="Configure the limits">
  Configure the required Streaming limits.
  </Step>
</Steps>

Streaming services are disabled by default for new customers until the required limits are configured.

## Manage trial limits

When a new Streaming account is created, all Streaming limits are set to `0` by default, regardless of the account status. For customers requesting access to live streaming for the first time, the following limits must be configured in the account settings before the service can be used:

- **Streams count**: the maximum number of simultaneous live streams.
- **Restreams count**: the number of simultaneous restream destinations.
- **Video storage minutes**: the number of minutes available for storing video recordings.
- **Encoding video minutes**: the number of minutes available for video transcoding.
- **VOD storage**: the available storage capacity for video-on-demand content, in GB.

### Trial configuration

Typical trial account limits are more restricted:

- Streams count: 1
- Restreams count: 1
- Video storage minutes: 30
- Encoding video minutes: 30
- VOD storage: 1000 GB

Resellers can adjust these values depending on the trial conditions agreed with the customer.

## Free features

Some Streaming features can be enabled for customers as free features in the account settings.

<Note>
Enabling free features requires contacting the [Gcore support team](https://support.gcore.com/) or the account manager. Some features may require additional configuration by Gcore engineers.
</Note>

Available free features include:

- `video_editor`: allows editing uploaded videos directly in Streaming.
- `browsercast`: enables browser-based live streaming.
- `original_recording`: allows storing the original stream recording.
- `html_overlays`: enables HTML overlays for live streams.
- `closest_transcoder_routing`: routes streams to the nearest transcoder for improved performance.
- `audit_log`: provides access to activity logs for Streaming operations.

Free features can be enabled or disabled individually for each customer account.
