Use the **Products** page to enable WAAP for a customer account. The customer can see WAAP but can use it only when its status is **Active**.

In **General**, open **Accounts**, select the account ID, and open **Products**. The [product&nbsp;status](/reseller-support/accounts/service-statuses) determines whether the customer can use WAAP.

The **Product** filter in [usage&nbsp;reports](/reseller-support/reports-and-activity/generate-monthly-reports) includes WAAP. Billable consumption, the total or per-client accrual of protected domains, data volume, requests, or clean requests, is available through the WAAP Reseller API.

<p>An [API&nbsp;token](/account-settings/api-tokens) is required. Set it as an environment variable before running the examples:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Get aggregated consumption

<p>Returns the selected metric aggregated across all matching clients into a single daily total for the reporting period.</p>

| Parameter | Description |
|---|---|
| `metric` | Path parameter: `domains`, `volume`, `requests`, or `requests_clean`. |
| `from` | Report start date (inclusive), in ISO 8601 format. Required. |
| `to` | Report end date (exclusive), in ISO 8601 format. Required. |
| `client_ids` | Client IDs to filter by. Omit to include every client. |
| `limit` | Number of items to return, up to 100. Defaults to 100. |
| `offset` | Number of items to skip. Defaults to 0. |

```bash
curl -s "https://api.gcore.com/waap/reseller/v1/prebilling/total/requests?from=2026-07-01&to=2026-07-08" \
  -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>The API returns:</p>

```json
{
  "limit": 100,
  "offset": 0,
  "count": 7,
  "results": [
    {"date": "2026-07-01", "amount": 128340},
    {"date": "2026-07-02", "amount": 131980}
  ]
}
```

<p>The `amount` field reports the accrued value of the selected metric for that date.</p>

## Get consumption per client

<p>Returns the selected metric as one entry per client instead of a single aggregated total. `from`, `to`, and `client_ids` filter the report as they do for the aggregated total. `limit`, `offset`, and `count` count clients. `limit` accepts 1 to 100 and defaults to 100, and `offset` defaults to 0.</p>

```bash
curl -s "https://api.gcore.com/waap/reseller/v2/prebilling/breakdown/requests?from=2026-07-01&to=2026-07-08" \
  -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>The API returns:</p>

```json
{
  "limit": 100,
  "offset": 0,
  "count": 2,
  "results": [
    {
      "client_id": 12345,
      "items": [
        {"date": "2026-07-01", "amount": 54200},
        {"date": "2026-07-02", "amount": 55830}
      ]
    },
    {
      "client_id": 67890,
      "items": [
        {"date": "2026-07-01", "amount": 74140},
        {"date": "2026-07-02", "amount": 76150}
      ]
    }
  ]
}
```

<p>Each object in `results` is one client. `items` holds that client's `date` and `amount` pairs, all on the same page.</p>
