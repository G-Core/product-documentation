---
title: Configure password policy
ai-navigation: Describe how resellers enable username and password login and configure password expiration and reuse rules in the Admin Portal.
---

A predefined password security policy protects reseller and customer accounts from unauthorized access through two rules: password reuse and password expiration.

- Password reuse: after a password expires, a user must create three unique passwords before reusing an old one; Gcore stores the last three passwords to enforce this rule.
- Password expiration: the frequency of expiration is configurable, or the requirement can be disabled entirely to let passwords remain valid indefinitely.

## Enable password policy

The password policy can't be saved unless the **Username/Password login** option is enabled first.

<Steps>
  <Step title="Enable username and password login">
  (Optional) Skip this step if username and password login is already enabled.

  1. Navigate to the **Security** settings.
  2. Click **Authorization**.
  3. Enable the **Username/Password login** toggle.
  4. Click **Save** to apply the changes.

  <Frame>
  <img src="/images/docs/reseller-support/manuals/configure-password-policy/configure-password-policy-image1.png" alt="Authorization settings with Username/Password login and SSO login toggles" width="70%"/>
  </Frame>
  </Step>
  <Step title="Activate password policy">
  1. Navigate to the **Security** settings.
  2. Click **Password policy**.
  3. Enable the **Frequency of the password changing** toggle.
  4. Specify the number of days after which the password expires, between 30 and 180 days.
  5. Click **Save** to apply the changes.

  <Frame>
  <img src="https://assets.gcore.pro/docs/reseller-support/manuals/configure-password-policy/policy-disabled.png" alt="Password policy page with the Frequency of the password changing toggle off" width="70%"/>
  </Frame>

  <Frame>
  <img src="https://assets.gcore.pro/docs/reseller-support/manuals/configure-password-policy/policy-enabled.png" alt="Password policy page with the frequency toggle enabled and set to 70 days" width="70%"/>
  </Frame>

  <Tip>
  A frequency between 60 and 90 days balances security and convenience.
  </Tip>
  </Step>
</Steps>

Two weeks before a password expires, users with the policy enabled receive an email reminder to change it.
