The **Sellers** tab of the **Users** section adds, edits, and deletes users with the Seller role, and the **Actions** column for each seller also has **Edit** and **Log in** entries for updating a seller's details or signing in as that seller. The tab also has a **Blocked** column, covered in [blocking sellers](/reseller-support/manuals/block-activate-users-and-sellers).

## Add a seller

Opening the **Sellers** tab and clicking **Create Seller** opens a window for entering the seller's name, email, and phone number.

<Frame>
![Creating Seller accounts](/images/docs/reseller-support/manuals/manage-sellers/manage-sellers-image1.png)
</Frame>

Clicking **Send Invite** emails a password setup link to that address, active for 24 hours. The **Status** column on the **Sellers** tab shows whether a seller has followed the link (**Activated**) or not yet (**Not activated**).

If the link expires, a reseller can resend the invitation: clicking **Resend invite** in the **Actions** column for that seller sends a new one. This button only appears for accounts that haven't been activated, and the timestamp of the last invitation appears next to the seller's status.

<Frame>
<img src="https://assets.gcore.pro/docs/reseller-support/manuals/manage-sellers/resend-invite-20.png" alt="Resend Invite button"/>
</Frame>

## Delete a seller

Clicking **Delete** in the **Actions** column for a seller removes that seller's access to the Admin Portal and password recovery, and the user profile (name, email, phone) becomes unavailable.

<Frame>
<img src="https://assets.gcore.pro/docs/reseller-support/manuals/manage-sellers/delete-seller-30.png" alt="Deleting Seller accounts"/>
</Frame>

## Reset a seller's password

Resetting a seller's password happens in one of two ways:

- Clicking **Reset password** in the **Actions** column for that seller resets it directly.
- Asking the seller to reset it independently through the login form at [admin.gcore.top](https://admin.gcore.top).

<Frame>
<img src="https://assets.gcore.pro/docs/reseller-support/manuals/manage-sellers/recover-password-40.png" alt="Reset password"/>
</Frame>

<Frame>
![Reset password via the login form](https://assets.gcore.pro/docs/reseller-support/manuals/manage-sellers/forgot-password-form-50.png)

The old password stops working only once the new password is set up.
