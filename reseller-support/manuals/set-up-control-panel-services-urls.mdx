The customer's Customer Portal combines several Gcore products, each served from its own subdomain of a shared Base customer portal domain, configured on the [Vendor settings](/reseller-support/manuals/vendor-settings) page. Setting up a new reseller starts with choosing that domain and providing it to the Gcore account manager, who configures the products to use it.

## Product URL structure

Every product URL shares the same Base customer portal domain, for example `gcore.com`, with the product's subdomain added automatically:

- `auth.gcore.com`: authorization.
- `accounts.gcore.com`: customer account management.
- `cdn.gcore.com`: CDN product.
- `cloud.gcore.com`: Edge Cloud product.
- `streaming.gcore.com`: Video Streaming product.
- `storage.gcore.com`: Storage product.
- `waap.gcore.com`: Web Application and API Protection (WAAP) product.
- `dns.gcore.com`: Managed DNS product.
- `api.gcore.com`: API domain.
- `api.gcore.com/docs`: API documentation.

Single sign-on ([SSO](/reseller-support/manuals/configure-sso-via-saml)) links these products together, so once a user logs in to the Customer Portal through the authorization service, the same session grants access to the other products automatically.

## CDN Resources and the technical account

A CDN Resource powers every product URL. Gcore creates these resources in the reseller's technical account: the first customer account in the Admin Portal, created automatically with an email address and company name matching the reseller's own. The technical account collects statistics for [monthly reports](/reseller-support/manuals/generate-monthly-reports) and lists every Admin Portal user, both Reseller and Sellers, but can't be deleted.

<Caution>
Avoid making changes to the technical account or its CDN Resources, since unexpected changes can affect Customer Portal performance.
</Caution>

## SSL and DNS configuration

The Customer Portal works only over HTTPS, so each CDN Resource requires an SSL certificate, either one per resource or a single wildcard certificate covering the Base customer portal domain.

After Gcore configures the CDN Resources, the reseller adds one CNAME record per product URL to their DNS settings, pointed to a personal domain zone that Gcore provides. Once the CNAME records are in place, Gcore adds the Base customer portal domain to the matching field on the **Branding settings** page.
