The Activity logs section records actions taken by [customers](/reseller-support/manuals/manage-clients) and [sellers](/reseller-support/manuals/manage-sellers), split into two tabs: **Platform**, which logs API and Customer Portal requests, and **Logins**, which logs sign-in attempts.

## Platform log

The **Platform** tab, found under **Activity logs** in the **Security** section, lists every API and Customer Portal request made by a customer or seller.

<Frame>
![Activity logs Platform tab listing recent requests with their account, user, method, and status](https://assets.gcore.pro/docs/reseller-support/manuals/view-the-history-of-users-requests-and-actions-via-activity-logs/activity-logs-platform.png)
</Frame>

### Available columns

Each row represents one request, described across the following columns.

| Column | Description |
|---|---|
| Account | ID of the account associated with the request. |
| User ID | ID of the user who made the request. |
| Token ID | ID of the API token used, blank for requests made without a token. |
| User email | Email address of the user who made the request. |
| Requested at | Date and time when the request was made. |
| Method | Request HTTP method, such as `GET`, `POST`, `PUT`, `PATCH`, or `DELETE`. |
| Path | Request URL. |
| Data | Request body, either **No Data** or a **Show changes** link that opens the changed fields. |
| Reverted | Whether the request was rolled back. |
| Status code | Status code returned in the response. |
| Remote IP | IP address the request came from. |
| Host | Host that received the request, such as `api.gcore.com`. |

**Token ID** and **User email** are hidden by default; click **Manage Columns** and toggle a column on or off to show or hide it in the table.

<Frame>
![Manage Columns menu with Token ID and User email toggles](https://assets.gcore.pro/docs/reseller-support/manuals/view-the-history-of-users-requests-and-actions-via-activity-logs/image3501-20.png)
</Frame>

### Filter platform logs

Click **Add filter**, select a column, then set a condition and value; for example, selecting **Requested at** with a **Last week** preset limits the table to that period, and clicking **Apply filter** confirms it.

<Frame>
![Add filter panel with the Requested at column filtered to a one-week date range](https://assets.gcore.pro/docs/reseller-support/manuals/view-the-history-of-users-requests-and-actions-via-activity-logs/Group190991-30.png)
</Frame>

Filtering by the **Account** column only returns requests made directly by that account's own users, because a seller acting on the account's behalf is logged under the seller's own user ID rather than the account's. Filtering the **Path** column by the account ID instead returns every request that references the account, regardless of who made it.

<Frame>
![Path filter set to an account ID value](https://assets.gcore.pro/docs/reseller-support/manuals/view-the-history-of-users-requests-and-actions-via-activity-logs/image3503-40.png)
</Frame>

## Login log

The **Logins** tab lists every sign-in attempt to the Customer Portal and Admin Portal, whether it succeeded or not.

| Column | Description |
|---|---|
| User ID | ID of the user who attempted to log in. |
| Login date | Date and time of the attempt. |
| IP | IP address the attempt came from. |
| Auth type | Authentication method used, such as password or SSO. |
| Success | Whether the attempt succeeded. |
| User agent | Browser or client used for the attempt. |

Instead of the customizable filter panel used on the **Platform** tab, the **Logins** tab shows a fixed filter row: **User ID**, a date range that defaults to the last 24 hours, **IP**, **Success**, and **User agent**. Click **Reset all** to clear them.
