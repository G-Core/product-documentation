Use the **Products** page to enable Object Storage for a customer account. The customer can see Object Storage but can use it only when its status is **Active**.

In **General**, open **Accounts**, select the account ID, and open **Products**.

<Frame>![Object Storage on the Products page](/images/docs/reseller-support/storage/storage-service-management/object-storage.png)</Frame>

## Status

The [product&nbsp;status](/reseller-support/accounts/service-statuses) determines whether the customer can use Object Storage. Trial dates are set on the same card. **Paused to Deleted** and **TrialEnd to Deleted** set how many days pass before the status becomes **Deleted**.

When the status changes to **Deleted**, the customer's Object Storage resources and files are removed.
