The **Products** page turns Cloud on for a customer account. The account can see Cloud and cannot use it until the status is **Active**.

In **General**, open **Accounts**, select the account ID, and open **Products**.

<Frame>
  ![Cloud on the Products page](/images/docs/reseller-support/cloud/cloud-service-management/cloud-service-management-image1.png)
</Frame>

## Status

The [product&nbsp;status](/reseller-support/accounts/service-statuses) decides when the customer can use Cloud. Trial dates and the days before **Deleted** are set on the same card.

## Quotas

Each Cloud region limits how many resources the account can create. The customer checks usage and requests a [quota&nbsp;increase](/cloud/getting-started/request-a-quota-increase) in Cloud.
