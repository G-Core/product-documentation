---
title: Usage and expense files
sidebarTitle: Reports
description: Request customer usage or charges for a date range.
---

Use **Reseller Statistics V2** when the file should show what customers consumed, so the cost of the services can be calculated from it. Use **Expenses** when the file should show the charges for a date range.

<Steps>
  <Step title="Navigate to General > Billing > Reports">
    
  </Step>
  <Step title="Click Create new report">
    
    <Frame>![Reports page with one report row](/images/docs/reseller-support/reports-and-activity/generate-monthly-reports/create-new-report.png)</Frame>
  </Step>
  <Step title="Select a template">
    Select **Reseller Statistics V2** or **Expenses**.

    For **Reseller Statistics V2**:

    - Group the usage by **Client**, **Resource**, **Region**, or a combination of them.
    - **Client** is selected by default.
    - **Date from** and **Date to** are required. Future dates cannot be selected.
    - **Product** is optional.

    <Frame>![Create new report for Reseller Statistics V2](/images/docs/reseller-support/reports-and-activity/generate-monthly-reports/statistics-report.png)</Frame>

    For **Expenses**:

    - Set **Date from** and **Date to**. Future dates cannot be selected.
    - **Plan ID** and **Product** are optional.
    - The plan ID is the number shown when hovering **Plan name** on [Addendums](/reseller-support/billing/addendums).

    <Frame>![Create new report for the Expenses template](/images/docs/reseller-support/reports-and-activity/generate-monthly-reports/expenses-report.png)</Frame>
  </Step>
  <Step title="Create and download">
    Click **Create** after the required fields are set. When **Status** is **Completed**, open the row menu and download CSV, JSON, or Excel.

    <Frame>![Report row menu with download and delete](/images/docs/reseller-support/reports-and-activity/generate-monthly-reports/download-report.png)</Frame>
  </Step>
</Steps>

A **Reseller Statistics V2** file for the previous month is complete on the second day of the new month.

If a row fails, **View log** shows the error. **Delete** removes the row.
