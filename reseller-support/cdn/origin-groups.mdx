An origin group is the set of sources a CDN resource pulls content from.

<Steps>
  <Step title="Navigate to CDN > Origin groups">
    Search by name or ID, or by source, bucket name, or FastEdge app ID.
  </Step>
  <Step title="Open Edit">
    Click the group name, or click the three dots at the end of the row and then **Edit**.
  </Step>
  <Step title="Change the name and the URL source">
    - Change **Origin group name**.
    - For a **URL** source, set **Origin source** to the host or IP address, without `http://` or `https://`.
    - Clear **Use default port** to enter a port.
    - Switching that source to **S3 storage** or **FastEdge** opens a warning that the current configuration is reset. Click **Change** to continue.

    <Frame>
      ![Edit origin group](/images/docs/reseller-support/cdn/origin-groups/origin-group.png)
    </Frame>
  </Step>
  <Step title="Add a source">
    - Click **Add origin** and fill in the new source.
    - With more than one source, **Use next upstream** sends the request to the next source in the list when a source returns an error.
    - Set a source to **Active** or **Use origin as a backup**.
    - **Delete origin** removes a source.
  </Step>
  <Step title="Click Save changes">
  </Step>
</Steps>
