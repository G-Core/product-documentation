---
title: Review CDN activity
sidebarTitle: Activity logs
description: Find a CDN request in a time range and read its response.
---

In **CDN** > **Activity logs**, set **Requested at (UTC)** to the start and end of the period. The list shows the requests from that range.

- Each row is one request for the account in **Account ID**.
- **Method** and **Path** identify the operation, and **Status code** is the HTTP status of the response.
- A read shows **No Data**.
- When the request included a body, **Show changes** opens **Log data**, the JSON that was submitted.
