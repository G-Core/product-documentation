The CDN section collects information about customers who use CDN and the resources they use. It includes the subsections Customers, CDN resources, Activity logs, and Origin groups.

## Customers

This subsection provides details about customers who have created CDN resources. Each entry includes:

- The customer's account ID
- The CDN resource custom domain
- The email associated with the account
- The company name
- The date the CDN resource was created
- The CDN resource ID, along with custom domains and traffic data
- The amount of incoming traffic
- A list of paid features activated for the CDN resources
- The CDN resource status (New, Trial, Trial End, Active, Paused, Activating, or Deleted)

Filters narrow the list down to specific entries; by default, only CDN resources with an Active status are displayed. Editing an account's settings from the three-dot icon on the right follows the same steps as [managing clients](/reseller-support/manuals/manage-clients#edit-an-account), while the arrow icon logs in to the [Gcore Customer Portal](https://portal.gcore.com) as that customer.

## CDN resources

This subsection lists all CDN resources created by customers. Each entry includes:

- The CDN resource ID
- The CDN resource's [custom domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) (CNAME)
- The customer's account ID
- The ID of the main resource, not the reserve, if an [origin group](/cdn/add-an-origin-group) contains multiple origins
- The SSL ID, if applicable
- The shielding status, if enabled
- Any CDN resource rules, if created
- The origin group ID
- The CDN resource status (Active, Suspended, Processing, or Deleted)
- The resource type (default or technical)
- A toggle indicating whether automatic suspension is enabled for the CDN resource
- The date the CDN resource was created

Clicking the arrow logs in as the customer to configure specific CDN resource settings without opening the Customer Portal separately, which saves a navigation step. Filtering resources scheduled for automatic suspension helps identify customers to contact about their plans for the resource, or to refine suspension and data deletion procedures.

## Activity logs

This subsection documents CDN resource changes, rule configuration changes, and purge and prefetch requests. Each entry includes:

- The account ID
- The user ID, since customers can create multiple users per account
- The date and time of the request, in UTC
- The HTTP request method (GET, POST, PUT, DELETE, or PATCH)
- The requested path
- Request data, if available
- The request status code (200, 404, 503, and other HTTP status codes)
- The customer's remote IP address
- The requested host
- The API token ID and the ID of the user who issued it

Filters narrow the log entries down by these parameters.

<Frame>
![Activity logs tab in the CDN section](https://assets.gcore.pro/docs/reseller-support/cdn-section-overview/activity-logs-tab-30.png)
</Frame>

## Origin groups

This subsection provides information about origin groups. Each entry includes:

- The origin group ID
- The origin group name
- A list of origins included in the group
- The CDN resource's custom domain and ID, if a CDN resource has been specified for the origin group

Editing or deleting an origin group happens by clicking the three dots and selecting the appropriate action.
