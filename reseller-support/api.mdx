Six reseller references cover customer accounts, branding, billing, and product configuration.

## API references by product

Each product's reseller endpoints are documented separately, grouped by the operations they expose.

| Product | Covers | Reference |
|---------|--------|-----------|
| IAM | Client accounts, sellers, product availability, service status, branding, and notification settings | [IAM&nbsp;reseller](/api-reference/iam-resellers) |
| CDN | CDN service, features, activity logs, and usage statistics | [CDN&nbsp;reseller](/api-reference/cdn-resellers) |
| Cloud | Quota limit requests | [Cloud&nbsp;reseller](/api-reference/cloud-resellers) |
| FastEdge | Apps, clients, groups, plans, templates, and usage statistics | [FastEdge&nbsp;reseller](/api-reference/fastedge-resellers) |
| WAAP | Pre-billing usage data | [WAAP&nbsp;reseller](/api-reference/waap-resellers) |
| Billing | Addendums, expenses, plans, reports, and ERP invoices | [Billing&nbsp;reseller](/api-reference/billing) |

The IAM reference covers the widest range of operations, since it manages the customer accounts the other five references act on.

## Authentication

Create the token in [API&nbsp;tokens](/reseller-support/security/api-tokens). Set it as an environment variable before running the commands:

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

```http
GET https://api.gcore.com/iam/clients
Authorization: APIKey $GCORE_API_KEY
```

The Account operations return a token for a client administrator or for a user. That token is the API form of **Log in** in [Manage&nbsp;accounts](/reseller-support/accounts/manage-clients).

## Quick start

Listing customer accounts confirms the token works:

```bash
curl -H "Authorization: APIKey $GCORE_API_KEY" "https://api.gcore.com/iam/clients"
```

A `200 OK` response returns the customer accounts from **Accounts**.
