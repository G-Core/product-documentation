The Admin Portal manages two types of FastEdge applications and their templates:

- HTTP applications: cloud applications deployed on edge servers across the Gcore CDN network.
- CDN applications: FastEdge applications integrated with Gcore CDN infrastructure to extend CDN functionality.

## Manage FastEdge applications

The **HTTP Applications** and **CDN Applications** pages contain information about all FastEdge apps created and used by customers.

<Frame>
![HTTP Applications page](https://assets.gcore.pro/docs/reseller-support/fastedge-management/http-apps-page.png)
</Frame>

<Tip>
Preferred filters and columns for the applications and templates tables can be saved using [search presets](/reseller-support/new-admin-panel-interface#search-presets).
</Tip>

### Filter data in the applications table

Application data can be filtered by:

- **Account ID**: a unique identifier for the customer account where the application was created.
- **Status**: the current state of the application, either Active (running) or Disabled (stopped).
- **Template**: a unique identifier for the template used to create the application; an empty value means the application was created without a template.
- **Binary ID**: a unique identifier for the binary file the application was created from, useful for distinguishing versions of an app built from the same template.
- **Plan**: the subscription plan the application is billed under, typically determined by the customer's plan.

<Frame>
![List of table filters](https://assets.gcore.pro/docs/reseller-support/fastedge-management/app-filters.png)
</Frame>

To filter information in the table:

<Steps>
  <Step title="Add a filter">
  Click **Add filter**.

  <Frame>
  ![Add filter button highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/add-filter.png)
  </Frame>
  </Step>
  <Step title="Specify the criteria">
  Specify the required criteria. Setting the application status to **Active** filters the table down to running applications.

  <Frame>
  ![Table filter set to active status](https://assets.gcore.pro/docs/reseller-support/fastedge-management/filter-sample-active.png)
  </Frame>
  </Step>
  <Step title="Apply the filter">
  Click **Apply filter**.
  </Step>
</Steps>

The table then lists all currently running applications. Click **Reset all** to switch back to the default view.

<Frame>
![Reset all link highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/reset-all.png)
</Frame>

### Configure columns in the applications table

The applications table displays the following information about FastEdge apps:

- **ID**: a unique identifier for the application, useful for troubleshooting and included in support requests.
- **Name**: the application name specified during creation in the Customer Portal.
- **Upgradeable**: if the column shows **Outdated**, the application was created from a template and uses an old binary version; [updating the application](/reseller-support/fastedge-management#upgrade-a-binary-version) applies the newest version.
- **URL** (HTTP applications only): the link to the deployed application.
- **Reseller**: the ID of the reseller account associated with the application.
- **Description**: the description provided by the customer when creating the application in the Customer Portal, if any.

### Stop or start an application

<Steps>
  <Step title="Open the relevant page">
  Open **HTTP Applications** or **CDN Applications**.
  </Step>
  <Step title="Find the application">
  Find the application to manage and click the three-dot icon next to it.
  </Step>
  <Step title="Select an action">
  Select **Stop** or **Start**.

  <Frame>
  ![Application settings menu with stop button highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/stop-app.png)
  </Frame>
  </Step>
</Steps>

The application status change is also reflected in the Customer Portal, where customers can independently stop or start applications.

### Upgrade a binary version

The **Outdated** status in the **Upgradeable** column applies only to applications created from templates, and means the template has been updated since the application's binary was built. Upgrading the application binary to the newest template version applies the latest improvements and security fixes:

<Steps>
  <Step title="Open the relevant page">
  Open **HTTP Applications** or **CDN Applications**.
  </Step>
  <Step title="Find the application">
  Find the application to update and click the three-dot icon next to it.
  </Step>
  <Step title="Upgrade the binary">
  Click **Upgrade binary version**.

  <Frame>
  ![Application settings menu with upgrade button highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/upgrade-app.png)
  </Frame>
  </Step>
</Steps>

The application binary updates to the latest version.

### Delete an application

<Note>
Deleting a FastEdge CDN application requires disconnecting it from the CDN resource first; the deletion can't proceed otherwise.
</Note>

Deleting a FastEdge application permanently removes it from the Customer Portal.

<Steps>
  <Step title="Open the relevant page">
  Open **HTTP Applications** or **CDN Applications**.
  </Step>
  <Step title="Find the application">
  Find the application to remove and click the three-dot icon next to it.
  </Step>
  <Step title="Delete the application">
  Click **Delete**.

  <Frame>
  ![Application settings menu with delete button highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/delete-app.png)
  </Frame>
  </Step>
  <Step title="Confirm the deletion">
  Click **Yes, delete**.
  </Step>
</Steps>

The application is removed.

## Manage application templates

The **Templates** pages list all templates created by customers in the Customer Portal.

<Frame>
![CDN Templates page](https://assets.gcore.pro/docs/reseller-support/fastedge-management/cdn-templates-page.png)
</Frame>

### Filter data in the templates table

Templates can be filtered by:

- **Account ID**: a unique identifier for the customer account where the template was created.
- **Group ID**: the identifier of the group assigned to the template, managed in [Shared Access](#manage-shared-access-groups).

<Frame>
![List of table filters](https://assets.gcore.pro/docs/reseller-support/fastedge-management/cdn-templates-filter.png)
</Frame>

To filter templates in the table:

<Steps>
  <Step title="Add a filter">
  Click **Add filter**.
  </Step>
  <Step title="Specify the criteria">
  Specify the required criteria. Entering a customer's account ID filters the table down to that customer's templates.
  </Step>
  <Step title="Apply the filter">
  Click **Apply filter**.
  </Step>
</Steps>

The table then lists templates matching the criteria.

### Manage shared access groups

The **Shared Access** section lists the groups that control which customers see a shared template. Each group shows its name, assigned accounts, templates, and description; clicking **Create group** adds a new one. Groups can also be managed via the [Groups API](/api-reference/fastedge-resellers/groups/list-groups).

### Configure columns in the templates table

The templates table displays the following information:

- **ID**: a unique identifier for the template.
- **Name**: the template name specified in the Customer Portal.
- **Reseller**: the ID of the reseller account associated with the template.
- **Group ID**: the group ID from Shared Access, if the template is shared.
- **Description**: the description provided by the customer when creating the template in the Customer Portal, if any.
- **Instructions**: usage guidelines for the template, if provided in the Customer Portal.

### Share or unshare a template

Sharing a template assigns it to the reseller's group in Shared Access, making it accessible to that group's customers in the Customer Portal; they can view it in the templates list and create FastEdge applications from it.

<Steps>
  <Step title="Open the relevant template page">
  Open the template page under **HTTP Applications** or **CDN Applications**.
  </Step>
  <Step title="Find the template">
  Find the template and click the three-dot icon next to it.
  </Step>
  <Step title="Share or unshare">
  Click **Share template** or **Unshare template**.

  <Frame>
  ![Template settings menu with unshare button highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/share-template.png)
  </Frame>
  </Step>
</Steps>

Shared templates show their group ID in the table; an empty **Group ID** column means the template isn't shared, and customers can't see it in the Customer Portal.

### Delete a template

Deleting a template removes it from the Customer Portal permanently; restoring it requires uploading the template again.

<Steps>
  <Step title="Open the relevant template page">
  Open the template page under **HTTP Applications** or **CDN Applications**.
  </Step>
  <Step title="Find the template">
  Find the template to remove and click the three-dot icon next to it.
  </Step>
  <Step title="Delete the template">
  Click **Delete template**.

  <Frame>
  ![Template settings menu with delete button highlighted](https://assets.gcore.pro/docs/reseller-support/fastedge-management/delete-template.png)
  </Frame>
  </Step>
  <Step title="Confirm the deletion">
  Click **Yes, delete**.
  </Step>
</Steps>

The template is removed.
