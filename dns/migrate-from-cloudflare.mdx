<p>Moving DNS from Cloudflare to Gcore Managed DNS means exporting the zone file, importing records into Gcore, then switching authoritative nameservers at the domain registrar. Nameserver changes can take up to 24 hours to propagate, so plan the cutover for a low-traffic window.</p>

## TTL preparation

<p>Lower the TTL on critical DNS records in Cloudflare before the cutover. During the migration window, some resolvers still serve records from Cloudflare while the nameserver change propagates. A shorter TTL limits how long those resolvers cache the records, so any corrections to the zone take effect faster.</p>

1. Log in to the Cloudflare dashboard and select the domain.
2. Navigate to **DNS** > **Records**.
3. Edit each critical record and set the TTL to **10 minutes** (or the lowest available value).
4. Wait for the current TTL to expire before continuing, so old cached records stop being served.

<Warning>
If DNSSEC is enabled on the domain in Cloudflare, disable it before switching nameservers. Changing nameservers while DNSSEC is active causes DNSSEC validation to fail, and the domain stops resolving for many clients. Disable DNSSEC in Cloudflare, remove the DS record at the registrar, wait for the DS record TTL to expire, then proceed with the nameserver switch.
</Warning>

<Steps>
  <Step title="Export DNS records from Cloudflare">
  <p>Download a BIND zone file from Cloudflare so the same records can be imported into Gcore.</p>

  1. In the Cloudflare dashboard, select the domain and navigate to **DNS** > **Records**.
  2. Click **Export** to download the DNS records as a BIND zone file (`.txt` format).

  <Warning>
  Before importing the zone file, review records that were proxied through Cloudflare and confirm their values point to the intended origin server or Gcore CDN endpoint.
  </Warning>
  </Step>

  <Step title="Create a DNS zone in Gcore">
  <p>Create a zone in the [Gcore Customer Portal](https://portal.gcore.com) so imported records have a destination. The [zone creation](/dns/manage-a-dns-zone) guide covers the same flow with screenshots.</p>

  1. Navigate to [DNS](https://portal.gcore.com/dns/zones) in the Customer Portal and click **Add zone**.
  2. Enter the domain name and click **Confirm**.
  3. Gcore scans and displays any existing DNS records it can detect. Review them, then click **Confirm**.

  <Tip>
  Check the **Skip scanning** box to import all records manually from the Cloudflare zone file in the next step.
  </Tip>
  </Step>

  <Step title="Import DNS records">
  <p>Import the Cloudflare zone file into the new Gcore zone, then review every record before changing nameservers.</p>

  1. In the All zones tab, open the newly created zone.
  2. Click **Import records**.
  3. In the pop-up, either paste the contents of the Cloudflare zone file directly, or rename the exported `.txt` file to `.zone` and click **Upload zone file** to upload it.
  4. Click **Import**.

  <p>Review the imported records and confirm they look correct. Pay particular attention to records that were previously proxied through Cloudflare and verify that they point to the intended origin server or Gcore CDN endpoint.</p>

  <Info>
  Cloudflare supports CNAME flattening, which lets a CNAME record exist at the domain root (`example.com`). Standard DNS does not permit CNAME at the apex. Root records that used CNAME flattening in Cloudflare may appear differently in the zone file or after import — check them carefully and confirm they resolve to the expected address.
  </Info>

  <Warning>
  Only DNS records are migrated. Cloudflare CDN, proxy rules, WAF, page rules, redirects, Workers, and SSL/TLS settings are not transferred automatically. Configure those services separately in Gcore or another provider after the DNS cutover.
  </Warning>
  </Step>

  <Step title="Update nameservers at the registrar">
  <p>Point the domain to Gcore nameservers by updating the nameserver settings at the domain registrar (the company where the domain was purchased or is managed).</p>

  <Warning>
  Update the nameserver settings at the domain registrar, not inside Cloudflare. Adding or editing NS records inside the Cloudflare dashboard does not change which DNS provider is authoritative for the domain, because the registrar controls that setting.
  </Warning>

  <p>Set the nameservers to the following Gcore values:</p>

  | Nameserver | Value |
  |---|---|
  | NS 1 | `ns1.gcorelabs.net` |
  | NS 2 | `ns2.gcdn.services` |

  <p>Look for a **Nameservers** or **DNS** section in the registrar control panel. The exact steps vary by registrar.</p>
  </Step>

  <Step title="Verify propagation">
  <p>DNS changes can take up to 24 hours to propagate globally. Check progress in both of these places:</p>

  - Use a DNS propagation checker to verify that the domain's NS records resolve to Gcore nameservers worldwide. {/* LEGAL REVIEW NEEDED: third-party tool reference removed pending legal clearance */}
  - In the Customer Portal, a notification appears on the DNS zone until propagation is complete. This is expected and clears automatically.

  <p>Once the NS records resolve to Gcore, verify that critical migrated records return the expected values:</p>

  ```sh
  dig A yourdomain.com
  dig AAAA yourdomain.com
  dig MX yourdomain.com
  dig TXT yourdomain.com
  dig CNAME www.yourdomain.com
  ```

  <p>Compare the answers against the values in the original Cloudflare zone to confirm the migration is complete.</p>

  <Info>
  Keep the Cloudflare DNS zone intact for at least 48 hours after migration. Switching the nameservers back at the registrar provides a rollback path if the Gcore configuration needs to be corrected — the rollback is subject to the same DNS propagation delay.
  </Info>
  </Step>
</Steps>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Create a Gcore DNS zone and import records from a BIND zone file as the Gcore-side steps of a Cloudflare-to-Gcore migration. Export the zone file from Cloudflare first, and update nameservers at the domain registrar after the import completes. To update nameservers, set them to `ns1.gcorelabs.net` and `ns2.gcdn.services` in the registrar's control panel.</p>

<Warning>
Before importing the zone file, review records that were proxied through Cloudflare and confirm their values point to the intended origin server or Gcore CDN endpoint.
</Warning>

<Info>
An [API token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export these variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export ZONE_NAME="{YOUR_ZONE_NAME}"
export ZONE_FILE="{PATH_TO_ZONE_FILE}"
```

## Quickstart

<p>Create a zone and import a BIND zone file with a single script.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    ZONE_NAME = os.environ["ZONE_NAME"]
    ZONE_FILE  = os.environ["ZONE_FILE"]

    client = Gcore()

    # Step 1. Create the DNS zone
    client.dns.zones.create(name=ZONE_NAME)
    print(f"Zone created: {ZONE_NAME}")

    # Step 2. Import DNS records
    with open(ZONE_FILE, "rb") as f:
        zone_data = f.read()

    result = client.dns.zones.import_(
        zone_name=ZONE_NAME,
        body=zone_data,
        extra_headers={"Content-Type": "text/plain"},
    )
    print(f"Imported: {result.imported.rrsets} RRsets, {result.imported.resource_records} records")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "bytes"
        "context"
        "fmt"
        "io"
        "net/http"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/dns"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        zoneName     := os.Getenv("ZONE_NAME")
        zoneFilePath := os.Getenv("ZONE_FILE")

        // Step 1. Create the DNS zone
        _, err := client.DNS.Zones.New(ctx, dns.ZoneNewParams{Name: zoneName})
        if err != nil {
            panic(err)
        }
        fmt.Printf("Zone created: %s\n", zoneName)

        // Step 2. Import DNS records
        zoneData, err := os.ReadFile(zoneFilePath)
        if err != nil {
            panic(err)
        }

        req, err := http.NewRequest("POST",
            "https://api.gcore.com/dns/v2/zones/"+zoneName+"/import",
            bytes.NewReader(zoneData))
        if err != nil {
            panic(err)
        }
        req.Header.Set("Authorization", "APIKey "+os.Getenv("GCORE_API_KEY"))
        req.Header.Set("Content-Type", "text/plain")

        resp, err := http.DefaultClient.Do(req)
        if err != nil {
            panic(err)
        }
        defer resp.Body.Close()
        body, _ := io.ReadAll(resp.Body)
        fmt.Printf("Import response: %s\n", string(body))
    }
    ```
  </Tab>
</Tabs>

## Create the zone and import records

<Steps>
  <Step title="Create the DNS zone">
  Create the destination zone. The request requires only the domain name.

  | Parameter | Required | Description |
  |-----------|----------|-------------|
  | `name` | Yes | The domain name to create the zone for, e.g. `yourdomain.com`. |

  <Tabs>
    <Tab title="Python SDK">
      ```python
      import os
      from gcore import Gcore

      client = Gcore()
      client.dns.zones.create(name=os.environ["ZONE_NAME"])
      print(f"Zone created: {os.environ['ZONE_NAME']}")
      ```
    </Tab>
    <Tab title="Go SDK">
      ```go
      package main

      import (
          "context"
          "fmt"
          "os"

          gcore "github.com/G-Core/gcore-go"
          "github.com/G-Core/gcore-go/dns"
      )

      func main() {
          client := gcore.NewClient()
          ctx := context.Background()

          _, err := client.DNS.Zones.New(ctx, dns.ZoneNewParams{Name: os.Getenv("ZONE_NAME")})
          if err != nil {
              panic(err)
          }
          fmt.Printf("Zone created: %s\n", os.Getenv("ZONE_NAME"))
      }
      ```
    </Tab>
    <Tab title="curl">
      ```bash
      curl -s -X POST "https://api.gcore.com/dns/v2/zones" \
        -H "Authorization: APIKey $GCORE_API_KEY" \
        -H "Content-Type: application/json" \
        -d "{\"name\": \"${ZONE_NAME}\"}"
      ```

      <p>The API returns:</p>

      ```json
      {"id": 12345}
      ```
    </Tab>
  </Tabs>
  </Step>

  <Step title="Import DNS records">
  Send the BIND zone file as a plain-text request body. Import adds new RRsets to the zone; existing RRsets with the same name and type are skipped. The `warnings` field in the response lists any skipped records.

  <Tabs>
    <Tab title="Python SDK">
      ```python
      import os
      from gcore import Gcore

      client = Gcore()

      with open(os.environ["ZONE_FILE"], "rb") as f:
          zone_data = f.read()

      result = client.dns.zones.import_(
          zone_name=os.environ["ZONE_NAME"],
          body=zone_data,
          extra_headers={"Content-Type": "text/plain"},
      )
      print(f"Imported: {result.imported.rrsets} RRsets, {result.imported.resource_records} records")
      ```
    </Tab>
    <Tab title="Go SDK">
      ```go
      package main

      import (
          "bytes"
          "fmt"
          "io"
          "net/http"
          "os"
      )

      func main() {
          zoneName := os.Getenv("ZONE_NAME")

          zoneData, err := os.ReadFile(os.Getenv("ZONE_FILE"))
          if err != nil {
              panic(err)
          }

          req, err := http.NewRequest("POST",
              "https://api.gcore.com/dns/v2/zones/"+zoneName+"/import",
              bytes.NewReader(zoneData))
          if err != nil {
              panic(err)
          }
          req.Header.Set("Authorization", "APIKey "+os.Getenv("GCORE_API_KEY"))
          req.Header.Set("Content-Type", "text/plain")

          resp, err := http.DefaultClient.Do(req)
          if err != nil {
              panic(err)
          }
          defer resp.Body.Close()
          body, _ := io.ReadAll(resp.Body)
          fmt.Printf("Status: %d\n%s\n", resp.StatusCode, string(body))
      }
      ```
    </Tab>
    <Tab title="curl">
      ```bash
      curl -s -X POST "https://api.gcore.com/dns/v2/zones/${ZONE_NAME}/import" \
        -H "Authorization: APIKey $GCORE_API_KEY" \
        -H "Content-Type: text/plain" \
        --data-binary "@$ZONE_FILE"
      ```

      <p>The API returns:</p>

      ```json
      {
        "imported": {
          "rrsets": 5,
          "resource_records": 5,
          "qtype": 4,
          "skipped_resource_records": 0
        },
        "success": true,
        "warnings": {}
      }
      ```
    </Tab>
  </Tabs>
  </Step>

  <Step title="Verify imported records">
  List all RRsets in the zone to confirm the records were created.

  <Tabs>
    <Tab title="Python SDK">
      ```python
      import os
      from gcore import Gcore

      client = Gcore()
      page = client.dns.zones.rrsets.list(zone_name=os.environ["ZONE_NAME"])
      print(f"Total RRsets: {page.total_amount}")
      for rr in page.rrsets or []:
          print(f"  {rr.type:<6}  {rr.name}")
      ```
    </Tab>
    <Tab title="Go SDK">
      ```go
      package main

      import (
          "context"
          "fmt"
          "os"

          gcore "github.com/G-Core/gcore-go"
          "github.com/G-Core/gcore-go/dns"
      )

      func main() {
          client := gcore.NewClient()
          ctx := context.Background()

          page, err := client.DNS.Zones.Rrsets.List(ctx, os.Getenv("ZONE_NAME"), dns.ZoneRrsetListParams{})
          if err != nil {
              panic(err)
          }
          fmt.Printf("Total RRsets: %d\n", page.TotalAmount)
          for _, rr := range page.Rrsets {
              fmt.Printf("  %-6s  %s\n", rr.Type, rr.Name)
          }
      }
      ```
    </Tab>
    <Tab title="curl">
      ```bash
      curl -s "https://api.gcore.com/dns/v2/zones/${ZONE_NAME}/rrsets" \
        -H "Authorization: APIKey $GCORE_API_KEY"
      ```


  </Tabs>
  </Step>
</Steps>
