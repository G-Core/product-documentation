[Public&nbsp;DNS](https://gcore.com/public-dns) is a free recursive DNS resolver service. It is separate from [Managed&nbsp;DNS](/dns) (authoritative DNS for domain zones). Use Public DNS as an alternative to provider-supplied resolvers to improve resolution speed and protect against DNS substitution attacks. The service accepts up to 100 queries per second from each client IP address.

Configure a DNS client with one of these resolver addresses:

- IPv4: `95.85.95.85` or `2.56.220.2`
- IPv6: `2a03:90c0:999d::1` or `2a03:90c0:9992::1`

Public DNS supports DNS over HTTPS (DoH) and DNS over TLS (DoT). The [`gcoredns.com`](https://gcoredns.com) domain is the server name for DoT connections and redirects browser requests to the Public DNS product page.
