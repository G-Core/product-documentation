Gcore Public DNS is a free recursive resolver available to anyone without registration. Use it instead of the ISP or network default to route queries through infrastructure not controlled by an access provider.

DNS queries are anonymized, processed under EU jurisdiction, and not shared with third parties except as required by law. The service accepts up to 100 requests per second per client IP. [Managed&nbsp;DNS](/dns) handles authoritative DNS — hosting records for a domain — as a separate service.

## Resolver addresses

The following addresses accept plain DNS (UDP/TCP port 53), DoH, and DoT queries.

| Protocol | Address |
|----------|---------|
| IPv4 | `95.85.95.85` or `2.56.220.2` |
| IPv6 | `2a03:90c0:999d::1` or `2a03:90c0:9992::1` |

[DoH&nbsp;and&nbsp;DoT](/dns/configure-doh-and-dot) encrypt queries in transit on the same addresses.
