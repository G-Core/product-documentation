The [Grafana&nbsp;plugin](/developer-tools/grafana/install-the-grafana-plugin) adds the Gcore Platform-EN data source. Set **Service** to **DNS** and build time-series panels for DNS request counts.

## Configure a dashboard

With the data source connected, create a panel for DNS statistics.

1. In the Grafana main menu, click **New** > **New dashboard**.

2. Click **Add** > **Panel**, then **Configure visualization**.

3. In the data source dropdown, select **Gcore Platform-EN**.

4. In the query editor, under **Edge Network**, set **Service** to **DNS**.

5. Under **Query Props**, set **Zone**, **Granularity**, and **Record type**. **Legend** is optional.

6. Click **Save** to keep the panel, then **Save** the dashboard and enter a name.

## Query fields

A DNS query returns one series of request counts.

**Zone:** **All Zones**, or one zone. **All Zones** returns one series of request counts with the legend `Requests (All Zones)`, and one zone uses that zone name in the legend.

**Record type:** `ALL`, `A`, `AAAA`, `NS`, `CNAME`, `MX`, `TXT`, `SVCB`, or `HTTPS`. `ALL` includes requests for all record types, and any other value limits the series to that type and appends the type to the legend.

**Granularity:** `5m`, `10m`, `15m`, `30m`, `1h`, `1.5h`, `2h45m`, or `24h`. The default value is `5m`, and each point is the number of requests in that interval.

**Legend:** optional. An empty field keeps the generated series name.

## Grafana Alerting

Gcore Platform-EN is a backend data source with alerting enabled, so DNS panel queries can be used in [Grafana&nbsp;Alerting](https://grafana.com/docs/grafana/latest/alerting/) rules. Create an alert rule from the query and use Grafana expressions (Reduce, Math, Threshold) to turn the time series into a condition.
