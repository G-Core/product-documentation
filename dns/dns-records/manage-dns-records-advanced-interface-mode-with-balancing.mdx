<p>Gcore [Managed&nbsp;DNS](https://gcore.com/dns) advanced interface mode allows creating DNS record sets (RRSets) with [dynamic&nbsp;response](/dns/dns-records/configure-weight-balancing-and-geobalancing) — routing DNS responses based on geography, weight, latency, or health checks.</p>

## Create a DNS record

<Steps>
  <Step title="Select a DNS zone">
    Navigate to [All&nbsp;zones](https://portal.gcore.com/dns/zones) and select the zone to which records should be added. Alternatively, click the three-dot icon on the right and select **Go to records**.

    <Frame>![All zones list with a DNS zone ready to open](/images/docs/dns/dns-records/manage-dns-records-advanced-interface-mode-with-balancing/manage-dns-records-advanced-interface-mode-with-balancing-image1.png)</Frame>

    Check that the **Advanced** toggle in the **Interface mode** section is enabled (green):

    <Frame>![Zone records page with the Advanced interface mode toggle enabled](/images/docs/dns/dns-records/manage-dns-records-advanced-interface-mode-with-balancing/manage-dns-records-advanced-interface-mode-with-balancing-image2.png)</Frame>
  </Step>
  <Step title="Open the record creation form">
    Click **Add record set**.

    <Frame>![Zone records in advanced mode with the Add record set button](/images/docs/dns/dns-records/manage-dns-records-advanced-interface-mode-with-balancing/manage-dns-records-advanced-interface-mode-with-balancing-image3.png)</Frame>

    A new page opens with the record creation form.

    <Frame>![Add record form with Type, Name, TTL, Dynamic response, and Records fields](/images/docs/dns/dns-records/manage-dns-records-advanced-interface-mode-with-balancing/manage-dns-records-advanced-interface-mode-with-balancing-image4.png)</Frame>
  </Step>
  <Step title="Select the record type">
    In the **Type** field, select the DNS record type: A, AAAA, NS, CNAME, MX, SRV, HTTPS, TXT, CAA, or SVCB. Each type is described in [DNS&nbsp;records](/dns/dns-records).
  </Step>
  <Step title="Set the record name">
    In the **Name** field, specify the subdomain the record belongs to. The options are:

    * Leave the field blank to add a record for the apex domain (`sample-test.com`).
    * Enter a subdomain name to add a record for that subdomain. Entering `one` creates a record for `one.sample-test.com`.
    * Enter an asterisk (`*`) to add a wildcard record that applies to all subdomains.
  </Step>
  <Step title="Set the TTL">
    In the **TTL** field, specify the TTL (time to live) in seconds.

    <Accordion title="TTL operation">
    Consider an A record with a TTL of 300 seconds, equal to 5 minutes. If the value changes from `10.0.0.1` to `10.0.0.0`, users whose recursive DNS resolver cached the old value can continue receiving `10.0.0.1` until the cached record expires. After the TTL expires, the resolver requests the record again and receives the new value, `10.0.0.0`.

    After a record changes, resolvers that cached the previous value can continue returning it until its remaining TTL expires. With a TTL of 300 seconds, the old value can therefore remain visible for up to 5 minutes. Select a TTL duration according to the maximum acceptable propagation delay.
    </Accordion>
  </Step>
  <Step title="Configure dynamic response (optional)">
    <Note>
    The dynamic response feature is available on the Free plan, but creating more than one dynamic RRset requires a paid plan.
    </Note>

    Gcore's DNS servers can return different DNS records to different users — users in Asia can be directed to an Asian server and users in Europe to a European one. This is called dynamic response. Full configuration instructions are in [dynamic&nbsp;response](/dns/dns-records/configure-weight-balancing-and-geobalancing).

    To enable dynamic response, check the **Dynamic response** checkbox. Leave it unchecked to proceed without dynamic response.
  </Step>
  <Step title="Set the record value status">
    Each record value is active by default. To save a value without activating it, uncheck the toggle next to that record.
  </Step>
  <Step title="Enter the record value">
    In the **Content** field, enter a value for the record type.

    <Accordion title="Example values by record type">
    Record type | Example value
    ---|---
    A | ```128.128.128.128```
    AAAA | ```2001:0db8:85a3:0000:0000:8a2e:0370:7334```
    NS | ```ns1.smth.com```
    CNAME | ```uuuuu8.cdn.co```
    MX | ```ASPMX.L.GOOGLE.COM``` (for multiple servers, fill in the **Priority** field; lower value = higher priority)
    SRV | ```_sip._tcp.example.com. 3600 IN SRV 10 50 5060 sipserver.example.com```
    HTTPS | ```example.com. 1800 IN HTTPS 1 . alpn=h3,h3-29,h2 ipv4hint=1.2.3.4,9.8.7.6```
    TXT | ```logmein-verification-code=976afe6f-8039-40e4-95a5-261b462```
    CAA | ```0 issue "comodo.com"``` (format: `[flags] [tag] "[value]"`)
    </Accordion>
  </Step>
  <Step title="Add metadata (optional)">
    Specify associated metadata to be used for dynamic response configuration. The [metadata&nbsp;guide](/dns/dns-records/configure-weight-balancing-and-geobalancing) covers the full configuration.
  </Step>
  <Step title="Add more record values (optional)">
    Click **Add record** to specify additional values for the record set. A new record entry appears — enter the content and metadata as needed. To remove a record value, click the minus button next to it. To disable a value without removing it, uncheck its toggle.
  </Step>
  <Step title="Create the record">
    Click **Create**.

    The record set is created with the specified parameters. Use the [DNS&nbsp;Lookup](https://gcore.com/dev-tools/dns-lookup) tool to verify that the record resolves with the expected values.
  </Step>
</Steps>

  <MethodSection id="api" label="REST API">

<p>The DNS API manages record sets (RRsets) using `POST`, `GET`, `PUT`, and `DELETE` requests. Advanced interface mode enables dynamic response: pickers control which records are returned based on per-record metadata such as `weight`, `countries`, or `continents`. Full picker and selector options are documented in the [dynamic response guide](/dns/dns-records/configure-weight-balancing-and-geobalancing).</p>

<p>The code samples below use an A record. To work with another supported type (AAAA, CNAME, MX, TXT, and others), replace `A` with the required RRset type and provide the corresponding record content.</p>

<Info>
An [API token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export ZONE_NAME="{YOUR_ZONE_NAME}"        # e.g. example.com
export RECORD_NAME="{YOUR_RECORD_NAME}"    # e.g. app.example.com
```

## Create a record

<p>Creating an RRset with pickers enables dynamic response. The two-picker chain below applies weighted probability to distribute traffic and then limits the response to a single record: `weighted_shuffle` assigns each record a relative probability proportional to its `weight`, and `first_n` with `limit: 1` selects one record from the shuffled list. Omit the `pickers` field to create a static record that always returns all values.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    rrset = client.dns.zones.rrsets.create(
        zone_name=os.environ["ZONE_NAME"],
        rrset_name=os.environ["RECORD_NAME"],
        rrset_type="A",
        ttl=300,
        resource_records=[
            {"content": ["1.2.3.4"], "meta": {"weight": 10}},
            {"content": ["5.6.7.8"], "meta": {"weight": 5}},
        ],
        pickers=[
            {"type": "weighted_shuffle"},
            {"type": "first_n", "limit": 1},
        ],
    )
    print(rrset.name, rrset.type, [p.type for p in (rrset.pickers or [])])
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/dns"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        rrset, err := client.DNS.Zones.Rrsets.New(ctx, "A", dns.ZoneRrsetNewParams{
            ZoneName:  os.Getenv("ZONE_NAME"),
            RrsetName: os.Getenv("RECORD_NAME"),
            Ttl:       gcore.Int(300),
            ResourceRecords: []dns.ZoneRrsetNewParamsResourceRecord{
                {Content: []any{"1.2.3.4"}, Meta: map[string]any{"weight": 10}},
                {Content: []any{"5.6.7.8"}, Meta: map[string]any{"weight": 5}},
            },
            Pickers: []dns.ZoneRrsetNewParamsPicker{
                {Type: "weighted_shuffle"},
                {Type: "first_n", Limit: gcore.Int(1)},
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Printf("created: %s %s pickers:%d\n", rrset.Name, rrset.Type, len(rrset.Pickers))
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/dns/v2/zones/$ZONE_NAME/$RECORD_NAME/A" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "ttl": 300,
        "resource_records": [
          {"content": ["1.2.3.4"], "meta": {"weight": 10}},
          {"content": ["5.6.7.8"], "meta": {"weight": 5}}
        ],
        "pickers": [
          {"type": "weighted_shuffle"},
          {"type": "first_n", "limit": 1}
        ]
      }'
    ```

    <p>The API returns:</p>

    ```json
    {
      "name": "app.example.com",
      "type": "A",
      "ttl": 300,
      "pickers": [
        {"type": "weighted_shuffle", "strict": false},
        {"type": "first_n", "limit": 1, "strict": false}
      ],
      "resource_records": [
        {"id": 1001, "content": ["1.2.3.4"], "enabled": true, "meta": {"weight": 10}},
        {"id": 1002, "content": ["5.6.7.8"], "enabled": true, "meta": {"weight": 5}}
      ]
    }
    ```
  </Tab>
</Tabs>

## List records

<p>Returns all RRsets in a zone, including their type, TTL, and pickers. Use this to locate an RRset when its name or type is unknown before retrieving or editing it.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    result = client.dns.zones.rrsets.list(zone_name=os.environ["ZONE_NAME"])
    print("total:", result.total_amount)
    for r in result.rrsets or []:
        print(r.name, r.type, "pickers:", [p.type for p in (r.pickers or [])])
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/dns"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        result, err := client.DNS.Zones.Rrsets.List(ctx, os.Getenv("ZONE_NAME"), dns.ZoneRrsetListParams{})
        if err != nil {
            panic(err)
        }
        fmt.Println("total:", result.TotalAmount)
        for _, r := range result.Rrsets {
            fmt.Printf("  %s %s pickers:%d\n", r.Name, r.Type, len(r.Pickers))
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/dns/v2/zones/$ZONE_NAME/rrsets" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns:</p>

    ```json
    {
      "rrsets": [
        {
          "name": "app.example.com",
          "type": "A",
          "ttl": 300,
          "pickers": [
            {"type": "weighted_shuffle", "strict": false},
            {"type": "first_n", "limit": 1, "strict": false}
          ]
        }
      ],
      "total_amount": 1
    }
    ```
  </Tab>
</Tabs>

## Get a record

<p>Returns the full RRset including all resource records and their metadata. Retrieve the current state before editing to preserve existing values that should not change.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    rrset = client.dns.zones.rrsets.get(
        zone_name=os.environ["ZONE_NAME"],
        rrset_name=os.environ["RECORD_NAME"],
        rrset_type="A",
    )
    print(rrset.name, "ttl:", rrset.ttl, "records:", len(rrset.resource_records or []))
    ```
  </Tab>
  <Tab title="Go SDK">

## Edit a record

<p>`PUT` fully replaces the RRset — all existing resource records and pickers are overwritten. Fetch the current state first (see [Get a record](#get-a-record)), then submit the complete updated body.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    rrset = client.dns.zones.rrsets.replace(
        zone_name=os.environ["ZONE_NAME"],
        rrset_name=os.environ["RECORD_NAME"],
        rrset_type="A",
        ttl=600,
        resource_records=[
            {"content": ["1.2.3.4"], "meta": {"weight": 20}},
            {"content": ["5.6.7.8"], "meta": {"weight": 5}},
        ],
        pickers=[
            {"type": "weighted_shuffle"},
            {"type": "first_n", "limit": 1},
        ],
    )
    print("updated ttl:", rrset.ttl)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/dns"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        rrset, err := client.DNS.Zones.Rrsets.Replace(ctx, "A", dns.ZoneRrsetReplaceParams{
            ZoneName:  os.Getenv("ZONE_NAME"),
            RrsetName: os.Getenv("RECORD_NAME"),
            Ttl:       gcore.Int(600),
            ResourceRecords: []dns.ZoneRrsetReplaceParamsResourceRecord{
                {Content: []any{"1.2.3.4"}, Meta: map[string]any{"weight": 20}},
                {Content: []any{"5.6.7.8"}, Meta: map[string]any{"weight": 5}},
            },
            Pickers: []dns.ZoneRrsetReplaceParamsPicker{
                {Type: "weighted_shuffle"},

            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Printf("updated ttl:%d pickers:%d\n", rrset.Ttl, len(rrset.Pickers))
    }
    ```
  </Tab>

## Delete a record

<p>Removes the RRset and all its resource records permanently.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    client.dns.zones.rrsets.delete(
        zone_name=os.environ["ZONE_NAME"],
        rrset_name=os.environ["RECORD_NAME"],
        rrset_type="A",
    )
    print("deleted")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/dns"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        _, err := client.DNS.Zones.Rrsets.Delete(ctx, "A", dns.ZoneRrsetDeleteParams{
            ZoneName:  os.Getenv("ZONE_NAME"),
            RrsetName: os.Getenv("RECORD_NAME"),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println("deleted")
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X DELETE "https://api.gcore.com/dns/v2/zones/$ZONE_NAME/$RECORD_NAME/A" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns HTTP 200 with an empty body on success.</p>
  </Tab>
</Tabs>
