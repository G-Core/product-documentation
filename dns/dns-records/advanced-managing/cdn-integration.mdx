<p>CDN integration links an A or AAAA record directly to a Gcore CDN resource, so Gcore DNS resolves the hostname to CDN addresses without a CNAME record.</p>

## Configure CDN integration

<Steps>
  <Step title="Navigate to DNS">
    In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **DNS**.

    <Frame>![DNS zones list](/images/docs/dns/dns-records/advanced-managing/cdn-integration/cdn-integration-image1.png)</Frame>
  </Step>
  <Step title="Open the DNS zone">
    Click the domain name of the DNS zone to configure.

    <Note>
    CDN integration is available only for **A** and **AAAA** record types.
    </Note>
  </Step>
  <Step title="Open CDN Integration">
    Click the three-dot icon next to the A or AAAA record and select **CDN Integration**.

    <Frame>![Record sets list with CDN Integration option in the three-dot menu](/images/docs/dns/dns-records/advanced-managing/cdn-integration/cdn-integration-10.png)</Frame>
  </Step>
  <Step title="Save the settings">
    In the **CDN Integration** popup, the **Domain** field shows the delivery domain of the CDN resource associated with this account. Click **Save changes**.

    <Frame>![CDN Integration popup with the Domain field pre-filled](/images/docs/dns/dns-records/advanced-managing/cdn-integration/cdn-integration-20.png)</Frame>
  </Step>
</Steps>

<p>The DNS record is now linked to Gcore CDN. The record content changes to **Managed by CDN** and the details column shows **CDN Integration**.</p>

<Frame>![DNS record set showing Managed by CDN content and CDN Integration in the details column](/images/docs/dns/dns-records/advanced-managing/cdn-integration/cdn-integration-30.png)</Frame>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>CDN integration links an A or AAAA record to a Gcore CDN resource so DNS resolves the hostname directly to the optimal CDN endpoint. The link is set via the `geodns_link` field in the RRset metadata — its value is the CNAME of the target CDN resource.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. CDN integration applies to A and AAAA records only.
</Info>

<p>Export these variables before running the code:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export ZONE_NAME="{YOUR_ZONE_NAME}"
export RECORD_NAME="{RECORD_FQDN}"
export CDN_CNAME="{YOUR_CDN_CNAME}"
```

<p>`RECORD_NAME` is the FQDN of the target record. `CDN_CNAME` is the delivery domain of the Gcore CDN resource — find it in **CDN** → **Resources** in the portal, or retrieve it with `GET /cdn/resources`.</p>

## Enable CDN integration

<p>The code uses an A record. For AAAA, replace `"A"` with `"AAAA"` and preserve the existing IPv6 addresses in `resource_records`.</p>

<Warning>
`replace` (PUT) overwrites the entire RRset. Fetch the current resource records and TTL before sending — `GET /dns/v2/zones/${ZONE_NAME}/${RECORD_NAME}/A` — and include them unchanged in the request body.
</Warning>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()

rrset = client.dns.zones.rrsets.replace(
    "A",
    zone_name=os.environ["ZONE_NAME"],
    rrset_name=os.environ["RECORD_NAME"],
    resource_records=[{"content": ["1.2.3.4"]}],  # use the existing IP(s)
    meta={"geodns_link": os.environ["CDN_CNAME"]},
    ttl=600,
)
print(rrset.name, rrset.meta)
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/dns"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    rrset, err := client.DNS.Zones.Rrsets.Replace(ctx, "A", dns.ZoneRrsetReplaceParams{
        ZoneName:  os.Getenv("ZONE_NAME"),
        RrsetName: os.Getenv("RECORD_NAME"),
        ResourceRecords: []dns.ZoneRrsetReplaceParamsResourceRecord{
            {Content: []any{"1.2.3.4"}}, // use the existing IP(s)
        },
        Meta: map[string]any{"geodns_link": os.Getenv("CDN_CNAME")},
        Ttl:  gcore.Int(600),
    })
    if err != nil {
        panic(err)
    }
    fmt.Println(rrset.Name, rrset.Meta)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X PUT "https://api.gcore.com/dns/v2/zones/${ZONE_NAME}/${RECORD_NAME}/A" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"ttl\": 600,
    \"resource_records\": [{\"content\": [\"<CURRENT_IP>\"]}],
    \"meta\": {\"geodns_link\": \"${CDN_CNAME}\"}
  }"
```

<p>The API returns the updated RRset:</p>

```json
{
  "name": "example.com",
  "type": "A",
  "ttl": 600,
  "meta": {
    "geodns_link": "www.my-domain-1.com"
  },
  "resource_records": [
    {"content": ["1.2.3.4"], "enabled": true, "meta": {}}
  ]
}
```
  </Tab>
</Tabs>

## Disable CDN integration

<p>Remove `geodns_link` from the RRset metadata. If the RRset has other metadata fields — `failover`, `notes`, or similar — include them in the request body while omitting only `geodns_link`. The record reverts to standard DNS resolution.</p>

<Warning>
`replace` (PUT) overwrites the entire RRset. Preserve the existing resource records and TTL — retrieve them first with `GET /dns/v2/zones/${ZONE_NAME}/${RECORD_NAME}/A`.
</Warning>

  <MethodSection id="terraform" label="Terraform">

<p>Link A or AAAA records to a Gcore CDN resource using the `gcore_dns_zone_rrset` resource from the [Gcore&nbsp;Terraform&nbsp;provider](/developer-tools/terraform/overview) v2. The link is set via `meta.geodns_link` at the RRset level — its value is the CNAME of the target CDN resource. CDN integration applies to A and AAAA records only.</p>

## Enable CDN integration

<p>Set `meta.geodns_link` to the delivery domain of the CDN resource. Find it in **CDN** → **Resources** in the portal.</p>

```hcl
resource "gcore_dns_zone" "example" {
  name = "yourdomain.com"
}

resource "gcore_dns_zone_rrset" "app" {
  zone_name  = gcore_dns_zone.example.name
  rrset_name = gcore_dns_zone.example.name
  rrset_type = "A"
  ttl        = 600

  meta = {
    geodns_link = "cdn-cname.gcdn.co"  # delivery domain of the CDN resource
  }

  resource_records = [
    { content = ["1.2.3.4"] },  # keep the existing record IP(s)
  ]
  # terraform import gcore_dns_zone_rrset.app yourdomain.com/yourdomain.com/A
}
```

## Disable CDN integration

<p>Remove `geodns_link` by setting `meta` to an empty map. Terraform applies the change in place — the record reverts to standard DNS resolution.</p>

```hcl
resource "gcore_dns_zone_rrset" "app" {
  zone_name  = gcore_dns_zone.example.name
  rrset_name = gcore_dns_zone.example.name
  rrset_type = "A"
  ttl        = 600

  meta = {}  # clears geodns_link; include other metadata fields if present

  resource_records = [
    { content = ["1.2.3.4"] },
  ]
}
```

## Delete a record

<p>Remove the resource block — Terraform detects the missing declaration and deletes the RRset on the next `terraform apply`.</p>

```hcl
# Remove or comment out this block:
# resource "gcore_dns_zone_rrset" "app" { ... }
```

```bash
terraform apply
```
