sidebarTitle: Import and export
ai-navigation: Export or import Gcore Managed DNS records using BIND .zone files that include domain name, TTL, RRsets, time intervals, and authoritative NS server records.
---

Use import and export to gain more control over DNS records and make domain migration easier.

<Steps>
  <Step title="Open the domain zone">
    Navigate to the [All&nbsp;zones](https://portal.gcore.com/dns/zones) page and open the domain zone to import records into.

    <Frame>![All zones list](/images/docs/dns/dns-records/import-and-export-records/import-and-export-records-image1.png)</Frame>
  </Step>
  <Step title="Click Export records or Import records">
    Click **Export records** or **Import records** and follow the relevant instructions below.

    <Frame>![Zone records page with Export records and Import records buttons](/images/docs/dns/dns-records/import-and-export-records/import-and-export-records-image2.png)</Frame>

    <Tabs>
      <Tab title="Export">
        After clicking **Export records**, the BIND zone file will be downloaded to the local machine as a text file with the .zone extension, e.g., `sample-test.com.zone`.

        The downloaded file includes domain name, TTL, RRsets, time intervals (refresh, update, and expiry), and the authoritative NS server:

        ```sh
        $ORIGIN test.dnsexample.com.
        $TTL 300
        @ IN SOA ns1.gcorelabs.net. support.gcore.com. (
          1690969313 ; serial number
          5400 ; refresh
          3600 ; update retry
          1209600 ; expiry
          300 ; minimum
        )
        $TTL 3600
        @ IN NS ns1.gcorelabs.net.
        @ IN NS ns2.gcdn.services.
        $TTL 600
        @ IN A 1.2.3.4
        @ IN A 4.5.6.7
        * IN CNAME sample.domains.com.
        * IN CNAME sample-2.domains.com.
        ```
      </Tab>
      <Tab title="Import">
        After clicking **Import records**, a dialog will appear. Specify the content of the BIND zone file for the domain or click **Upload zone file** to import records from a file with the .zone extension. Then, click **Import**.

        <Frame>![Import records dialog with zone file content field and Upload zone file button](/images/docs/dns/dns-records/import-and-export-records/import-and-export-records-image3.png)</Frame>
      </Tab>
    </Tabs>
  </Step>
</Steps>
