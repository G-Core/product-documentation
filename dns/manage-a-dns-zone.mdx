  <MethodSection id="portal" label="Customer Portal">

<p>To use Managed DNS, create a DNS zone for a domain or subdomain in the [Gcore Customer Portal](https://portal.gcore.com) and point the domain to Gcore's nameservers. The zone can then serve DNS queries through Gcore's global network.</p>

## Create DNS zones

<p>Navigate to the [DNS](https://portal.gcore.com/dns/zones) section of the Customer Portal, then follow these steps:</p>

<Steps>
  <Step title="Open the zone creation wizard">
    Click **Add zone**.

    <Frame>![The All zones page](/images/docs/dns/manage-a-dns-zone/getting-started-dns-10.png)</Frame>
  </Step>
  <Step title="Enter the domain name">
    Enter a domain or subdomain name in the **Domain name** field and click **Create zone**.

    <Tip>
    Check **Skip scanning** to skip automatic record detection and proceed directly to the nameserver step.
    </Tip>

    <Frame>![The Enter domain page](/images/docs/dns/manage-a-dns-zone/getting-started-dns-20.png)</Frame>
  </Step>
  <Step title="Review existing records">
    The portal scans existing DNS records automatically and opens the **Review records** page. Review, edit, or delete records as needed, then click **Confirm**.

    <Frame>![The Review records page](/images/docs/dns/manage-a-dns-zone/getting-started-dns-30.png)</Frame>
  </Step>
  <Step title="Update nameserver records">
    In the domain's DNS registrar or hosting panel, replace the current NS records with `ns1.gcorelabs.net` and `ns2.gcdn.services`, then return to the portal and click **Confirm**.

    <Frame>![The Change nameservers page](/images/docs/dns/manage-a-dns-zone/getting-started-dns-40.png)</Frame>
  </Step>
</Steps>

<p>The zone is now created in Gcore. Records and settings are available in the Customer Portal.</p>

<Info>
Nameserver changes may take up to 24 hours to propagate through DNS caches.
</Info>

<p>The status on [All&nbsp;zones](https://portal.gcore.com/dns/zones) reflects the zone in Gcore, not whether public nameserver records already point to Gcore. Confirm public delegation in the REST API tab.</p>

<p>Open the zone from All zones to add or edit [DNS&nbsp;records](/dns/dns-records/manage-dns-records-non-advanced-interface-mode).</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Create a DNS zone through the API, point the domain to Gcore nameservers, and verify public delegation before adding records.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Export these variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export ZONE_NAME="{YOUR_ZONE_NAME}"
```

## Create a DNS zone

<p>Create the zone for the domain or subdomain that Gcore will serve. Gcore automatically adds the default NS records for `ns1.gcorelabs.net` and `ns2.gcdn.services`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    zone = client.dns.zones.create(name=os.environ["ZONE_NAME"])
    print(zone.id)
    print(zone.warnings)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/dns"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        zone, err := client.DNS.Zones.New(ctx, dns.ZoneNewParams{
            Name: os.Getenv("ZONE_NAME"),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(zone.ID)
        fmt.Println(zone.Warnings)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/dns/v2/zones" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d "{\"name\": \"${ZONE_NAME}\"}"
    ```

    <p>The API returns:</p>

    ```json
    {
      "id": 1300358,
      "warnings": [
        "The contract is currently set to reseller default and in order to modify it, you need to upgrade your tariff plan.",
        "Your primary server has been set to default. In order to alter the primary server, you are required to upgrade your tariff plan."
      ]
    }
    ```
  </Tab>
</Tabs>

<p>The zone now exists in Gcore, but DNS traffic will reach it only after the domain is delegated to Gcore nameservers. At the registrar, replace the current NS records with `ns1.gcorelabs.net` and `ns2.gcdn.services`.</p>

## Check zone delegation

<p>The [Delegation&nbsp;status](/api-reference/dns/analyze/check-delegation-status) call looks up public NS records for the domain. When those NS records point to Gcore, `gcore_authorized_count` is greater than zero and `zone_exists` is `true`.</p>

<p>When the domain has no public NS records, the API returns HTTP 404. Nameserver changes may take up to 24 hours to propagate through DNS caches.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    status = client.dns.zones.check_delegation_status(os.environ["ZONE_NAME"])
    print(status.zone_exists, status.gcore_authorized_count)
    for ns in status.authoritative_name_servers:
        print(ns.name, ns.ipv4_addresses)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        status, err := client.DNS.Zones.CheckDelegationStatus(ctx, os.Getenv("ZONE_NAME"))
        if err != nil {
            panic(err)
        }
        fmt.Println(status.ZoneExists, status.GcoreAuthorizedCount)
        for _, ns := range status.AuthoritativeNameServers {
            fmt.Println(ns.Name, ns.Ipv4Addresses)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -s "https://api.gcore.com/dns/v2/analyze/${ZONE_NAME}/delegation-status" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns for a domain delegated to Gcore:</p>

    ```json
    {
      "zone_exists": true,
      "gcore_authorized_count": 5,
      "non_gcore_authorized_count": 0,
      "is_whitelabel_delegation": false,
      "authoritative_name_servers": [
        {
          "name": "ns1.gcorelabs.net.",
          "ipv4Addresses": ["92.223.100.253", "92.223.100.53"],
          "ipv6Addresses": ["2a03:90c0:9990::1053"]
        },
        {
          "name": "ns2.gcdn.services.",
          "ipv4Addresses": ["92.223.77.53"],
          "ipv6Addresses": ["2a03:90c0:9990::2053"]
        }
      ]
    }
    ```
  </Tab>
</Tabs>

<p>`gcore_authorized_count` is the number of Gcore nameservers currently authoritative for the zone. A value of `0` means registrar NS records do not yet point to Gcore, or propagation is still in progress.</p>

<p>When `gcore_authorized_count` is greater than zero, add and edit records with the [DNS&nbsp;records](/dns/dns-records/manage-dns-records-non-advanced-interface-mode) API.</p>
