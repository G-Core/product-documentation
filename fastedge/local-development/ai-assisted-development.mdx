The `gcore-fastedge` plugin adds FastEdge skills to Claude Code, Codex, and Cursor. Natural-language requests scaffold projects, build WebAssembly binaries, and deploy applications to FastEdge.

## Set up with one prompt

Paste this prompt into the agent:

```text
Fetch and execute the appropriate instructions to set me up for FastEdge from https://portal.gcore.com/external-statics/fast-edge/agent-connect-prompt.md
```

The prompt is the same for every agent. The agent downloads the instructions, detects which client it is, and runs the matching install steps. **Copy prompt** on the FastEdge dashboard onboarding card copies this same text.

After installation, follow any additional steps the agent reports:

- Claude Code: run `/reload-plugins`.
- Cursor: open `/plugins`, switch to the **Marketplace** tab, and select **Gcore FastEdge**.

On the first FastEdge API call, the agent reports that it is not signed in and prints a link.

<Warning>
This access is not limited to FastEdge. Until it expires, the token can reach any Gcore product the **Engineers** role allows.
</Warning>

Open the link and approve the account shown on the page. The link uses the Customer Portal session already open in the browser, so switch to the account that should be connected before approving.

The plugin normally starts the MCP server in Docker. Manual installation, an API token, Docker fallback, and other MCP clients are in [Plugin&nbsp;setup](/fastedge/local-development/configure-plugin-and-mcp-server).

## Build the first app

Paste this prompt into the agent:

```text
HTTP app named geo-page, in TypeScript: a page showing the visitor's IP, country and city. Create it in a new folder called geo-page, deploy it and show me the live URL.
```

The agent creates the project from a template, builds it, deploys it, and returns a live URL. Open the returned URL and confirm that the page shows the IP address, country, and city.

Command prefixes and the full skill list are in the [skills&nbsp;reference](/fastedge/local-development/ai-skills-reference).
