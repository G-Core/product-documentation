The [Grafana&nbsp;plugin](/developer-tools/grafana/install-the-grafana-plugin) adds the Gcore Platform-EN data source. Set **Service** to **FastEdge** and build time-series panels for application duration.

## Configure a dashboard

With the data source connected, create a panel for FastEdge statistics.

1. In the Grafana main menu, click **New** > **New dashboard**.

2. Click **Add** > **Panel**, then **Configure visualization**.

3. In the data source dropdown, select **Gcore Platform-EN**.

4. In the query editor, under **Edge Network**, set **Service** to **FastEdge**.

5. Under **Query Props**, set **App Name**, **Metric**, and **Step (s)**. **Network** is optional.

6. Click **Save** to keep the panel, then **Save** the dashboard and enter a name.

## Query fields

A FastEdge query returns one duration series. The values are microseconds.

**App Name:** **All**, or one application. **All** includes every application. The table heading joins the selected name and the metric: `All avg`. The graph legend reads `value`.

**Metric:** `avg`, `min`, `max`, `median`, `perc75`, or `perc90`.

| Metric | Description |
|---|---|
| `avg` | Average duration |
| `min` | Shortest duration |
| `max` | Longest duration |
| `median` | Median duration |
| `perc75` | 75th percentile duration |
| `perc90` | 90th percentile duration |

**Step (s):** sampling interval in seconds. The default value is 60.

**Network:** optional network name. An empty field does not filter by network.

## Grafana Alerting

Gcore Platform-EN is a backend data source with alerting enabled, so FastEdge panel queries can be used in [Grafana&nbsp;Alerting](https://grafana.com/docs/grafana/latest/alerting/) rules. Create an alert rule from the query and use Grafana expressions (Reduce, Math, Threshold) to turn the time series into a condition.
