FastEdge application duration can be shown as Grafana time-series panels. The [Grafana&nbsp;plugin](/developer-tools/grafana/install-the-grafana-plugin) adds the **Gcore Platform-EN** data source.
## Configure a dashboard

The panel uses the connected **Gcore Platform-EN** data source.

1. In the top bar, click **+**, then **New dashboard**.

<Frame>![Plus menu open on New dashboard](/images/docs/fastedge/grafana/view-fastedge-statistics-in-grafana/new-dashboard-menu.png)</Frame>

2. The **Add** drawer opens on the right. Click **Panel**.

<Frame>![Add drawer with the Panel control](/images/docs/fastedge/grafana/view-fastedge-statistics-in-grafana/add-panel.png)</Frame>

3. Click **Edit visualization**.

4. Under **Data source**, select **Gcore Platform-EN**.

5. Under **Edge Network**, set **Service** to **FastEdge**.

6. Under **Query Props**, set **App Name**, **Metric**, and **Step (s)**. **Network** is optional.

7. Click **Save**. In **Save dashboard**, enter a title and click **Save**.

The saved dashboard shows the title and the panel.

<Frame>![Saved dashboard with the Duration panel](/images/docs/fastedge/grafana/view-fastedge-statistics-in-grafana/saved-dashboard.png)</Frame>

## Query fields

A FastEdge query returns one duration series. The values are microseconds. An [alert&nbsp;rule](/developer-tools/grafana/create-an-alert-rule) on that series changes state when the duration crosses a threshold.

**App Name:** **All**, or one application. **All** includes every application. The table heading joins the selected name and the metric: `All avg`. The graph legend reads `value`.

**Metric:** `avg`, `min`, `max`, `median`, `perc75`, or `perc90`.

| Metric | Description |
|---|---|
| `avg` | Average duration |
| `min` | Shortest duration |
| `max` | Longest duration |
| `median` | Median duration |
| `perc75` | 75th percentile duration |
| `perc90` | 90th percentile duration |

**Step (s):** sampling interval in seconds. The default value is 60.

**Network:** optional network name. An empty field does not filter by network.
