The Always Online option serves stale cached content when the origin is unavailable. CDN checks origin availability on each incoming request and switches back to live content when the origin recovers. Stale responses include the `X-Cache: Stale` header.

The following conditions trigger stale content delivery:

- **error** — network or connectivity issue
- **updating** — cache is being refreshed
- Timeout
- Invalid Header
- Error 500
- Error 502
- Error 503
- Error 504
- Error 403
- Error 404
- Error 429

<Warning>
When the origin is unavailable, the CDN cache may not contain all assets needed to render a complete page. Some images, scripts, or stylesheets may be missing from the stale response.
</Warning>

## Enable Always Online

1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** > **CDN resources** and click the resource.
2. In the sidebar, click **Cache**, then click **Always online**.
3. Enable the **Enable always online** toggle.
4. In the **Serve stale cached content in case of the following errors** field, select the error codes for which CDN should serve stale content.
5. Click **Save changes**.
