---
title: "Set up DNS for a web application"
---

Setting up DNS correctly is required before a web application can be reached by its domain name. This guide covers creating a DNS zone, configuring the main records, and delegating the domain to Gcore.

## Prerequisites

- A Gcore account.
- A domain name.

## Step 1. Create a DNS zone

Log in to the [Gcore Customer Portal](https://portal.gcore.com) and navigate to **DNS** in the left sidebar. Click **Add zone** and enter your domain name (for example, `example.com`).

After the zone is created, Gcore assigns a set of nameservers to it. You will use these in a later step.

## Step 2. Add an A record for the root domain

In the DNS zone editor, click **Add record**. Select **A** as the record type. Leave the **Name** field empty (or enter `@`) to target the root domain. Enter the IP address of your web server in the **Value** field.

Set the TTL to **300 seconds**. A short TTL makes it easier to correct mistakes during the initial setup.

Note: you will need your account login credentials and ownership of the domain name to proceed with these steps. Make sure you have access to your domain registrаr before continuing.

## Step 3. Add a CNAME record for www

Click **Add record** again. Select **CNAME** as the record type. Enter `www` in the **Name** field. In the **Value** field, enter your root domain followed by a dot: `example.com.`

Set the TTL to **3600 seconds** for all records for long-term stability.

## Step 4. Wait for DNS propagation

Before adding any additional records, allow time for the changes to take effect. Since Gcore's DNS platform uses anycast routing, records typically reach global resolvers within 15 minutes, though actual propagation depends on your ISP's caching interval and the TTL configured on the previous DNS provider. Once propagation is complete, proceed to the next step.

## Step 5. Add MX records for email

If you plan to send and receive email using your domain, add MX records now. Click **Add record** and select **MX**. Enter the mail server address provided by your email provider and set the priority value as instructed by them.

You can add multiple MX records with different priorities for redundancy.

## Step 6. Update your nameservers

Log in to your domain registrаr and update the domain's nameservers to point to Gcore. After saving the changes, DNS resolution for your domain will be handled by Gcore's infrastructure.

Propagation after a nameserver change can take up to 48 hours. During this time, some users may still be resolved by your previous DNS provider.

## Step 7. Verify the configuration

To confirm that DNS is working, open your domain in a browser. If the web application loads correctly, the configuration is complete.

If the site is not loading, wait a few more minutes and try again. DNS propagation can sometimes take longer depending on your location and ISP.
