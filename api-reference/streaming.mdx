Publish a live broadcast or play an uploaded video, and read who watched it.

The base URL is `https://api.gcore.com/streaming`.

## Live

A broadcast is what viewers open. The stream is the ingest behind it, and a restream sends that ingest somewhere else.

- [Broadcasts](/api-reference/streaming/broadcasts/get-all-broadcasts) — open a live event and read how many people are watching
- [Streams](/api-reference/streaming/streams/get-all-live-streams) — take the ingest, record it, clear the DVR window, and cut a clip
- [Restreams](/api-reference/streaming/restreams/get-all-restreams) — send the ingest to another destination
- [Overlays](/api-reference/streaming/overlays/get-all-overlays) — place a graphic on the live picture

## Uploaded video

A video is the file. Directories organize files, and a player or a playlist is how they are played.

- [Videos](/api-reference/streaming/videos/get-list-of-videos) — upload a file and read whether processing has finished
- [Directories](/api-reference/streaming/directories/get-list-of-directories) — arrange videos in a tree
- [Subtitles](/api-reference/streaming/subtitles/get-all-subtitles) — attach a subtitle track to a video
- [Playlists](/api-reference/streaming/playlists/get-all-playlists) — put videos in an order for playback
- [Players](/api-reference/streaming/players/get-all-players) — configure the built-in player and preview it
- [QualitySets](/api-reference/streaming/qualitysets/get-all-quality-sets) — set the transcoding ladder and which ladder is used by default

## Processing and audience

- [AI](/api-reference/streaming/ai/get-list-of-ai-tasks) — start a processing task, cancel it, and read the result
- [Statistics](/api-reference/streaming/statistics/get-unique-viewers-via-cdn) — read viewers, watch time, storage, and transcoding usage
