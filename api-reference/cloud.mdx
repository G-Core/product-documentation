Create virtual machines, networks, and block storage in a project and region. Kubernetes, databases, functions, containers, and GPU clusters use that same project.

The base URL is `https://api.gcore.com/cloud`.

## Account scope

Most calls need a project and a region. Quotas limit what that project can run, and cost calls report what it spent.

- [Projects](/api-reference/cloud/projects/list-projects) — separate resources and their limits
- [Regions](/api-reference/cloud/regions/list-regions) — see where a resource can be created
- [Quotas](/api-reference/cloud/quotas/get-all-quotas) — read regional and global limits, and the requests opened to raise one
- [Pricing](/api-reference/cloud/pricing/list-gpu-prices) — read the hourly price of a bare metal or virtual GPU
- [Cost&nbsp;reports](/api-reference/cloud/cost-reports/get-monthly-cost-report-totals-commits-and-pay-as-you-go) — read daily and monthly spend, including the cost of each resource
- [Reservations](/api-reference/cloud/reservations/list-reservations) — read committed capacity, the resources in it, and its price
- [Tasks](/api-reference/cloud/tasks/list-tasks) — follow an operation that another request started and see whether it is still running
- [User&nbsp;actions](/api-reference/cloud/user-actions/list-user-actions) — read the log of account changes and subscribe to new entries
- [User&nbsp;role&nbsp;assignments](/api-reference/cloud/user-role-assignments/list-role-assignments) — see which person has which role

## Servers and disks

- [Instances](/api-reference/cloud/instances/list-instances) — create a virtual machine, resize it, and attach a network interface
- [Bare&nbsp;Metal](/api-reference/cloud/bare-metal/list-bare-metal-servers) — order a physical server and select its size
- [Images](/api-reference/cloud/images/list-images) — select or upload the disk image, including an image for a physical server
- [Volumes](/api-reference/cloud/volumes/list-volumes) — attach block storage to a virtual machine
- [Snapshots](/api-reference/cloud/snapshots/list-snapshots) — copy a volume
- [Snapshot&nbsp;schedules](/api-reference/cloud/snapshot-schedules/list-snapshot-policies) — take those copies on a schedule
- [Placement&nbsp;groups](/api-reference/cloud/placement-groups/list-placement-groups) — group virtual machines so the scheduler places them as a set
- [SSH&nbsp;keys](/api-reference/cloud/ssh-keys/list-ssh-keys) — store a public key the server accepts at login

## GPU

- [GPU&nbsp;Virtual](/api-reference/cloud/gpu-virtual/list-virtual-gpu-clusters) — run a cluster of virtual machines with GPUs, including their disks and images
- [GPU&nbsp;Bare&nbsp;Metal](/api-reference/cloud/gpu-bare-metal/list-bare-metal-gpu-clusters) — run a cluster of physical GPU servers
- [Everywhere&nbsp;Inference](/api-reference/cloud/everywhere-inference/list-inference-deployments) — deploy a model and give the deployment a key
- [Everywhere&nbsp;Inference&nbsp;Apps](/api-reference/cloud/everywhere-inference-apps/list-inference-application-deployments) — deploy an application from a catalog template

## Networking

- [Networks](/api-reference/cloud/networks/list-networks) — create a private network and its subnets
- [Routers](/api-reference/cloud/routers/list-routers) — attach a subnet so traffic can leave it
- [Ports](/api-reference/cloud/ports/list-ports) — the interface a server uses on that network
- [Floating&nbsp;IPs](/api-reference/cloud/floating-ips/list-floating-ips) — give a port a public address, and see which addresses are still free
- [Reserved&nbsp;IPs](/api-reference/cloud/reserved-ips/list-reserved-fixed-ips) — hold a fixed address in a subnet and see which ports use it
- [Security&nbsp;groups](/api-reference/cloud/security-groups/list-security-groups) — allow or deny traffic to a server
- [Load&nbsp;balancers](/api-reference/cloud/load-balancers/list-load-balancers) — distribute traffic across members, with listeners, pools, and Layer 7 rules
- [IP&nbsp;ranges](/api-reference/cloud/ip-ranges/list-cloud-egress-public-ips) — the public addresses cloud traffic uses when it leaves the region
- [DDoS&nbsp;Protection](/api-reference/cloud/ddos-protection/list-ddos-protection-profiles) — attach a filtering profile to a cloud resource

## Clusters, containers, and files

- [File&nbsp;shares](/api-reference/cloud/file-shares/list-file-shares) — create shared file storage and set who can mount it
- [Registry](/api-reference/cloud/registry/list-registries) — store container images and control who can pull them
- [Managed&nbsp;Kubernetes](/api-reference/cloud/managed-kubernetes/list-k8s-clusters) — create a cluster, add a node pool, and read which versions can be installed
- [Managed&nbsp;PostgreSQL](/api-reference/cloud/managed-postgresql/list-postgresql-clusters) — create a database cluster
- [Functions](/api-reference/cloud/function-as-a-service/list-functions) — create a namespace and deploy a function into it
- [Containers](/api-reference/cloud/container-as-a-service/list-containers) — run a container and store the registry credentials it uses to pull the image
- [Logging](/api-reference/cloud/logging/list-logging-topics) — read the topics that receive logs and the regions that can store them
- [Secrets](/api-reference/cloud/secrets/list-secrets) — store a value another cloud resource can read
