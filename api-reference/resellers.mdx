Create a customer, change what that customer can use, and read what they owe.

Requests use `https://api.gcore.com`. IAM, CDN, Cloud, FastEdge, WAAP, and Billing each keep their own path prefix.

## Customers

The customer account is created in IAM. The other groups change one product on an account that already exists.

- [IAM](/api-reference/iam-resellers/clients/get-clients) — create a customer, sign in as that customer, and set which products they can see

## One product on an account

- [CDN](/api-reference/cdn-resellers/cdn-service/get-cdn-service) — change a customer's CDN service and select where that traffic is delivered
- [Cloud](/api-reference/cloud-resellers/quotas/list-quota-limit-requests) — approve or reject a request for a higher quota; an approval applies the new limits
- [FastEdge](/api-reference/fastedge-resellers/clients/list-clients) — set the plan that limits a customer's applications, and read those applications
- [WAAP](/api-reference/waap-resellers/pre-billing/get-aggregated-billable-consumption-by-metric) — read how much WAAP each customer consumed, as a total or split by account

## Charges

- [Billing](/api-reference/billing/accounting/list-balances) — read a balance and a charge, change a trial, and download an invoice or a report
