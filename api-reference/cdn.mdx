Serve a site or files from an origin, and set cache, HTTPS, and request logs for that hostname.

The base URL is `https://api.gcore.com/cdn`.

## Delivery

A hostname pulls files from an origin group. A rule or a preset can override cache and security for one path.

- [CDN&nbsp;service](/api-reference/cdn/cdn-service/get-cdn-service-details) — see whether CDN is enabled, which features are on, and the account limits
- [CDN&nbsp;resources](/api-reference/cdn/cdn-resources/get-cdn-resources-list) — create the hostname, set where it pulls from, and change how responses are cached and delivered
- [Origins](/api-reference/cdn/origins/get-origin-groups-list) — group the servers that hold the original files
- [Rules](/api-reference/cdn/rules/get-rules-list) — override settings for one path or file type; an option left unset keeps the resource value
- [Rule&nbsp;templates](/api-reference/cdn/rule-templates/get-rule-templates-list) — save those overrides and apply them to another resource
- [Presets](/api-reference/cdn/presets/get-presets-list) — apply a fixed bundle of options; the included options stay locked until the bundle is removed
- [Aliases](/api-reference/cdn/aliases/get-aliases-list) — serve a second hostname with the same settings and a separate certificate
- [Origin&nbsp;shielding](/api-reference/cdn/origin-shielding/get-origin-shielding-locations) — send origin pulls through one location instead of every edge server

## HTTPS

A resource can use an uploaded certificate, one issued for that hostname, or a CA certificate when the CDN connects to the origin.

- [SSL&nbsp;certificates](/api-reference/cdn/ssl-certificates/get-ssl-certificates-list) — upload a certificate and see which hostnames use it
- [Let's&nbsp;Encrypt&nbsp;certificates](/api-reference/cdn/lets-encrypt-certificates/get-lets-encrypt-certificate-issuing-details) — issue, renew, or revoke a certificate and check whether issuance finished
- [CA&nbsp;certificates](/api-reference/cdn/ca-certificates/get-trusted-ca-certificates-list) — trust a CA when the CDN connects to the origin

## Logs and usage

Request history, exported logs, and consumption figures are separate calls.

- [CDN&nbsp;activity&nbsp;logs](/api-reference/cdn/cdn-activity-logs/get-cdn-activity-logs) — see who changed CDN settings, from the API or the Customer Portal
- [Log&nbsp;viewer](/api-reference/cdn/log-viewer/get-cdn-logs) — read recent requests; the field set and the time range are limited
- [Logs&nbsp;uploader](/api-reference/cdn/logs-uploader/get-policies-list) — send the full request log to external storage, with a format and a destination
- [Statistics](/api-reference/cdn/statistics/cdn-resource-statistics) — read traffic and request series, including shielding, exported logs, and extra hostnames
- [Advanced&nbsp;analytics](/api-reference/cdn/advanced-analytics/playground) — query visitors, traffic, and requests for the last 90 days by country, directory, browser, device, or operating system

## Cache and origin access

- [Tools](/api-reference/cdn/tools/purge-cache) — delete cached files, or load files onto edge servers before anyone requests them
- [Purge&nbsp;history](/api-reference/cdn/purge-history/get-purges-history-list) — see whether a purge finished
- [IP&nbsp;addresses&nbsp;list](/api-reference/cdn/ip-addresses-list/get-cdn-servers-ip-addresses) — the addresses that connect to the origin, for an origin firewall
