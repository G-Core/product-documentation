Run a WebAssembly application at the edge, and give it secrets and key-value data it can read while handling a request.

The base URL is `https://api.gcore.com/fastedge`.

## Deploy

An application points at a binary and holds the settings for that copy. A template is a binary other applications can be created from.

- [Apps](/api-reference/fastedge/apps/list-clients-apps) — deploy the application, set its environment, and read its logs
- [Binaries](/api-reference/fastedge/binaries/list-binaries) — upload the WebAssembly file the application runs
- [Templates](/api-reference/fastedge/templates/list-app-templates) — store a binary that can be the starting point for a new application

## Data the application reads

- [Secrets](/api-reference/fastedge/secrets/list-available-secrets) — store a value the application can read without putting it in the environment
- [Edge&nbsp;Storage](/api-reference/fastedge/edge-storage/list-available-edge-stores) — keep key-value data the application reads at the edge
- [Stats](/api-reference/fastedge/stats/execution-duration-statistics) — read how many calls ran, how long they took, and how much storage they used
- [Clients](/api-reference/fastedge/clients/get-status-and-limits-for-the-client) — read the account limits
