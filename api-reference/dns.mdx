Publish DNS for a domain delegated to Gcore, sign the zone, or serve a copy of a zone that is hosted elsewhere.

The base URL is `https://api.gcore.com/dns`.

## Zones and records

Records belong to a zone. Signing the zone, and copying a zone from another provider, are separate from editing the records.

- [Zones](/api-reference/dns/zones/list-of-zones) — create the domain, turn it on or off, and import or export the zone file
- [RRsets](/api-reference/dns/rrsets/list-of-rrset) — add, change, and remove records, and read when failover switched the answer
- [DNSSEC](/api-reference/dns/dnssec/get-dnssec-ds) — turn signing on and read the DS record to publish at the registrar
- [SecondaryZones](/api-reference/dns/secondaryzones/list-secondary-zones) — pull a zone from named primary servers, and see whether the transfer worked

## Dynamic answers

A record can return a different answer by location or by the network the query came from.

- [Locations](/api-reference/dns/locations/all-locations) — the continents, countries, and regions an answer can target
- [Pickers](/api-reference/dns/pickers/list-of-picker) — the rules that select which answer a query receives
- [NetworkMappings](/api-reference/dns/networkmappings/list-network-mapping) — return an answer based on the client's network
- [Lookup](/api-reference/dns/lookup/lookup) — resolve a name the way the service will
- [Analyze](/api-reference/dns/analyze/check-delegation-status) — check that the registrar delegates the domain here

## Account
