Create S3 or SFTP storage, then control who can read a bucket and how much data the account uses.

The base URL is `https://api.gcore.com/storage`.

## S3 and SFTP

Creating the storage, a bucket, and an access key is one section. CORS, a lifecycle rule, and public access on that bucket are in another.

- [S3-Compatible&nbsp;Storage](/api-reference/storage/s3-compatible-storage/list-s3-compatible-storages) — create the storage, make a bucket, and issue an access key
- [Storage](/api-reference/storage/storage/list-storages) — set CORS, a lifecycle rule, and whether the bucket is public
- [SFTP&nbsp;Storage](/api-reference/storage/sftp-storage/list-sftp-storages) — create storage that accepts SFTP
- [SSHKeys](/api-reference/storage/sshkeys/list-ssh-keys) — add a key and use it to sign in over SFTP

## Where it runs and how much it uses

- [Storage&nbsp;Locations](/api-reference/storage/storage-locations/list-locations) — see where a storage can be placed
- [Notifications](/api-reference/storage/notifications/list-events) — alert when usage, file count, traffic, or request count crosses a threshold
- [Storage&nbsp;Statistics](/api-reference/storage/storage-statistics/storage-usage-series) — read usage over time and the total
