title: Data deletion
description: Data deletion timelines after suspension, an inactivity pause, and a Free Service Period.
---

Gcore deletes a service, its settings, and associated customer data on a timeline that depends on the product and on the reason the service stopped. This timeline applies to an individual product still tied to an active account. Closing the entire account, including all products and personal data at once, is covered separately in [account&nbsp;deletion](/account-settings/account/account-deletion).

A service stops for one of four reasons:

1. The product was [disabled](/account-settings/account/services) manually. This is a suspension.
2. The product is suspended because a payment charge failed. This is a suspension. When one product is suspended for this reason, all other products on the account are also suspended.
3. Gcore places a service without a commitment on an inactivity pause after metering records no consumption. A service with a commitment is not paused for inactivity. A pause is not a suspension. The pause notice states how long the service and its data are kept. The service can be reactivated before that time ends. If it is still paused when the time ends, Gcore deletes the service and its data without a further notice.
4. A Free Service Period ended without a plan enabled. Trial limits are listed in [trial&nbsp;conditions](/account-settings/billing/trial-conditions). The end of a Free Service Period is not a suspension.

## Deletion timelines by product

The reason the service stopped selects the column. Each timeline starts when that state begins: at suspension, at the start of the inactivity pause, or at the end of the Free Service Period. After suspension, Basic VM, Virtual Machines, Volumes, File Shares, and Snapshots are deleted after 14 days. Gcore emails that date and emails again if it changes or the deletion is cancelled. A Bare Metal server on a PAYG plan can be deleted at any time after suspension.

<Warning>
The periods below apply to all Gcore accounts by default. They can differ for a specific account if a personal manager or technical support agrees to a different number of days in advance.

Gcore reserves the right to delete data, including without prior notice, to enforce its rights under the Master Services Agreement, other Gcore documentation, or applicable law.
</Warning>

| Edge Cloud | [Container as a Service](/cloud/caas) | Worker nodes immediately. Attached volumes within 14 days | 30 days | 3 days |

<Note>
An asterisk (*) means Object Storage data can still be manually recovered for 14 days after it is deleted at the end of the 48-hour suspension timeline. That recovery window is separate from the 14 days after a Free Service Period.
</Note>

Standard deletion timelines are subject to change, per the [Master&nbsp;Services&nbsp;Agreement](https://gcore.com/legal) (item 16) and individual product specifications.

## Deleted data by product

Each product deletes a specific set of resources when the timeline in the table ends. A product with no row in this table deletes the service configuration and the customer data stored for that service.

| Product | Feature | Data deleted |
|---------|---------|----------------|
| CDN | - | CDN resources, SSL certificates, created rules, and origin groups |
| Edge Cloud | Managed Kubernetes | Nodes with all data stored locally |
| Edge Cloud | Function as a Service | Created functions |
| Edge Cloud | Container as a Service | Created containers |
| Edge Cloud | GPU SPOT Clusters | Clusters and all nodes with all data stored locally |
| Edge Cloud | Managed Logging | Logs and other data |
| Edge Cloud | Managed PostgreSQL | Databases and other data |
| Edge Cloud | Basic VM, Virtual Machines, Volumes, File Shares, Snapshots | Virtual Machines, Volumes, File Shares, and Snapshots |
| Edge Cloud | Bare Metal, PAYG | Bare Metal servers |
| Object Storage | - | Storages, buckets, and all files and objects |
| Managed DNS | - | Zones and records |
| Video Streaming | - | CDN resources and added media |
| DDoS Protection | - | DDoS profile |
| WAAP | - | Resources under WAAP protection |
