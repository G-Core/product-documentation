Cloud project costs are listed on Cost Report in Cloud Management. Reserved resource costs are listed on Reservation Cost Report in the same section.

## Cost Report

To open the report:

<Steps>
  <Step title="Open Cloud">
    In the [Gcore Customer Portal](https://portal.gcore.com), select **Cloud**.
  </Step>
  <Step title="Open Cost Report">
    In **Cloud Management**, select **Cost Report**.

    <Frame>![Cost Report in Cloud Management with period filters and column headers](/images/docs/account-settings/billing/expenses/cost-report.png)</Frame>
  </Step>
</Steps>

Each row shows the resource name, flavor, region, project, tags, usage, and cost.

Filter by project, region, type, tag, or period (**Last 7 days**, **Last 30 days**, or **Custom**). The chart groups spend by region, type, flavor, or project.

## Reservation Cost Report

**Reservation Cost Report** in **Cloud Management** lists reserved resource costs. Each row shows the resource type, feature name, region, usage, and cost.
