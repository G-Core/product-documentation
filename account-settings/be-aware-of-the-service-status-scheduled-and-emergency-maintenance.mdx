[Status&nbsp;Page](https://status.gcore.com) displays service status, outages, and planned maintenance. Open it directly, or in the [Gcore Customer Portal](https://portal.gcore.com) select the book icon and then **Status page**.

<Frame>![Status page in the book menu](/images/docs/account-settings/be-aware-of-the-service-status-scheduled-and-emergency-maintenance/book-menu-05.png)</Frame>

## Get updates

Click **Get updates** in the upper-right corner.

<Frame>![Get updates menu](/images/docs/account-settings/be-aware-of-the-service-status-scheduled-and-emergency-maintenance/subscribe-sp-10.png)</Frame>

The menu lists Email, Slack, Microsoft Teams, Discord, Google Chat, Webhook, RSS, Atom, and API.

### Email

To subscribe by email:

1. Select **Email**.
2. Enter the address in **Email address**.
3. Keep **Send me all updates**, or select **Let me choose** and pick components. **Select all** selects every component.
4. Click **Subscribe**.

<Frame>![Email subscription form](/images/docs/account-settings/be-aware-of-the-service-status-scheduled-and-emergency-maintenance/email-sp-20.png)</Frame>

The subscription is active. The page shows **You're subscribed**, the address, and the components. **Send me all updates** is shown as **All components**. **Back to status page** returns to the status page.

<Frame>![Email subscription confirmed](/images/docs/account-settings/be-aware-of-the-service-status-scheduled-and-emergency-maintenance/subscribed-30.png)</Frame>

### Slack

To subscribe in Slack:

1. Select **Slack**.
2. Keep **Send me all updates**, or select **Let me choose** and pick components.
3. Click **Get updates on Slack**. Sign in to Slack and complete **Choose where we should post**.

<Frame>![Slack subscription page](/images/docs/account-settings/be-aware-of-the-service-status-scheduled-and-emergency-maintenance/slack-70.png)</Frame>

### Webhook

A webhook subscription sends a JSON request to a URL for each incident and maintenance update.

1. Select **Webhook**.
2. Enter the endpoint in **Webhook URL**. **Send test** becomes available after the URL is entered. **Request settings** sets the method, headers, and signing secret. The default is POST, signed, and no headers.
3. Enter an address in **Email for delivery problems**. Status Page uses that address when the URL stops responding.
4. Keep **Send me all updates**, or select **Let me choose** and pick components.
5. Click **Subscribe**.

**Payload format** describes the JSON for an incident, a maintenance update, and a component update.

<Frame>![Webhook subscription form](/images/docs/account-settings/be-aware-of-the-service-status-scheduled-and-emergency-maintenance/webhook-120.png)</Frame>

Microsoft Teams, Discord, Google Chat, RSS, Atom, and API are available from the same **Get updates** menu.

## Components

Components are grouped by service: Gcore Systems, CDN, Cloud, Cloud AI, Colocation, DDoS Protection, FastEdge, Gclaw, Hosting, Managed DNS, Object Storage, Streaming, WAAP, and Edge Proxy. Hosting is also split by region.

A component shows **Operational**, **Partial outage**, or **Major outage**.
