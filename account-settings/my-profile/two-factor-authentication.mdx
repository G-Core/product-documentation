Two-factor authentication (2FA) asks for a one-time code at login in addition to the password. Turn it on from **My profile** with an authenticator app, and store backup codes for when that app is unavailable.

## Enable two-factor authentication

The setup dialog accepts Google Authenticator or Microsoft Authenticator.

<Steps>
  <Step title="Open My profile">
    In the [Gcore Customer Portal](https://portal.gcore.com), click the avatar in the top-right corner and select **Profile**.
  </Step>
  <Step title="Click Enable 2FA">
    <Frame>
      ![Two-Factor authentication section with the Enable 2FA button](/images/docs/account-settings/my-profile/two-factor-authentication/enable-2fa-button.png)
    </Frame>
  </Step>
  <Step title="Install an authenticator app">
    In the **Enable Two-Factor authentication** dialog, download and install one of the listed apps:

    * Google Authenticator ([iOS](https://itunes.apple.com/app/google-authenticator/id388497605?mt=8), [Android](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2&hl=en))
    * Microsoft Authenticator ([iOS](https://apps.apple.com/app/microsoft-authenticator/id983156458?mt=8), [Android](https://play.google.com/store/apps/details?id=com.azure.authenticator&hl=en))
  </Step>
  <Step title="Scan the QR-code">
    In the authenticator app, scan the code shown under **Scan the QR-code**.
  </Step>
  <Step title="Enter the code and click Check">
    Enter the six-digit code from the app and click **Check**.

    <Frame>
      ![Enable Two-Factor authentication dialog with a QR code](/images/docs/account-settings/my-profile/two-factor-authentication/2fa-qr-dialog.png)
    </Frame>
  </Step>
</Steps>

<Accordion title="Troubleshooting authenticator apps">
If **Check** rejects a code, check the following.

### Check time synchronization

2FA needs the authenticator app and the login device to share the same time. If a correct code is rejected, confirm the date and time and turn on network time synchronization on the login device.

### Check device configuration

If the authenticator app was moved to a new device, confirm that it is set up on that device.
</Accordion>

After **Check** succeeds, 2FA is active for that user.

### Generate backup verification codes

After 2FA is active, the **Two-Factor authentication** section shows an **Enabled** badge, **Disable 2FA**, and **Generate backup code**. Backup codes sign the user in when the authenticator app is unavailable. On the My profile page, click **Generate backup code**.

<Frame>
![Two-Factor authentication section with Disable 2FA and Generate backup code](/images/docs/account-settings/my-profile/two-factor-authentication/2fa-security-section.png)
</Frame>

<Warning>
Each backup code can be used only once. **Generate backup code** replaces the previous set.
</Warning>

The dialog is titled **Copy backup verification codes**. It shows five codes, with **Print**, **Copy**, **Download**, and **Regenerate**. Store the codes before closing the dialog. **Regenerate** replaces the current set.

<Frame>
![Copy backup verification codes dialog](/images/docs/account-settings/my-profile/two-factor-authentication/backup-codes-dialog.png)
</Frame>

## Log in with two-factor authentication

With 2FA active, the [login&nbsp;page](https://auth.gcore.com/login/signin) asks for an authenticator code after the password.

<Steps>
  <Step title="Enter the email and password">
    On the login page, enter the email address and password, then click **Log in**.

    <Frame>
      ![Login page with email, password, and Log in](/images/docs/account-settings/my-profile/two-factor-authentication/login-page.png)
    </Frame>
  </Step>
  <Step title="Enter the verification code">
    On **Enter authenticator passcode**, enter the code from the authenticator app in **Verification code**, or a [backup&nbsp;code](#generate-backup-verification-codes), then click **Log in**.

    <Frame>
      ![Enter authenticator passcode screen](/images/docs/account-settings/my-profile/two-factor-authentication/enter-code-auth.png)
    </Frame>
  </Step>
</Steps>

## Disable two-factor authentication

Disabling 2FA sends a confirmation link to the email address on the account.

<Steps>
  <Step title="Click Disable 2FA">
    On the [My&nbsp;profile](https://portal.gcore.com/accounts/settings/user-profile) page, in the **Two-Factor authentication** section, click **Disable 2FA**.

    <Frame>
      ![My profile page with the Disable 2FA button](/images/docs/account-settings/my-profile/two-factor-authentication/disable-2fa-section.png)
    </Frame>
  </Step>
  <Step title="Confirm the dialog">
    In the confirmation dialog, click **Confirm**. A confirmation link is sent to the email address on the account. The address is masked in the dialog.
  </Step>
  <Step title="Open the confirmation link">
    Open the email and click the confirmation link.
  </Step>
</Steps>

2FA is inactive, and the Customer Portal returns to **My profile**.

<Warning>
The confirmation link is single-use and expires after a short period. If the link has expired or was already used, an error page appears. Return to **My profile** and click **Disable 2FA** to request a new link.
</Warning>

## User 2FA status

The [All&nbsp;users](https://portal.gcore.com/accounts/settings/users) page lists a **Two-Factor authentication** column for each user. Filter that column with **Activated** or **Not activated**.

**Require 2FA for all users in the account** is on the same page. The control states that users without 2FA are asked to set it up the next time they sign in, including users invited later. The switch stays unavailable until 2FA is enabled on the signed-in user's profile, and the tooltip says to enable 2FA in the profile first.
