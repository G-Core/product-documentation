<Info>
SSO accounts authenticated through Microsoft, Google, or GitHub cannot change their password in the Customer Portal. Use the identity provider instead.
</Info>

## Change a password

<Steps>
  <Step title="Open My profile">
    In the [Gcore Customer Portal](https://portal.gcore.com), click the avatar in the top-right corner and select **Profile**.

    <Frame>
      ![Dashboard page with the avatar dropdown open showing Profile, Language, Appearance, and Sign out](/images/docs/account-settings/my-profile/change-password/avatar-menu-profile-option.png)
    </Frame>
  </Step>
  <Step title="Click Change password">
    In the **Password** section, click **Change password**.

    <Frame>
      ![My profile page with the Password section and Change password button](/images/docs/account-settings/my-profile/change-password/change-password-page.png)
    </Frame>
  </Step>
  <Step title="Enter the passwords">
    In the dialog, enter the current password in **Verify current password**, then enter the new password in **New password** and **Confirm new password**.

    <Frame>
      ![Change password dialog with Verify current password, New password, and Confirm new password fields](/images/docs/account-settings/my-profile/change-password/change-password-dialog.png)
    </Frame>
  </Step>
  <Step title="Click Save">
    An email notification confirming the password change is sent to the account's email address.

    <Frame>
      ![Email confirmation of a password change](/images/docs/account-settings/my-profile/change-password/password-change-confirmation.png)
    </Frame>
  </Step>
</Steps>

## Reset a forgotten password

Navigate to the [reset&nbsp;password&nbsp;page](https://auth.gcore.com/login/forgot-password), enter an email address, and click **Reset password**. A link to create a new password is sent to that address.

<Frame>
  ![Password reset page with email field and Reset password button](/images/docs/account-settings/my-profile/change-password/password-reset-form.png)
</Frame>
