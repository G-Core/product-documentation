**My profile** stores settings for the signed-in user. Edits on this page do not change other users on the same Gcore account.

In the [Gcore Customer Portal](https://portal.gcore.com), click the avatar in the top-right corner and select **Profile**.

<Frame>
  ![My profile page in the Customer Portal](/images/docs/account-settings/my-profile/overview/my-profile-overview.png)
</Frame>

## General settings

The General section holds the display name, the login address, and the interface language. **Username** is the name shown in the Customer Portal. **Email** is the address used to sign in and to receive notifications, and it can be changed up to 10 times in one hour. **Language** sets the interface language.

Click **Save** to keep edits to these fields, or **Discard** to drop them.

<Info>
Email address changes are not available for accounts created with Google or GitHub authentication.
</Info>

## Two-factor authentication

[2FA](/account-settings/my-profile/two-factor-authentication) asks for a one-time code at login in addition to the password.

When 2FA is off, the section shows **Enable 2FA**.

<Frame>
  ![Two-factor authentication and Password sections in My profile](/images/docs/account-settings/my-profile/overview/my-profile-security-section.png)
</Frame>

When 2FA is on, the section shows an **Enabled** badge, **Disable 2FA**, and **Generate backup code**. **Generate backup code** creates recovery codes for a lost authenticator app.

<Warning>
Store backup codes in a secure location. If both the authenticator app and the backup codes are unavailable, account recovery requires contacting support.
</Warning>

## Password

A password account updates its password from this section. [Password&nbsp;changes](/account-settings/my-profile/change-password) take effect immediately, and existing sessions stay active until logout.

In the **Password** section, click **Change password**. The dialog asks for **Verify current password**, **New password**, and **Confirm new password**.

<Frame>
  ![Change password dialog with fields for current password, new password, and confirmation](/images/docs/account-settings/my-profile/overview/change-password-dialog.png)
</Frame>

<Info>
**Change password** is unavailable for accounts that sign in with SSO (Microsoft, Google, or GitHub). Those passwords are managed by the identity provider.
</Info>

## Last logins

Last logins lists attempts to sign in to this account, including failed attempts. On an account with several users, only an Administrator sees every user's attempts. Other users see only their own.

Each row is one attempt:

| Column | Description |
|--------|-------------|
| Login date | Date and time of the attempt, in the local timezone of the device |
| IP | Address the attempt came from |
| OS | Operating system of the attempt |
| Browser | Browser of the attempt |
| Success | `true` for a successful login, `false` for a failed attempt |
| User Agent | Browser user agent string. Listed in **Manage Columns** and hidden until selected |

### Login filters

The table filters by date, address, and result:

- **Date range**: **Last 24 hours**, **Last week**, **Last month**, **Last 3 months**, or a custom range
- **IP**: match one address
- **Success**: `true` or `false`

### Filter presets

A saved set of filters can be reapplied from **My Presets**. The menu starts with **Default**.

<Steps>
  <Step title="Apply filters">
    Set the date range, IP address, or success status on the table.
  </Step>
  <Step title="Save the current set">
    Click **My Presets** and select **Save current set as a preset**.

    <Frame>
      ![My Presets dropdown with Save current set as a preset option](/images/docs/account-settings/my-profile/overview/my-presets-dialog.png)
    </Frame>
  </Step>
  <Step title="Name the preset">
    Enter a name, then click **Create**. The preset is then listed in **My Presets**.
  </Step>
</Steps>

### Table display

**Manage Columns** shows or hides columns. **Display Density** sets row spacing to **Large**, **Medium**, or **Small**, and can turn on **Zebra Stripes**.
