<p>In the article, you'll learn how to manage users in the Gcore Customer Portal. You can invite users whether or not they are already registered with Gcore.</p>

## Invite a user

<p>**Note**: Only the user with the [Administrator role](/account-settings/users/about-users) can add new users to the account.</p>

1. Navigate to [Users](https://portal.gcore.com/accounts/settings/users).

2. Click **Invite user**.


<Frame>![A page for inviting users](/images/docs/account-settings/users/manage-users/invite-users-10.png)</Frame>


<p>The following pop-up will appear, where you will perform the remaining steps.</p>


<Frame>![A page where you specify interface language, mail, roles](/images/docs/account-settings/users/manage-users/invite-users-20-v2.png)</Frame>


3. Enter the name of the invited user. The name can be anything; we recommend using first name and surname for ease of use. It will be displayed in the Gcore Customer Portal.

<p>You can invite both existing Gcore users and users who are not yet registered with Gcore:</p>

  * If a user isn't yet in the Gcore system, when you try to add them, an email will be sent to their email address with a link to create a password. The invited user should accept the invitation and create a password. Then, they can log in to the account.
  * If a user already exists in the Gcore system, a notification about the new account access will be sent to their email address. After accepting the invitation, users can log in to their account during authorization.

4. Enter their email address. It will be used to send an invitation to become a user, and for other notifications.

5. Specify the language of the interface: English, German, Chinese, or Russian.

6. Select the CDN service and Customer Portal (IAM) role. Learn more about [which actions are available for each role](/account-settings/users/about-users).

<p>**Note**: Depending on the role selected in IAM/CDN, the role for Edge Cloud will be automatically selected. For example, if you want to create a user with the Administrator CDN role, the user will also have the most access to the Edge Cloud service.</p>

7. Select the scope for the Edge Cloud service. There are two options:

  * **Client**. The scope will be applied to all projects. You can either grant no access or assign the administrator role.
  * **Project**. You set up roles for each project. Select the project in the left part and the role on the right. Learn more about [which actions are available for each role](/cloud/getting-started/projects/users/user-roles-and-rights).

8. For other services (Billing, Managed DNS, Object Storage, Video Streaming, Web Application Security), the invited user will automatically be provided with full permissions (administrator role).

9. Click **Invite user**.

<p>That's it! An entry containing information about the invited user with their unique ID will appear in the [Users](https://portal.gcore.com/accounts/settings/users) section. From there, you can filter invited users by criteria (e.g., two-factor authentication) and search for a specific user by ID or email.</p>

### Sending and resending the invitation

<p>**Note**: The invitation link is valid only for 24 hours. It will expire if users don't confirm their email by clicking the link in that timeframe. Account administrators can resend an invitation on the [Users](https://portal.gcore.com/accounts/settings/users) page by clicking the three dots on the right of the user's row and clicking **Resend invite**.</p>

<p>After the user has been sent an invitation, their user row will show whether they have accepted the invitation ("Status" column) and whether they have enabled two-factor authentication (column "Two-Factor authentication.")</p>


<Frame>![How to resend an invitation to a user](/images/docs/account-settings/users/manage-users/invite-users-30.png)</Frame>


## Change the user's account information

<p>**Note**: Only the user and the account administrator can change the user account information.</p>

  * If you are an account administrator, go to the [Users](https://portal.gcore.com/accounts/settings/users) section. Click three dots next to the user, then click **Edit**.


<Frame>![Edit a user from the Users page](/images/docs/account-settings/users/manage-users/invite-users-40.png)</Frame>


<p>In the pop-up window, you can change your (Administrator) username, Role, and Language. As for other users, you can change only their [Role](/account-settings/users/about-users).</p>

  * If you are a user, edit your info in the General section of the [Account](https://portal.gcore.com/accounts/settings/user-profile) page.


<Frame>![Edit a user on the General page](/images/docs/account-settings/users/manage-users/invite-users-50.png)</Frame>


## Delete a user

<p>Navigate to [Users](https://portal.gcore.com/accounts/settings/users), click the three dots next to the user, then click **Delete**.</p>


<Frame>![How to delete a user](/images/docs/account-settings/users/manage-users/invite-users-60.png)</Frame>


<p>Confirm the deletion.</p>

### Deletion features

  * If a user has roles in several accounts and you want to delete the user from all of them, you should do the steps above from each account.
  * If an [API token](/account-settings/api-tokens) was issued by a user who will be deleted, first delete those tokens before removing the user. Otherwise, an error will appear: "You can't remove the user as they have active tokens."
  * After deleting a user, the tokens they previously issued remain visible in the [API tokens](/account-settings/api-tokens) section with their name and email crossed out. The tokens were deleted in the step above; they remain in the list as historical records. Hovering over their name shows "The user has been deleted":


<Frame>![ API tokens section](/images/docs/account-settings/users/manage-users/deletion-massage-70.png)</Frame>

<p>Manage account users through the IAM API — invite new members, update profiles, change roles, and revoke access.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required for all calls.
</Info>

<p>Set the API key as an environment variable before running the calls:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Get account details

<p>The account ID is required when inviting or deleting users. Retrieve it from the account details endpoint. In the SDK calls below, the ID is captured in a variable; in curl commands, export it as `CLIENT_ID`:</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    account = client.iam.get_account_overview()
    client_id = account.id
    print(f"Account ID: {client_id}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        account, err := client.Iam.GetAccountOverview(ctx)
        if err != nil {
            panic(err)
        }
        clientID := account.ID
        fmt.Printf("Account ID: %d\n", clientID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X GET "https://api.gcore.com/iam/clients/me" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns:</p>

    ```json
    {
      "id": 12345,
      "email": "admin@example.com",
      "companyName": "My Company"
    }
    ```

    <p>Export the returned ID for the curl commands that follow:</p>

    ```bash
    export CLIENT_ID="{ACCOUNT_ID}"
    ```
  </Tab>
</Tabs>

## Invite a user

<p>Sending an invitation emails the new member. Users not yet registered with Gcore receive a link to create a password; users with an existing Gcore account receive a notification about the new access.</p>

<p>Specify the IAM role using its numeric ID and name:</p>

| Role | ID |
|------|----|
| Administrators | 1 |
| Users | 2 |
| Engineers | 5 |
| Purge and Prefetch only (API+Web) | 3009 |
| Purge and Prefetch only (API) | 3022 |

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore
    from gcore.types.iam import UserGroupParam

    client = Gcore()

    account = client.iam.get_account_overview()

    invited = client.iam.users.invite(
        client_id=account.id,
        email="newuser@example.com",
        user_role=UserGroupParam(id=2, name="Users"),
        name="Jane Smith",
        lang="en",
    )
    print(f"Invited user ID: {invited.user_id}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/iam"
        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        account, err := client.Iam.GetAccountOverview(ctx)
        if err != nil {
            panic(err)
        }

        invited, err := client.Iam.Users.Invite(ctx, iam.UserInviteParams{
            ClientID: account.ID,
            Email:    "newuser@example.com",
            UserRole: iam.UserGroupParam{
                ID:   param.NewOpt(int64(2)),
                Name: "Users",
            },
            Name: param.NewOpt("Jane Smith"),
            Lang: "en",
        })
        if err != nil {
            panic(err)
        }
        fmt.Printf("Invited user ID: %d\n", invited.UserID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/iam/clients/invite_user" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "client_id": '"$CLIENT_ID"',
        "email": "newuser@example.com",
        "user_role": {"id": 2, "name": "Users"},
        "name": "Jane Smith",
        "lang": "en"
      }'
    ```

    <p>The API returns:</p>

    ```json
    {
      "status": "sent",
      "user_id": 12346
    }
    ```
  </Tab>
</Tabs>

## List users

<p>Returns all account users. The SDK methods handle pagination internally and return an iterable collection. The curl endpoint accepts a `limit` query parameter to get a paginated response with `count`, `results`, `next`, and `previous` fields.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    # SDK iterates over all users automatically
    for user in client.iam.users.list():
        print(f"ID: {user.id}  email: {user.email}  role: {user.groups[0].name if user.groups else 'none'}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/iam"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        // SDK returns the first page; use Results to iterate
        page, err := client.Iam.Users.List(ctx, iam.UserListParams{})
        if err != nil {
            panic(err)
        }
        for _, user := range page.Results {
            fmt.Printf("ID: %d  email: %s\n", user.ID, user.Email)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/iam/users?limit=50" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns:</p>

    ```json
    {
      "count": 3,
      "next": null,
      "previous": null,
      "results": [
        {
          "id": 12345,
          "email": "admin@example.com",
          "name": "Admin User",
          "lang": "en",
          "groups": [{"id": 1, "name": "Administrators"}],
          "activated": true,
          "two_fa": false
        }
      ]
    }
    ```
  </Tab>
</Tabs>

## Update own profile

<p>Updates the calling user's own display name and interface language. Administrators cannot update other users' names or languages through this endpoint — only their own. To change another user's IAM role, use the role endpoint below.</p>

<p>Available language codes: `en`, `de`, `ru`, `zh`, `az`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    # USER_ID is the calling user's own ID
    updated = client.iam.users.update(
        user_id=12345,
        name="Jane Smith",
        lang="de",
    )
    print(f"Updated: name={updated.name}  lang={updated.lang}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/iam"
        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        // userID is the calling user's own ID
        updated, err := client.Iam.Users.Update(ctx, 12345, iam.UserUpdateParams{
            Name: param.NewOpt("Jane Smith"),
            Lang: "de",
        })
        if err != nil {
            panic(err)
        }
        fmt.Printf("Updated: name=%s  lang=%s\n", updated.Name, updated.Lang)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/iam/users/12345" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "Jane Smith", "lang": "de"}'
    ```

    <p>The API returns the updated user object:</p>

    ```json
    {
      "id": 12345,
      "email": "admin@example.com",
      "name": "Jane Smith",
      "lang": "de"
    }
    ```
  </Tab>
</Tabs>

## Change user role

<p>Changes the IAM role for any account user. Both the numeric role ID and the role name are required. The API returns HTTP 204 with no response body on success.</p>

```bash
curl -X PUT "https://api.gcore.com/iam/clients/$CLIENT_ID/client-users/{USER_ID}" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"user_role": {"id": 5, "name": "Engineers"}}'
```

## Delete a user

<p>Removes a user from the account. If the user is a member of only one account, their Gcore account is deleted entirely. If they are a member of multiple accounts, only access to the current account is revoked.</p>

<Warning>
Delete any active [API&nbsp;tokens](/account-settings/api-tokens) issued by the user before removing them. The API returns an error if the user has active tokens.
</Warning>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    account = client.iam.get_account_overview()
    user_id = 12346   # user ID from list()

    client.iam.users.delete(
        user_id=user_id,
        client_id=account.id,
    )
    print("User removed")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/iam"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        account, err := client.Iam.GetAccountOverview(ctx)
        if err != nil {
            panic(err)
        }

        userID := int64(12346)   // user ID from List()
        err = client.Iam.Users.Delete(ctx, userID, iam.UserDeleteParams{
            ClientID: account.ID,
        })
        if err != nil {
            panic(err)
        }
        fmt.Println("User removed")
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X DELETE "https://api.gcore.com/iam/clients/$CLIENT_ID/client-users/{USER_ID}" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns HTTP 200 with an empty body on success.</p>
  </Tab>
</Tabs>
