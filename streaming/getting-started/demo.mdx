## Players

The demos above embed Gcore's [built-in web player](/streaming/player/customize-appearance-of-the-built-in-player) — a ready-made player that runs in an iframe, requires no coding, and can be embedded on any site or opened directly via a link. Its colors, logo, autoplay, and other appearance options can be customized through the Customer Portal or the REST API.

For full control over playback UI and behavior in your own app, use the [JS Video Player & SDK](/streaming/player/player-api-tutorial) — a fully custom, native JavaScript player (`@gcorevideo/player`) built on hls.js, dash.js, and the native `<video />` element. It supports HLS, LL-HLS, MPEG-DASH, LL-DASH, and MP4, and works with any source URL, including non-Gcore sources.

## More demos and integration examples

These demos are a sample of what the platform supports. [gcore-videoplayer-js](https://github.com/G-Core/gcore-videoplayer-js) is our public GitHub repository for the JS Video Player & SDK — it has the full source code, more demo videos and live streams, and technical explanations for integrating the player into other projects. 

- The repository's [player demo page](https://g-core.github.io/gcore-videoplayer-js/example/player.html) shows a full example of player and API integration into a real web page. 
- To test player configuration options and overrides interactively, use [player-lab](https://g-core.github.io/gcore-videoplayer-js/example/player-lab.html).
