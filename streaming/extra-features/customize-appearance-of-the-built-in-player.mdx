## Main principles

<p>A built-in HTML web player is a ready-made video player provided by the platform. It runs inside an Iframe, so it can be easily embedded into any website or opened directly via a link. For most cases where you just need to show video quickly and reliably, this is the simplest and best option — no coding, no extra setup.</p>

<iframe
  src="https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg?sub_lang=en&t=5s"
  width="100%"
  height="360"
  loading="lazy"
  allow="autoplay; fullscreen; picture-in-picture"
  allowFullScreen />

<p>Direct link to the player: [https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg](https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg)</p>

<p>Functionality of built-in player:</p>

  - Instant playback
  - Supports all web browsers
  - Supports Live streams, and VOD
  - Branding, logo, color customization
  - Statistics of views
  - Embed into any web site via HTML iframe
  - Direct access as HTML web page via direct link

<p>Example code to embed this demo player looks pretty simple:</p>

```
<iframe
  src="https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg?sub_lang=en&t=5s"
  width="100%"
  height="360"
  loading="lazy"
  allow="autoplay; fullscreen; picture-in-picture"
  allowFullScreen
/>
```

<p>For more specific or advanced scenarios — such as fine-grained control over initialization and configuration — it is better to use a JavaScript-based web player that exposes the full player API. This approach requires more development effort but gives maximum flexibility. See the [JS Video Player & SDK](/streaming/api/player-api-tutorial) guide and the live Native JS demo: https://g-core.github.io/gcore-videoplayer-js/example/</p>

## Customization options

<p>Let's compare the default and custom player. To show you the customization options:</p>

  * We set new interface colors.
  * Add a logo (dog icon in the bottom-right corner).
  * Add the button to select the playback speed.
  * Enable the "mute" option by default.

<Frame>![customization options](/images/docs/streaming-platform/extra-features/customize-appearance-of-the-built-in-player/mceclip0.png)</Frame>

<p>1\. Go to the [Players](https://portal.gcore.com/streaming/players/list) tab and click **Create a player**.</p>

<Frame>![Players tab](/images/docs/streaming-platform/extra-features/customize-appearance-of-the-built-in-player/create-player.png)</Frame>

<p>2\. Enter the name of your player (it will be displayed in the Gcore Customer Portal) and click **Create**.</p>

<Frame>![Enter the name of your player](/images/docs/streaming-platform/extra-features/customize-appearance-of-the-built-in-player/mceclip2.png)</Frame>

<p>The configuration page opens. Complete the remaining steps in it.</p>

<Frame>![The configuration page](/images/docs/streaming-platform/extra-features/customize-appearance-of-the-built-in-player/mceclip3.png)</Frame>

<p>3\. Set the custom player as the default one for VOD or/and Live stream if you want to use this player for all videos/streams. You can also choose a custom player for a specific video or stream.</p>

<p>4\. Enable necessary video behavior options:</p>

  * **Autoplay**. If the option is active, a video starts playing automatically when a user opens the website page with it. This option should be enabled if you want to playback [Live imitation](/streaming/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos) automatically.

  * **Mute**. If the option is active, video plays with the sound off.

<Info>
If both Autoplay and Mute options are active, only one option will work. It depends on an end user's browser policy ([Mozilla](https://developer.mozilla.org/en-US/docs/Web/Media/Autoplay_guide), [Chrome](https://developer.chrome.com/blog/autoplay)).
</Info>

<p>5\. Enable necessary player control options:</p>

  * **Disable skin**. If the option is active, the player control elements are hidden.
  * **Save user settings.** If the option is active, users watch the video with the same quality and sound settings they have had previously. It works until the browser cache gets cleared.
  * **Share video.** If the option is active, a sharing button appears in the upper-right corner of the video for the users to post it to social networks.
  * **Playback speed control.** If the option is active, users can slow down and speed up VOD playback.
  * **Pause when clicking on player.** If the option is active, video stops by clicking at any point on the player's screen.

<p>6\. Select colors for different elements of your player:</p>

  * Background color for the bottom panel of the player.
  * Foreground color for the elements on the bottom panel.
  * Text color for timeline.
  * Hover color for those elements on the bottom panel that the cursor is hovering over.

<p>7\. To collect data on your viewers' actions in the player, activate the Enables Google Analytics option and specify your Google Analytics ID.</p>

<p>8\. Add a logo that will be displayed on the screen.</p>

<p>9\. Select the logo position.</p>

<p>10\. Save changes.</p>

## Embed into a web page


### Embed via iframe

<p>Just copy value if `Iframe embed code` field from Live and VOD page in UI Customer Portal and insert into your web page on Wordpress, Wix, etc.</p>

<p>Example:</p>

```
<iframe width="100%" src="https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog" frameborder="0" allow="fullscreen; autoplay; encrypted-media" allowfullscreen></iframe>
```

### Use direct link

<p>Just copy value if `Iframe embed code` field from Live and VOD page in UI Customer Portal and insert into your web page on Wordpress, Wix, etc.</p>

<p>Example (copy-paste into your browser):</p>

```
https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog
```
<p>It will open a new web page: <a target="_blank" href="https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog">click here</a></p>


## Customize player behavior using query string

<p>You can make real-time adjustments to the player's functionality by adding the following parameters to the player's URL:</p>

  * `?no_low_latency`
  * `?t=(time)`
  * `?sub_lang=(language)`

### ?no_low_latency

<p>Use this parameter to ensure that the player uses non-low-latency streams HLS MPEG-TS instead of MPEG-DASH CMAF or LL-HLS CMAF. This parameter takes no arguments. Applicable only for Lives.</p>

<p>Example: `https://player.gvideo.co/broadcasts/2675_21606?no_low_latency`</p>

### ?t=(time)

<p>Set time to rewind from the beginning of play. Applicable only for VOD.</p>

<p>This parameter takes two arguments:</p>

| **Argument**                               | **Description**                                          | **Example**                                                                                                            |
|--------------------------------------------|----------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------|
| `t = (integer)`                            | Number of seconds to start playing from.                 | `t=15`<br/><br/><code>https://player.gvideo.co/videos/2675_iKbrdNMcS9ylGuw?t=15</code>                                   |
| `t = [(integer)h][(integer)m][(integer)s]` | Set start time point in HMS format, where h = hours, m = minutes, s = seconds. | `t=1h30m, 34m, 2m30s`<br/><br/><code>https://player.gvideo.co/videos/2675_iKbrdNMcS9ylGuw?t=1m2s</code> |
  
  
### ?sub_lang=(language)

<p>Display subtitles in a specific language. Applicable only for VOD.</p>

<p>This parameter takes the following argument:</p>

| **Argument**                                 | **Description**                                             | **Example**                                                                                                           |
|----------------------------------------------|-------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| `sub_lang = (ISO language code, 2 letters)`  | Use two letters that correspond to the [ISO 639 language codes](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes). | `sub_lang=de`<br/><br/><code>https://player.gvideo.co/videos/2675_iKbrdNMcS9ylGuw?sub_lang=de</code> |

<p>Please note that here a simplified 2-symbol language code is indicated as more understandable to the average user (while in the API 3 symbols are used everywhere for internal needs).</p>

## Create a player

<p>Send `POST /streaming/players` with a `name` and any customization fields. The API returns the full player object including the generated `id`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
client.streaming.players.create(
    player={
        "name": "My custom player",
        "speed_control": True,
        "mute": False,
        "bg_color": "#000000",
        "fg_color": "#FFFFFF",
        "hover_color": "#ef9047",
    }
)
# The SDK create method does not return the new player.
# Retrieve the player id using list().
players = list(client.streaming.players.list())
player = next(p for p in players if p.name == "My custom player")
print(f"Player ID: {player.id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    err := client.Streaming.Players.New(ctx, streaming.PlayerNewParams{
        Player: streaming.PlayerParam{
            Name:         "My custom player",
            SpeedControl: param.NewOpt(true),
            Mute:         param.NewOpt(false),
            BgColor:      param.NewOpt("#000000"),
            FgColor:      param.NewOpt("#FFFFFF"),
            HoverColor:   param.NewOpt("#ef9047"),
        },
    })
    if err != nil {
        panic(err)
    }
    // The SDK New method does not return the new player.
    // Retrieve the player id using List.
    page, err := client.Streaming.Players.List(ctx, streaming.PlayerListParams{})
    if err != nil {
        panic(err)
    }
    for _, p := range page.Items {
        if p.Name == "My custom player" {
            fmt.Printf("Player ID: %d\n", p.ID)
            break
        }
    }
}
```
  </Tab>

## Update player settings

<p>Use `PATCH /streaming/players/{player_id}` to update any field. Returns the full updated player object.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

player_id = int(os.environ["PLAYER_ID"])

client = Gcore()
player = client.streaming.players.update(
    player_id=player_id,
    player={
        "name": "My custom player",
        "speed_control": True,
        "autoplay": True,
        "mute": True,
        "logo": "https://example.com/logo.png",
        "logo_position": "br",
    },
)
print(f"Name:          {player.name}")
print(f"Speed control: {player.speed_control}")
print(f"Logo:          {player.logo}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    playerID, _ := strconv.ParseInt(os.Getenv("PLAYER_ID"), 10, 64)

    client := gcore.NewClient()
    ctx := context.Background()

    player, err := client.Streaming.Players.Update(ctx, playerID,
        streaming.PlayerUpdateParams{
            Player: streaming.PlayerParam{
                Name:         "My custom player",
                SpeedControl: param.NewOpt(true),
                Autoplay:     param.NewOpt(true),
                Mute:         param.NewOpt(true),
                Logo:         param.NewOpt("https://example.com/logo.png"),
                LogoPosition: param.NewOpt("br"),
            },
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("Name:          %s\n", player.Name)
    fmt.Printf("Speed control: %v\n", player.SpeedControl)
    fmt.Printf("Logo:          %v\n", player.Logo)
}
```
  </Tab>
  <Tab title="curl">
```bash

             "logo_position": "br"

```

## Delete a player

<p>Send `DELETE /streaming/players/{player_id}`. Returns HTTP 204 with no body on success.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

player_id = int(os.environ["PLAYER_ID"])

client = Gcore()
client.streaming.players.delete(player_id)
print("Player deleted.")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    playerID, _ := strconv.ParseInt(os.Getenv("PLAYER_ID"), 10, 64)

    client := gcore.NewClient()
    ctx := context.Background()

    err := client.Streaming.Players.Delete(ctx, playerID)
    if err != nil {
        panic(err)
    }
    fmt.Println("Player deleted.")
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X DELETE "https://api.gcore.com/streaming/players/$PLAYER_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
