## Overview

A built-in HTML web player is a ready-made video player provided by Gcore. It runs inside an iframe, so it can be embedded into any website or opened directly via a link. For most use cases, this option requires no coding and no extra setup.

<iframe
  src="https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg?sub_lang=en&t=5s"
  width="100%"
  height="360"
  loading="lazy"
  allow="autoplay; fullscreen; picture-in-picture"
  allowFullScreen />

Direct link to the player: [https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg](https://player.gvideo.co/videos/2675_de6eWEOdUoCe77cg)

The player works for both live streams and VOD, supports branding (colors, logo), and collects view statistics. To embed it, copy the iframe snippet from the video settings page (see [Embed into a web page](#embed-into-a-web-page)).

For advanced scenarios such as fine-grained control over initialization and playback, use the [JS Video Player & SDK](/streaming/api/player-api-tutorial) instead.

## Create and configure a player

The example below shows a customized player with new interface colors, a logo in the bottom-right corner, and the playback speed control enabled.

<Frame>![Player customization example](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/player-customization-example.png)</Frame>

1. Go to the [Players](https://portal.gcore.com/streaming/players/list) tab and click **Create a player**.

<Frame>![Players tab with Create a player button](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/create-player.png)</Frame>

2. Enter the player title (it is displayed in the Gcore Customer Portal) and click **Create**.

<Frame>![Create a player dialog](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/create-player-dialog.png)</Frame>

The **Player settings** page opens. Complete the remaining steps on this page.

<Frame>![Player settings page](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/player-settings.png)</Frame>

3. To use this player for all videos or streams, enable **Set as default for VOD** or **Set as default for Live**. To assign a player to a specific video or stream, open that video or stream settings and select the player there.

4. Configure video behavior options:

  * **Autoplay**: the video starts playing automatically when a user opens the page. Enable this option to autoplay [Live imitation](/streaming/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos) videos.
  * **Mute**: the video plays with sound off.

<Info>
If both Autoplay and Mute are enabled, only one takes effect, depending on the browser's autoplay policy. See [Mozilla](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) and [Chrome](https://developer.chrome.com/blog/autoplay) documentation.
</Info>

5. Configure player control options:

  * **Disable Skin**: hides all player control elements.
  * **Save user settings**: retains each user's volume and quality settings between sessions until the browser cache is cleared.
  * **Share video**: shows a sharing button in the upper-right corner so users can post the video to social networks.
  * **Playback speed control**: lets users slow down or speed up VOD playback.
  * **Pause when clicking on player**: pauses the video when a user clicks anywhere on the player.

6. Select colors for the player interface elements:

  * **Background color**: bottom panel background.
  * **Foreground color**: icons and controls on the bottom panel.
  * **Text color**: timeline labels.
  * **Hover color**: bottom panel elements on hover.

7. Upload a logo to display on the player. The logo must be a PNG file no larger than 1 MB.

8. Select the logo position.

9. Click **Save changes**.

## Embed into a web page

### Embed via iframe

Open the video or live stream settings page in the Customer Portal. Copy the value of the **Iframe embed code** field and paste it into the web page.

Example:

```html
<iframe width="100%" src="https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog" frameborder="0" allow="fullscreen; autoplay; encrypted-media" allowfullscreen></iframe>
```

### Use direct link

Open the video or live stream settings page in the Customer Portal. Copy the value of the **Video page URL** field and paste it into a browser or share it directly.

Example:

```text
https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog
```

Opening the URL displays the video on a standalone player page: [https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog](https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog)

## Customize player behavior using query string

Append the following parameters to the player URL to control playback behavior at runtime:

  * `?no_low_latency`
  * `?t=(time)`
  * `?sub_lang=(language)`

### ?no_low_latency

Forces the player to use non-low-latency HLS MPEG-TS streams instead of MPEG-DASH CMAF or LL-HLS CMAF. This parameter takes no arguments. Applicable to live streams only.

Example: `https://player.gvideo.co/broadcasts/2675_21606?no_low_latency`

### ?t=(time)

Sets the start time offset from the beginning of the video. Applicable to VOD only.

This parameter accepts two argument formats:

| **Argument**                               | **Description**                                          | **Example**                                                                                                            |
|--------------------------------------------|----------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------|
| `t = (integer)`                            | Number of seconds to start playing from.                 | `t=15`<br/><br/><code>https://player.gvideo.co/videos/2675_iKbrdNMcS9ylGuw?t=15</code>                                   |
| `t = [(integer)h][(integer)m][(integer)s]` | Set start time point in HMS format, where h = hours, m = minutes, s = seconds. | `t=1h30m, 34m, 2m30s`<br/><br/><code>https://player.gvideo.co/videos/2675_iKbrdNMcS9ylGuw?t=1m2s</code> |

### ?sub_lang=(language)

Displays subtitles in the specified language. Applicable to VOD only.

This parameter accepts the following argument:

| **Argument**                                 | **Description**                                             | **Example**                                                                                                           |
|----------------------------------------------|-------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| `sub_lang = (ISO language code, 2 letters)`  | Two-letter [ISO 639-1 language code](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes). | `sub_lang=de`<br/><br/><code>https://player.gvideo.co/videos/2675_iKbrdNMcS9ylGuw?sub_lang=de</code> |

The player uses a simplified 2-letter language code. The API uses 3-letter codes internally.

A built-in player is a hosted HTML video player that can be embedded in any web page via an iframe or opened as a direct URL. Configure its colors, logo, autoplay, mute, and speed controls by creating a player via the API.

## Create a player

Send `POST /streaming/players` with a `name` and any customization fields. The API returns the full player object including the generated `id`. The Python and Go SDKs do not return the new player — retrieve the `id` by calling `list()` after creation.

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Player name (required) |
| `autoplay` | bool | Start playing on page load. Default: `false` |
| `mute` | bool | Start with sound off. Default: `false` |
| `disable_skin` | bool | Hide all player controls. Default: `false` |
| `save_options_to_cookies` | bool | Persist volume and quality settings between sessions. Default: `true` |
| `show_sharing` | bool | Show sharing button. Default: `true` |
| `speed_control` | bool | Show playback speed selector (VOD only). Default: `false` |
| `bg_color` | string | Bottom panel background color in `#RRGGBB` format |
| `fg_color` | string | Bottom panel element color in `#RRGGBB` format |
| `text_color` | string | Timeline text color in `#RRGGBB` format |
| `hover_color` | string | Hover color for bottom panel elements in `#RRGGBB` format |
| `logo_position` | string | Logo position: `tl`, `tr`, `bl`, `br` |

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
client.streaming.players.create(
    player={
        "name": "My custom player",
        "autoplay": False,
        "mute": False,
        "disable_skin": False,
        "save_options_to_cookies": True,
        "show_sharing": True,
        "speed_control": True,
        "bg_color": "#000000",
        "fg_color": "#FFFFFF",
        "text_color": "#CCCCCC",
        "hover_color": "#ef9047",
    }
)
# create() returns None — retrieve the id using list()
players = list(client.streaming.players.list())
player = next(p for p in players if p.name == "My custom player")
print(f"Player ID: {player.id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    err := client.Streaming.Players.New(ctx, streaming.PlayerNewParams{
        Player: streaming.PlayerParam{
            Name:                 "My custom player",
            Autoplay:             param.NewOpt(false),
            Mute:                 param.NewOpt(false),
            DisableSkin:          param.NewOpt(false),
            SaveOptionsToCookies: param.NewOpt(true),
            ShowSharing:          param.NewOpt(true),
            SpeedControl:         param.NewOpt(true),
            BgColor:              param.NewOpt("#000000"),
            FgColor:              param.NewOpt("#FFFFFF"),
            TextColor:            param.NewOpt("#CCCCCC"),
            HoverColor:           param.NewOpt("#ef9047"),
        },
    })
    if err != nil {
        panic(err)
    }
    // New() returns no player object — retrieve the id using List
    page, err := client.Streaming.Players.List(ctx, streaming.PlayerListParams{})
    if err != nil {
        panic(err)
    }
    for _, p := range page.Items {
        if p.Name == "My custom player" {
            fmt.Printf("Player ID: %d\n", p.ID)
            break
        }
    }
}
```

## Update player settings

Use `PATCH /streaming/players/{player_id}` to update any field. Returns the full updated player object. In the Go SDK, `Name` is always required — read the current name with `Get()` before calling `Update()`.

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

player_id = int(os.environ["PLAYER_ID"])

client = Gcore()
player = client.streaming.players.update(
    player_id=player_id,
    player={
        "speed_control": True,
        "mute": False,
        "bg_color": "#1a1a2e",
        "hover_color": "#ef9047",
    },
)
print(f"Name:          {player.name}")
print(f"Speed control: {player.speed_control}")
print(f"BG color:      {player.bg_color}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    playerID, _ := strconv.ParseInt(os.Getenv("PLAYER_ID"), 10, 64)

    client := gcore.NewClient()
    ctx := context.Background()

    // Name is required for Update — read it first
    existing, err := client.Streaming.Players.Get(ctx, playerID)
    if err != nil {
        panic(err)
    }

    player, err := client.Streaming.Players.Update(ctx, playerID,
        streaming.PlayerUpdateParams{
            Player: streaming.PlayerParam{
                Name:         existing.Name,
                SpeedControl: param.NewOpt(true),
                Mute:         param.NewOpt(false),
                BgColor:      param.NewOpt("#1a1a2e"),
                HoverColor:   param.NewOpt("#ef9047"),
            },
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("Name:          %s\n", player.Name)
    fmt.Printf("Speed control: %v\n", player.SpeedControl)
    fmt.Printf("BG color:      %v\n", player.BgColor)
}
```

## Delete a player

Send `DELETE /streaming/players/{player_id}`. Returns HTTP 204 with no body on success.

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

player_id = int(os.environ["PLAYER_ID"])

client = Gcore()
client.streaming.players.delete(player_id)
print("Player deleted.")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    playerID, _ := strconv.ParseInt(os.Getenv("PLAYER_ID"), 10, 64)

    client := gcore.NewClient()
    ctx := context.Background()

    err := client.Streaming.Players.Delete(ctx, playerID)
    if err != nil {
        panic(err)
    }
    fmt.Println("Player deleted.")
}
```
  </Tab>

```bash
curl -X DELETE "https://api.gcore.com/streaming/players/$PLAYER_ID" \
```
