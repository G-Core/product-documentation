<p>A built-in HTML web player is a ready-made video player provided by Gcore. It runs inside an iframe, so it can be embedded into any website or opened directly via a link. For most use cases, this option requires no coding and no extra setup.</p>

<p>The player works for both live streams and VOD, supports branding (colors, logo), and collects view statistics. To embed it, copy the iframe snippet from the video settings page — [embedding&nbsp;instructions&nbsp;below](#embed-into-a-web-page).</p>

<p>For fine-grained control over initialization and playback, the [player&nbsp;SDK](/streaming/api/player-api-tutorial) provides a JavaScript API instead.</p>

## Create and configure a player

<p>The example below shows a customized player with new interface colors, a logo in the bottom-right corner, and the playback speed control enabled.</p>

<Frame>![Player customization example](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/player-customization-example.png)</Frame>

<Steps>
  <Step title="Open the Players tab">
    Navigate to the [Players](https://portal.gcore.com/streaming/players/list) tab and click **Create a player**.

    <Frame>![Players tab with Create a player button](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/create-player.png)</Frame>
  </Step>

  <Step title="Create the player">
    Enter the player title (it is displayed in the Gcore Customer Portal) and click **Create**.

    <Frame>![Create a player dialog](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/create-player-dialog.png)</Frame>

    The **Player settings** page opens.

    <Frame>![Player settings page](/images/docs/streaming/player/customize-appearance-of-the-built-in-player/player-settings.png)</Frame>
  </Step>

  <Step title="(Optional) Set as default">
    To use this player for all videos or streams, enable **Set as default for VOD** or **Set as default for Live**. To assign a player to a specific video or stream, open that video or stream settings and select the player there.
  </Step>

  <Step title="Configure appearance and behavior">
    Options include interface colors, a PNG logo up to 1 MB with configurable position, playback speed controls (VOD only), autoplay, and mute. To autoplay [Live&nbsp;imitation](/streaming/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos) videos, enable **Autoplay**.

    <Info>
    Browser autoplay policies affect whether playback starts automatically. Muted autoplay is generally less restricted. [Mozilla](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) and [Chrome](https://developer.chrome.com/blog/autoplay) document their policies.
    </Info>
  </Step>

  <Step title="Save changes">
  </Step>
</Steps>

<p>After saving, copy the embed code from the video or live stream settings page to add the player to a web page.</p>

## Embed into a web page

### Embed via iframe

<p>Open the video or live stream settings page in the Customer Portal. Copy the value of the **Iframe embed code** field and paste it into the web page.</p>

<p>Example:</p>

```html
<iframe width="100%" src="https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog" frameborder="0" allow="fullscreen; autoplay; encrypted-media" allowfullscreen></iframe>
```

### Use direct link

<p>Open the video or live stream settings page in the Customer Portal. Copy the value of the **Video page URL** field and paste it into a browser or share it directly.</p>

<p>Example:</p>

```text
https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog
```

<p>Opening the URL displays the video on a standalone player page: [https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog](https://player.gvideo.co/videos/2675_mvsPGvDVx0Hzbog)</p>

## Customize player behavior using query string

<p>Append the following parameters to the player URL to control playback behavior at runtime.</p>

| Parameter | Applies to | Description | Example |
|-----------|------------|-------------|---------|
| `?no_low_latency` | Live | Uses non-low-latency HLS MPEG-TS instead of MPEG-DASH CMAF or LL-HLS CMAF. Takes no arguments. | `...?no_low_latency` |
| `?t=(time)` | VOD | Starts playback at the specified offset. Accepts seconds (`t=15`) or HMS format (`t=1h30m`, `t=2m30s`). | `...?t=1m2s` |
| `?sub_lang=(code)` | VOD | Displays subtitles in the specified two-letter [ISO&nbsp;639-1 code](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes). | `...?sub_lang=de` |

</MethodSection>

## Create a player

<p>Send `POST /streaming/players` with a `name` and any customization fields. The API returns the full player object including the generated `id`. The Python and Go SDKs do not return the new player — retrieve the `id` by calling `list()` after creation.</p>

<p>The examples below create a customized player and configure its playback controls and interface colors.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
client.streaming.players.create(
    player={
        "name": "My custom player",
        "autoplay": False,
        "mute": False,
        "disable_skin": False,
        "save_options_to_cookies": True,
        "show_sharing": True,
        "speed_control": True,
        "bg_color": "#000000",
        "fg_color": "#FFFFFF",
        "text_color": "#CCCCCC",
        "hover_color": "#ef9047",
    }
)
# create() returns None — retrieve the id using list()
players = list(client.streaming.players.list())
player = next(p for p in players if p.name == "My custom player")
print(f"Player ID: {player.id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    err := client.Streaming.Players.New(ctx, streaming.PlayerNewParams{
        Player: streaming.PlayerParam{
            Name:                 "My custom player",
            Autoplay:             param.NewOpt(false),
            Mute:                 param.NewOpt(false),
            DisableSkin:          param.NewOpt(false),
            SaveOptionsToCookies: param.NewOpt(true),
            ShowSharing:          param.NewOpt(true),
            SpeedControl:         param.NewOpt(true),
            BgColor:              param.NewOpt("#000000"),
            FgColor:              param.NewOpt("#FFFFFF"),
            TextColor:            param.NewOpt("#CCCCCC"),
            HoverColor:           param.NewOpt("#ef9047"),
        },
    })
    if err != nil {
        panic(err)
    }
    // New() returns no player object — retrieve the id using List
    page, err := client.Streaming.Players.List(ctx, streaming.PlayerListParams{})
    if err != nil {
        panic(err)
    }
    for _, p := range page.Items {
        if p.Name == "My custom player" {
            fmt.Printf("Player ID: %d\n", p.ID)
            break
        }
    }
}
```

## Update player settings

<p>Use `PATCH /streaming/players/{player_id}` to update any field. Returns the full updated player object. In the Go SDK, `Name` is always required — read the current name with `Get()` before calling `Update()`. The `logo_position` field accepts `tl`, `tr`, `bl`, or `br` (top-left, top-right, bottom-left, bottom-right).</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

player_id = int(os.environ["PLAYER_ID"])

client = Gcore()
player = client.streaming.players.update(
    player_id=player_id,
    player={
        "speed_control": True,
        "mute": False,
        "bg_color": "#1a1a2e",
        "hover_color": "#ef9047",
    },
)
print(f"Name:          {player.name}")
print(f"Speed control: {player.speed_control}")
print(f"BG color:      {player.bg_color}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    playerID, _ := strconv.ParseInt(os.Getenv("PLAYER_ID"), 10, 64)

    client := gcore.NewClient()
    ctx := context.Background()

    // Name is required for Update — read it first
    existing, err := client.Streaming.Players.Get(ctx, playerID)
    if err != nil {
        panic(err)
    }

    player, err := client.Streaming.Players.Update(ctx, playerID,
        streaming.PlayerUpdateParams{
            Player: streaming.PlayerParam{
                Name:         existing.Name,
                SpeedControl: param.NewOpt(true),
                Mute:         param.NewOpt(false),
                BgColor:      param.NewOpt("#1a1a2e"),
                HoverColor:   param.NewOpt("#ef9047"),
            },
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("Name:          %s\n", player.Name)
    fmt.Printf("Speed control: %v\n", player.SpeedControl)
    fmt.Printf("BG color:      %v\n", player.BgColor)
}
```

## Delete a player

<p>Send `DELETE /streaming/players/{player_id}`. Returns HTTP 204 with no body on success.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

player_id = int(os.environ["PLAYER_ID"])

client = Gcore()
client.streaming.players.delete(player_id)
print("Player deleted.")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    playerID, _ := strconv.ParseInt(os.Getenv("PLAYER_ID"), 10, 64)

    client := gcore.NewClient()
    ctx := context.Background()

    err := client.Streaming.Players.Delete(ctx, playerID)
    if err != nil {
        panic(err)
    }
    fmt.Println("Player deleted.")
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X DELETE "https://api.gcore.com/streaming/players/$PLAYER_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
