<p>Four delivery formats are available for video-on-demand. The format decides the manifest, the container, and whether playback is adaptive or a single file.</p>

| Format | Use it for |
| --- | --- |
| HLS MPEG-TS | H.264 playback with broad device support |
| HLS CMAF | HLS playback when the video also has HEVC or AV1 renditions |
| MPEG-DASH | Adaptive playback from one manifest, mainly on Android and Windows |
| MP4 | One file per rendition, for playback or download |

## Playback links

<p>Video settings include the player URL, the default HLS playlist, and an iframe snippet.</p>

<p>1. In the [Gcore Customer Portal](https://portal.gcore.com/streaming/video/list), navigate to **Streaming** > **Video Hosting**.</p>

<p>2. Open the video.</p>

<Frame>![Video settings with export links and a visible poster](/images/docs/streaming/video-hosting/hls-and-mp4/export-video-links.png)</Frame>

<p>3. In the **Links for the export** section, copy the relevant link:</p>

  * **Video page URL**: Web player URL for the video.
  * **HLS manifest URL**: The default HLS master playlist (`master.m3u8`). Packaging is MPEG-TS for an H.264-only video and CMAF when HEVC or AV1 renditions are present.
  * **Iframe embed code**: HTML for an iframe player.

<p>The MPEG-DASH manifest uses the <code>master.mpd</code> pattern in [URL&nbsp;modifiers](#manifest-url-modifiers). An MP4 file is downloaded from **Download video** on the same page. Download options are in [MP4&nbsp;downloads](/streaming/video-hosting/download-mp4-files).</p>

## HLS TS and CMAF formats

<p>HTTP Live Streaming (HLS) delivers video as short segments. A player switches quality as the connection changes. Segments are 2 to 6 seconds and are cached on the CDN. HLS supports AES-128 encryption and major DRM systems.</p>

<p>H.264 in an MPEG-TS container is limited to High Profile [level&nbsp;4.1](https://en.wikipedia.org/wiki/Advanced_Video_Coding#Levels). HEVC and AV1 are not carried in that container.</p>

<p><code>hls_url</code> is the default master playlist (<code>master.m3u8</code>). <code>hls_cmaf_url</code> is the CMAF master playlist (<code>master-cmaf.m3u8</code>). CMAF chunks use fragmented MP4, so the playlist can include H.264, HEVC, and AV1.</p>

<p>Packaging follows the codecs on the video:</p>

  * <code>master.m3u8</code> uses MPEG-TS when the video has H.264 only.
  * <code>master.m3u8</code> uses CMAF when the video also has HEVC or AV1. Apple devices do not play HEVC or AV1 in an MPEG-TS container, and those codecs are not standardized in TS.
  * <code>master-cmaf.m3u8</code> always uses CMAF chunks.

<p>Public demo playlists:</p>

  - https://demo-public.gvideo.io/videos/2675_FnlHXwA16ZMxmUr/master.m3u8
  - https://demo-public.gvideo.io/videos/2675_FnlHXwA16ZMxmUr/master-cmaf.m3u8

## DASH format

<p>Dynamic Adaptive Streaming over HTTP (DASH) uses one manifest for adaptive playback. Players on Android and Windows commonly request it. A player can switch quality during playback. DASH works with multiple DRM systems.</p>

<p>The manifest (<code>.mpd</code>) lists segments, quality levels, bitrates, and the order in which a player requests each segment.</p>

<p>The chunk container follows the video codec:</p>

  - CMAF for H.264 and HEVC
  - WebM for AV1

<p>WebM output:</p>

```xml
... 
    <AdaptationSet 
        id="1" 
        segmentAlignment="true" 
        maxWidth="3840" 
        maxHeight="2160" 
        maxFrameRate="45000/751"> 
        <SegmentTemplate 
            timescale="1000" 
            media="dash-segment-$Number$-$RepresentationID$.webm" 
            initialization="dash-init-$RepresentationID$.webm" 
            startNumber="1"> 
... 
        </SegmentTemplate> 
      <Representation 
          id="f1-v1-x3" 
          mimeType="video/webm" 
          codecs="av01.0.13M.08" 
          width="3840" 
          height="2160" 
          frameRate="45000/751" 
          sar="1:1" 
          startWithSAP="1"  
```

<p>Public demo manifest: https://demo-public.gvideo.io/videos/2675_FnlHXwA16ZMxmUr/master.mpd</p>

## Manifest URL modifiers

<p>Optional suffixes change the master URL. The full HLS pattern is:</p>

```sh
https://domain.com/videos/{client_id}_{video_slug}/master[-cmaf][-min-N][-max-N][-img][-(h264|hevc|av1)].m3u8
```

<p>The full MPEG-DASH pattern is:</p>

```sh
https://domain.com/videos/{client_id}_{video_slug}/master[-min-N][-max-N][-(h264|hevc|av1)].mpd
```

<p>Where:</p>

  * <code>{"{client_id}"}</code>: Account ID.
  * <code>{"{video_slug}"}</code>: Video slug.
  * <code>[-cmaf]</code>: HLS CMAF playlist, the same target as <code>hls_cmaf_url</code>. The field is documented in [video&nbsp;list](/api-reference/streaming/videos/get-list-of-videos).
  * <code>[-min-N]</code> and <code>[-max-N]</code>: Limit the resolutions included in the manifest. Rules are in [quality&nbsp;range](#manifest-quality-range).
  * <code>[-img]</code>: Adds a thumbnail image stream for [Roku&nbsp;trick&nbsp;play](/streaming/video-hosting/timeline-hover-previews-use-in-players-and-roku-devices#roku-trick-play).
  * <code>[-(h264|hevc|av1)]</code>: Limits the manifest to one codec family when the video was transcoded to more than one codec.

## MP4 files

<p>Each rendition is also a single MP4 file named <code>quality_version_codec_bitrate_height.mp4</code>. A 720p file from the public demo is https://demo-public.gvideo.io/videos/2675_FnlHXwA16ZMxmUr/qid3570v3_h264_1566_720.mp4</p>

<p>Download, a custom filename, a speed limit, a secure token, and a byte range are covered in [MP4&nbsp;downloads](/streaming/video-hosting/download-mp4-files). Direct MP4 URLs are internal and can change.</p>

## Manifest quality range

<p>The HLS and MPEG-DASH manifests include every rendition by default. Append <code>-min-N</code>, <code>-max-N</code>, or both to keep a resolution range.</p>

  * <code>-min-N</code>: lowest resolution is at least N
  * <code>-max-N</code>: highest resolution is at most N

<p><code>N</code> is a height or width from 240 to 9999. For a horizontal video, <code>N</code> is the height. For a vertical video, <code>N</code> is the width.</p>

<p>A request for 360p and 480p, with the Roku image stream:</p>

```sh
curl https://demo-public.gvideo.io/videos/2675_FnlHXwA16ZMxmUr/master-min-360-max-480-img.m3u8
```

<p>The response is:</p>

```
#EXTM3U
#EXT-X-STREAM-INF:PROGRAM-ID=1,BANDWIDTH=928000,RESOLUTION=1118x468,FRAME-RATE=24.000,CODECS="avc1.4d401f,mp4a.40.2",VIDEO-RANGE=SDR
index-s0q3573v3-v1-a1.m3u8
#EXT-X-STREAM-INF:PROGRAM-ID=1,BANDWIDTH=514000,RESOLUTION=860x360,FRAME-RATE=24.000,CODECS="avc1.42c01e,mp4a.40.2",VIDEO-RANGE=SDR
index-s0q3576v3-v1-a1.m3u8

#EXT-X-I-FRAME-STREAM-INF:BANDWIDTH=72357,RESOLUTION=1118x468,CODECS="avc1.4d401f",URI="iframes-s0q3573v3-v1-a1.m3u8",VIDEO-RANGE=SDR
#EXT-X-I-FRAME-STREAM-INF:BANDWIDTH=44076,RESOLUTION=860x360,CODECS="avc1.42c01e",URI="iframes-s0q3576v3-v1-a1.m3u8",VIDEO-RANGE=SDR

#EXT-X-IMAGE-STREAM-INF:BANDWIDTH=4200,RESOLUTION=100x42,CODECS=jpeg,URI=tiles.m3u8
```

<p>Retrieve all playback URLs for a video with a single API call. The response includes <code>hls_url</code>, <code>hls_cmaf_url</code>, <code>dash_url</code>, and per-quality <code>mp4_url</code> values in the <code>converted_videos</code> array.</p>

An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
```

## Playback URLs

<p>Each request calls <code>GET /streaming/videos/{id}</code> and prints the playback URLs from the video object.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    video_id = int(os.environ["VIDEO_ID"])
    video = client.streaming.videos.get(video_id)

    print(video.hls_url)       # default HLS master playlist
    print(video.hls_cmaf_url)  # HLS CMAF master playlist
    print(video.dash_url)      # MPEG-DASH manifest

    for quality in video.converted_videos:
        print(quality.name, quality.mp4_url)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go

        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
        video, err := client.Streaming.Videos.Get(ctx, videoID)
        if err != nil {
            panic(err)
        }

        fmt.Println(video.HlsURL)      // default HLS master playlist
        fmt.Println(video.HlsCmafURL)  // HLS CMAF master playlist
        fmt.Println(video.DashURL)     // MPEG-DASH manifest

            fmt.Println(quality.Name, quality.MP4URL)
        }
    }
    ```

## HLS and DASH quality range

<p>Append <code>-min-N</code>, <code>-max-N</code>, or both to <code>hls_url</code> or <code>dash_url</code>. <code>N</code> is the height of a horizontal video or the width of a vertical video, from 240 to 9999.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()

    video_id = int(os.environ["VIDEO_ID"])
    video = client.streaming.videos.get(video_id)

    # Serve only 360p and 480p — insert suffixes before the file extension
    base = video.hls_url.replace("master.m3u8", "master-min-360-max-480.m3u8")
    print(base)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"
        "strings"

        gcore "github.com/G-Core/gcore-go"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
        video, err := client.Streaming.Videos.Get(ctx, videoID)
        if err != nil {
            panic(err)
        }

        // Serve only 360p and 480p
        base := strings.Replace(video.HlsURL, "master.m3u8", "master-min-360-max-480.m3u8", 1)
        fmt.Println(base)
    }
    ```
