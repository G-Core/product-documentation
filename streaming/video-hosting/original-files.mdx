An original video file is the recording uploaded to Gcore Video Streaming. Transcoding creates renditions of that file in different [codecs&nbsp;and&nbsp;resolutions](/streaming/video-hosting/hls-and-mp4).

<Info>
Gcore Video Streaming deletes the uploaded original file after transcoding finishes. Keep a separate copy. The original file is not available for download.
</Info>

## Transcoded files

Transcoded MP4 files are available in the [Gcore Customer Portal](https://portal.gcore.com).

<Steps>
  <Step title="Open video settings">
    1. Navigate to **Streaming**.
    2. Select **Video Hosting**.
    3. Open **All videos**.
    4. Click the video name.

    <Frame>
      ![All videos list in Video Hosting](/images/docs/streaming/video-hosting/original-files/original-files-vod-1.png)
    </Frame>
  </Step>
  <Step title="Select video quality">
    On **Video settings**, in **Download video**, select **Video quality**.

    <Frame>
      ![Video settings page with the Download video section](/images/docs/streaming/video-hosting/original-files/original-files-vod-2.png)
    </Frame>
  </Step>
  <Step title="Download the MP4 file">
    Click **Download video**. The browser saves the transcoded MP4 file for the selected quality.
  </Step>
</Steps>
