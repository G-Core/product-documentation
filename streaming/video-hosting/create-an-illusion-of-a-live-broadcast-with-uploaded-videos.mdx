<p>Live imitation plays uploaded videos from a scheduled start time, in list order, so viewers see a broadcast rather than an on-demand file. Until that time, the player does not show the videos. A playlist holds up to 512 videos.</p>

## Live imitation

<p>1. Upload the videos first, using steps 1-4 in [Upload&nbsp;a&nbsp;video](/streaming/video-hosting/upload-a-video-and-embed-it-to-your-app).</p>

<p>2. In the [Gcore Customer Portal](https://portal.gcore.com/streaming/playlists/live), open **Streaming** > **Video Hosting** > **Live imitation**.</p>

<Frame>![Live imitation list with one saved broadcast](/images/docs/streaming/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos/live-imitation-main-page.png)</Frame>

<p>3. Click **Create a Live imitation**.</p>

<p>4. In **Live imitation name**, enter the name shown on the Live imitation page.</p>

<Frame>![Create a Live imitation dialog with the name filled in](/images/docs/streaming/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos/live-imitation-pop-up.png)</Frame>

<p>5. Click **Create**.</p>

<p>The settings page opens.</p>

<Frame>![Live imitation settings with the player showing the uploaded video](/images/docs/streaming/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos/live-imitation-settings.png)</Frame>

<p>6. Leave **Active** on. With **Active** off, the embedded player does not broadcast.</p>

<p>7. Set **Start date and time**. **Timezone** shows the detected zone and cannot be edited. Set the start time in that zone.</p>

<p>8. (Optional) Change **Live imitation name**. The name appears only in the Customer Portal.</p>

<p>9. Under **Editor**, click **Add** next to each video. Playback follows the list from top to bottom. Drag a video to change the order.</p>

<p>10. Click **Save changes**.</p>

<p>11. In **Export**, copy the iframe and place it on the site. The player uses that code.</p>

<Warning>
Automatic playback uses the [custom&nbsp;player](/streaming/player/customize-appearance-of-the-built-in-player) with Autoplay enabled.
</Warning>

<p>At the start time, the player plays the videos in list order.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Live imitation uses the [Playlists&nbsp;API](/api-reference/streaming/playlists/get-all-playlists). A playlist with <code>start_time</code> set to a future date and <code>active: true</code> behaves as a scheduled live broadcast. Until the start time, the manifest returns an empty stream. At the scheduled moment, playback of the video list begins in sequence.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
```

## Scheduled broadcast

<p>Create a playlist with a list of video IDs and a scheduled start time in ISO 8601 format (UTC). Set <code>active: true</code> to enable playback. Use <code>loop: true</code> to repeat the sequence continuously after it ends.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from datetime import datetime, timezone, timedelta
from gcore import Gcore

client = Gcore()

# Start time must be a future UTC datetime in ISO 8601 format.
start_time = (datetime.now(timezone.utc) + timedelta(hours=24)).strftime(
    "%Y-%m-%dT%H:%M:%SZ"
)

broadcast = client.streaming.playlists.create(
    name="Product launch — September premiere",
    active=True,
    start_time=start_time,
    loop=False,
    video_ids=[int(os.environ["VIDEO_ID"])],
)
print(f"Playlist ID: {broadcast.id}")
print(f"Embed URL: {broadcast.iframe_url}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"
	"time"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	// Start time must be a future UTC datetime in ISO 8601 format.
	startTime := time.Now().UTC().Add(24 * time.Hour).Format(time.RFC3339)

	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
	broadcast, err := client.Streaming.Playlists.New(ctx, streaming.PlaylistNewParams{
		Playlist: streaming.PlaylistParam{
			Name:      param.NewOpt("Product launch — September premiere"),
			Active:    param.NewOpt(true),
			StartTime: param.NewOpt(startTime),
			Loop:      param.NewOpt(false),
			VideoIDs:  []int64{videoID},
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Playlist ID: %d\n", broadcast.ID)
	fmt.Printf("Embed URL: %s\n", broadcast.IframeURL)
}
```
  </Tab>
  <Tab title="curl">
```bash
START_TIME=$(date -u -d "+24 hours" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null || \

  -H "Content-Type: application/json" \

    \"name\": \"Product launch — September premiere\",

    \"loop\": false,

```

## Schedule and video list

<p>Change the video sequence, reschedule the start time, or toggle loop mode. Only the fields included in the request are updated.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from datetime import datetime, timezone, timedelta
from gcore import Gcore

client = Gcore()
playlist_id = int(os.environ["PLAYLIST_ID"])

# Reschedule to 48 hours from now, replace the video list, and enable loop
new_start = (datetime.now(timezone.utc) + timedelta(hours=48)).strftime(
    "%Y-%m-%dT%H:%M:%SZ"
)

updated = client.streaming.playlists.update(
    playlist_id,
    start_time=new_start,
    video_ids=[int(os.environ["VIDEO_ID"])],
    loop=True,
)
print(f"Updated start time: {updated.start_time}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"
	"time"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	playlistID, _ := strconv.ParseInt(os.Getenv("PLAYLIST_ID"), 10, 64)
	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)

	newStart := time.Now().UTC().Add(48 * time.Hour).Format(time.RFC3339)
	updated, err := client.Streaming.Playlists.Update(ctx, playlistID, streaming.PlaylistUpdateParams{
		Playlist: streaming.PlaylistParam{
			StartTime: param.NewOpt(newStart),
			VideoIDs:  []int64{videoID},
			Loop:      param.NewOpt(true),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Updated start time: %s\n", updated.StartTime)
}
```

## Active state

<p>Set <code>active: false</code> to pause a broadcast without deleting it. Set <code>active: true</code> to resume it. A disabled broadcast serves an empty manifest even if the start time has passed.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
playlist_id = int(os.environ["PLAYLIST_ID"])

# Disable
updated = client.streaming.playlists.update(playlist_id, active=False)
print(f"Active: {updated.active}")

# Re-enable
updated = client.streaming.playlists.update(playlist_id, active=True)
print(f"Active: {updated.active}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	playlistID, _ := strconv.ParseInt(os.Getenv("PLAYLIST_ID"), 10, 64)

	// Disable
	updated, err := client.Streaming.Playlists.Update(ctx, playlistID, streaming.PlaylistUpdateParams{
		Playlist: streaming.PlaylistParam{
			Active: param.NewOpt(false),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Active: %v\n", updated.Active)

	// Re-enable
	updated, err = client.Streaming.Playlists.Update(ctx, playlistID, streaming.PlaylistUpdateParams{
		Playlist: streaming.PlaylistParam{
			Active: param.NewOpt(true),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Active: %v\n", updated.Active)
}
```
