## What is live imitation?

<p>Live imitation is a free feature for broadcasting videos uploaded to your account in live mode. For example, you are an owner of a movie streaming service. On September 1, you will premiere a new series for your viewers. One way to do it is to use the Live imitation feature. In this case, you upload episodes to our Video Streaming as usual videos and select the start date and time (e.g., September 1 at 9 PM). So, up to this moment, videos will not be shown. Your viewers will be able to see it only at a fixed time. From their point of view, it would not look like watching a video but like a live stream.</p>

## Configure live imitation

<p>1. Upload videos that you want to broadcast in live mode according to steps 1–4 in the [Upload a video and embed it to your app](/streaming/video-hosting/upload-a-video-and-embed-it-to-your-app) guide. You can upload up to 512 videos to a playlist.</p>

<p>2. Go to the [Live imitation]() section.</p>

<p>3. Click **Create a Live imitation**.</p>

<Frame>![A Live imitation main page](/images/docs/streaming-platform/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos/live-imitation-main-page.png)</Frame>

<p>A pop-up will appear.</p>

<p>4. Enter the name of your entity. It will be displayed on the Gcore Customer Portal in the Live imitation page.</p>

<p>5. Click **Create**.</p>

<Frame>![Create a Live imitation pop up](/images/docs/streaming-platform/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos/live-imitation-pop-up.png)</Frame>

<p>A new window will open. Complete the remaining steps there.</p>

<Frame>![Configure Live imitation](/images/docs/streaming-platform/video-hosting/create-an-illusion-of-a-live-broadcast-with-uploaded-videos/live-imitation-settings.png)</Frame>

<p>6. Ensure that the feature is **Active**. If the toggle is disabled, Live imitation won't be broadcast even if it's embedded on the website.</p>

<p>7. Set the date and time when the imitating video will start.</p>

<Info>
Our system automatically detects your time zone, and the start time you set will be adjusted accordingly. If your audience is located in a different time zone, please set the time accordingly by considering the difference with GMT.
</Info>

<p>8. (Optional) Change the name of Live imitation if necessary. It is displayed only in the Streaming Gcore Customer Portal. Your users won't see it.</p>

<p>9. Copy the iframe code of the player and embed it on your website or app. Live imitation will be shown by this code.</p>

<Warning>
For videos to play automatically, you must use the [Gcore custom player](/streaming/extra-features/customize-appearance-of-the-built-in-player) and configure the Autoplay option in it.
</Warning>

<p>10. Add videos that you want to show as live imitation. You can add several videos. They will be played from the top to the bottom of the list. Drag and drop the video if you want to change the playback order.</p>

<p>11. Save changes.</p>

<p>Live imitation is configured. On the start date, videos will be played on your website.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Live imitation uses the [Playlists API](/api-reference/streaming/playlists/get-all-playlists). A playlist with <code>start_time</code> set to a future date and <code>active: true</code> behaves as a scheduled live broadcast. Until the start time, the manifest returns an empty stream. At the scheduled moment, the platform begins playing the video list in sequence.</p>

<Info>
An [API token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
export PLAYLIST_ID="{YOUR_PLAYLIST_ID}"
```

## Create a scheduled broadcast

<p>Create a playlist with a list of video IDs and a scheduled start time in ISO 8601 format (UTC). Set <code>active: true</code> to enable playback. Use <code>loop: true</code> to repeat the sequence continuously after it ends.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from datetime import datetime, timezone, timedelta
from gcore import Gcore

client = Gcore()

# Start time must be a future UTC datetime in ISO 8601 format.
start_time = (datetime.now(timezone.utc) + timedelta(hours=24)).strftime(
    "%Y-%m-%dT%H:%M:%SZ"
)

broadcast = client.streaming.playlists.create(
    name="Product launch — September premiere",
    active=True,
    start_time=start_time,
    loop=False,
    video_ids=[int(os.environ["VIDEO_ID"])],
)
print(f"Playlist ID: {broadcast.id}")
print(f"Embed URL: {broadcast.iframe_url}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"
	"time"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	// Start time must be a future UTC datetime in ISO 8601 format.
	startTime := time.Now().UTC().Add(24 * time.Hour).Format(time.RFC3339)

	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
	broadcast, err := client.Streaming.Playlists.New(ctx, streaming.PlaylistNewParams{
		Playlist: streaming.PlaylistParam{
			Name:      param.NewOpt("Product launch — September premiere"),
			Active:    param.NewOpt(true),
			StartTime: param.NewOpt(startTime),
			Loop:      param.NewOpt(false),
			VideoIDs:  []int64{videoID},
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Playlist ID: %d\n", broadcast.ID)
	fmt.Printf("Embed URL: %s\n", broadcast.IframeURL)
}
```
  </Tab>
  <Tab title="curl">
```bash
START_TIME=$(date -u -d "+24 hours" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null || \
             date -u -v+24H '+%Y-%m-%dT%H:%M:%SZ')

curl -X POST "https://api.gcore.com/streaming/playlists" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"name\": \"Product launch — September premiere\",
    \"active\": true,
    \"start_time\": \"$START_TIME\",
    \"loop\": false,
    \"video_ids\": [$VIDEO_ID]
  }"
```

<p>The API returns the created playlist. Save the <code>id</code> for subsequent operations and the <code>iframe_url</code> for embedding the player on your site.</p>

```json
{
  "id": 25691,
  "name": "Product launch — September premiere",
  "active": true,
  "start_time": "2026-09-12T08:16:00.000Z",
  "loop": false,
  "iframe_url": "https://player.gvideo.co/playlists/1000503_25691",
  "video_ids": [14753315]
}
```

## List broadcasts

<p>Retrieve all playlists in the account to check their names, active state, and embed URLs.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
playlists = list(client.streaming.playlists.list())
print(f"Total broadcasts: {len(playlists)}")
for pl in playlists:
    print(f"  id={pl.id}, name={pl.name}, active={pl.active}, start={pl.start_time}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	page, err := client.Streaming.Playlists.List(ctx, streaming.PlaylistListParams{})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Total broadcasts: %d\n", len(page.Items))
	for _, pl := range page.Items {
		fmt.Printf("  name=%s, active=%v, embed=%s\n", pl.Name, pl.Active, pl.IframeURL)
	}
}
```

## Update video list or reschedule

<p>Change the video sequence, reschedule the start time, or toggle loop mode. Only the fields included in the request are updated.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from datetime import datetime, timezone, timedelta
from gcore import Gcore

client = Gcore()
playlist_id = int(os.environ["PLAYLIST_ID"])

# Reschedule to 48 hours from now and add another video
new_start = (datetime.now(timezone.utc) + timedelta(hours=48)).strftime(
    "%Y-%m-%dT%H:%M:%SZ"
)

updated = client.streaming.playlists.update(
    playlist_id,
    start_time=new_start,
    video_ids=[int(os.environ["VIDEO_ID"])],
    loop=True,
)
print(f"Updated start time: {updated.start_time}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"
	"time"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	playlistID, _ := strconv.ParseInt(os.Getenv("PLAYLIST_ID"), 10, 64)
	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)

	newStart := time.Now().UTC().Add(48 * time.Hour).Format(time.RFC3339)
	updated, err := client.Streaming.Playlists.Update(ctx, playlistID, streaming.PlaylistUpdateParams{
		Playlist: streaming.PlaylistParam{
			StartTime: param.NewOpt(newStart),
			VideoIDs:  []int64{videoID},
			Loop:      param.NewOpt(true),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Updated start time: %s\n", updated.StartTime)
}
```

## Enable or disable a broadcast

<p>Set <code>active: false</code> to pause a broadcast without deleting it. Set <code>active: true</code> to resume it. A disabled broadcast serves an empty manifest even if the start time has passed.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
playlist_id = int(os.environ["PLAYLIST_ID"])

# Disable
updated = client.streaming.playlists.update(playlist_id, active=False)
print(f"Active: {updated.active}")

# Re-enable
updated = client.streaming.playlists.update(playlist_id, active=True)
print(f"Active: {updated.active}")
```
  </Tab>
  <Tab title="Go SDK">
```go

	"context"
	"fmt"
	"os"
	"strconv"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	playlistID, _ := strconv.ParseInt(os.Getenv("PLAYLIST_ID"), 10, 64)

	// Disable
	updated, err := client.Streaming.Playlists.Update(ctx, playlistID, streaming.PlaylistUpdateParams{
		Playlist: streaming.PlaylistParam{
			Active: param.NewOpt(false),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Active: %v\n", updated.Active)
}
```
