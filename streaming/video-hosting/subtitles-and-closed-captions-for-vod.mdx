## What are subtitles and closed captions?

<p><em>Subtitles</em> are the transcribed speech in your video, including narration, dialogues, and monologues.</p>

<p><em>Closed captions</em> or just <em>captions</em> are transcribed speech showing what is said in your video and explaining any audio context, such as background music, comments about moods, and emotions behind the spoken words.</p>

<p>By using timed text tracks for your videos' subtitles and closed captions, you can engage wider audiences, such as deaf and hard-of-hearing people or non-native speakers.</p>

<p>Your videos may need text accompaniment in the following cases:</p>

- Watching muted videos on web pages with autoplay
- Watching videos without headphones in a noisy public environment
- Watching foreign videos with translation to the user's language
- Improving SEO and searchability through text indexation
- Enhancing learning and comprehension, especially in an educational context

## Formats of subtitles and captions

<p>We support SRT and WebVTT formats for timed text tracks.</p>

**SRT** (SubRip file format) is a simple text file with the `.srt` extension.

```
1
00:00:00,009 --> 00:00:03,689
Come on team, we mustn't dilly dally when there's so much nature to see!

2
00:00:04,129 --> 00:00:08,169
I was thinking, we should call our class project, Fungi in a Forest!
```

**WebVTT** (Web Video Text Tracks) is a text file with the `.vtt` extension. It is based on the SRT but expanded without backward compatibility. A WebVTT can contain captions, descriptions, chapters, and metadata cues such as caption alignment.

<Info>We recommend using WebVTT. It is supported by most devices, players, and browsers.</Info>

```
WEBVTT

00:00:00.009 --> 00:00:03.689
Come on team, we mustn't dilly dally when there's so much nature to see!

00:00:04.129 --> 00:00:08.169
I was thinking, we should call our class project, Fungi in a Forest!
```

## How to get subtitles and captions

<p>Gcore provides AI-generated subtitles — see [Generate AI subtitles and add them to video](/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal) for details. Automatically generated text tracks are subtitles only (not closed captions). Subtitles are created in the video's original language and can then be automatically translated into other languages.</p>

<p>You can also generate subtitles with third-party tools and attach the resulting file. Free services include [Veed](https://www.veed.io/tools/auto-subtitle-generator-online) and [Kapwing](https://www.kapwing.com/subtitles). External services may have use limitations.</p>

<p>Guides for downloading subtitles from popular external platforms:</p>

- [YouTube](https://developers.google.com/youtube/v3/docs/captions)
- [Vimeo](https://help.vimeo.com/hc/en-us/articles/12425955868817-Download-a-video-with-captions-or-subtitles)
- [Zoom](https://support.zoom.us/hc/en-us/articles/360060958752-Saving-closed-captions-in-a-meeting)
- [Webex](https://help.webex.com/en-us/article/ng387ab/Manage-notes,-meeting-minutes,-and-closed-captions-in-Webex-Meetings-and-WebexWebinars)
- [MS Teams](https://support.microsoft.com/en-au/office/use-live-captions-in-microsoft-teams-meetings-4be2d304-f675-4b57-8347-cbd000a21260)
- [SharePoint](https://learn.microsoft.com/en-us/stream/portal-add-subtitles-captions#download-subtitles-or-captions)

## Add subtitles via Customer Portal

1\. Go to [Video Hosting](https://portal.gcore.com/streaming/video/list) and open the video where you want to add subtitles.

<Frame>![Video Hosting section](/images/docs/streaming-platform/video-hosting/subtitles-and-closed-captions-for-vod/captions-20.png)</Frame>

2\. Click **Add subtitles**. You can add several files.

3\. Select the subtitle language for each file from the dropdown list.

4\. Click **Save**.

<Info>It takes about 15 minutes for the changes to take effect. After that, an icon appears to the left of the time indicator in the player — click it to select the subtitle language.</Info>

## View subtitles in the Gcore Player

<p>Captions are integrated into Gcore's Player. Click the icon to the left of the volume indicator in the bottom panel of the Player to select captions.</p>

## View subtitles in custom and native players

<p>For a custom player, retrieve the subtitle list from the [Subtitles API](/api-reference/streaming/subtitles/get-all-subtitles) and load the VTT content into your player's text-track element.</p>

<p>Captions are embedded in the HLS manifest automatically. The manifest includes `EXT-X-MEDIA` entries for each attached subtitle track, so subtitle-aware HLS players pick them up without additional configuration.</p>

<p>Example manifest excerpt:</p>

```
#EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs0",NAME="English",LANGUAGE="en",AUTOSELECT=YES,DEFAULT=YES,URI="index-f5.m3u8"
#EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs0",NAME="Español",LANGUAGE="es",AUTOSELECT=NO,DEFAULT=NO,URI="index-f6.m3u8"
```

<p>Set the environment variables before running the examples:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
```

<Info>
Specify the subtitle language as a three-letter code from [ISO 639-2 (bibliographic)](https://en.wikipedia.org/wiki/List_of_ISO_639-2_codes). For example: `eng` for English, `ger` for German, `spa` for Spanish.

## List subtitles

<p>Retrieve all subtitle tracks attached to a video.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])

    subtitles = client.streaming.videos.subtitles.list(video_id)
    for sub in subtitles:
        print(sub.id, sub.language, sub.name)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subs, err := client.Streaming.Videos.Subtitles.List(ctx, videoID)
    	if err != nil {
    		panic(err)
    	}
    	for _, s := range *subs {
    		fmt.Printf("id=%d lang=%s name=%s\n", s.ID, s.Language, s.Name)
    	}
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The response is an array of subtitle objects:</p>

    ```json
    [
      {
        "id": 5823,
        "name": "English",
        "language": "eng",
        "vtt": "WEBVTT\n\n1\n00:00:00.009 --> 00:00:03.689\nHello world!"
      }
    ]
    ```

## Add a subtitle

<p>Attach a subtitle track to a video. Pass the full subtitle text in the `vtt` field — both SRT and WebVTT formats are accepted.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])

    subtitle = client.streaming.videos.subtitles.create(
        video_id,
        body={
            "language": "eng",
            "name": "English",
            "vtt": (
                "WEBVTT\n\n"
                "1\n00:00:00.009 --> 00:00:03.689\n"
                "Come on team, we mustn't dilly dally!\n\n"
                "2\n00:00:04.129 --> 00:00:08.169\n"
                "I was thinking, we should call our class project, Fungi in a Forest!"
            ),
        },
    )
    print(f"Added subtitle ID: {subtitle.id}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subtitle, err := client.Streaming.Videos.Subtitles.New(
    		ctx,
    		videoID,
    		streaming.VideoSubtitleNewParams{
    			Body: streaming.VideoSubtitleNewParamsBody{
    				SubtitleBaseParam: streaming.SubtitleBaseParam{
    					Language: param.NewOpt("eng"),
    					Name:     param.NewOpt("English"),
    					Vtt: param.NewOpt(
    						"WEBVTT\n\n" +
    							"1\n00:00:00.009 --> 00:00:03.689\n" +
    							"Come on team, we mustn't dilly dally!\n\n" +
    							"2\n00:00:04.129 --> 00:00:08.169\n" +
    							"I was thinking, we should call our class project, Fungi in a Forest!",
    					),
    				},
    			},
    		},
    	)
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Added subtitle ID: %d\n", subtitle.ID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "language": "eng",
        "name": "English",
        "vtt": "WEBVTT\n\n1\n00:00:00.009 --> 00:00:03.689\nCome on team!\n\n2\n00:00:04.129 --> 00:00:08.169\nFungi in a Forest!"
      }'
    ```

    <p>The API returns the created subtitle:</p>


## Update a subtitle

<p>Modify the subtitle name, language code, or VTT content. Pass only the fields you want to change.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])
    subtitle_id = int(os.environ["SUBTITLE_ID"])

    updated = client.streaming.videos.subtitles.update(
        subtitle_id,
        video_id=video_id,
        name="English (revised)",
    )
    print(f"Updated subtitle: {updated.name}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subtitleID, _ := strconv.ParseInt(os.Getenv("SUBTITLE_ID"), 10, 64)

    	updated, err := client.Streaming.Videos.Subtitles.Update(
    		ctx,
    		subtitleID,
    		streaming.VideoSubtitleUpdateParams{
    			VideoID: videoID,
    			SubtitleBase: streaming.SubtitleBaseParam{
    				Name: param.NewOpt("English (revised)"),
    			},
    		},
    	)
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Updated subtitle: %s\n", updated.Name)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles/$SUBTITLE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "English (revised)"}'
    ```

    <p>The response returns the updated subtitle object.</p>
  </Tab>
</Tabs>

## Delete a subtitle

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])
    subtitle_id = int(os.environ["SUBTITLE_ID"])

    client.streaming.videos.subtitles.delete(subtitle_id, video_id=video_id)
    print(f"Subtitle {subtitle_id} deleted.")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subtitleID, _ := strconv.ParseInt(os.Getenv("SUBTITLE_ID"), 10, 64)

    	if err := client.Streaming.Videos.Subtitles.Delete(
    		ctx,
    		subtitleID,
    		streaming.VideoSubtitleDeleteParams{VideoID: videoID},
    	); err != nil {
    		panic(err)
    	}
    	fmt.Printf("Subtitle %d deleted.\n", subtitleID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X DELETE "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles/$SUBTITLE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>A successful delete returns HTTP 204 No Content with an empty body.</p>
  </Tab>
</Tabs>
