<p>Gcore Player shows subtitles and closed captions on a timed text track: subtitles are the spoken words, and closed captions add non-speech audio, including music and the speaker's tone. SRT and WebVTT files are accepted, and WebVTT is recommended because most devices, players, and browsers support it.</p>

<Frame>![Gcore Player with a caption track selected](/images/docs/streaming/video-hosting/subtitles-and-closed-captions-for-vod/captions-10-optimized.gif)</Frame>

## Subtitle files

<p>Gcore can generate subtitles with [AI&nbsp;subtitles](/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal). The generated tracks are subtitles only, not closed captions: they start in the video's original language and can be translated into other languages.</p>

<p>An existing SRT or WebVTT file from another tool can be attached as well.</p>

## Add subtitles

<p>Attach a subtitle file on the video settings page and select its language.</p>

<Steps>
  <Step title="Open the video">
    In [Video&nbsp;Hosting](https://portal.gcore.com/streaming/video/list), open the video that needs subtitles.

    <Frame>![Video Hosting section](/images/docs/streaming/video-hosting/subtitles-and-closed-captions-for-vod/captions-20.png)</Frame>
  </Step>
  <Step title="Add the subtitle file">
    Click **Add subtitles** and select the subtitle file. A .vtt file can be checked in the [WebVTT&nbsp;parser](https://w3c.github.io/webvtt.js/parser.html) before it is attached. Several files can be added.
  </Step>
  <Step title="Select the language">
    Select **Subtitle language** for each file.
  </Step>
  <Step title="Save the video">
    Click **Save**.

    <Info>It takes about 15 minutes for the changes to take effect. After that, an icon appears to the left of the volume control in the player. Click it to select the subtitle language.</Info>
  </Step>
</Steps>

## Custom and native players

<p>A custom player can load the VTT content from the [Subtitles&nbsp;API](/api-reference/streaming/subtitles/get-all-subtitles) into its text-track element.</p>

<p>Captions are embedded in the HLS manifest automatically. The manifest includes `EXT-X-MEDIA` entries for each attached subtitle track, so subtitle-aware HLS players pick them up without additional configuration.</p>

<p>A manifest with two subtitle tracks:</p>

```
#EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs0",NAME="English",LANGUAGE="en",AUTOSELECT=YES,DEFAULT=YES,URI="index-f5.m3u8"
#EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs0",NAME="Español",LANGUAGE="es",AUTOSELECT=NO,DEFAULT=NO,URI="index-f6.m3u8"
```

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Manage subtitles and captions for VOD videos using the [Subtitles&nbsp;API](/api-reference/streaming/subtitles/get-all-subtitles). Subtitles are attached per video and can be in SRT or WebVTT format. After adding a subtitle, changes take up to 15 minutes to appear in the player and HLS manifest.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
```

<Info>
Specify the subtitle language as a three-letter [ISO&nbsp;639-2](https://en.wikipedia.org/wiki/List_of_ISO_639-2_codes) code: `eng` for English, `ger` for German, `spa` for Spanish.
</Info>

## List subtitles

<p>Retrieve all subtitle tracks attached to a video.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])

    subtitles = client.streaming.videos.subtitles.list(video_id)
    for sub in subtitles:
        print(sub.id, sub.language, sub.name)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subs, err := client.Streaming.Videos.Subtitles.List(ctx, videoID)
    	if err != nil {
    		panic(err)
    	}
    	for _, s := range *subs {
    		fmt.Printf("id=%d lang=%s name=%s\n", s.ID, s.Language, s.Name)
    	}
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The response is an array of subtitle objects:</p>

    ```json
    [
      {
        "id": 5823,
        "name": "English",
        "language": "eng",
        "vtt": "WEBVTT\n\n1\n00:00:00.009 --> 00:00:03.689\nHello world!"
      }
    ]
    ```
  </Tab>
</Tabs>

## Add a subtitle

<p>Attach a subtitle track to a video. Pass the full subtitle text in the `vtt` field — both SRT and WebVTT formats are accepted.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])

    subtitle = client.streaming.videos.subtitles.create(
        video_id,
        body={
            "language": "eng",
            "name": "English",
            "vtt": (
                "WEBVTT\n\n"
                "1\n00:00:00.009 --> 00:00:03.689\n"
                "Come on team, we mustn't dilly dally!\n\n"
                "2\n00:00:04.129 --> 00:00:08.169\n"
                "I was thinking, we should call our class project, Fungi in a Forest!"
            ),
        },
    )
    print(f"Added subtitle ID: {subtitle.id}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subtitle, err := client.Streaming.Videos.Subtitles.New(
    		ctx,
    		videoID,
    		streaming.VideoSubtitleNewParams{
    			Body: streaming.VideoSubtitleNewParamsBody{
    				SubtitleBaseParam: streaming.SubtitleBaseParam{
    					Language: param.NewOpt("eng"),
    					Name:     param.NewOpt("English"),
    					Vtt: param.NewOpt(
    						"WEBVTT\n\n" +
    							"1\n00:00:00.009 --> 00:00:03.689\n" +
    							"Come on team, we mustn't dilly dally!\n\n" +
    							"2\n00:00:04.129 --> 00:00:08.169\n" +
    							"I was thinking, we should call our class project, Fungi in a Forest!",
    					),
    				},
    			},
    		},
    	)
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Added subtitle ID: %d\n", subtitle.ID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "language": "eng",
        "name": "English",
        "vtt": "WEBVTT\n\n1\n00:00:00.009 --> 00:00:03.689\nCome on team!\n\n2\n00:00:04.129 --> 00:00:08.169\nFungi in a Forest!"
      }'
    ```

    <p>The API returns the created subtitle:</p>

    ```json
    {
      "id": 506636,
      "name": "English",
      "language": "eng",
      "vtt": "WEBVTT\n\n1\n00:00:00.009 --> 00:00:03.689\nCome on team!\n\n2\n00:00:04.129 --> 00:00:08.169\nFungi in a Forest!"
    }
    ```
  </Tab>
</Tabs>

<p>Use the subtitle ID returned by the list or create request to update or delete that subtitle. Export it as an environment variable:</p>

```bash
export SUBTITLE_ID="{YOUR_SUBTITLE_ID}"
```

## Update a subtitle

<p>Modify the subtitle name, language code, or VTT content. Pass only the fields that change.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])
    subtitle_id = int(os.environ["SUBTITLE_ID"])

    updated = client.streaming.videos.subtitles.update(
        subtitle_id,
        video_id=video_id,
        name="English (revised)",
    )
    print(f"Updated subtitle: {updated.name}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subtitleID, _ := strconv.ParseInt(os.Getenv("SUBTITLE_ID"), 10, 64)

    	updated, err := client.Streaming.Videos.Subtitles.Update(
    		ctx,
    		subtitleID,
    		streaming.VideoSubtitleUpdateParams{
    			VideoID: videoID,
    			SubtitleBase: streaming.SubtitleBaseParam{
    				Name: param.NewOpt("English (revised)"),
    			},
    		},
    	)
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Updated subtitle: %s\n", updated.Name)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles/$SUBTITLE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "English (revised)"}'
    ```

    <p>The response returns the updated subtitle object.</p>
  </Tab>
</Tabs>

## Delete a subtitle

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])
    subtitle_id = int(os.environ["SUBTITLE_ID"])

    client.streaming.videos.subtitles.delete(subtitle_id, video_id=video_id)
    print(f"Subtitle {subtitle_id} deleted.")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	subtitleID, _ := strconv.ParseInt(os.Getenv("SUBTITLE_ID"), 10, 64)

    	if err := client.Streaming.Videos.Subtitles.Delete(
    		ctx,
    		subtitleID,
    		streaming.VideoSubtitleDeleteParams{VideoID: videoID},
    	); err != nil {
    		panic(err)
    	}
    	fmt.Printf("Subtitle %d deleted.\n", subtitleID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X DELETE "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles/$SUBTITLE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>A successful delete returns HTTP 204 No Content with an empty body.</p>
  </Tab>
</Tabs>
