## What is the playlists feature?

<p>Playlists are a free feature that allows you to merge several videos into one playlist and play them alternately. A single playlist can contain up to 512 videos.</p>

## Enable the playlists feature

<p>To enable the feature, send us a request via [support@gcore.com](mailto:support@gcore.com) or the chat window in the bottom-right corner of our website. Please specify your ID in the request, so we can identify your account. You can find it on the main page in the Gcore Customer Portal.</p>

<Frame>![Enable the Playlists feature](/images/docs/streaming-platform/video-hosting/create-and-configure-playlists-for-videos/9672671990033.png)</Frame>

<p>The message template: _"Greetings! Please enable the Playlists feature for the account with ID … (your ID)"_.</p>

<p>We will notify you when the feature is enabled. After that, you will be able to use it for your account.</p>

## Create and configure playlists

<p>1. In the Gcore Customer Portal, navigate to [Streaming](https://portal.gcore.com/streaming/playlists/list) > **Playlists**.</p>

<p>2. Click **Create a playlist**.</p>

<Frame>![Playlists tab](/images/docs/streaming-platform/video-hosting/create-and-configure-playlists-for-videos/playlists-annotated.png)</Frame>

<p>2. Enter the name of your playlist and click the **Create** button. The playlist's title will be displayed in the Gcore Customer Portal so you can quickly find it.</p>

<Frame>![Create  playlist](/images/docs/streaming-platform/video-hosting/create-and-configure-playlists-for-videos/9672672040977.png)</Frame>

<p>A new page will open. Complete the remaining steps in it.</p>

<Frame>![ remaining steps](/images/docs/streaming-platform/video-hosting/create-and-configure-playlists-for-videos/9672672048657.png)</Frame>

<p>3. Scroll down the page to the Editor section. All videos uploaded to your account are displayed here. Click the **Add** button in front of the videos you want to add to the playlist. This will move the video up from the list of all videos to a separate list for the playlist.</p>

<p>4. (optional) Set the order of the video in the playlist. Drag the icon on the left of the video and drop it above or below.</p>

<p>5. (optional) Press the three-point icon opposite the video to duplicate it (copies of the video will be added at the bottom of the list) or remove it from the playlist (the video will be moved down to the list of all videos).</p>

<p>6. Click the **Save changes** button when your playlist is completed.</p>

<p>7. Scroll the page up to the Export tab. Copy the code to embed the playlist on a website.</p>

<Frame>![Export tab](/images/docs/streaming-platform/video-hosting/create-and-configure-playlists-for-videos/9672672084497.png)</Frame>

<p>That's it. Viewers can now watch videos from your playlist.</p>

<p>You can [view statistics](/streaming) for your playlist. To do this, open the settings of the playlist needed in the control panel and go to the **Statistics** tab.</p>

<Frame>![statistics for your playlist](/images/docs/streaming-platform/video-hosting/create-and-configure-playlists-for-videos/9672700287121.png)</Frame>

<p>Create and configure video playlists using the [Playlists API](/api-reference/streaming/playlists/get-all-playlists). A playlist plays a curated sequence of uploaded videos as a live stream — viewers cannot skip ahead.</p>

<Info>
An [API token](/account-settings/api-tokens) is required. The Playlists feature must be enabled for the account — contact [support@gcore.com](mailto:support@gcore.com) to enable it.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
export PLAYLIST_ID="{YOUR_PLAYLIST_ID}"
```

## Quickstart

<p>Find two existing videos in the account, create a playlist from them, and print its embed code and HLS URL.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from datetime import datetime, timezone
from gcore import Gcore

client = Gcore()

# Step 1. Find video IDs to include
videos = list(client.streaming.videos.list(per_page=10))
video_ids = [v.id for v in videos][:2]
print("Video IDs:", video_ids)

# Step 2. Create the playlist
now = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
playlist = client.streaming.playlists.create(
    name="My Playlist",
    start_time=now,
    video_ids=video_ids,
    loop=True,
)
print(f"Playlist ID: {playlist.id}")
print(f"HLS URL: {playlist.hls_url}")
print(f"Embed code: {playlist.iframe_embed_code}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"time"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()
	now := time.Now().UTC().Format(time.RFC3339)

	// Step 1. Find video IDs to include
	page, err := client.Streaming.Videos.List(ctx, streaming.VideoListParams{})
	if err != nil {
		panic(err)
	}
	var videoIDs []int64
	for i, v := range page.Items {
		if i >= 2 {
			break
		}
		videoIDs = append(videoIDs, v.ID)
	}
	fmt.Println("Video IDs:", videoIDs)

	// Step 2. Create the playlist
	playlist, err := client.Streaming.Playlists.New(ctx, streaming.PlaylistNewParams{
		Playlist: streaming.PlaylistParam{
			Name:      param.NewOpt("My Playlist"),
			StartTime: param.NewOpt(now),
			VideoIDs:  videoIDs,
			Loop:      param.NewOpt(true),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Playlist ID: %d\n", playlist.ID)
	fmt.Printf("HLS URL: %s\n", playlist.HlsURL)
	fmt.Printf("Embed URL: %s\n", playlist.IframeURL)
}
```

## Create a playlist

<p>Create a playlist with an ordered list of video IDs. The playlist plays as a live stream starting at <code>start_time</code>. A playlist can hold up to 128 videos; the order of IDs in <code>video_ids</code> determines the playback order.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from datetime import datetime, timezone
from gcore import Gcore

client = Gcore()
now = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")

playlist = client.streaming.playlists.create(
    name="Season 1 — Episodes 1–3",
    start_time=now,
    video_ids=[int(os.environ["VIDEO_ID"])],
    loop=False,
)
print(f"Created playlist ID: {playlist.id}")
print(f"HLS URL: {playlist.hls_url}")
print(f"Embed code: {playlist.iframe_embed_code}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"
	"time"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()
	now := time.Now().UTC().Format(time.RFC3339)

	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
	playlist, err := client.Streaming.Playlists.New(ctx, streaming.PlaylistNewParams{
		Playlist: streaming.PlaylistParam{
			Name:      param.NewOpt("Season 1 — Episodes 1–3"),
			StartTime: param.NewOpt(now),
			VideoIDs:  []int64{videoID},
			Loop:      param.NewOpt(false),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Created playlist ID: %d\n", playlist.ID)
	fmt.Printf("HLS URL: %s\n", playlist.HlsURL)
	fmt.Printf("Embed URL: %s\n", playlist.IframeURL)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/playlists" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"name\": \"Season 1 — Episodes 1–3\",
    \"start_time\": \"$(date -u '+%Y-%m-%dT%H:%M:%SZ')\",
    \"video_ids\": [$VIDEO_ID],
    \"loop\": false
  }"
```

<p>The API returns the created playlist object:</p>

```json
{
  "id": 25568,
  "name": "Season 1 — Episodes 1–3",
  "start_time": "2026-09-07T10:00:00.000Z",
  "loop": false,
  "video_ids": [14753315],
  "hls_url": "https://1000503.gvideo.io/playlists/1000503_25568/master.m3u8",
  "iframe_url": "https://player.gvideo.co/playlists/1000503_25568",
  "iframe_embed_code": "<iframe width=\"560\" height=\"315\" src=\"https://player.gvideo.co/playlists/1000503_25568\" frameborder=\"0\" allowfullscreen></iframe>"
}
```

<p>Use <code>hls_url</code> to stream the playlist, or copy <code>iframe_embed_code</code> to embed it on a website.</p>

## Get a playlist

import os
from gcore import Gcore

client = Gcore()

package main

import (

	"fmt"

## Update a playlist

<p>Change the playlist name, video order, loop setting, or start time. Only the fields included in the request are updated.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
playlist_id = int(os.environ["PLAYLIST_ID"])

updated = client.streaming.playlists.update(
    playlist_id,
    name="Season 1 — All Episodes",
    video_ids=[int(os.environ["VIDEO_ID"])],
    loop=True,
)
print(f"Updated playlist: {updated.name}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/packages/param"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	playlistID, _ := strconv.ParseInt(os.Getenv("PLAYLIST_ID"), 10, 64)
	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
	updated, err := client.Streaming.Playlists.Update(ctx, playlistID, streaming.PlaylistUpdateParams{
		Playlist: streaming.PlaylistParam{
			Name:     param.NewOpt("Season 1 — All Episodes"),
			VideoIDs: []int64{videoID},
			Loop:     param.NewOpt(true),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Updated playlist: %s\n", updated.Name)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X PATCH "https://api.gcore.com/streaming/playlists/$PLAYLIST_ID" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"name\": \"Season 1 — All Episodes\",
    \"video_ids\": [$VIDEO_ID],
    \"loop\": true
  }"
```

<p>The API returns the full updated playlist object.</p>
  </Tab>
</Tabs>

## Delete a playlist

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
playlist_id = int(os.environ["PLAYLIST_ID"])
client.streaming.playlists.delete(playlist_id)
print(f"Playlist {playlist_id} deleted.")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"
	"os"
	"strconv"

	gcore "github.com/G-Core/gcore-go"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	playlistID, _ := strconv.ParseInt(os.Getenv("PLAYLIST_ID"), 10, 64)
	if err := client.Streaming.Playlists.Delete(ctx, playlistID); err != nil {
		panic(err)
	}
	fmt.Printf("Playlist %d deleted.\n", playlistID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X DELETE "https://api.gcore.com/streaming/playlists/$PLAYLIST_ID" \
  -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>A successful delete returns HTTP 204 No Content with an empty body.</p>
