<p>Directories place videos in a folder structure. Tags add another grouping and leave each video in its current directory. Videos stored by date can also carry tags for content type.</p>

## Directories

<p>A directory is the folder a video belongs to. Create a directory, move videos into it, or delete it after the videos have been moved.</p>

### Create a directory and upload videos

<p>A new directory opens as its own video list, with the same upload actions as **All videos**.</p>

<Steps>
  <Step title="Open the video list">
    <p>In the [Gcore Customer Portal](https://portal.gcore.com):</p>

    1. Navigate to **Streaming**.
    2. Select **Video Hosting**.
    3. Open **All videos**.
  </Step>
  <Step title="Start a directory">
    <p>Click **Create a directory**.</p>

    <Frame>![All videos page with Create a directory](/images/docs/streaming/video-hosting/organize-uploaded-videos/create-directory-button.png)</Frame>
  </Step>
  <Step title="Name the directory">
    <p>In **New directory**, enter a name in **Name** and click **Create**.</p>

    <Frame>![New directory dialog](/images/docs/streaming/video-hosting/organize-uploaded-videos/create-directory-dialog.png)</Frame>
  </Step>
  <Step title="Upload videos">
    <p>The new directory opens. Click **Click to upload** and select one or more videos.</p>

    <Frame>![Empty directory with upload](/images/docs/streaming/video-hosting/organize-uploaded-videos/new-directory.png)</Frame>
  </Step>
</Steps>

### Move videos to a directory

<p>Move one or more videos from the current list into a directory.</p>

<Steps>
  <Step title="Select videos">
    <p>On the **All videos** page, select the checkbox next to each video to move.</p>
  </Step>
  <Step title="Open the directory list">
    <p>Click **Move**.</p>

    <Frame>![Selected videos with Move](/images/docs/streaming/video-hosting/organize-uploaded-videos/move-videos-panel.png)</Frame>
  </Step>
  <Step title="Confirm the directory">
    <p>In **Select directory**, select the target directory and click **Move**.</p>
  </Step>
</Steps>

### Delete a directory

<p>The directory menu includes **Rename**, **Move**, and **Remove directory**.</p>

<Warning>
Videos in the directory are permanently deleted and cannot be restored. To remove only the directory, move the videos to another directory first.
</Warning>

<Steps>
  <Step title="Open the directory menu">
    <p>Click the three-dot icon next to the directory.</p>

    <Frame>![Directory menu with Remove directory](/images/docs/streaming/video-hosting/organize-uploaded-videos/remove-directory.png)</Frame>
  </Step>
  <Step title="Confirm removal">
    <p>Click **Remove directory**. In **Remove object**, click **Yes, delete**.</p>
  </Step>
</Steps>

## Tags

<p>A tag is a label on a video. Add tags in video settings, then filter the video list by those labels.</p>

### Add a tag to a video

<p>Tags are stored on the video settings page.</p>

<Steps>
  <Step title="Open video settings">
    <p>On the **All videos** page, click the video name.</p>
  </Step>
  <Step title="Add a tag">
    <p>In **Tags**, enter a new name and press Enter, or select an existing tag. A video can carry more than one tag.</p>
  </Step>
  <Step title="Save the tag">
    <p>Click **Save**.</p>

    <Frame>![Tags field on video settings](/images/docs/streaming/video-hosting/organize-uploaded-videos/add-tags.png)</Frame>
  </Step>
</Steps>

### Filter videos by tags

<p>On the **All videos** page, expand **Tags** and select the checkbox next to a tag. **Select all** includes every tag in the list.</p>

<Frame>![Tags filter with checkboxes](/images/docs/streaming/video-hosting/organize-uploaded-videos/tag-list.png)</Frame>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Manage video directories with the [Directories&nbsp;API](/api-reference/streaming/directories/get-list-of-directories). The API supports creating, renaming, and deleting directories, and moving videos between them.</p>

<p>Requests authenticate with an [API&nbsp;token](/account-settings/api-tokens). Set the API key and the video ID before the calls:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
```

## List directories

<p>Retrieve the directory tree. Each directory can contain nested directories in <code>descendants</code>.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()
    tree = client.streaming.directories.get_tree()
    for directory in tree.tree:
        dir_id = directory["id"] if isinstance(directory, dict) else directory.id
        dir_name = directory["name"] if isinstance(directory, dict) else directory.name
        print(dir_id, dir_name)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"

    	gcore "github.com/G-Core/gcore-go"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	tree, err := client.Streaming.Directories.GetTree(ctx)
    	if err != nil {
    		panic(err)
    	}
    	for _, dir := range tree.Tree {
    		fmt.Printf("id=%d  name=%s\n", dir.ID, dir.Name)
    	}
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/streaming/directories/tree" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The response contains a nested tree of directory objects:</p>

    ```json
    {
      "tree": [
        {
          "id": 13766,
          "name": "Season 1",
          "parent_id": null,
          "items_count": 5,
          "descendants": []
        }
      ]
    }
    ```
  </Tab>
</Tabs>

## Create a directory

<p>Create a new directory. The calls below create a top-level directory. To create a subdirectory, also pass <code>parent_id</code> with the parent directory ID.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()
    result = client.streaming.directories.create(name="Season 1")
    # The API response is wrapped in {"directory": {...}};
    # access the data through the .directory attribute.
    dir_id = result.directory["id"]
    print(f"Created directory id={dir_id}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"encoding/json"
    	"fmt"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/streaming"
    )

    // dirIDFromRaw extracts the directory ID from the SDK response.
    func dirIDFromRaw(d *streaming.DirectoryBase) int64 {
    	var w struct {
    		Directory struct {
    			ID int64 `json:"id"`
    		} `json:"directory"`
    	}
    	json.Unmarshal([]byte(d.RawJSON()), &w)
    	return w.Directory.ID
    }

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	result, err := client.Streaming.Directories.New(ctx, streaming.DirectoryNewParams{
    		Name: "Season 1",
    	})
    	if err != nil {
    		panic(err)
    	}
    	dirID := dirIDFromRaw(result)
    	fmt.Printf("Created directory id=%d\n", dirID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/streaming/directories" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "Season 1"}'
    ```

    <p>The response returns the created directory object:</p>

    ```json
    {
      "directory": {
        "id": 13766,
        "name": "Season 1",
        "parent_id": null,
        "items_count": 0
      }
    }
    ```
  </Tab>
</Tabs>

<p>Save the directory ID from the list response or the create response:</p>

```bash
export DIRECTORY_ID="{YOUR_DIRECTORY_ID}"
```

## Move a video to a directory

<p>Assign a video to a directory by updating its <code>directory_id</code>. [Videos&nbsp;API](/api-reference/streaming/videos/get-list-of-videos) returns the video ID.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    video_id = int(os.environ["VIDEO_ID"])
    dir_id = int(os.environ["DIRECTORY_ID"])

    # Retrieve current video name — required by the SDK update call.
    video = client.streaming.videos.get(video_id)
    client.streaming.videos.update(video_id, name=video.name, directory_id=dir_id)
    print(f"Video {video_id} moved to directory {dir_id}.")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	videoID, _ := strconv.ParseInt(os.Getenv("VIDEO_ID"), 10, 64)
    	dirID, _ := strconv.ParseInt(os.Getenv("DIRECTORY_ID"), 10, 64)

    	// Retrieve current video name — required by the SDK update call.
    	video, err := client.Streaming.Videos.Get(ctx, videoID)
    	if err != nil {
    		panic(err)
    	}
    	_, err = client.Streaming.Videos.Update(ctx, videoID, streaming.VideoUpdateParams{
    		CreateVideo: streaming.CreateVideoParam{
    			Name:        video.Name,
    			DirectoryID: param.NewOpt(dirID),
    		},
    	})
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Video %d moved to directory %d.\n", videoID, dirID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/streaming/videos/$VIDEO_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"directory_id": $DIRECTORY_ID}'
    ```

    <p>A successful response returns the updated video object with <code>directory_id</code> set to the new value.</p>
  </Tab>
</Tabs>

## Rename a directory

<p>Change the name of an existing directory. The same call can move it to a different parent by passing <code>parent_id</code>.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    dir_id = int(os.environ["DIRECTORY_ID"])
    result = client.streaming.directories.update(dir_id, name="Season 1 — Remastered")
    print(f"Renamed to: {result.directory['name']}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"encoding/json"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    // dirNameFromRaw extracts the directory name from the SDK response.
    func dirNameFromRaw(d *streaming.DirectoryBase) string {
    	var w struct {
    		Directory struct {
    			Name string `json:"name"`
    		} `json:"directory"`
    	}
    	json.Unmarshal([]byte(d.RawJSON()), &w)
    	return w.Directory.Name
    }

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	dirID, _ := strconv.ParseInt(os.Getenv("DIRECTORY_ID"), 10, 64)
    	result, err := client.Streaming.Directories.Update(ctx, dirID, streaming.DirectoryUpdateParams{
    		Name: param.NewOpt("Season 1 — Remastered"),
    	})
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Renamed to: %s\n", dirNameFromRaw(result))
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/streaming/directories/$DIRECTORY_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "Season 1 — Remastered"}'
    ```

    <p>The response returns the updated directory object with the new name.</p>
  </Tab>
</Tabs>

## Delete a directory

<Warning>
Deleting a directory permanently removes all videos and subdirectories inside it. This action cannot be undone. Move videos to another directory first to preserve them.
</Warning>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    dir_id = int(os.environ["DIRECTORY_ID"])
    client.streaming.directories.delete(dir_id)
    print(f"Directory {dir_id} deleted.")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	dirID, _ := strconv.ParseInt(os.Getenv("DIRECTORY_ID"), 10, 64)
    	if err := client.Streaming.Directories.Delete(ctx, dirID); err != nil {
    		panic(err)
    	}
    	fmt.Printf("Directory %d deleted.\n", dirID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X DELETE "https://api.gcore.com/streaming/directories/$DIRECTORY_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>A successful delete returns HTTP 204 No Content with an empty body.</p>
  </Tab>
</Tabs>
