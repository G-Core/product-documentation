<MethodSwitch>
  <MethodSection id="portal" label="Customer Portal">

<p>Create and configure a live stream in the Gcore Customer Portal, then start broadcasting from an encoder, media server, or browser.</p>

<Steps>
  <Step title="Check active stream limits">
    <p>The live stream limit applies to active live streams, not to created live stream entities. Any number of live stream entities can be created, but only the allowed number can be enabled at the same time.</p>

    <p>Before creating or enabling another stream, check the active-stream limit in the notification on the **Live Streaming** page.</p>

    <Frame>![Active live stream limit notification in the Customer Portal](/images/docs/streaming/live-streaming/create-a-live-stream/live-active-limits.png)</Frame>
  </Step>

  <Step title="Initiate the process">
    <p>1. In the **Gcore Customer Portal**, navigate to **Streaming** > [Live Streaming](https://portal.gcore.com/streaming/streaming).</p>

    <p>2. Click the **Create Live stream** button on the top right.</p>

    <Frame>![Live stream button on the life streaming page](/images/docs/streaming/live-streaming/create-a-live-stream/live-streaming-annotated.png)</Frame>

    <Accordion title="The 'Create Live stream' button is unavailable?">
    If the button is non-responsive, the live stream limit has been reached. Remove an existing stream from the list or request [technical support](mailto:support@gcore.com) to increase the limit.
    </Accordion>

    <p>3. Enter the live stream name in the window that appears and click **Create**.</p>

    <Frame>![Create and manage live stream dialog with a name field and Create button](/images/docs/streaming/live-streaming/create-a-live-stream/9651635790481.png)</Frame>

    <p>The Live stream settings page opens for the new stream.</p>
  </Step>

  <Step title="Choose the ingest type">
    <Frame>![Live stream settings page with Enable toggle, Record, DVR, ingest type, and Go live from your browser section](/images/docs/streaming/live-streaming/create-a-live-stream/live-stream-settings-push.png)</Frame>

    <p>1. Enable the **Enable live stream** toggle. Gcore delivers the stream in low-latency mode (2–3 second latency) via LL-HLS and LL-DASH by default — no configuration required.</p>

    <Accordion title="Low latency details and protocol options">
    LL-DASH is compatible with all devices except iOS Safari; LL-HLS is compatible with iOS. Both are active for all users from the start, including trial and free tier, with no plan upgrade required. Legacy HLS with MPEG-TS segments is also available; [How&nbsp;low-latency&nbsp;streaming&nbsp;works](/streaming/live-streaming/how-low-latency-streaming-works) covers protocol details and tradeoffs.
    </Accordion>

    <p>2. Select the **Ingest type**: **Push** or **Pull**.</p>

    <Accordion title="Go live from your browser (beta)">
    The settings page also shows a **Go live from your browser** section with a **Start WebRTC + webcam** button. Clicking it starts a WebRTC broadcast directly from the current browser tab using the webcam — no encoder or external software needed. The live stream begins within approximately 10 seconds. Closing the page stops the broadcast. This option is independent of the Push or Pull ingest type selection above.
    </Accordion>

    **Push vs Pull: which to choose**

    <Tabs>
      <Tab title="Push (most common)">
        Choose Push if:
        - The stream source is a webcam, mobile device, or computer
        - A streaming encoder (OBS, Streamlabs, vMix, or other hardware/software encoder) is the broadcast tool
        - No dedicated streaming server is available

        How it works:
        1. Configure the encoder with Gcore's server URL and stream key
        2. The encoder sends (pushes) the stream to Gcore via RTMP, SRT, or WebRTC WHIP
        3. Gcore transcodes the stream into multiple quality levels
        4. Gcore delivers via CDN in HLS and MPEG-DASH formats
      </Tab>
      <Tab title="Pull (if a source stream is already running)">
        Choose Pull if:
        - A stream is already running on an origin server
        - The stream URL is known
        - Gcore should fetch the stream and redistribute it

        How it works:
        1. Provide the source stream URL (e.g., `rtmp://1.1.1.1/live/stream`)
        2. Gcore pulls (fetches) the stream from the origin server
        3. Gcore transcodes the stream into ABR (adaptive bitrate) up to 1080p
        4. Gcore delivers via CDN in HLS and MPEG-DASH formats

        Example Pull URLs:
        - RTMP: `rtmp://1.1.1.1/live/stream`
        - SRT: `srt://1.1.1.1/live/stream`
        - HLS: `https://1.1.1.1/live/stream.m3u8`
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configure ingest">
    <p>For Push streams, encoder setup depends on the protocol — [RTMP/RTMPS](protocols/rtmp), [SRT](protocols/srt), and [WebRTC&nbsp;to&nbsp;HLS](protocols/webrtc) each have a dedicated configuration guide.</p>

    <p>For Pull ingest, configure the source URL directly on the settings page:</p>

    <p>1. **Prepare the source stream URL** — confirm the source stream is running, then copy its complete URL (e.g., `https://1.1.1.1/live/stream.m3u8`).</p>

    <p>2. **Enter the URL in the URL field** — paste the stream URL. Multiple URLs separated by spaces enable failover (optional). Example with backup: `rtmp://1.1.1.1/live/stream rtmp://1.1.1.2/live/stream`</p>

    <p>3. **Select geo-distributed pull point (optional)** — contact [support](mailto:support@gcore.com) to configure the optimal pull location to minimize latency.</p>

    <p>4. Click **Save**. The stream becomes active within approximately 15 seconds, and a preview appears on the settings page when ready.</p>

    <Info>
    **Troubleshooting:** If the stream does not appear after 2 minutes, confirm that the source stream is actively running and accessible, the URL is correct and publicly reachable, and the firewall allows Gcore's servers to reach the source.
    </Info>

    <Accordion title="Optional: Enable recording or DVR">
    These features can be enabled before or after the stream starts:

    - [Record](/streaming/live-streaming/record-your-live-streams-and-save-them-as-videos) — click **Start record** on the settings page while the stream is active to begin recording. The recording is saved to the Video tab.
    - [DVR](/streaming/live-streaming/pause-and-rewind-the-live-streams) — lets viewers pause and rewind the broadcast. Enable the DVR toggle before the stream starts.
    </Accordion>
  </Step>

  <Step title="Start the stream">
    <p>Start the broadcast on the encoder or media server. A streaming preview appears on the **Live Stream Settings** page once the stream is active.</p>
  </Step>

  <Step title="Get playback and embed links">
    <p>The **Live stream settings** page provides manifest URLs and player embed options for integrating the stream into an application or website.</p>

    <Frame>![Export links and player options](/images/docs/streaming/live-streaming/create-a-live-stream/live-stream-export-links.png)</Frame>

    **Links for the export**

    | Link | Description |
    |------|-------------|
    | **MPEG-DASH manifest URL** | Low-latency adaptive bitrate streaming. Compatible with most modern devices except iOS Safari. |
    | **HLS manifest URL** | Low-latency HLS (LL-HLS) with CMAF segments. Compatible with all devices including iOS. |
    | **HLS non-low-latency manifest URL** | Traditional HLS with MPEG-TS segments. Use for outdated devices or unstable connections. |

    **Player**

    | Option | Description |
    |--------|-------------|
    | **Player URL** | Direct link to the hosted player page. Share with viewers or use for testing. |
    | **Iframe embed code** | Copy and paste into a website or CMS to embed the player. |
  </Step>
</Steps>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Create and manage live streams using the [Streams&nbsp;API](/api-reference/streaming/streams/get-all-live-streams). After creating a stream, configure the encoder with the returned `push_url` (RTMP) or `push_url_srt` (SRT) and use `iframe_url` or `hls_cmaf_url` to embed playback.</p>

<Info>
Requests to the Streams API authenticate using an [API&nbsp;token](/account-settings/api-tokens).
</Info>

<p>Set environment variables before running the examples:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export STREAM_ID="{YOUR_STREAM_ID}"
```

## Create a push stream

<p>Create a push stream and get ingest credentials. The encoder sends video to Gcore using `push_url` (RTMP), `push_url_srt` (SRT), or `push_url_whip` (WebRTC WHIP). A `backup_push_url` and `backup_push_url_srt` are also returned for a geographically redundant backup ingest point.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()

stream = client.streaming.streams.create(
    name="My Live Stream",
    active=True,
)
print(f"Stream ID:          {stream.id}")
print(f"RTMP push URL:      {stream.push_url}")
print(f"RTMP backup URL:    {stream.backup_push_url}")
print(f"SRT push URL:       {stream.push_url_srt}")
print(f"SRT backup URL:     {stream.backup_push_url_srt}")
print(f"WebRTC WHIP URL:    {stream.push_url_whip}")
print(f"Embed URL:          {stream.iframe_url}")
print(f"HLS URL:            {stream.hls_cmaf_url}")
print(f"DASH URL:           {stream.dash_url}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    stream, err := client.Streaming.Streams.New(ctx, streaming.StreamNewParams{
        Name:   "My Live Stream",
        Active: param.NewOpt(true),
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("Stream ID:          %d\n", stream.ID)
    fmt.Printf("RTMP push URL:      %s\n", stream.PushURL)
    fmt.Printf("RTMP backup URL:    %s\n", stream.BackupPushURL)
    fmt.Printf("SRT push URL:       %s\n", stream.PushURLSrt)
    fmt.Printf("Embed URL:          %s\n", stream.IframeURL)
    fmt.Printf("HLS URL:            %s\n", stream.HlsCmafURL)
}
```
  </Tab>

## Create a pull stream

<p>For a pull stream, set `pull: true` and provide the source stream URL in `uri`. Multiple URLs separated by spaces enable failover.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()

stream = client.streaming.streams.create(
    name="My Pull Stream",
    active=True,
    pull=True,
    uri="rtmp://your-server.example.com/live/stream",
)
print(f"Stream ID: {stream.id}")
print(f"HLS URL:   {stream.hls_cmaf_url}")
```
  </Tab>
  <Tab title="Go SDK">
```go

    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"

)

    client := gcore.NewClient()
    ctx := context.Background()

    stream, err := client.Streaming.Streams.New(ctx, streaming.StreamNewParams{

    }
```

## Get a stream

```go
package main
```

## Embed playback

<p>After creating a stream, use the returned URLs to embed playback in an application:</p>

| Field | URL pattern | Use for |
|-------|-------------|---------|
| `iframe_url` | `https://player.gvideo.co/streams/{client_id}_{stream_id}` | Embed the hosted Gcore player in any website via `<iframe>` |
| `hls_cmaf_url` | `https://{client_id}.gvideo.io/cmaf/…/master.m3u8` | LL-HLS with CMAF segments — compatible with all devices including iOS |
| `dash_url` | `https://{client_id}.gvideo.io/cmaf/…/index.mpd` | LL-DASH — compatible with most modern devices except iOS Safari |
| `hls_mpegts_url` | `https://{client_id}.gvideo.io/mpegts/…/master_mpegts.m3u8` | Legacy HLS with MPEG-TS segments — use for older devices or unstable connections |

## Manage streams

<p>Once a stream is created, the following operations are available to control its state, configuration, and lifecycle.</p>

### Enable or disable a stream

<p>The `active` field corresponds to the **Enable live stream** toggle in the Customer Portal. Disable a stream to stop accepting ingest without deleting it; re-enable it when ready.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
stream_id = int(os.environ["STREAM_ID"])

# Enable
stream = client.streaming.streams.update(stream_id, stream={"active": True})
print(f"Enabled: {stream.active}")

# Disable
stream = client.streaming.streams.update(stream_id, stream={"active": False})
print(f"Disabled: {stream.active}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)

    // Enable
    stream, err := client.Streaming.Streams.Update(ctx, streamID, streaming.StreamUpdateParams{

            Active: param.NewOpt(true),

    }

}
```

### Configure DVR and recording

<p>DVR lets viewers pause and rewind a live broadcast. Auto-recording starts recording as soon as the stream goes live. Both can be set at creation time or updated later.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
stream_id = int(os.environ["STREAM_ID"])

stream = client.streaming.streams.update(
    stream_id,
    stream={
        "dvr_enabled": True,
        "dvr_duration": 7200,   # seconds viewers can rewind (default: 3600)
        "auto_record": True,
    },
)
print(f"DVR enabled:   {stream.dvr_enabled}")
print(f"DVR duration:  {stream.dvr_duration}s")
print(f"Auto-record:   {stream.auto_record}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)
    stream, err := client.Streaming.Streams.Update(ctx, streamID, streaming.StreamUpdateParams{
        Stream: streaming.StreamUpdateParamsStream{
            DvrEnabled:  param.NewOpt(true),
            DvrDuration: param.NewOpt(int64(7200)),
            AutoRecord:  param.NewOpt(true),
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("DVR enabled:  %v\n", stream.DvrEnabled)
    fmt.Printf("DVR duration: %v s\n", stream.DvrDuration)
    fmt.Printf("Auto-record:  %v\n", stream.AutoRecord)
}
```

```bash
       "stream": {
         "dvr_enabled": true,
```
