## Step 1. Check active stream limits

<p>The live stream limit applies to active live streams, not to created live stream entities. Any number of live stream entities can be created, but only the allowed number can be enabled at the same time.</p>

<p>Before creating or enabling another stream, check the active-stream limit in the notification on the **Live Streaming** page.</p>

<Frame>![Active live stream limit notification in the Customer Portal](/images/docs/streaming-platform/live-streaming/create-a-live-stream/live-active-limits.png)</Frame>

## Step 2. Initiate the process

<p>1. In the **Gcore Customer Portal**, navigate to **Streaming** > [Live Streaming](https://portal.gcore.com/streaming/streaming).</p>

<p>2. Click the **Create Live stream** button on the top right.</p>

<Frame>![Live stream button on the life streaming page](/images/docs/streaming-platform/live-streaming/create-a-live-stream/live-streaming-annotated.png)</Frame>

<Accordion title="The 'Create Live stream' button is unavailable?">
If the button is non-responsive, you have exceeded your live stream limit. To create a new stream, remove an existing stream from the list or request [technical support](mailto:support@gcore.com) to increase your limits.
</Accordion>

<p>2A. Enter the name of your live stream in the window that appears and click the **Create** button.</p>

<Frame>![Enter the name of your live stream](/images/docs/streaming-platform/live-streaming/create-a-live-stream/9651635790481.png)</Frame>

<p>A new page will appear. Perform the remaining steps there.</p>

## Step 3. Set the ingest type and additional features

<Frame>![Live stream page](/images/docs/streaming-platform/live-streaming/create-a-live-stream/live-stream-settings-push.png)</Frame>

<p>1. Make sure that the **Enable live stream** toggle is on.</p>

<Accordion title="Low latency explanation">
By default, we offer live streams with low latency (a 4–5 second delay.) Low latency is available in two protocols: LL-DASH ([compatible with all devices except iOS](/streaming/live-streaming/how-low-latency-streaming-works)) and LL-HLS (compatible with iOS). This feature is active from the start for all users, including those on the trial period or free tier, with no plan upgrades required. You can also obtain legacy HLS with MPEGTS format segments, in which case, please read [our article](/streaming/live-streaming/how-low-latency-streaming-works).
</Accordion>

<p>2. Review the live stream name and update it if needed.</p>

<p>3. Enable additional features:</p>

- [Record](/streaming/live-streaming/record-your-live-streams-and-save-them-as-videos) for live stream recording. It will be active when you start streaming. Remember to enable the toggle if you require a record of your stream.
- [DVR](/streaming/live-streaming/pause-and-rewind-the-live-streams) for an improved user experience. When the DVR feature is enabled, your viewers can pause and rewind the broadcast.

<p>4. Select the relevant **Ingest type**: **Push** or **Pull**.</p>

### When to choose Push vs Pull

<Tabs>
  <Tab title="Push (most common)">
    **Choose Push if:**
    - You generate a live stream from your web-cam, mobile device or computer
    - You're using a streaming encoder OBS, Streamlabs, vMix, or any other software and hardware encoder
    - You don't have your own streaming server

    **How it works:**
    1. Configure your encoder with Gcore's server URL and stream key
    2. Your encoder sends (pushes) the stream to our server via RTMP, SRT, WebRTC WHIP
    3. Gcore transcodes the stream into multiple quality levels
    4. Gcore delivers via CDN in HLS and MPEG-DASH formats
  </Tab>
  <Tab title="Pull (if you have your own streaming server)">
    **Choose Pull if:**
    - Stream is already running on some server
    - You know the URL of the stream
    - You want Gcore to fetch your stream and redistribute it

    **How it works:**
    1. You provide your existing stream URL (e.g., `rtmp://1.1.1.1/live/stream`)
    2. Gcore pulls (fetches) the stream from your server
    3. Gcore transcodes the stream into ABR (adaptive bitrate) up to 1080p
    4. Gcore delivers via CDN in HLS and MPEG-DASH formats

    **Example Pull URLs:**
    - RTMP: `rtmp://1.1.1.1/live/stream`
    - SRT: `srt://1.1.1.1/live/stream`
    - HLS: `https://1.1.1.1/live/stream.m3u8`
  </Tab>
</Tabs>

## Step 4. Configure your stream

<p>Depending on the selected ingest type and protocol, your settings will differ.</p>

### For PUSH streams

<p>Refer to specific protocol pages for detailed configuration:</p>

- [RTMP/RTMPS](protocols/rtmp)
- [SRT](protocols/srt)
- [WebRTC to HLS](protocols/webrtc)

### For PULL streams (step-by-step)

<p>If you selected **Pull** as your ingest type:</p>

<p>1. **Prepare your source stream URL** — ensure your stream is already running and copy the complete URL (e.g., `https://1.1.1.1/live/stream.m3u8`).</p>

<p>2. **Enter the URL in the PULL URL field** — paste your stream URL. You can enter multiple URLs separated by spaces for failover (optional). Example with backup: `rtmp://1.1.1.1/live/stream rtmp://1.1.1.2/live/stream`</p>

<p>3. **Select geo-distributed pull point (optional)** — contact [support](mailto:support@gcore.com) to configure the optimal pull location to minimize latency.</p>

<p>4. **Enable the stream** — make sure the **Enable live stream** toggle is **ON** (should be green) and click **Save**.</p>

<p>5. **Wait for activation** — the stream becomes active within approximately 15 seconds. A preview appears on the Live Stream Settings page when ready.</p>

<Info>
**Troubleshooting:** If the stream doesn't appear after 2 minutes, verify that your source stream is actively running and accessible, the URL is correct and publicly reachable, and your firewall allows Gcore's servers to access your stream.
</Info>

## Step 5. Start the stream

<p>Start a live stream on your media server or encoder. You will see a streaming preview on the **Live Stream Settings** page if everything is configured correctly.</p>

## Step 6. Embed the stream to your app

<p>After configuring your stream, embed it into your app or website. The **Live stream settings** page provides the export links and player embed options you need.</p>

<Frame>![Export links and player options](/images/docs/streaming-platform/live-streaming/create-a-live-stream/live-stream-export-links.png)</Frame>

### Links for the export

| Link | Description |
|------|-------------|
| **MPEG-DASH manifest URL** | Low-latency adaptive bitrate streaming. Compatible with most modern devices except iOS Safari. |
| **HLS manifest URL** | Low-latency HLS (LL-HLS) with CMAF segments. Compatible with all devices including iOS. |
| **HLS non-low-latency manifest URL** | Traditional HLS with MPEG-TS segments. Use for outdated devices or unstable connections. |

### Player

| Option | Description |
|--------|-------------|
| **Player URL** | Direct link to the hosted player page. Share with viewers or use for testing. |
| **Iframe embed code** | Copy and paste into your website or CMS to embed the player. |

  <MethodSection id="api" label="REST API">

<p>Create and manage live streams using the [Streams API](/api-reference/streaming/streams/get-all-live-streams). After creating a stream, configure your encoder with the returned `push_url` (RTMP) or `push_url_srt` (SRT) and use `iframe_url` or `hls_cmaf_url` to embed playback.</p>

<Info>
An [API token](/account-settings/api-tokens) is required.
</Info>

<p>Set the environment variable before running the examples:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Create a push stream

<p>Create a push stream and get ingest credentials. Your encoder uses `push_url` (RTMP) or `push_url_srt` (SRT) to send the video to Gcore. A `backup_push_url` is also returned for a geographically redundant backup ingest point.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    stream = client.streaming.streams.create(
        name="My Live Stream",
        active=True,
    )
    print(f"Stream ID: {stream.id}")
    print(f"RTMP push URL: {stream.push_url}")
    print(f"Backup RTMP: {stream.backup_push_url}")
    print(f"SRT push URL: {stream.push_url_srt}")
    print(f"Embed URL: {stream.iframe_url}")
    print(f"HLS URL: {stream.hls_cmaf_url}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	stream, err := client.Streaming.Streams.New(ctx, streaming.StreamNewParams{
    		Name:   "My Live Stream",
    		Active: param.NewOpt(true),
    	})
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Stream ID: %d\n", stream.ID)
    	fmt.Printf("RTMP push URL: %s\n", stream.PushURL)
    	fmt.Printf("Backup RTMP: %s\n", stream.BackupPushURL)
    	fmt.Printf("SRT push URL: %s\n", stream.PushURLSrt)
    	fmt.Printf("Embed URL: %s\n", stream.IframeURL)
    	fmt.Printf("HLS URL: %s\n", stream.HlsCmafURL)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/streaming/streams" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "My Live Stream",
        "active": true
      }'
    ```

    <p>The response includes ingest credentials and playback URLs:</p>

    ```json
    {
      "id": 4518887,
      "name": "My Live Stream",
      "active": true,
      "push_url": "rtmp://vp-push-ed2.gvideo.co/in/4518887?{token}",
      "backup_push_url": "rtmp://vp-push-anx1.gvideo.co/in/4518887b?{token}",
      "push_url_srt": "srt://vp-push-ed2.gvideo.co:5000?streamid=...",
      "iframe_url": "https://player.gvideo.co/streams/1000503_4518887",
      "hls_cmaf_url": "https://1000503.gvideo.io/cmaf/1000503_4518887/master.m3u8"
    }
    ```
  </Tab>
</Tabs>

## Create a pull stream

<p>For a pull stream, set `pull: true` and provide your source stream URL in `uri`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    stream = client.streaming.streams.create(
        name="My Pull Stream",
        active=True,
        pull=True,
        uri="rtmp://your-server.example.com/live/stream",
    )
    print(f"Stream ID: {stream.id}")
    print(f"HLS URL: {stream.hls_cmaf_url}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	stream, err := client.Streaming.Streams.New(ctx, streaming.StreamNewParams{
    		Name:   "My Pull Stream",
    		Active: param.NewOpt(true),
    		Pull:   param.NewOpt(true),
    		URI:    param.NewOpt("rtmp://your-server.example.com/live/stream"),
    	})
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Stream ID: %d\n", stream.ID)
    	fmt.Printf("HLS URL: %s\n", stream.HlsCmafURL)
    }
    ```

## Update stream settings

<p>Rename a stream or change its configuration. The `name` field is required in the Go SDK update call.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os
    from gcore import Gcore

    client = Gcore()
    stream_id = int(os.environ["STREAM_ID"])

    updated = client.streaming.streams.update(
        stream_id,
        stream={"name": "Renamed Stream", "auto_record": True},
    )
    print(f"Updated: {updated.name}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/packages/param"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)
    	updated, err := client.Streaming.Streams.Update(ctx, streamID, streaming.StreamUpdateParams{
    		Stream: streaming.StreamUpdateParamsStream{
    			Name:       "Renamed Stream",
    			AutoRecord: param.NewOpt(true),
    		},
    	})
    	if err != nil {
    		panic(err)
    	}
    	fmt.Printf("Updated: %s\n", updated.Name)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/streaming/streams/$STREAM_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "stream": {
          "name": "Renamed Stream",
          "auto_record": true
        }
      }'
    ```
  </Tab>
</Tabs>

## List and delete streams

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    # List
    page = client.streaming.streams.list()
    for stream in page.items:
        print(f"{stream.id}: {stream.name} (active={stream.active})")

    # Delete
    import os
    stream_id = int(os.environ["STREAM_ID"])
    client.streaming.streams.delete(stream_id)
    print(f"Deleted stream {stream_id}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
    	"context"
    	"fmt"
    	"os"
    	"strconv"

    	gcore "github.com/G-Core/gcore-go"
    	"github.com/G-Core/gcore-go/streaming"
    )

    func main() {
    	client := gcore.NewClient()
    	ctx := context.Background()

    	// List
    	page, err := client.Streaming.Streams.List(ctx, streaming.StreamListParams{})
    	if err != nil {
    		panic(err)
    	}
    	for _, stream := range page.Items {
    		fmt.Printf("%d: %s (active=%v)\n", stream.ID, stream.Name, stream.Active)
    	}

    	// Delete
    	streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)
    	if err := client.Streaming.Streams.Delete(ctx, streamID); err != nil {
    		panic(err)
    	}
    	fmt.Printf("Deleted stream %d\n", streamID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    # List
    curl "https://api.gcore.com/streaming/streams" \
      -H "Authorization: APIKey $GCORE_API_KEY"

    # Delete
    curl -X DELETE "https://api.gcore.com/streaming/streams/$STREAM_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```
  </Tab>
</Tabs>
