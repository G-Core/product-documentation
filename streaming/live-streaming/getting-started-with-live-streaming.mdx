Gcore Live Streaming is a cloud video streaming service that ingests live video over RTMP, SRT, or WebRTC WHIP, transcodes it once, and distributes HLS and MPEG-DASH streams globally via a CDN with 210+ PoPs.

<AccordionGroup>
  <Accordion title="Flexible ingest protocols">
    - RTMP/RTMPS: industry-standard push protocol for encoders (OBS, vMix, hardware encoders)
    - SRT: reliable transport for unstable or high-latency networks
    - WebRTC WHIP: browser-based ingest without encoder software; input is converted on the fly to HLS and DASH for CDN delivery
    - Pull RTMP/SRT/HLS: fetches a stream from an existing public ingest endpoint
  </Accordion>

  <Accordion title="Playback and delivery">
    <Info>
      Low-latency streaming (LL-HLS and LL-DASH) is active by default for all accounts, including trial and free tier, and requires no separate activation step.
    </Info>

    - LL-HLS / LL-DASH: 2–3 second latency using HLS CMAF and MPEG-DASH CMAF
    - Traditional HLS (MPEG-TS): maximum device compatibility at higher latency
    - Adaptive bitrate (ABR): automatic quality switching up to 1080p based on viewer bandwidth
  </Accordion>

  <Accordion title="Live streaming features">
    - Overlays: add graphics, logos, and text overlays
    - Playlists: schedule and automate content playback
    - Live clipping: create VOD highlights from a live stream
    - Restreams: broadcast simultaneously to YouTube, Facebook, Twitch, and other platforms
    - Recording: save streams automatically as VOD
    - DVR: let viewers pause and rewind live content
    - Multicamera: combine multiple input sources into a single broadcast
  </Accordion>
</AccordionGroup>

## Trial and activation

Trial accounts can start live streams for evaluation, but quotas can limit concurrent streams and available processing minutes. If the Gcore Customer Portal shows a limit alert, contact [support](mailto:support@gcore.com) or an account manager to request a higher trial quota.

To remove trial limits, activate the paid PAYG tariff. The [tariff&nbsp;overview](/streaming/billing/overview-of-tariffs) lists trial and active PAYG limits for live streams, storage, transcoding, delivery, and AI services.

[Create&nbsp;a&nbsp;stream](/streaming/live-streaming/create-a-live-stream) walks through setup from ingest configuration to playback verification.
