<p>Disable a live stream to stop ingest and playback temporarily, or delete the stream entity when its settings and statistics are no longer needed.</p>

<p>Disabling preserves the stream configuration for later use; deletion removes the stream entity permanently.</p>

## Stream disabling

<p>An enabled live stream can accept ingest and produce playable output. When disabled, ingest is not processed and existing player embeds have no video to play. Use disabling when the stream may be needed again later.</p>

<Steps>
  <Step title="Navigate to Live Streaming">
    Log in to the [Gcore Customer Portal](https://portal.gcore.com) and navigate to **Streaming** > **Live Streaming**.
  </Step>
  <Step title="Open the stream settings">
    Click the stream name to open its settings.
  </Step>
  <Step title="Disable the stream">
    Turn off **Enable live stream** and click **Save changes**.

    <Frame>![Live stream settings with the Enable live stream toggle](/images/docs/streaming/live-streaming/delete-live-stream/live-stream-disable.png)</Frame>
  </Step>
</Steps>

<p>To restore stream availability, turn on **Enable live stream** and click **Save changes**.</p>

## Stream deletion

<p>Delete the stream when its configuration, playback links, and statistics are no longer needed.</p>

<p>Deleting the live stream does not delete recordings created from it; they remain as VOD videos in Video Hosting.</p>

<Warning>
Live stream deletion is irreversible. It removes stream settings, ingest and playback links, and stream statistics.
</Warning>

<Steps>
  <Step title="Find the stream">
    On the **Live Streaming** page, find the stream to remove.
  </Step>
  <Step title="Open the context menu">
    Click **⋯** at the end of the stream row and select **Delete**.

    <Frame>![Live stream list with the Delete option in the context menu](/images/docs/streaming/live-streaming/delete-live-stream/live-stream-delete.png)</Frame>
  </Step>
  <Step title="Confirm deletion">
    Click **Yes, delete**.
  </Step>
</Steps>
</MethodSection>
  <MethodSection id="api" label="REST API">
<p>Disable or delete live streams with the Streams API. All requests authenticate with an [API&nbsp;token](/account-settings/api-tokens).</p>

<p>Set the API token and live stream ID before running the examples:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export STREAM_ID="{STREAM_ID}"
```

## Disable or re-enable a stream

<p>Set `stream.active` to `false` with the [Change&nbsp;stream](/api-reference/streaming/streams/change-live-stream) endpoint to stop ingest and playback without removing the stream entity.</p>

```bash
curl -X PATCH "https://api.gcore.com/streaming/streams/$STREAM_ID" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"stream":{"active":false}}'
```

<p>To re-enable the stream, set `stream.active` to `true`.</p>

```bash
curl -X PATCH "https://api.gcore.com/streaming/streams/$STREAM_ID" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"stream":{"active":true}}'
```

<p>Both requests return the updated stream object with the new `active` value.</p>

## Stream deletion

<p>The [Delete&nbsp;stream](/api-reference/streaming/streams/delete-live-stream) endpoint removes the stream entity permanently — call it only when the stream is no longer needed.</p>

<Warning>
Live stream deletion is irreversible. It removes stream settings, ingest and playback links, and stream statistics.
</Warning>

```bash
curl -X DELETE "https://api.gcore.com/streaming/streams/$STREAM_ID" \
  -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>A successful delete request returns no response body.</p>

<p>Recordings created from the stream are not deleted. They remain available as separate VOD videos in Video Hosting.</p>
