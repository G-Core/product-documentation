<p>DVR (Digital Video Recorder) lets viewers pause and rewind a live broadcast by caching recent stream content.</p>

<p>The DVR window defines how far back viewers can rewind. The default window is 1 hour. `dvr_duration` can be set through the API to extend the window up to 4 hours; the Customer Portal does not support changing the DVR duration. Enterprise accounts can [contact support](https://gcore.com/contact-us) to request a DVR window of up to 24 hours.</p>

<p>Example of how the DVR window works for a stream that has been running for more than 1 hour:</p>

```text
Start                                                     Now
  |----- outside DVR window ----|<--- DVR: last 1 hour --->| Live edge
  |  older part of the stream   | viewers can rewind here  |
```

  <MethodSection id="portal" label="Customer Portal">

## Enable DVR

<p>1. Create a new live stream (see [Create a live stream](/streaming/live-streaming/create-a-live-stream)) or open an existing one.</p>

<p>2. On the Live stream settings page, enable the **DVR** toggle. After the broadcast starts, allow about 10 minutes for content to accumulate before viewers can rewind.</p>


<Frame>![Live stream settings page with DVR toggle](/images/docs/streaming/live-streaming/pause-and-rewind-the-live-streams/dvr-live-stream-settings.png)</Frame>


<p>3. Click **Save**. Viewers can then use the player timeline to pause and rewind the broadcast.</p>


<Frame>![Embedded player showing DVR rewind scroll bar](/images/docs/streaming/live-streaming/pause-and-rewind-the-live-streams/9654917633553.png)</Frame>


<p>Before starting a new broadcast on an existing stream, click **Clear** next to the DVR toggle to remove content cached from the previous broadcast. Otherwise, viewers may watch the end of the previous broadcast from the cache.</p>

<p>Viewers can rewind with the player timeline. On Android, they can also double-tap the left or right side of the Gcore player to rewind or skip forward by 10–15 seconds.</p>

</MethodSection>

## Enable DVR on a stream

<p>Update an existing stream with `dvr_enabled: true`. Set `dvr_duration` (in seconds) to control how far back viewers can rewind. After the broadcast starts, allow about 10 minutes for content to accumulate before viewers can rewind.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
stream_id = int(os.environ["STREAM_ID"])

# Enable DVR on an existing stream
stream = client.streaming.streams.update(
    stream_id,
    stream={
        "name": "My live stream",
        "dvr_enabled": True,
        "dvr_duration": 3600,  # 1 hour window
    },
)
print(f"DVR enabled: {stream.dvr_enabled}, window: {stream.dvr_duration}s")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)

    // Enable DVR on an existing stream
    stream, err := client.Streaming.Streams.Update(ctx, streamID, streaming.StreamUpdateParams{
        Stream: streaming.StreamUpdateParamsStream{
            Name:        "My live stream",
            DvrEnabled:  param.NewOpt(true),
            DvrDuration: param.NewOpt[int64](3600), // 1 hour window
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("DVR enabled: %v, window: %ds\n", stream.DvrEnabled, stream.DvrDuration)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X PATCH "https://api.gcore.com/streaming/streams/$STREAM_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"dvr_enabled": true, "dvr_duration": 3600}'
```

<p>The API returns the updated stream object with `dvr_enabled: true` and `dvr_duration: 3600`.</p>
  </Tab>
</Tabs>

<p>The `dvr_enabled` and `dvr_duration` fields are also accepted in `POST /streaming/streams` when creating a new stream. The full create request is documented in [Create a live stream](/streaming/live-streaming/create-a-live-stream).</p>

## Clear the DVR cache

<p>Clear the DVR cache between broadcasts so viewers don't see the end of the previous stream when a new one starts.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
stream_id = int(os.environ["STREAM_ID"])

client.streaming.streams.clear_dvr(stream_id)
print("DVR cache cleared")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)

    if err := client.Streaming.Streams.ClearDvr(ctx, streamID); err != nil {
        panic(err)
    }
    fmt.Println("DVR cache cleared")
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X PUT "https://api.gcore.com/streaming/streams/$STREAM_ID/dvr_cleanup" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>The API returns HTTP 204 No Content on success.</p>
