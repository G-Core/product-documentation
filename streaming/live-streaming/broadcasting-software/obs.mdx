[OBS](https://obsproject.com) is a free encoder that pushes a live stream from a PC or laptop to Gcore Video Streaming over RTMP.

## Setup

1. Download [OBS](https://obsproject.com) from the official website.

2. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **Streaming** → **Live Streaming** and open **Live stream settings** for the target stream. In the **URLs for encoder** section, select the **RTMP** tab and copy the **Server** and **Stream Key** values.

   <Frame>
     ![Live stream settings page showing the URLs for encoder section with Server and Stream Key fields](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-live-stream-settings.png)
   </Frame>

3. In OBS, open **Settings** and navigate to the **Stream** tab.

   <Frame>
     ![OBS Stream tab showing the Service dropdown set to Custom... and the Server and Stream Key fields](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-stream-tab.png)
   </Frame>

4. Select **Custom...** from the **Service** dropdown, then enter the copied values:

   - Server URL into the **Server** field.
   - Stream Key into the **Stream Key** field.

5. Click **Apply**.

## Configure encoding

Configure these settings before starting the stream. Open **Settings** in OBS, then navigate to each tab below.

### Output

1. Navigate to the **Output** tab. In **Simple** mode, set the following:

   - **Video Bitrate:** 2000 Kbps for 720p or 4000 Kbps for 1080p.
   - **Audio Bitrate:** 128 Kbps.
   - **Video Encoder:** Software (x264).
   - **Encoder Preset:** veryfast.

   <Frame>
     ![OBS Output tab in Simple mode showing Video Bitrate, Audio Bitrate, Video Encoder, and Encoder Preset fields](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-output-simple.png)
   </Frame>

2. Switch **Output Mode** to **Advanced**. In the **Encoder Settings** section, set:

   - **Rate Control:** CRF.
   - **Keyframe Interval (0=auto):** 2 s.
   - **Profile:** baseline.

   <Frame>
     ![OBS Output tab in Advanced mode showing Rate Control, Keyframe Interval, and Profile fields](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-output-advanced.png)
   </Frame>

3. Click **Apply**.

<Tip>
  To stream at 60 FPS, double the Video Bitrate to maintain stream quality.
</Tip>

### Audio

1. Navigate to the **Audio** tab.

2. In the **General** section, confirm that **Sample Rate** is set to 48 kHz and **Channels** is set to **Stereo**. These are the OBS defaults and require no change.

3. Click **Apply**.

   <Frame>
     ![OBS Audio tab showing Sample Rate set to 48 kHz and Channels set to Stereo](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-audio.png)
   </Frame>

### Video (optional)

To downscale the source resolution:

1. Navigate to the **Video** tab.

2. Set the following:

   - **Output (Scaled) Resolution:** 1280×720
   - **Downscale Filter:** Bicubic
   - **Common FPS Values:** 30

3. Click **Apply**.

   <Frame>
     ![OBS Video tab showing Output (Scaled) Resolution, Downscale Filter, and Common FPS Values fields](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-video.png)
   </Frame>

## Start streaming

In the main OBS window, select a source (video capture device, display capture, or another source) and click **Start Streaming**.

<Frame>
  ![OBS main window showing the Controls panel with the Start Streaming button](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-main-window.png)
</Frame>

Set the FPS value before starting — Gcore detects the source frame rate when the live transcoding session begins.

<Info>
  If OBS connects while already sending a reduced frame rate due to CPU overload, dropped frames, or unstable source timing, Gcore starts the transcoding session with that lower detected FPS. After fixing the source, restart the stream so a new session begins with the correct source metadata.
</Info>

To embed the broadcast on a website, open **Live stream settings** in the Customer Portal and copy the **Iframe embed code** from the **Links for the export** section.

<Frame>
  ![Live stream settings page showing the Links for the export section with the Iframe embed code field](/images/docs/streaming/live-streaming/broadcasting-software/obs/obs-links-for-export.png)
</Frame>
