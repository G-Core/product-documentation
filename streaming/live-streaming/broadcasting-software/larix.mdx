[Larix&nbsp;Broadcaster](https://softvelum.com/larix/) is a free mobile encoder for live streaming. Use it to stream from a smartphone or tablet to Gcore Video Streaming over RTMP, with stream parameters configured through [Larix&nbsp;Grove](https://softvelum.com/larix/grove/).

## Setup

1. Install [Larix&nbsp;Broadcaster](https://softvelum.com/larix/) on a mobile device.
2. To get the server URL and stream key, navigate to the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com), select **Streaming** → **Live Streaming**, open the **Live stream settings** for the target stream, and copy the relevant values from the **URLs for encoder** section.

   The **Live stream settings** page shows these fields:

   <Frame>
     ![Live stream settings showing the URLs for encoder section with RTMP Server and Stream Key fields](/images/docs/streaming/live-streaming/broadcasting-software/larix/larix-live-stream-settings.png)
   </Frame>

   Concatenate the Server URL and Stream Key to form the full RTMP URL for the stream:

   ```
   rtmp://vp-push-ed2.gvideo.co/in/{STREAM_ID}?{TOKEN}
   ```

3. Open [Larix&nbsp;Grove](https://softvelum.com/larix/grove/) to create a Larix configuration and share it via QR code.
4. In **Larix Grove**, scroll down to the **Connection** section.
5. Enter the URL and a name for the connection.
6. Click the **QR-code** button to generate a QR code.
7. On the mobile device, open the Larix app and tap the gear icon to open the settings.
8. Tap **Larix Grove** and then tap **Scan Grove QR code**.
9. Scan the QR code generated in Larix Grove. The app configures the connection automatically.
10. Return to the main screen and tap the big white button to start streaming.

## Configure stream parameters

Adjust these settings in [Larix&nbsp;Grove](https://softvelum.com/larix/grove/), which generates the configuration and connection URL as a QR code for sharing with team members.

After changing the settings, click the **QR-code** button to generate a new QR code.

<Frame>
  ![Larix Grove configuration form showing Connection, Camera, Video encoder, and Audio encoder sections with recommended values](/images/docs/streaming/live-streaming/broadcasting-software/larix/larix-grove.png)
</Frame>

### Camera parameters

To reduce the original resolution (downscale), set the Resolution field to the target value.

For 60 fps, double the bitrate to maintain stream quality.

- **Resolution:** 1280×720
- **Frame rate:** 30

### Video encoder parameters

- **Video Bitrate:** 2000000 for 720p resolution or 4000000 for 1080p resolution.
- **Keyframe Interval:** 60 (i.e., 2 seconds)

### Audio encoder parameters

- **Audio Bitrate:** 128000
- **Sample Rate:** 44100 or 48000
- **Channels count:** 2
