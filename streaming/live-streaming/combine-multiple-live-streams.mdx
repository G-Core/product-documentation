<p>Multicamera combines two or more live streams into one player. Viewers can switch between streams using a button in the player — to select a camera angle at a live event or a language track for a multilingual broadcast.</p>

<Frame>![Multicamera player with stream switch button](/images/docs/streaming/live-streaming/combine-multiple-live-streams/multicamera.png)</Frame>

## Configure multicamera

<p>Create at least two [live&nbsp;streams](/streaming/live-streaming/create-a-live-stream) before configuring a multicamera.</p>

<p>1\. Click **Create a multicamera**, enter a name (visible only in the Customer Portal, not to viewers), and select at least two live streams to combine. Click **Create**.</p>

<Frame>![Create a multicamera dialog with stream selection](/images/docs/streaming/live-streaming/combine-multiple-live-streams/create-multicamera-dialog.png)</Frame>

<p>The multicamera settings page opens.</p>

<Frame>![Multicamera settings page with status, streams, export, and poster sections](/images/docs/streaming/live-streaming/combine-multiple-live-streams/multicamera-settings.png)</Frame>

<p>2\. Select a stream status. The status determines what a viewer sees in the player:</p>

  * _Live_ — the live stream
  * _Waiting for start_ — a black screen with the "Waiting for start" message, or a poster from Step 5
  * _Paused_ — a black screen with the "Paused" message, or a poster from Step 5
  * _Ended_ — a black screen with the "Ended" message, or a poster from Step 5

<p>The status can be changed at any time during the broadcast — switch to "Paused" to suspend the stream during a technical issue, then switch back to "Live" when resolved.</p>

<p>3\. (Optional) Select a custom player from the **Player** dropdown if a custom player template exists. Custom player templates are created in [Players](/streaming/extra-features/customize-appearance-of-the-built-in-player).</p>

<p>4\. In the **Streams** section, drag streams to set the playback order. Viewers see the first stream in the list by default and can switch between streams using the player button. Click **Edit streams** to add streams or use the delete icon to remove individual streams.</p>

<p>5\. Upload a poster in the **Poster** section to display an image instead of a plain text message when the status is "Waiting for start", "Paused", or "Ended".</p>

<p>6\. Click **Save changes**.</p>

<p>7\. Copy the embed code from the **Export** section and add it to the webpage where the player should appear.</p>

<p>The player shows the primary stream. Viewers can switch to other streams using the camera button in the player corner.</p>

export GCORE_API_KEY="{YOUR_API_KEY}"

<p>In the API, Multicamera is called a **broadcast**. Create the broadcast with a list of stream IDs. Use `status: "pending"` for "Waiting for Start", `"live"` for Live, `"paused"` for Paused, or `"finished"` for Ended.</p>

## Create a multicamera

<p>Send `POST /streaming/broadcasts` with the broadcast name, initial status, and the list of stream IDs to include.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
stream_id_1 = int(os.environ["STREAM_ID_1"])
stream_id_2 = int(os.environ["STREAM_ID_2"])

resp = client.streaming.broadcasts.with_raw_response.create(
    broadcast={
        "name": "My multicamera broadcast",
        "status": "pending",
        "stream_ids": [stream_id_1, stream_id_2],
    }
)
data = resp.http_response.json()
broadcast_id = data["id"]
print(f"Broadcast ID: {broadcast_id}")
print(f"Embed code:   {data['iframe_embed_code']}")
print(f"Player URL:   {data['iframe_url']}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "net/http"
    "os"
    "strconv"
)

func main() {
    apiKey := os.Getenv("GCORE_API_KEY")
    stream1, _ := strconv.ParseInt(os.Getenv("STREAM_ID_1"), 10, 64)
    stream2, _ := strconv.ParseInt(os.Getenv("STREAM_ID_2"), 10, 64)

    body := fmt.Sprintf(
        `{"broadcast":{"name":"My multicamera broadcast","status":"pending","stream_ids":[%d,%d]}}`,
        stream1, stream2,
    )
    req, _ := http.NewRequest(http.MethodPost,
        "https://api.gcore.com/streaming/broadcasts",
        bytes.NewBufferString(body),
    )
    req.Header.Set("Authorization", "APIKey "+apiKey)
    req.Header.Set("Content-Type", "application/json")

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    raw, _ := io.ReadAll(resp.Body)
    var broadcast map[string]any
    _ = json.Unmarshal(raw, &broadcast)
    fmt.Printf("Broadcast ID:  %v\n", broadcast["id"])
    fmt.Printf("Embed code:    %v\n", broadcast["iframe_embed_code"])
    fmt.Printf("Player URL:    %v\n", broadcast["iframe_url"])
}
```

## Change broadcast status

<p>Update the broadcast status to control what viewers see. Set `status` to `"live"` to start the broadcast, `"paused"` to pause it, or `"finished"` to end it.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

broadcast_id = int(os.environ["BROADCAST_ID"])

client = Gcore()
broadcast = client.streaming.broadcasts.update(
    broadcast_id=broadcast_id,
    broadcast={
        "name": "My multicamera broadcast",
        "status": "live",
    },
)
print(f"Status updated to: {broadcast.status}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    broadcastID, _ := strconv.ParseInt(os.Getenv("BROADCAST_ID"), 10, 64)

    client := gcore.NewClient()
    broadcast, err := client.Streaming.Broadcasts.Update(
        context.Background(),
        broadcastID,
        streaming.BroadcastUpdateParams{
            Broadcast: streaming.BroadcastUpdateParamsBroadcast{
                Name:   "My multicamera broadcast",
                Status: param.NewOpt("live"),
            },
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("Status updated to: %s\n", broadcast.Status)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X PATCH "https://api.gcore.com/streaming/broadcasts/$BROADCAST_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"broadcast": {"name": "My multicamera broadcast", "status": "live"}}'
```
  </Tab>
</Tabs>

## Update stream list

<p>Send `PATCH /streaming/broadcasts/{broadcast_id}` with a new `stream_ids` array to add, remove, or reorder streams. The order of IDs in the array determines the playback order in the player.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

broadcast_id = int(os.environ["BROADCAST_ID"])
stream_id_1 = int(os.environ["STREAM_ID_1"])
stream_id_2 = int(os.environ["STREAM_ID_2"])

client = Gcore()
broadcast = client.streaming.broadcasts.update(
    broadcast_id=broadcast_id,
    broadcast={
        "name": "My multicamera broadcast",
        "stream_ids": [stream_id_2, stream_id_1],
    },
)
print(f"Streams: {broadcast.stream_ids}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "bytes"
    "fmt"
    "io"
    "net/http"
    "os"
    "strconv"
)

func main() {
    apiKey := os.Getenv("GCORE_API_KEY")
    broadcastID, _ := strconv.ParseInt(os.Getenv("BROADCAST_ID"), 10, 64)
    stream1, _ := strconv.ParseInt(os.Getenv("STREAM_ID_1"), 10, 64)
    stream2, _ := strconv.ParseInt(os.Getenv("STREAM_ID_2"), 10, 64)

    body := fmt.Sprintf(
        `{"broadcast":{"name":"My multicamera broadcast","stream_ids":[%d,%d]}}`,
        stream2, stream1,
    )
    req, _ := http.NewRequest(http.MethodPatch,
        fmt.Sprintf("https://api.gcore.com/streaming/broadcasts/%d", broadcastID),
        bytes.NewBufferString(body),
    )
    req.Header.Set("Authorization", "APIKey "+apiKey)
    req.Header.Set("Content-Type", "application/json")

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()
    raw, _ := io.ReadAll(resp.Body)
    fmt.Println(string(raw))
}
```

  <Tab title="curl">

     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d "{\"broadcast\": {\"name\": \"My multicamera broadcast\", \"stream_ids\": [$STREAM_ID_2, $STREAM_ID_1]}}"

## Delete a multicamera

<p>Send `DELETE /streaming/broadcasts/{broadcast_id}`. The endpoint returns HTTP 204 with no body on success.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

broadcast_id = int(os.environ["BROADCAST_ID"])

client = Gcore()
client.streaming.broadcasts.delete(broadcast_id)
print("Broadcast deleted.")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    broadcastID, _ := strconv.ParseInt(os.Getenv("BROADCAST_ID"), 10, 64)

    client := gcore.NewClient()
    err := client.Streaming.Broadcasts.Delete(context.Background(), broadcastID)
    if err != nil {
        panic(err)
    }
    fmt.Println("Broadcast deleted.")
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X DELETE "https://api.gcore.com/streaming/broadcasts/$BROADCAST_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
