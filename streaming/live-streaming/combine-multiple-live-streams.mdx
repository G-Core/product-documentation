## What is multicamera?

<p>Multicamera is a feature used to combine two or more live streams into one player. You deliver several streams at once, and a user can switch between them using a button in the video player.</p>

<Frame>![multicamera](/images/docs/streaming-platform/live-streaming/combine-multiple-live-streams/multicamera.png)</Frame>

<p>This feature is useful when you need to stream the event simultaneously from several angles or in different languages.</p>

<p>**Multiple angles.** You are broadcasting a film award ceremony. Your audience wants to see not only the stage, where the host announces winners but also the hall with celebrities. With a Multicamera, you stream from two cameras at once — one shoots the stage, and the other films the hall. Each viewer can click a button in the player to switch between cameras at any time.</p>

<p>**Multiple languages.** You are broadcasting for a multilingual audience: Germans, English and French. You create three live streams dubbed into English, German and French, respectively. You send these streams through Multicamera, and viewers get the opportunity to instantly switch between different voice-overs.</p>

## Configure multicamera

<p>Create at least two live streams before you configure the Multicamera. To do this, you can use our guide: [Create a live stream](/streaming/live-streaming/create-a-live-stream).</p>

<p>1\. Click **Create a multicamera**, enter the name (it will be displayed only in the Gcore Customer Portal and will be invisible to viewers), and select the live streams you want to combine. Click **Create**.</p>

<p>You can also select only one stream.</p>

<Frame>![Configure Multicamera](/images/docs/streaming-platform/live-streaming/combine-multiple-live-streams/9768430076433.png)</Frame>

<p>A new window will open. Do the remaining steps in it.</p>

<Frame>![remaining steps](/images/docs/streaming-platform/live-streaming/combine-multiple-live-streams/9768930910097.png)</Frame>

<p>2\. Select a stream status. The status determines what a viewer will see in the player:</p>

  * _Live_ — your stream
  * _Waiting for Start_ — a black screen with the "Waiting for Start" message or a screensaver from Step 4 of this guide
  * _Paused_ — a black screen with the "Paused" message or a screensaver from Step 4 of this guide
  * _Ended_ — a black screen with the "Ended" message or a screensaver from Step 4 of this guide

<p>You can change the status as you stream. For example, in case of a technical problem, set the "Paused" status to suspend your stream. When you fix the issue, change the status to "Live", and the broadcast will be continued.</p>

<p>3\. If you enable the [Players](/streaming/extra-features/customize-appearance-of-the-built-in-player) feature, you can select here a custom player.</p>

<p>4\. Set the order of the live streams. When a viewer opens the player, they will first see the first live stream from the list, and then will be able to skip to others by clicking the buttons. At this step, you can delete and add live streams.</p>

<p>5\. Upload a screensaver if you want to show an image in the "Waiting for Start", "Paused" and "Ended" statuses instead of the text message.</p>

<p>6\. Copy the iFrame code and embed it into your webpage code.</p>

<p>7\. Click **Save changes**.</p>

<p>The player will show the primary stream, and your users will be able to switch to other streams using the button in the corner.</p>

<p>In the API, Multicamera is called a **broadcast**. Create the broadcast with a list of stream IDs. Use `status: "pending"` for "Waiting for Start", `"live"` for Live, `"paused"` for Paused, or `"finished"` for Ended.</p>

## Create a multicamera

<p>Send `POST /streaming/broadcasts` with the broadcast name, initial status, and the list of stream IDs to include.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

client = Gcore()
stream_id_1 = int(os.environ["STREAM_ID_1"])
stream_id_2 = int(os.environ["STREAM_ID_2"])

resp = client.streaming.broadcasts.with_raw_response.create(
    broadcast={
        "name": "My multicamera broadcast",
        "status": "pending",
        "stream_ids": [stream_id_1, stream_id_2],
    }
)
data = resp.http_response.json()
broadcast_id = data["id"]
print(f"Broadcast ID: {broadcast_id}")
print(f"Embed code:   {data['iframe_embed_code']}")
print(f"Player URL:   {data['iframe_url']}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "net/http"
    "os"
    "strconv"
)

func main() {
    apiKey := os.Getenv("GCORE_API_KEY")
    stream1, _ := strconv.ParseInt(os.Getenv("STREAM_ID_1"), 10, 64)
    stream2, _ := strconv.ParseInt(os.Getenv("STREAM_ID_2"), 10, 64)

    body := fmt.Sprintf(
        `{"broadcast":{"name":"My multicamera broadcast","status":"pending","stream_ids":[%d,%d]}}`,
        stream1, stream2,
    )
    req, _ := http.NewRequest(http.MethodPost,
        "https://api.gcore.com/streaming/broadcasts",
        bytes.NewBufferString(body),
    )
    req.Header.Set("Authorization", "APIKey "+apiKey)
    req.Header.Set("Content-Type", "application/json")

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    raw, _ := io.ReadAll(resp.Body)
    var broadcast map[string]any
    _ = json.Unmarshal(raw, &broadcast)
    fmt.Printf("Broadcast ID:  %v\n", broadcast["id"])
    fmt.Printf("Embed code:    %v\n", broadcast["iframe_embed_code"])
    fmt.Printf("Player URL:    %v\n", broadcast["iframe_url"])
}
```
  </Tab>
  <Tab title="curl">

         "name": "My multicamera broadcast",

         "stream_ids": ['"$STREAM_ID_1"', '"$STREAM_ID_2"']
       }
     }'

## Change broadcast status

<p>Update the broadcast status to control what viewers see. Set `status` to `"live"` to start the broadcast, `"paused"` to pause it, or `"finished"` to end it.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

broadcast_id = int(os.environ["BROADCAST_ID"])

client = Gcore()
broadcast = client.streaming.broadcasts.update(
    broadcast_id=broadcast_id,
    broadcast={
        "name": "My multicamera broadcast",
        "status": "live",
    },
)
print(f"Status updated to: {broadcast.status}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/packages/param"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    broadcastID, _ := strconv.ParseInt(os.Getenv("BROADCAST_ID"), 10, 64)

    client := gcore.NewClient()
    broadcast, err := client.Streaming.Broadcasts.Update(
        context.Background(),
        broadcastID,
        streaming.BroadcastUpdateParams{
            Broadcast: streaming.BroadcastUpdateParamsBroadcast{
                Name:   "My multicamera broadcast",
                Status: param.NewOpt("live"),
            },
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("Status updated to: %s\n", broadcast.Status)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X PATCH "https://api.gcore.com/streaming/broadcasts/$BROADCAST_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"broadcast": {"name": "My multicamera broadcast", "status": "live"}}'
```
  </Tab>
</Tabs>

## Delete a multicamera

<p>Send `DELETE /streaming/broadcasts/{broadcast_id}`. The endpoint returns HTTP 204 with no body on success.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

broadcast_id = int(os.environ["BROADCAST_ID"])

client = Gcore()
client.streaming.broadcasts.delete(broadcast_id)
print("Broadcast deleted.")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    broadcastID, _ := strconv.ParseInt(os.Getenv("BROADCAST_ID"), 10, 64)

    client := gcore.NewClient()
    err := client.Streaming.Broadcasts.Delete(context.Background(), broadcastID)
    if err != nil {
        panic(err)
    }
    fmt.Println("Broadcast deleted.")
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X DELETE "https://api.gcore.com/streaming/broadcasts/$BROADCAST_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
