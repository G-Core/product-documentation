<p>The Monitoring tab in Live stream settings tracks four metrics updated every minute while the stream is active:</p>

  * **Number of concurrent viewers** shows the number of unique viewers counted within each one-minute interval.
  * **FPS** measures the frame rate of the source stream.
  * **Interval between key frames** captures the key frame interval of the source stream.
  * **Bitrate** reflects the source stream bitrate in kb/s.

<p>The charts remain available after the stream ends.</p>

## Monitoring

<p>1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **Streaming** → **Live Streaming**.</p>

<p>2. Click the three-dot menu next to the stream. The stream can be active or finished.</p>

<p>3. Select **Monitoring**.</p>

<Frame>![Live stream list with the three-dot menu open showing Monitoring, Statistics, Settings, and Delete options](/images/docs/streaming/statistics/view-your-live-stream-metrics/live-stream-list-context-menu.png)</Frame>

<p>The Monitoring tab displays all four metrics as separate time-series charts. Each chart plots values at one-minute intervals, so a gap in the line means no signal was received during that minute.</p>

<p>The controls above the charts provide preset or custom time ranges (**Last hour**, **Last 4 hours**, **Last 8 hours**), local or UTC time, and automatic refresh.</p>

<Frame>![Monitoring tab in Live stream settings showing time range controls and four metric charts stacked vertically](/images/docs/streaming/statistics/view-your-live-stream-metrics/monitoring-overview.png)</Frame>

<p>Hovering over a data point shows the exact metric value for that minute. An unstable bitrate, unexpected frame rate, or gaps in a chart can indicate a problem with the source stream — the time of the anomaly can then be compared with encoder or source-connection events.</p>

<Frame>![Monitoring charts showing FPS, key frame interval, and bitrate data with visible spikes from an active stream session](/images/docs/streaming/statistics/view-your-live-stream-metrics/monitoring-charts-data.png)</Frame>

</MethodSection>

## Get stream metrics

<p>Use <code>GET /streaming/statistics/ffprobe</code> to retrieve a timeseries of bitrate, FPS, and key frame interval for a specific live stream.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
import datetime
from gcore import Gcore

stream_id = os.environ["STREAM_ID"]

client = Gcore()
now = datetime.datetime.now(datetime.timezone.utc)
hour_ago = now - datetime.timedelta(hours=1)

metrics = client.streaming.statistics.get_ffprobes(
    stream_id=stream_id,
    date_from=hour_ago.strftime("%Y-%m-%dT%H:%M:%SZ"),
    date_to=now.strftime("%Y-%m-%dT%H:%M:%SZ"),
    units="minute",
)
print(f"Data points: {len(metrics.data) if metrics.data else 0}")
for point in (metrics.data or []):
    print(f"time={point.time}, bitrate={point.avg_bitrate:.1f} Kbps, fps={point.max_fps:.2f}, key_interval={point.max_keyframe_interval}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()
    streamID := os.Getenv("STREAM_ID")

    now := time.Now().UTC()
    hourAgo := now.Add(-1 * time.Hour)

    metrics, err := client.Streaming.Statistics.GetFfprobes(
        ctx,
        streaming.StatisticGetFfprobesParams{
            StreamID: streamID,
            DateFrom: hourAgo.Format(time.RFC3339),
            DateTo:   now.Format(time.RFC3339),
            Units:    streaming.StatisticGetFfprobesParamsUnitsMinute,
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("Data points: %d\n", len(metrics.Data))
    for _, point := range metrics.Data {
        fmt.Printf("time=%s, bitrate=%.1f Kbps, fps=%.2f, key_interval=%d\n",
            point.Time, point.AvgBitrate, point.MaxFps, point.MaxKeyframeInterval)
    }
}
```

## Get viewer count

<p>Use <code>GET /streaming/statistics/stream/viewers</code> to retrieve a timeseries of unique viewer counts for a specific live stream. The data comes from CDN and is available regardless of which player the viewers used.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import datetime
import os
from gcore import Gcore

stream_id = int(os.environ["STREAM_ID"])

client = Gcore()
now = datetime.datetime.now(datetime.timezone.utc)
hour_ago = now - datetime.timedelta(hours=1)

result = client.streaming.statistics.get_live_unique_viewers(
    from_=hour_ago.strftime("%Y-%m-%dT%H:%M:%SZ"),
    to=now.strftime("%Y-%m-%dT%H:%M:%SZ"),
    stream_id=stream_id,
    granularity="1m",
)
for item in result:
    for timestamp, viewers in item.metrics.streams:
        if viewers:
            print(f"time={timestamp}, viewers={viewers}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "strconv"
    "time"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()
    streamID, _ := strconv.ParseInt(os.Getenv("STREAM_ID"), 10, 64)

    now := time.Now().UTC()
    hourAgo := now.Add(-1 * time.Hour)

    result, err := client.Streaming.Statistics.GetLiveUniqueViewers(
        ctx,
        streaming.StatisticGetLiveUniqueViewersParams{
            From:        hourAgo.Format(time.RFC3339),
            To:          now.Format(time.RFC3339),
            StreamID:    gcore.Int(streamID),
            Granularity: streaming.StatisticGetLiveUniqueViewersParamsGranularity1m,
        },
    )
    if err != nil {
        panic(err)
    }
    for _, item := range *result {
        fmt.Printf("client=%d\n%s\n", item.Client, item.Metrics.RawJSON())
    }
}
```

```json
  {

        [1789927260, 3],
        [1789927320, 0]

]
```

<p>Each element in <code>streams</code> is a <code>[unix_timestamp, viewer_count]</code> pair at the requested granularity.</p>
