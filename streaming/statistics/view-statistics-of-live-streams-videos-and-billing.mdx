  <MethodSection id="portal" label="Customer Portal">
<p>Statistics data is collected only when the Gcore built-in player is in use. Third-party players do not report data to this page.</p>

<p>The **Reports** page shows information about [videos](https://portal.gcore.com/streaming/video/list) and [live streams](https://portal.gcore.com/streaming/streaming/list): viewers, their browsers and operating systems, geography, popular videos (only for the **Built-in player: VOD** page), as well as URLs of pages that host a player with the video. The data is updated every five minutes and stored for one year.</p>

<p>To see overall statistics:</p>

<p>1. In the Gcore Customer Portal, navigate to **Streaming** > **Reports**.</p>

<p>2. Choose the relevant subsection: **Built-in player: VOD** or **Built-in player: Live**.</p>

<p>3. Select a predefined interval (**Last 24 hours**, **Last 48 hours**, **Last week**, **Last month**, or **Last 3 months**) or specify a custom date range.</p>

<p>4. Choose a parameter from the dropdown: **Browsers**, **Geography**, **Hosts**, **OS**, **Popular videos**, or **Viewers**.</p>

<Frame>![Reports page showing VOD statistics with Viewers parameter selected](/images/docs/streaming/statistics/view-statistics-of-live-streams-videos-and-billing/reports.png)</Frame>

<p>**Parameters overview**</p>

- **Viewers**: The number of viewers. The following information is collected about viewer behavior:
  - **Uploads**: The number of times a page containing the video or live stream was opened. This metric does not refer to uploading content to Gcore.
  - **Starts**: The number of times viewers clicked the **Play** button.
  - **Viewers**: The number of viewers who watched a video or a live stream for at least 5 seconds. Each viewing session is counted separately, including repeat views by the same person.
  - **Unique viewers**: The number of deduplicated viewers. Viewers are identified by a combination of IP address, screen size, browser, and cookie — repeat views by the same identified viewer are counted once.

- **Popular videos** (available only for videos): A list of the most viewed videos. Only views longer than five seconds are counted.

- **Browsers**: Statistics on browsers that viewers use to watch the video or live stream.

- **OS**: Statistics on viewers' operating systems.

- **Hosts**: Statistics on the URL of requested pages. Only views longer than five seconds are counted. The `"streaming.gcore.com"` URL means a video was watched from the Customer Portal.

- **Geography**: A world map highlighting countries where viewers watch videos or live streams for at least 5 seconds. A viewer's IP address determines the country.

### View statistics for a specific video or live stream

<p>Open the video or live stream settings and go to the **Statistics** tab.</p>

An [API token](/account-settings/api-tokens) is required. All statistics endpoints accept `date_from` and `date_to` as ISO 8601 datetime strings. Aggregation endpoints also accept the optional `type` query parameter (`"live"`, `"vod"`, or `"playlist"`) to filter metrics by content type.

## Get viewer statistics

<p>Use `GET /streaming/statistics/views` to retrieve view counts for a time range. Filter by `type` (`"vod"`, `"live"`, or `"playlist"`) to scope results to videos, live streams, or playlists.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import datetime
from gcore import Gcore

client = Gcore()

now = datetime.datetime.now(datetime.timezone.utc)
week_ago = now - datetime.timedelta(days=7)

views = client.streaming.statistics.get_views(
    date_from=week_ago.strftime("%Y-%m-%dT%H:%M:%SZ"),
    date_to=now.strftime("%Y-%m-%dT%H:%M:%SZ"),
    type="vod",
)
print(f"View data points: {len(views.data)}")
for point in views.data:
    print(point)
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "time"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    now := time.Now().UTC()
    weekAgo := now.AddDate(0, 0, -7)

    views, err := client.Streaming.Statistics.GetViews(
        context.Background(),
        streaming.StatisticGetViewsParams{
            DateFrom: weekAgo.Format(time.RFC3339),
            DateTo:   now.Format(time.RFC3339),
            Type:     "vod",
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("View data points: %d\n", len(views.Data))
}
```
  </Tab>
  <Tab title="curl">
```bash
DATE_FROM=$(date -u -d '7 days ago' '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null || \
            date -u -v-7d '+%Y-%m-%dT%H:%M:%SZ')
DATE_TO=$(date -u '+%Y-%m-%dT%H:%M:%SZ')

curl "https://api.gcore.com/streaming/statistics/views?date_from=${DATE_FROM}&date_to=${DATE_TO}&type=vod" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```

</Tabs>

## Get statistics by browser

<p>Use `GET /streaming/statistics/browsers` to see which browsers viewers use. Filter by `type` (`"vod"`, `"live"`, or `"playlist"`) to scope statistics to a specific content type.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import datetime
from gcore import Gcore

client = Gcore()

now = datetime.datetime.now(datetime.timezone.utc)
week_ago = now - datetime.timedelta(days=7)

by_browser = client.streaming.statistics.get_views_by_browsers(
    date_from=week_ago.strftime("%Y-%m-%dT%H:%M:%SZ"),
    date_to=now.strftime("%Y-%m-%dT%H:%M:%SZ"),
    type="vod",
)
for item in by_browser.data:
    print(item)
```
  </Tab>
  <Tab title="Go SDK">
```go

    byBrowser, err := client.Streaming.Statistics.GetViewsByBrowsers(
```
