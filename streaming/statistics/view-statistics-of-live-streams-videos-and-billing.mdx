Statistics data is collected only when you use the standard player.

<MethodSwitch>
  <MethodSection id="portal" label="Customer Portal">
<p>The **Reports** page shows information about [videos](https://portal.gcore.com/streaming/video/list) and [live streams](https://portal.gcore.com/streaming/streaming/list): viewers, their browsers and operating systems, geography, popular videos (only for the **Video** page), as well as URLs of pages that host a player with your video. The data is updated every five minutes and stored for one year.</p>

<p>You can check reports for all videos and live streams or only for a single one. To see overall statistics:</p>

1\. In the Gcore Customer Portal, navigate to **Streaming** > **Reports**.

2\. Choose the relevant subsection: **Built-in player: VOD** or **Built-in player: Live**.

2\. Select the preferred interval (24 hours, 48 hours, week, or month) and dates.

3\. Choose one or more parameters: **Browsers**, **Geography**, **Hosts**, **OS**, or **Viewers**.

<Frame>![Reports page](/images/docs/streaming-platform/billing/usage-and-billing-reports/reports.png)</Frame>

**Parameters overview**

  * **Viewers**: The number of viewers. We collect the following information about their behavior:

    * **Uploads**: Shows how many times users opened a video or live stream page.
    * **Starts**: Indicates how many times users clicked the **Play** button.
    * **Viewers**: Specifies how many viewers have watched a video or a live stream for at least 5 seconds.
    * **Unique viewers**: Represents the number of unique viewers (we distinguish viewers using several parameters at once: an IP address, screen size, browser, and cookie).

  * **Popular videos** (available only for videos): A list of the most viewed videos. We consider only views that are longer than five seconds.

  * **Browsers**: Statistics on browsers that your viewers use to watch your video/live stream.

  * **OS**: Statistics on users' operating systems.

  * **Hosts**: Static data on the URL of requested pages. We consider only views that are longer than five seconds. The `"streaming.gcore.com"` URL means a video was watched from a personal account.

  * **Geography**: A world map that highlights countries where your viewers watch videos/live streams for at least 5 seconds. A user's IP address determines a country.

<p>If you want to see reports for a specific video or live stream, open its settings and navigate to the **Statistics** tab.</p>
  </MethodSection>

## Get viewer statistics

<p>Use `GET /streaming/statistics/views` to retrieve view counts for a time range. Filter by `type` (`"vod"` or `"live"`) to scope results to videos or live streams.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import datetime
from gcore import Gcore

client = Gcore()

now = datetime.datetime.now(datetime.timezone.utc)
week_ago = now - datetime.timedelta(days=7)

views = client.streaming.statistics.get_views(
    date_from=week_ago.strftime("%Y-%m-%dT%H:%M:%SZ"),
    date_to=now.strftime("%Y-%m-%dT%H:%M:%SZ"),
    type="vod",
)
print(f"View data points: {len(views.data)}")
for point in views.data:
    print(point)
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "time"

    "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()
    now := time.Now().UTC()
    weekAgo := now.AddDate(0, 0, -7)

    views, err := client.Streaming.Statistics.GetViews(
        ctx,
        streaming.StatisticGetViewsParams{
            DateFrom: weekAgo.Format(time.RFC3339),
            DateTo:   now.Format(time.RFC3339),
        },
    )
    if err != nil {
        panic(err)
    }
    fmt.Printf("View data points: %d\n", len(views.Data))
}
```
  </Tab>
  <Tab title="curl">
```bash
DATE_FROM=$(date -u -d '7 days ago' '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null || \
            date -u -v-7d '+%Y-%m-%dT%H:%M:%SZ')
DATE_TO=$(date -u '+%Y-%m-%dT%H:%M:%SZ')

curl "https://api.gcore.com/streaming/statistics/views?date_from=${DATE_FROM}&date_to=${DATE_TO}&type=vod" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
  </Tab>
</Tabs>

## Get statistics by browser

<p>Use `GET /streaming/statistics/browsers` to see which browsers your viewers use.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import datetime
from gcore import Gcore

client = Gcore()

now = datetime.datetime.now(datetime.timezone.utc)
week_ago = now - datetime.timedelta(days=7)

by_browser = client.streaming.statistics.get_views_by_browsers(
    date_from=week_ago.strftime("%Y-%m-%dT%H:%M:%SZ"),
    date_to=now.strftime("%Y-%m-%dT%H:%M:%SZ"),
)
for item in by_browser.data:
    print(item)
```
