  <MethodSection id="portal" label="Customer Portal">

<p>The NSFW detection task scans an MP4 video for content inappropriate for a workplace environment and reports a confidence score for each flagged frame.</p>

<Steps>
  <Step title="Open AI tasks">
    In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **Streaming** > **AI tasks**.
    <Frame><img src="/images/docs/streaming-platform/ai-video-service/ai-nudity-detection/ai-tasks-page.png" width="70%" alt="AI tasks page" /></Frame>
  </Step>
  <Step title="Select the video">
    In the **Origin URL** field, enter the URL of the MP4 video. Two options are available:
    * **Paste video origin URL**: if the video is stored externally, provide a URL to its location. Verify the video is accessible via HTTP or HTTPS.
    * **Select from uploaded videos**: select a video hosted on Gcore.
  </Step>
  <Step title="Configure and generate the task">
    1. In the **Task type**, select **Content Moderation**.
    2. In the dropdown that appears, select **NSFW detection**.
    3. Click **Generate task**.
  </Step>
  <Step title="Review the result">
    Wait until the task has the **Success** status, then click the task ID to open task details. Check the **Parsed result** field:
    * **NSFW detection: not found** — the video has no NSFW content.
    * If sensitive content is found, the result identifies the flagged frame and the confidence score — _"nsfw: detected at frame №2 with score 41%"._
    <Frame><img src="/images/docs/streaming-platform/ai-video-service/ai-nudity-detection/nsfw-detection.png" width="70%" alt="NSFW detection task details" /></Frame>
  </Step>
</Steps>
</MethodSection>
  <MethodSection id="api" label="REST API">

<p>NSFW detection runs asynchronously: create a task first, then use its ID to retrieve the result.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Create the detection task

<p>Send `POST /streaming/ai/tasks` with `task_name: "content-moderation"` and `category: "nsfw"`. The response returns a `task_id`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
task = client.streaming.ai_tasks.create(
    task_name="content-moderation",
    category="nsfw",
    url="https://example.com/video.mp4",
)
print(f"Task ID: {task.task_id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    task, err := client.Streaming.AITasks.New(ctx, streaming.AITaskNewParams{
        OfAIContentModerationNsfwTaskData: &streaming.AIContentmoderationNsfwParam{
            TaskName: streaming.AIContentmoderationNsfwTaskNameContentModeration,
            Category: streaming.AIContentmoderationNsfwCategoryNsfw,
            URL:      "https://example.com/video.mp4",
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task ID: %s\n", task.TaskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
           "task_name": "content-moderation",
           "category": "nsfw",
           "url": "https://example.com/video.mp4"
         }'
```

<p>The API returns:</p>

```json
{"task_id": "6aa450af-8243-40b0-b0c5-244f2ff9ca5b"}
```
  </Tab>
</Tabs>

<p>The poll and cancel examples below read `task_id` from the `TASK_ID` environment variable. Set it from the ID returned above:</p>

```bash
export TASK_ID="<task_id>"
```

## Get the result

<p>Poll `GET /streaming/ai/tasks/{task_id}` until `status` is `"SUCCESS"` or `"FAILURE"`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
import time
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
while True:
    task = client.streaming.ai_tasks.get(task_id)
    print(f"Status: {task.status}  Progress: {task.progress}%")
    if task.status in ("SUCCESS", "FAILURE"):
        break
    time.sleep(5)

if task.status == "SUCCESS":
    print(f"NSFW detected: {task.result.nsfw_detected}")
    for frame in task.result.frames:
        print(f"  Frame {frame.frame_number}: {frame.label} (confidence {frame.confidence:.0%})")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    for {
        task, err := client.Streaming.AITasks.Get(ctx, taskID)
        if err != nil {
            panic(err)
        }
        fmt.Printf("Status: %s  Progress: %d%%\n", task.Status, task.Progress)
        if task.Status == "SUCCESS" || task.Status == "FAILURE" {
            if task.Status == "SUCCESS" {
                result := task.Result.AsAITaskGetResponseResultAIResultsContentmoderationNsfw()
                fmt.Printf("NSFW detected: %v\n", result.NsfwDetected)
                for _, frame := range result.Frames {
                    fmt.Printf("  Frame %d: %s (confidence %.0f%%)\n",
                        frame.FrameNumber, frame.Label, frame.Confidence*100)
                }
            }
            break
        }
        time.Sleep(5 * time.Second)
    }
}
```
  </Tab>
  <Tab title="curl">
```bash
curl "https://api.gcore.com/streaming/ai/tasks/$TASK_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>The API returns:</p>

```json
{
  "task_id": "6aa450af-8243-40b0-b0c5-244f2ff9ca5b",
  "status": "SUCCESS",
  "progress": 100,
  "result": {
    "nsfw_detected": false,
    "detection_results": [],
    "frames": []
  }
}
```
  </Tab>
</Tabs>

<p>When `status` is `"SUCCESS"`, check `result.nsfw_detected`:</p>

- `false` — no NSFW content found in the video.
- `true` — NSFW content detected. The `frames` array lists each flagged frame with `frame_number`, `label` (`"nsfw"`), and `confidence` (decimal 0.0–1.0, e.g. `0.41` means 41% confidence).

## Cancel the task

<p>If the result is no longer needed, cancel a running detection with `POST /streaming/ai/tasks/{task_id}/cancel`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
client.streaming.ai_tasks.cancel(task_id)
print(f"Task {task_id} canceled")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    _, err := client.Streaming.AITasks.Cancel(ctx, taskID)
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task %s canceled\n", taskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks/$TASK_ID/cancel" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
