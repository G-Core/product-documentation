  <MethodSection id="portal" label="Customer Portal">

<p>The soft nudity detection task analyzes an MP4 video for a broader set of body-related categories than hard nudity detection — including faces and exposed body parts — and reports a confidence score for each detection.</p>

<Steps>
  <Step title="Open AI tasks">
    In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **Streaming** > **AI tasks**.
    <Frame><img src="/images/docs/streaming-platform/ai-video-service/content-moderation/soft-nudity-detection/ai-tasks-page.png" width="70%" alt="AI tasks page" /></Frame>
  </Step>
  <Step title="Select the video">
    In the **Origin URL** field, enter the URL of the MP4 video. Two options are available:
    * **Paste video origin URL**: if the video is stored externally, provide a URL to its location. Verify the video is accessible via HTTP or HTTPS.
    * **Select from uploaded videos**: select a video hosted on Gcore.
  </Step>
  <Step title="Configure and generate the task">
    1. In the **Task type**, select **Content Moderation**.
    2. In the dropdown that appears, select **Soft nudity detection**.
    3. Click **Generate task**.
  </Step>
  <Step title="Review the result">
    Wait until the task has the **Success** status, then click the task ID to open task details. Check the **Parsed result** field:
    * **Soft nudity detection: not found** — the video contains no soft nudity content.
    * If sensitive content is found, the result identifies the detected element, the relevant frame, and the confidence score — _"BELLY_EXPOSED: detected at frame №2 with score 41%"_.
    <Frame><img src="/images/docs/streaming-platform/ai-video-service/content-moderation/soft-nudity-detection/soft-nudity-detection.png" width="70%" alt="Soft nudity detection task details" /></Frame>
  </Step>
</Steps>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Soft nudity detection runs asynchronously: create a task first, then use its ID to retrieve the result.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Create a soft nudity detection task

<p>Send `POST /streaming/ai/tasks` with `task_name: "content-moderation"` and `category: "soft_nudity"`. The response returns a `task_id` to use when polling for results.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
task = client.streaming.ai_tasks.create(
    task_name="content-moderation",
    category="soft_nudity",
    url="https://example.com/video.mp4",
)
print(f"Task ID: {task.task_id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    task, err := client.Streaming.AITasks.New(ctx, streaming.AITaskNewParams{
        OfAIContentModerationSoftNudityTaskData: &streaming.AIContentmoderationSoftnudityParam{
            TaskName: streaming.AIContentmoderationSoftnudityTaskNameContentModeration,
            Category: streaming.AIContentmoderationSoftnudityCategorySoftNudity,
            URL:      "https://example.com/video.mp4",
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task ID: %s\n", task.TaskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
           "task_name": "content-moderation",
           "category": "soft_nudity",
           "url": "https://example.com/video.mp4"
         }'
```

<p>The API returns:</p>

```json
{"task_id": "91ef4ec8-de85-4dd9-b318-63e7c63bf53f"}
```
  </Tab>
</Tabs>

<p>The poll and cancel examples below read `task_id` from the `TASK_ID` environment variable. Set it from the ID returned above:</p>

```bash
export TASK_ID="<task_id>"
```

## Poll for detection result

<p>Use `GET /streaming/ai/tasks/{task_id}` to check task status. Poll until `status` is `"SUCCESS"` or `"FAILURE"`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
import time
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
while True:
    task = client.streaming.ai_tasks.get(task_id)
    print(f"Status: {task.status}  Progress: {task.progress}%")
    if task.status in ("SUCCESS", "FAILURE"):
        break
    time.sleep(5)

if task.status == "SUCCESS":
    print(f"Nudity detected: {task.result.nudity_detected}")
    for frame in task.result.frames:
        print(f"  Frame {frame.frame_number}: {frame.label} (confidence {frame.confidence:.0%})")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    for {
        task, err := client.Streaming.AITasks.Get(ctx, taskID)
        if err != nil {
            panic(err)
        }
        fmt.Printf("Status: %s  Progress: %d%%\n", task.Status, task.Progress)
        if task.Status == "SUCCESS" || task.Status == "FAILURE" {
            if task.Status == "SUCCESS" {
                result := task.Result.AsAITaskGetResponseResultAIResultsContentmoderationSoftnudity()
                fmt.Printf("Nudity detected: %v\n", result.NudityDetected)
                for _, frame := range result.Frames {
                    fmt.Printf("  Frame %d: %s (confidence %.0f%%)\n",
                        frame.FrameNumber, frame.Label, frame.Confidence*100)
                }
            }
            break
        }
        time.Sleep(5 * time.Second)
    }
}
```
  </Tab>
  <Tab title="curl">
```bash
curl "https://api.gcore.com/streaming/ai/tasks/$TASK_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```

<p>The API returns:</p>

```json
{
  "task_id": "91ef4ec8-de85-4dd9-b318-63e7c63bf53f",
  "status": "SUCCESS",
  "progress": 100,
  "result": {
    "nudity_detected": true,
    "detection_results": ["FACE_FEMALE"],
    "frames": [
      {"frame_number": 2, "label": "FACE_FEMALE", "confidence": 0.53},
      {"frame_number": 6, "label": "FACE_FEMALE", "confidence": 0.67}
    ]
  }
}
```
  </Tab>
</Tabs>

<p>When `status` is `SUCCESS`, check `result.nudity_detected`:</p>

- `false` — no soft nudity content found in the video.
- `true` — soft nudity detected. The `detection_results` array lists the detected object categories. The `frames` array lists each flagged frame with `frame_number`, `label` (e.g. `"FACE_FEMALE"`), and `confidence` (decimal 0.0–1.0, where `0.53` means 53% confidence). Only objects detected with at least 30% confidence are included.

## Cancel a running task

<p>To cancel a task before it completes, send `POST /streaming/ai/tasks/{task_id}/cancel`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
client.streaming.ai_tasks.cancel(task_id)
print(f"Task {task_id} canceled")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    _, err := client.Streaming.AITasks.Cancel(ctx, taskID)
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task %s canceled\n", taskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks/$TASK_ID/cancel" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
