  <MethodSection id="portal" label="Customer Portal">

<p>To generate subtitles from the original audio and translate them into a language of choice, create corresponding tasks for the AI models.</p>

<p>Supported sources: MP4 videos stored on Gcore Video Hosting, or any external MP4 file accessible via HTTP or HTTPS.</p>

<Steps>
  <Step title="Choose the video">
    In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **Streaming** > **AI**. The **AI tasks** page opens.
    <Frame>![AI tasks page](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/ai-tasks-page.png)</Frame>
    In the **Origin URL** field, enter the link to the MP4 video. Two options are available:
    - **Paste video origin URL**: provide a URL to the video location. The video must be accessible via HTTP or HTTPS.
    - **Select from uploaded videos**: choose a video hosted on Gcore Video Hosting.
  </Step>
  <Step title="Configure and generate captions">
    In **Task type**, select **Transcribe & Translate Captions**.

    Choose the source and target languages:
    - **Audio language**: select the language spoken in the video, or keep **Auto-detect** to detect it automatically. For videos with multiple spoken languages, keep **Auto-detect** so all languages are captured correctly.
    - **Subtitles language**: select the original video language for transcription only, or a different language to translate the generated captions. To generate captions in multiple target languages, create a separate task for each language.

    Click **Generate task**.
    <Frame>![AI task with generate button highlighted](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/generate-task.png)</Frame>
    <Info>We only charge for the successfully processed translation tasks.</Info>
  </Step>
  <Step title="Download captions">
    The task appears in the **AI tasks** table. Processing time depends on the video length. While processing, the status may cycle between **Started** and **Pending** as resources are allocated to each processing sub-stage; use the progress percentage to track overall progress. If a task fails, the **Failure** status is shown — create the task again.
    <Frame>![AI tasks table with refresh button highlighted](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/tasks-table-refresh-button.png)</Frame>
    When the status changes to **Success**, click the task ID and select **Download VTT file** in the **Parsed result** section.
    <Frame>![AI task details dialog](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/tasks-details.png)</Frame>
    <Info>Task result data is deleted after one month.</Info>
  </Step>
</Steps>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Two approaches are available. For videos hosted on Gcore Video Streaming, pass `auto_transcribe_audio_language` directly in the video create or subtitle request. For any MP4 file accessible via a public HTTPS URL — including videos outside Gcore — submit a task to <code>POST /streaming/ai/tasks</code> and poll for results.</p>

<Info>
An [API token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the API key:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Gcore-hosted videos

### New video

<p>Add `auto_transcribe_audio_language` to the video create request. After the video finishes transcoding, Gcore automatically creates an AI transcription task and attaches the resulting WebVTT subtitles to the video. To translate into additional languages, also set `auto_translate_subtitles_language`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
result = client.streaming.videos.create(
    video={
        "name": "My Video",
        "origin_url": "https://example.com/video.mp4",
        "auto_transcribe_audio_language": "auto",
        # "auto_translate_subtitles_language": "fre,ger,ita",  # optional
    }
)
print(f"Video ID: {result[0].id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	result, err := client.Streaming.Videos.New(ctx, streaming.VideoNewParams{
		Video: streaming.CreateVideoParam{
			Name:                       "My Video",
			OriginURL:                  gcore.String("https://example.com/video.mp4"),
			AutoTranscribeAudioLanguage: streaming.CreateVideoAutoTranscribeAudioLanguageAuto,
			// AutoTranslateSubtitlesLanguage: streaming.CreateVideoAutoTranslateSubtitlesLanguage("fre,ger,ita"),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Video ID: %d\n", result[0].ID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/videos" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "video": {
      "name": "My Video",
      "origin_url": "https://example.com/video.mp4",
      "auto_transcribe_audio_language": "auto"
    }
  }'
```

<p>The API returns an array with the created video object. The AI transcription task is created automatically after transcoding completes.</p>
  </Tab>
</Tabs>

### Existing video

<p>Set the ID of the video already in Gcore Video Streaming:</p>

```bash
export VIDEO_ID="{YOUR_VIDEO_ID}"
```

<p>Trigger transcription by posting to its subtitles endpoint. The AI task runs automatically and attaches the resulting subtitles to the video.</p>

<Tabs>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"auto_transcribe_audio_language": "auto"}'
```

<p>To also translate subtitles, add `auto_translate_subtitles_language`:</p>

```bash
curl -X POST "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "auto_transcribe_audio_language": "auto",
    "auto_translate_subtitles_language": "fre,ger,ita,spa"
  }'
```
  </Tab>
</Tabs>

## External MP4 videos

### Create a transcription task

<p>Send `POST /streaming/ai/tasks` with `task_name: "transcription"` and the URL to an MP4 file. Optionally, specify `audio_language` (ISO-639-2 code, e.g. `"eng"`) and `subtitles_language` to translate subtitles into a different language. For multiple target languages, create a separate task for each.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
task = client.streaming.ai_tasks.create(
    task_name="transcription",
    url="https://example.com/video.mp4",
    # audio_language="eng",      # optional: set source language explicitly
    # subtitles_language="deu",  # optional: translate to German
)
print(f"Task ID: {task.task_id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
    // To set optional language fields, also import:
    // "github.com/G-Core/gcore-go/packages/param"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    task, err := client.Streaming.AITasks.New(ctx, streaming.AITaskNewParams{
        OfAITranscriptionTaskData: &streaming.AITaskNewParamsBodyAITranscriptionTaskData{
            TaskName: "transcription",
            URL:      "https://example.com/video.mp4",
            // AudioLanguage:     param.NewOpt("eng"),  // optional
            // SubtitlesLanguage: param.NewOpt("deu"),  // optional: translate to German
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task ID: %s\n", task.TaskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
           "task_name": "transcription",
           "url": "https://example.com/video.mp4"
         }'
```

<p>The API returns:</p>

```json
{"task_id": "bc35ecac-4ca5-43a5-8faf-b5aa398b963e"}
```
  </Tab>
</Tabs>

<p>Copy the task ID from the response and export it:</p>

```bash
export TASK_ID="{YOUR_TASK_ID}"
```

### Get the captions

<p>Use `GET /streaming/ai/tasks/{task_id}` to check the task status. While processing, `status` may cycle between `"STARTED"` and `"PENDING"` as resources are allocated to each sub-stage; use the `progress` field to track overall completion. Poll until `status` is `"SUCCESS"` or `"FAILURE"`. On success, `result.vtt_content` contains the WebVTT subtitle text.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
import time
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
while True:
    task = client.streaming.ai_tasks.get(task_id)
    print(f"Status: {task.status}  Progress: {task.progress}%")
    if task.status in ("SUCCESS", "FAILURE"):
        break
    time.sleep(5)

if task.status == "SUCCESS":
    print(task.result.vtt_content)
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    for {
        task, err := client.Streaming.AITasks.Get(ctx, taskID)
        if err != nil {
            panic(err)
        }
        fmt.Printf("Status: %s  Progress: %d%%\n", task.Status, task.Progress)
        if task.Status == "SUCCESS" || task.Status == "FAILURE" {
            if task.Status == "SUCCESS" {
                fmt.Println(task.Result.VttContent)
            }
            break
        }
        time.Sleep(5 * time.Second)
    }
}
```
  </Tab>
  <Tab title="curl">
```bash
curl "https://api.gcore.com/streaming/ai/tasks/$TASK_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```

### Cancel a running task

<p>To cancel a task that is still processing, send `POST /streaming/ai/tasks/{task_id}/cancel`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
client.streaming.ai_tasks.cancel(task_id)
print(f"Task {task_id} canceled")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    _, err := client.Streaming.AITasks.Cancel(ctx, taskID)
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task %s canceled\n", taskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks/$TASK_ID/cancel" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
  </Tab>
</Tabs>

## List AI tasks

<p>To retrieve all AI tasks, send `GET /streaming/ai/tasks`. Use the optional `search` query parameter to filter by ID, URL, task type, or status.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
for task in client.streaming.ai_tasks.list():
    print(f"{task.task_id}  {task.status}  {task.progress}%")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    page, err := client.Streaming.AITasks.List(ctx, streaming.AITaskListParams{})
    if err != nil {
        panic(err)
    }
    for _, task := range page.Results {
        fmt.Printf("%s  %s  %d%%\n", task.TaskID, task.Status, task.Progress)
    }
}
```
  </Tab>
  <Tab title="curl">
```bash
curl "https://api.gcore.com/streaming/ai/tasks" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```
  </Tab>
