<p>To generate subtitles from the original audio and translate them into a language of choice, create corresponding tasks for the AI models.</p>

<p>Supported sources: MP4 videos stored on Gcore Video Hosting, or any external MP4 file accessible via HTTP or HTTPS.</p>

<p>**Step 1. Choose a video**</p>

<p>1\. In the Gcore Customer Portal, navigate to **Streaming** > **AI**. The **AI tasks** page opens.</p>

<Frame>![AI tasks page](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/ai-tasks-page.png)</Frame>

<p>2\. In the **Origin URL** field, enter the link to the MP4 video. Two options are available:</p>

   - **Paste video origin URL**: provide a URL to the video location. The video must be accessible via HTTP or HTTPS.
   - **Select from uploaded videos**: choose a video hosted on Gcore Video Hosting.

<p>**Step 2. Select AI task**</p>

<p>In the **Task type**, choose **Transcribe & Translate Captions**.</p>

<p>To translate into multiple languages, create a separate task for each target language.</p>

<p>**Step 3. Select audio language**</p>

<p>In the **Audio language** dropdown, choose the video's original language. The default **Auto-detect** option identifies the language automatically.</p>

<Tip>
For videos with multiple languages, leave **Audio language** set to **Auto-detect**. Specifying a single language may cause incorrect results.
</Tip>

<p>**Step 4. Select subtitles language**</p>

<p>In the **Subtitles language** dropdown, select the target language:</p>

- For transcription only, choose the original video language.
- For translation, choose the language for the generated subtitles. Each target language requires a separate task.

<p>The default **Auto-detect** option creates subtitles in the detected language.</p>

<p>**Step 5. Generate AI task**</p>

<p>After configuring all settings, click **Generate task**.</p>

<Frame>![AI task with generate button highlighted](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/generate-task.png)</Frame>

<p>The AI task appears in the table with **Started** status. Processing time depends on the video length.</p>

<Frame>![AI tasks table with generate button highlighted](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/tasks-table-refresh-button.png)</Frame>

<Info>
We only charge for the successfully processed translation tasks.
</Info>

<p>**Step 6. Download captions**</p>

<p>When the task status changes to **Success**, subtitles are available for download in WebVTT format.</p>

<p>To download captions:</p>

<p>1\. Find the task in the AI tasks table.</p>

<p>2\. Click the task ID to open the **AI Task details** dialog.</p>

<p>3\. In the **Parsed result** section, click **Download VTT file** to download the generated subtitles.</p>

<Frame>![AI task details dialog](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/tasks-details.png)</Frame>

## AI task statuses

<p>Each AI task is processed in sub-stages: the source language is identified first, then transcription runs. During sub-stage transitions, the status may cycle between **Started** and **Pending** as resources are allocated. To track overall progress, check the progress percentage.</p>

<p>Task statuses:</p>

- **Success**: Processing completed.
- **Started**: Processing has started.
- **Pending**: Task is waiting for resources.
- **Failure**: Task failed. Create the task again.
- **Revoked**: Processing was canceled.
- **Retry**: Task failed due to an internal error and is queued for re-execution (up to 3 attempts).

<Info>
Task result data is deleted after one month.
</Info>

## Manage AI tasks

<p>All AI tasks are available in the Customer Portal on the **AI tasks** page:</p>

<Frame>![AI tasks page](/images/docs/streaming/ai-video-service/generate-ai-subtitles-and-add-them-to-video/generate-captions-in-customer-portal/ai-tasks-page-with-table.png)</Frame>

<p>Tasks can be sorted by creation date and filtered by ID, URL, task type, or status. Each task row includes a link to the original video file.</p>

<p>**View task details**</p>

<p>To view detailed information about a task, click its ID to open the **AI Task details** dialog:</p>

- **ID**: A unique identifier of an AI task.
- **URL**: The web address where the processed video file is hosted.
- **Task type**: Either **Transcribe & Translate Captions** or **Content Moderation**.
- **Status**: The outcome of task execution.
- **Contributed time**: The amount of time spent on task processing.
- **Started at (UTC)**, **Finished at (UTC)**: The date and time when the task was initiated and when it was completed.
- **Parsed result**: The output of the AI video processing task along with the WebVTT file that contains transcribed or translated text.
- **Request**: The API request to the server that initiated the video transcription or translation.
- **Response**: The response returned by the server with task details. The `"audio_language"` and `"subtitles_language"` parameters confirm that subtitles were produced in the correct languages.

<p>To generate subtitles from the original audio and optionally translate them, use one of two approaches. For videos hosted on Gcore Video Streaming, pass `auto_transcribe_audio_language` directly in the video create or subtitle request. For any MP4 file accessible via a public HTTPS URL — including videos outside Gcore — submit a task to <code>POST /streaming/ai/tasks</code> and poll for results.</p>

<Info>
An [API token](/account-settings/api-tokens) is required.
</Info>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export VIDEO_ID="{YOUR_VIDEO_ID}"
export TASK_ID="{YOUR_TASK_ID}"
```

## Transcribe a new video

<p>Add `auto_transcribe_audio_language` to the video create request. After the video finishes transcoding, Gcore automatically creates an AI transcription task and attaches the resulting WebVTT subtitles to the video. To translate into additional languages, also set `auto_translate_subtitles_language`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
result = client.streaming.videos.create(
    video={
        "name": "My Video",
        "origin_url": "https://example.com/video.mp4",
        "auto_transcribe_audio_language": "auto",
        # "auto_translate_subtitles_language": "fre,ger,ita",  # optional
    }
)
print(f"Video ID: {result[0].id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
	"context"
	"fmt"

	gcore "github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/streaming"
)

func main() {
	client := gcore.NewClient()
	ctx := context.Background()

	result, err := client.Streaming.Videos.New(ctx, streaming.VideoNewParams{
		Video: streaming.CreateVideoParam{
			Name:                       "My Video",
			OriginURL:                  gcore.String("https://example.com/video.mp4"),
			AutoTranscribeAudioLanguage: streaming.CreateVideoAutoTranscribeAudioLanguageAuto,
			// AutoTranslateSubtitlesLanguage: streaming.CreateVideoAutoTranslateSubtitlesLanguage("fre,ger,ita"),
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Video ID: %d\n", result[0].ID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/videos" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "video": {
      "name": "My Video",
      "origin_url": "https://example.com/video.mp4",
      "auto_transcribe_audio_language": "auto"
    }
  }'
```

<p>The API returns an array with the created video object. The AI transcription task is created automatically after transcoding completes.</p>

</Tabs>

## Transcribe an existing video

<p>Trigger AI transcription on a video already in Gcore Video Streaming by posting to its subtitles endpoint with `auto_transcribe_audio_language`. The AI task runs automatically and attaches the resulting subtitles to the video.</p>

<Tabs>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"auto_transcribe_audio_language": "auto"}'
```

<p>To also translate subtitles, add `auto_translate_subtitles_language`:</p>

```bash
curl -X POST "https://api.gcore.com/streaming/videos/$VIDEO_ID/subtitles" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "auto_transcribe_audio_language": "auto",
    "auto_translate_subtitles_language": "fre,ger,ita,spa"
  }'
```
  </Tab>
</Tabs>

## Create a transcription task

<p>Send `POST /streaming/ai/tasks` with `task_name: "transcription"` and the URL to an MP4 file. Optionally, specify `audio_language` (ISO-639-2 code, e.g. `"eng"`) and `subtitles_language` to translate subtitles into a different language. For multiple target languages, create a separate task for each.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
task = client.streaming.ai_tasks.create(
    task_name="transcription",
    url="https://example.com/video.mp4",
    # audio_language="eng",      # optional: set source language explicitly
    # subtitles_language="deu",  # optional: translate to German
)
print(f"Task ID: {task.task_id}")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
    // To set optional language fields, also import:
    // "github.com/G-Core/gcore-go/packages/param"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    task, err := client.Streaming.AITasks.New(ctx, streaming.AITaskNewParams{
        OfAITranscriptionTaskData: &streaming.AITaskNewParamsBodyAITranscriptionTaskData{
            TaskName: "transcription",
            URL:      "https://example.com/video.mp4",
            // AudioLanguage:     param.NewOpt("eng"),  // optional
            // SubtitlesLanguage: param.NewOpt("deu"),  // optional: translate to German
        },
    })
    if err != nil {
        panic(err)
    }
    fmt.Printf("Task ID: %s\n", task.TaskID)
}
```
  </Tab>
  <Tab title="curl">
```bash
curl -X POST "https://api.gcore.com/streaming/ai/tasks" \
     -H "Authorization: APIKey $GCORE_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
           "task_name": "transcription",
           "url": "https://example.com/video.mp4"
         }'
```

<p>The API returns:</p>

```json
{"task_id": "bc35ecac-4ca5-43a5-8faf-b5aa398b963e"}
```
  </Tab>
</Tabs>

## Poll for transcription result

<p>Use `GET /streaming/ai/tasks/{task_id}` to check the task status. Poll until `status` is `"SUCCESS"` or `"FAILURE"`. On success, the `result.vtt_content` field contains the WebVTT subtitle text.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
import time
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
while True:
    task = client.streaming.ai_tasks.get(task_id)
    print(f"Status: {task.status}  Progress: {task.progress}%")
    if task.status in ("SUCCESS", "FAILURE"):
        break
    time.sleep(5)

if task.status == "SUCCESS":
    print(task.result.vtt_content)
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    gcore "github.com/G-Core/gcore-go"
)

func main() {
    taskID := os.Getenv("TASK_ID")
    client := gcore.NewClient()
    ctx := context.Background()

    for {
        task, err := client.Streaming.AITasks.Get(ctx, taskID)
        if err != nil {
            panic(err)
        }
        fmt.Printf("Status: %s  Progress: %d%%\n", task.Status, task.Progress)
        if task.Status == "SUCCESS" || task.Status == "FAILURE" {
            if task.Status == "SUCCESS" {
                fmt.Println(task.Result.VttContent)
            }
            break
        }
        time.Sleep(5 * time.Second)
    }
}
```
  </Tab>
  <Tab title="curl">
```bash
curl "https://api.gcore.com/streaming/ai/tasks/$TASK_ID" \
     -H "Authorization: APIKey $GCORE_API_KEY"
```

## List AI tasks

<p>To retrieve all AI tasks, send `GET /streaming/ai/tasks`. Use the optional `search` query parameter to filter by ID, URL, task type, or status.</p>

<Tabs>
  <Tab title="Python SDK">
```python
from gcore import Gcore

client = Gcore()
for task in client.streaming.ai_tasks.list():
    print(f"{task.task_id}  {task.status}  {task.progress}%")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
    "fmt"

    gcore "github.com/G-Core/gcore-go"
    "github.com/G-Core/gcore-go/streaming"
)

func main() {
    client := gcore.NewClient()
    ctx := context.Background()

    page, err := client.Streaming.AITasks.List(ctx, streaming.AITaskListParams{})
    if err != nil {
        panic(err)
    }
    for _, task := range page.Results {
        fmt.Printf("%s  %s  %d%%\n", task.TaskID, task.Status, task.Progress)
    }
}
```

## Cancel an AI task

<p>To cancel a running task, send `POST /streaming/ai/tasks/{task_id}/cancel`.</p>

<Tabs>
  <Tab title="Python SDK">
```python
import os
from gcore import Gcore

task_id = os.environ["TASK_ID"]

client = Gcore()
client.streaming.ai_tasks.cancel(task_id)
print(f"Task {task_id} canceled")
```
  </Tab>
  <Tab title="Go SDK">
```go
package main

import (
    "context"
```

## AI task statuses

<p>Each AI task is processed in sub-stages. For example, the original language is first determined in a video, and then transcription is done.</p>

<p>In such cases, the video processing status may change from **Started** to **Pending** and back. This happens during the allocation of resources for a specific sub-stage. To view a general task processing status, check the progress percentage.</p>

<p>A task can have the following statuses:</p>

- **Success**: The processing has been completed.
- **Started**: The processing has started.
- **Pending**: The task is being processed and is awaiting the allocation of available resources.
- **Failure**: A task has failed. Create the task again.
- **Revoked**: The processing was canceled by a user or system.
- **Retry**: The task execution failed due to internal reasons, the task is queued for re-execution (up to 3 times).

<Info>
We delete task result data after one month.
</Info>
