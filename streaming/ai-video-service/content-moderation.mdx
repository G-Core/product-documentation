Gcore AI content moderation analyzes video and image files and returns a confidence score for each detected object. The score represents the probability that a detected object belongs to a specific category. To run a check, submit a task via the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com) (Streaming → AI → AI tasks) or via the REST API.

## Detection tasks

Four detection tasks are available:

  * [NSFW&nbsp;materials](/streaming/ai-video-service/content-moderation/nsfw-detection) — detects general NSFW content
  * [Hard&nbsp;nudity](/streaming/ai-video-service/ai-nudity-detection) — detects exposed primary and secondary sex organs
  * [Soft&nbsp;nudity](/streaming/ai-video-service/content-moderation/soft-nudity-detection) — detects a wider range of nudity categories than hard nudity
  * [Sport&nbsp;activities](/streaming/ai-video-service/content-moderation/sport-detection) — detects sporting events and key moments

Each task guide covers the detected object classes, response fields, and API request examples.

## Analysis process

Content moderation processes video by analyzing keyframes (iFrames). The analysis frequency matches the keyframe interval set in the video encoding — objects between keyframes are not detected. Static images are also supported; image duration is treated as 1 second. After processing, the original file is deleted from Gcore storage.

Each task returns the detected object class, the video frame number, and a confidence percentage. Results with confidence below 30% are excluded by the service.

## Confidence scores

The confidence score is a probability value. There is no universal cutoff that applies across all services — a threshold appropriate for one context may be too strict or too permissive for another. Process a representative sample of videos and analyze the resulting score distribution to determine an appropriate cutoff before applying content filtering in production.
