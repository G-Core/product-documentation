Network submission is the second step in the [setup process](/ddos-protection/onboarding-service/service-activation), after [plan activation](/ddos-protection/onboarding-service/plan-activation). Submit the network to protect by providing its network details and a Letter of Authorization (LOA) document.

## Submission steps

Complete the following steps in the [Gcore Customer Portal](https://portal.gcore.com) to submit a network for protection.

1. In the **DDoS Protection** dashboard, click **Add protected network**.
   - This opens the network submission form.

   <Frame>
     ![Protected network form](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/protected-networks.png)
   </Frame>
2. Complete the required fields:

   | Field | Value |
   | --- | --- |
   | Network (CIDR format) | Network in CIDR notation, minimum prefix length `/24` (example: `198.51.100.0/24`) |
   | AS Number | Autonomous System (AS) number. Valid ranges: `1-65534` (16-bit ASNs) and `131072-4294967294` (32-bit ASNs); the gap between them is reserved for private and documentation use (examples: `64512`, `200000`) |
   | Letter of Authorization (LOA) | PDF confirming authorization to route and protect the submitted network, up to 10 MB |
3. Submit the network.
   - Review the entered information.
   - Click **Add protected network** to submit the request.
   - The portal redirects to the **Protected networks** page.

   <Frame>
     ![Add protected network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/add-protected-network.png)
   </Frame>
4. Check the submission status.
   - The newly submitted network appears in the list with the **Pending** status until the network operations center (NOC) team reviews it. Once approved, the status changes to **Inactive: need info**, which unlocks [network configuration](/ddos-protection/onboarding-service/network-configuration).

   <Note>
     The portal displays: "Your request is pending approval by our NOC team. We will notify you by email once the network is approved and ready for configuration."
   </Note>

   <Frame>
     ![Add protected network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/pending-approval.png)
   </Frame>

Continue with [review and approval](/ddos-protection/onboarding-service/review-and-approval) to track the NOC decision.
