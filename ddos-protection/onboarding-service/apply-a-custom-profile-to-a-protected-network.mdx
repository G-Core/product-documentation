After creating a custom protection profile, apply it to a protected network to activate its rules and policy.

## Step 1. Open protected networks

Complete the following steps to locate the target network.

1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **DDoS Protection** \> **Protected networks**.
2. Locate the protected network to update.

## Step 2. Edit the protected network

Open the edit view for the target network.

1. Next to the target network, click **…**.
2. Select **Edit**.

<Frame>
  ![Edit the protected network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/protected-networks-edit.png)
</Frame>

## Step 3. Assign a protection profile

Select the profile to apply from the network's edit view.

1. In the **Edit protected network** view, open the **Profile** list.
2. Select the required protection profile.

The list includes the default **Basic** profile and any custom profiles created for the account.

## Step 4. Save changes

Apply the selected profile to the network.

1. Review the selected profile.
2. Click **Save changes**.

The selected profile becomes active immediately.

<Frame>
  ![Save the protected network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/protected-network-save.png)
</Frame>

## Verification

After saving, the **Profile** field on the network shows the selected profile name.

- Watch traffic in the [events log](/ddos-protection/events-log) to confirm the profile behaves as expected.
- Adjust the profile settings if required.
