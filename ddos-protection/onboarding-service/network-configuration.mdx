Network configuration is the final portal step in the setup process, after [NOC approval](/ddos-protection/onboarding-service/review-and-approval). Set the GRE endpoint IP and a protection profile for the approved network.

Filtered traffic reaches that endpoint only once the [GRE tunnel](/ddos-protection/onboarding-service/gre-tunneling/set-a-gre-tunnel-with-gcore) is configured on the local router, so complete that router-side setup along with this portal step.

## Configuration steps

Complete the following steps in the [Gcore Customer Portal](https://portal.gcore.com) to configure an approved network.

1. Navigate to **DDoS Protection** \> **Protected networks**.
2. Locate the approved network.
   - Find the network with the **Inactive: need info** status.
   - Click the **…** (three dots) menu next to the network and select **Edit**.

   <Frame>
     ![Inactive network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/inactive-need-info.png)
   </Frame>
3. In the **Edit protected network** view, configure the following fields:
   - **GRE endpoint**
     - Enter the Generic Routing Encapsulation (GRE) endpoint IP address on the local router. This is the address Gcore uses to forward filtered traffic through the tunnel.
     - Example: `203.0.113.1`.
   - **Protection profile**
     - Select a protection profile from the dropdown list. Create [custom profiles](/ddos-protection/onboarding-service/custom-protection-profile-configuration) later if needed.
4. Review the settings and click **Save changes** to apply them.

   <Note>
     The default **Basic** profile is a network filtering profile, distinct from the free Basic protection mode described in [About&nbsp;DDoS&nbsp;Protection](/ddos-protection/about-ddos-protection). Changes to the protection profile take effect immediately and do not require a new network submission or NOC review.
   </Note>

   <Frame>
     ![Saved network configuration](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/protected-network-saving.png)
   </Frame>

Once the network is configured, check attack volume and incidents in the [events log](/ddos-protection/events-log) and adjust the protection profile as needed.
