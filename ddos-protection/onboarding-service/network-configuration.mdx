Network configuration is the final portal step in the setup process, after [NOC approval](/ddos-protection/onboarding-service/review-and-approval). Set the GRE endpoint IP and a protection profile for the approved network. Configure the [GRE tunnel](/ddos-protection/onboarding-service/gre-tunneling/set-a-gre-tunnel-with-gcore) on the local router so inbound filtered traffic can reach that endpoint.

## Configuration steps

Complete the following steps in the [Gcore Customer Portal](https://portal.gcore.com) to configure an approved network.

1. Navigate to **DDoS Protection** \> **Protected networks**.
2. Locate the approved network.
   - Find the network with the **Inactive: need info** status.
   - Click the **…** (three dots) menu next to the network and select **Edit**.

   <Frame>
     ![Inactive network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/inactive-need-info.png)
   </Frame>
3. Configure network settings.
   In the **Edit protected network** view, configure the following fields:
   - **GRE endpoint**
     - Enter the Generic Routing Encapsulation (GRE) endpoint IP address on the local router. This is the address Gcore uses to forward filtered traffic through the tunnel.
     - Example: `203.0.113.1`.
   - **Protection profile**
     - Select a protection profile from the dropdown list. The default **Basic** profile is a network filtering profile, not the free Basic protection mode. Create [custom profiles](/ddos-protection/onboarding-service/custom-protection-profile-configuration) later if needed.
4. Save the configuration.
   - Review the settings and click **Save changes** to apply them.

   <Note>
     - The **Basic** profile provides standard DDoS filtering for the protected network.
     - Custom protection profiles can be created and applied later.
     - Changes take effect immediately after saving.
   </Note>

   <Frame>
     ![Saved network configuration](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/protected-network-saving.png)
   </Frame>

Once the network is configured, check attack volume and incidents in the [events log](/ddos-protection/events-log) and adjust the protection profile as needed.
