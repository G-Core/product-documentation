Network configuration is the final step in the setup process, after [NOC approval](/ddos-protection/onboarding-service/review-and-approval). Configure the approved network by setting a GRE endpoint and selecting a protection profile.

## Configuration steps

Complete the following steps in the [Gcore Customer Portal](https://portal.gcore.com) to configure an approved network.

1. Navigate to **DDoS Protection** \> **Protected networks**.
2. Locate the approved network.
   - Find the network with the **Inactive: need info** status.
   - Click the **…** (three dots) menu next to the network and select **Edit**.

   <Frame>
     ![Inactive network](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/inactive-need-info.png)
   </Frame>
3. Configure network settings.
   In the **Edit protected network** view, configure the following fields:
   - **GRE endpoint**
     - Enter the Generic Routing Encapsulation (GRE) endpoint IP address, the address where traffic is tunneled after configuring the [GRE tunnel](/ddos-protection/onboarding-service/gre-tunneling/set-a-gre-tunnel-with-gcore) on the local router.
     - Example: `203.0.113.1`.
   - **Protection profile**
     - Select a protection profile from the dropdown list. Only the **Basic** profile is available by default; create [custom profiles](/ddos-protection/onboarding-service/custom-protection-profile-configuration) later.
4. Save the configuration.
   - Review the settings and click **Save changes** to apply them.

   <Note>
     - The **Basic** profile provides standard DDoS protection.
     - Custom protection profiles can be created and applied later.
     - Changes take effect immediately after saving.
   </Note>

   <Frame>
     ![Saved network configuration](/images/docs/ddos-protection/onboarding-service/custom-protection-profile-configuration/protected-network-saving.png)
   </Frame>

Once the network is configured, monitor traffic and adjust the protection profile as needed.
