<MethodSection id="portal" label="Customer Portal">

<p>The events log stores DDoS attacks and related incidents from the past three months in the [Gcore Customer Portal](https://portal.gcore.com). This page covers that log and attack email notifications. Live attack statistics stay on [Traffic Analytics](/ddos-protection/traffic-analytics).</p>

## Events log

<p>Each row is one incident. Open a row for traffic graphs and a source breakdown.</p>

<Steps>
  <Step title="Open the events log">
    <p>In the Customer Portal, navigate to **DDoS Protection** → **Reports** → **Events log**.</p>

    <Frame>![DDoS Protection sidebar with Events log selected under Reports](/images/docs/ddos-protection/events-log/events-log-image1.png)</Frame>
  </Step>
  <Step title="Find an incident">
    <p>Use **Search by Target IP**, the date range, and the **Show all** event-type filter to narrow the list. Adjust **Entries per page** and pagination when the log spans more than one page.</p>

    <Frame>![Events log table with search, date filter, Show all, and DDoS Attack rows](/images/docs/ddos-protection/events-log/events-log-image2.png)</Frame>
  </Step>
</Steps>

<Info>
BPS and PPS are the instantaneous rates measured at detection, after filtering has already started. Because part of the flood is suppressed by that point, these values can read lower than the graphs in event details, which reflect the full incident.
</Info>

| Column | Description |
| --- | --- |
| Date (UTC) | Date and time the event was detected |
| Event | Event type: DDoS Attack or RTBH |
| BPS | Instantaneous bits per second at detection |
| PPS | Instantaneous packets per second at detection |
| Target IP | IP address that was attacked |
| Unique Source IPs | Number of distinct source addresses in the attack |

<p>A DDoS Attack row is a detected flood. An RTBH row is a remotely triggered black hole that null-routes the target IP until the block lifts.</p>

## Event details

<p>Click an event to open attack details for that incident. The view combines a traffic-volume graph with breakdowns by country, IP, port, and protocol.</p>

<Frame>![DDoS Attack details with the Network traffic graph selected](/images/docs/ddos-protection/events-log/events-log-image3.png)</Frame>

<p>The tabs are:</p>

- **Network traffic** shows volume during the incident.
- **Packet sizes** shows how packet sizes were distributed.
- **Top source countries** lists countries that generated the most traffic.
- **Top source IPs** lists source addresses that generated the most traffic.
- **Top source ports** lists source ports used in the attack.
- **Top destination ports** lists destination ports the attack targeted.
- **Top protocols** lists protocols used in the attack.

## Attack email notifications

<p>Gcore sends attack and IP-block emails to the account's registered address, once **Protected Network notifications** is turned on in [notification&nbsp;settings](/account-settings/notifications). When the attack or the RTBH block ends, a separate email goes to the same address.</p>

<p>A DDoS end email uses the subject **Security Alert: DDoS Attack Resolved** and states how long the attack lasted. An RTBH end email states that the null-route was lifted and how long the block lasted.</p>

<p>A follow-up attack that starts while the IP is still null-routed does not generate another start email, so a quiet inbox during a prolonged block does not mean the attack stopped.</p>

<p>If an expected alert is missing, check the spam folder first, then confirm the registered address in the Customer Portal.</p>

## Quickstart

<p>The scripts list event logs and read the first event.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    page = client.security.events.list(limit=1, ordering="-attack_start_time")
    event = client.security.events.get(page.results[0].id)
    print(event.id, event.alert_type)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "log"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/packages/param"
        "github.com/G-Core/gcore-go/security"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        page, err := client.Security.Events.List(ctx, security.EventListParams{
            Limit:    param.NewOpt(int64(1)),
            Ordering: security.EventListParamsOrderingMinusAttackStartTime,
        })
        if err != nil {
            log.Fatalf("list event logs: %v", err)
        }

        event, err := client.Security.Events.Get(ctx, page.Results[0].ID)
        if err != nil {
            log.Fatalf("get event log: %v", err)
        }
        fmt.Println(event.ID, event.AlertType)
    }
    ```
  </Tab>
</Tabs>

<Steps>
  <Step title="List event logs">
    <p>The [event&nbsp;logs](/api-reference/ddos-protection/event-logs/event-logs-clients-view) list returns DDoS Attack (<code>ddos_alert</code>) and RTBH (<code>rtbh_alert</code>) rows.</p>

    | Parameter | Required | Description |
    | --- | --- | --- |
    | `date_from` | No | Start of the window, ISO 8601 |
    | `date_to` | No | End of the window, ISO 8601 |
    | `alert_type` | No | `ddos_alert` or `rtbh_alert` |
    | `targeted_ip_addresses` | No | Target IP address |
    | `ordering` | No | Sort field. A leading `-` sorts descending |
    | `limit` | No | Page size, from 1 to 500 |

    <Tabs>
