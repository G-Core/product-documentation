The events log stores DDoS attacks and related incidents from the past three months in the [Gcore Customer Portal](https://portal.gcore.com). This page covers that log and attack email notifications. Live attack statistics stay on the [Overview](/ddos-protection/about-ddos-protection) dashboard.

## Events log

Each row is one incident. Open a row for traffic graphs and a source breakdown.

<Steps>
  <Step title="Open the events log">
    In the Customer Portal, navigate to **DDoS Protection** → **Reports** → **Events log**.

    <Frame>![DDoS Protection sidebar with Events log selected under Reports](/images/docs/ddos-protection/events-log/events-log-image1.png)</Frame>
  </Step>
  <Step title="Find an incident">
    Use **Search by Target IP**, the date range, and the **Show all** event-type filter to narrow the list. Adjust **Entries per page** and pagination when the log spans more than one page.

    <Frame>![Events log table with search, date filter, Show all, and DDoS Attack rows](/images/docs/ddos-protection/events-log/events-log-image2.png)</Frame>
  </Step>
</Steps>

<Info>
BPS and PPS are the instantaneous rates at detection, after filtering has started, so they can be lower than the original attack and can differ from the graphs in event details.
</Info>

| Column | Description |
| --- | --- |
| Date (UTC) | Date and time the event was detected |
| Event | Event type: DDoS Attack or RTBH |
| BPS | Instantaneous bits per second at detection |
| PPS | Instantaneous packets per second at detection |
| Target IP | IP address that was attacked |
| Unique Source IPs | Number of distinct source addresses in the attack |

A DDoS Attack row is a detected flood. An RTBH row is a remotely triggered black hole that null-routes the target IP until the block lifts.

## Event details

Click an event to open attack details for that incident. The view matches volume over time with the countries, IPs, ports, and protocols behind the flood.

<Frame>![DDoS Attack details with the Network traffic graph selected](/images/docs/ddos-protection/events-log/events-log-image3.png)</Frame>

The tabs are:

- **Network traffic** shows volume during the incident.
- **Packet sizes** shows how packet sizes were distributed.
- **Top source countries** lists countries that generated the most traffic.
- **Top source IPs** lists source addresses that generated the most traffic.
- **Top source ports** lists source ports used in the attack.
- **Top destination ports** lists destination ports the attack targeted.
- **Top protocols** lists protocols used in the attack.

## Attack email notifications

Gcore sends attack and IP-block emails to the account's registered address. Turn **Protected Network notifications** on in [notification&nbsp;settings](/account-settings/notifications) so those messages are delivered.

A follow-up attack that starts while the IP is still null-routed does not generate another email. Check the spam folder if an expected alert is missing, then confirm the registered address in the Customer Portal.
