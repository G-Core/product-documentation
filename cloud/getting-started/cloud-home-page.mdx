The Cloud Home Page is the landing page for the Gcore Cloud section. It opens automatically when navigating to **Cloud** in the [Gcore Customer Portal](https://portal.gcore.com) and serves as a starting point for creating resources, accessing developer tools, and finding documentation.

<Frame>![Cloud Home Page showing the Welcome to Gcore Cloud banner with Virtual Instances, Bare Metals, and Managed Kubernetes service cards](/images/docs/cloud/getting-started/cloud-home-page/cloud-home-page-image1.png)</Frame>

## Cloud navigation

The left sidebar in the Cloud section provides direct access to all Cloud resource types. No project or region selection is required before navigating — click a resource type to open its list page. The sidebar also includes a search field to filter by category.

The sidebar structure:

- **Home Page** — returns to the Cloud Home Page
- **Cloud Management** — manages projects, regions, and account-level settings
- Resource categories: Virtual Instances, Bare Metal, Storage, Managed Kubernetes, Function as a Service, Container as a Service, Container Registry, Managed Logging, Managed PostgreSQL, Images, SSH Keys, Secrets Manager, Networking

## Get started

The **Get started** section displays three quickstart cards for the most commonly used Cloud services.

| Card | Action |
|---|---|
| Virtual Instances | Creates a scalable cloud server. Click **Create Virtual Instance** to open the instance creation form. |
| Bare Metals | Deploys a dedicated physical server. Click **Create Bare Metal** to open the Bare Metal creation form. |
| Managed Kubernetes | Deploys a Kubernetes cluster. Click **Create Cluster** to open the cluster creation form. |

Each card also includes a **Documentation** link that opens the corresponding article on the Gcore documentation site.

## Resource overview

The resource overview widget displays the count of active Cloud resources across all projects and regions, broken down by type: Compute, Storage, Managed Services, and Networking. Clicking a resource type opens its list page with the active project and region filters applied.

Two multi-select filters appear above the overview widget:

- **Project** — filters the overview by project; defaults to Show All
- **Region** — filters the overview by region; defaults to Show All

## Developer tools

The **Developer Tools** section provides links to SDKs, APIs, and infrastructure-as-code tools for automating Cloud resource management.

<Frame>![Cloud Home Page showing the Blog section with recent articles and the Developer Tools section with links to Kubernetes, Terraform, MCP Servers, Go SDK, Python SDK, CLI, and API docs](/images/docs/cloud/getting-started/cloud-home-page/cloud-home-page-image2.png)</Frame>

Available tools:

- **Kubernetes** — links to the Managed Kubernetes documentation
- **Terraform** — links to the Gcore Terraform provider documentation
- **MCP Servers** — links to the MCP server documentation for AI agent integration
- **Go SDK** — links to the Gcore Go SDK documentation
- **Python SDK** — links to the Gcore Python SDK documentation
- **CLI** — coming soon
- **API / API Docs** — links to the Gcore Cloud API reference

## Blog

The **Blog** section surfaces the three most recent articles from the Gcore blog. Click **View more** to open the full blog at [gcore.com/blog](https://gcore.com/blog).
