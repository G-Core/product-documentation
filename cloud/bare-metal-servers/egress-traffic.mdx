Outgoing (egress) traffic on Bare Metal servers is billed by volume — unlike Virtual Machines, where outgoing traffic is free. Current rates are on the [pricing&nbsp;page](https://gcore.com/pricing/cloud).

## Billed traffic

Egress is data sent outward from a Bare Metal server through its public network interface. Traffic leaving through a private (internal) network interface is not metered.

## Traffic between servers in the same data center

Two servers in the same data center communicating through public IP addresses generate billed egress. The traffic passes through the public network layer regardless of physical proximity.

The same communication through a private network interface is not billed. Gcore Cloud supports attaching both a public and a private interface to the same Bare Metal server.

## Network recommendations

Configure server-to-server communication through a [private&nbsp;network](/cloud/networking/create-and-manage-a-network) to avoid egress charges on internal traffic:

- Use private IPs for communication between Bare Metal servers and between Bare Metal servers and Virtual Machines in the same region.
- Reserve public IPs for servers that handle requests from external clients.
