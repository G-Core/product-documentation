Gcore Container as a Service (CaaS) is a cloud service for running containers without Kubernetes or VM management. Gcore handles infrastructure maintenance and scaling automatically.

To use CaaS, select a supported region, specify the container image, and manage it via the [Gcore Customer Portal](https://portal.gcore.com) or REST API. Step-by-step instructions are in [Create&nbsp;a&nbsp;container](/cloud/caas/create-a-container) and [Manage&nbsp;containers](/cloud/caas/manage-containers). A [GitHub&nbsp;Actions](/cloud/caas/build-and-deploy-containers-to-caas-via-github-actions) workflow is also available for CI/CD pipeline deployments.
