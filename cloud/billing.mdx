All clients are subscribed to the PAYG (pay-as-you-go) billing plan. Edge Cloud resources are charged per minute for the time they are in use. Current rates are listed on the [pricing&nbsp;page](https://gcore.com/pricing/cloud).

Before use, [top&nbsp;up](/account-settings/billing/payments#top-up) the account balance to at least €4 or $4. Gcore calculates Cloud usage approximately every five minutes and collects payment when accrued charges reach €4 or $4. The amount is deducted from the account balance, or charged to the saved payment method when the balance is insufficient.

## If payment fails

If the account balance is insufficient and the saved payment method cannot be charged, Edge Cloud services are suspended. Deletion then follows the timelines in [Data&nbsp;deletion](/account-settings/billing/data-deletion).

## Billing by resource type

| Resource | Billing conditions |
| --- | --- |
| Virtual Machine | Per minute from creation until the VM is completely stopped |
| VM volumes, snapshots, images, and IP addresses (floating, virtual, and reserved) | Separately, from creation until deletion, whether or not the VM is running |
| VM Windows license | Separately |
| VM outgoing traffic | Free |
| Bare Metal server | From creation until deletion, whether or not the server is running |
| Bare Metal IP addresses, images, Windows license, and outgoing traffic | Separately |
| AI GPU and IPU | From creation until deletion, whether or not the server is running. Rates follow [Edge&nbsp;AI&nbsp;billing](/edge-ai/billing) |
| Managed Logging | By the volume of stored logs |
| Function as a Service | By the compute used to run the function |

## Other payment arrangements

To pay monthly, [contact&nbsp;support](https://gcore.com/contact-us). Annual prepayments are discounted. [Contact&nbsp;sales](https://gcore.com/contact-sales) for the applicable discount.
