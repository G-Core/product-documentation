This is a demo page showing how **x-mint parameter pills** would look on a real API reference page. The endpoint is not live.

`POST /cloud/v1/lbaas/{project_id}/{region_id}/loadbalancers`

---

## Path parameters

<ParamField path="project_id" type="integer" required>
  Numeric project identifier.
</ParamField>

<ParamField path="region_id" type="integer" required>
  Numeric region identifier.
</ParamField>

---

## Body parameters

<ParamField body="name" type="string" required>
  Display name for the load balancer.
</ParamField>

<ParamField body="flavor" type="string" required>
  Load balancer flavor. <Badge color="blue">BETA</Badge>

  lb2 flavors: `lb2-2-2` (1.5 Gbps), `lb2-4-4` (5 Gbps), `lb2-8-8` (10 Gbps), `lb2-16-16` (10 Gbps).

  Standard lb1 flavors: `lb1-1-2`, `lb1-2-4`, `lb1-4-8`, `lb1-8-16`.
</ParamField>

<ParamField body="bandwidth_gbps" type="integer">
  Guaranteed network bandwidth in Gbps. <Badge color="blue">BETA</Badge> <Badge color="gray">lb2 only</Badge>

  Applies only to lb2 flavors. Configured via QoS policy. Allowed values: `1`, `5`, `10`.
</ParamField>

<ParamField body="vip_network_id" type="string">
  UUID of the network to attach the virtual IP address to.
</ParamField>

<ParamField body="vip_subnet_id" type="string">
  UUID of the subnet to attach the virtual IP address to.
</ParamField>

<ParamField body="listeners" type="array">
  List of listener configurations to create together with the load balancer.

  <Expandable title="listener object">
    <ParamField body="name" type="string" required>
      Display name for the listener.
    </ParamField>
    <ParamField body="protocol" type="string" required>
      Protocol the listener accepts. One of: `HTTP`, `HTTPS`, `TERMINATED_HTTPS`, `TCP`, `UDP`, `Prometheus`.
    </ParamField>
    <ParamField body="protocol_port" type="integer" required>
      TCP or UDP port the listener binds to.
    </ParamField>
    <ParamField body="connection_limit" type="integer">
      Maximum simultaneous connections. `-1` means unlimited.
    </ParamField>
    <ParamField body="timeout_client_data" type="integer">
      Idle timeout (ms) for client connections. <Badge color="orange">recommended for SSE / WebSockets</Badge>
    </ParamField>
  </Expandable>
</ParamField>

## Request example

```bash
curl -X POST "https://api.gcore.com/cloud/v1/lbaas/1186668/76/loadbalancers" \
  -H "Authorization: APIKey $GCORE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-lb2",
    "flavor": "lb2-4-4",
    "bandwidth_gbps": 5,
    "vip_subnet_id": "b0e329a5-3c52-4e58-a000-abcdef123456"
  }'
```
