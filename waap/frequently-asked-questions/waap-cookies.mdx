---
title: "What cookies and local storage does WAAP use?"
description: "Cookies and local storage entries that Gcore WAAP sets on protected websites for security purposes."
---

Gcore WAAP sets the cookies and local storage entries listed below on websites it protects. They are strictly necessary for WAAP to protect the website against malicious and automated traffic. They are not used for analytics or advertising.

Not every entry is set on every request.

<Info>
These cookies are set on your website's domain. We recommend that you list them in your own cookie policy and inform your visitors about them. Depending on regional regulations, you may be required to do so. You can use the descriptions on this page.
</Info>

## Cookies and local storage

| Name | Type | Purpose | Duration |
| --- | --- | --- | --- |
| `SPSI` | Cookie | Stores a session identifier used for security purposes. | Session |
| `SPSE` | Cookie | Stores an encrypted session identifier used for security purposes. | Session |
| `UTGv2` | Cookie | Stores a random browser identifier used for security purposes. | Persistent |
| `altutgv2` | Local storage | Stores a copy of the browser identifier (see `UTGv2`) used for security purposes. | Persistent |
| `PRLST` | Cookie | Stores temporary technical data used to detect automated traffic. | Session |
| `sp_lit` | Cookie | Stores encrypted technical data used to detect automated traffic. | Short-lived |
| `otr` | Local storage | Stores the result of a security check used to detect automated traffic. It does not record what the user types or clicks. | Persistent |
| `adOtr` | Cookie | Sends the result of a security check (see `otr`) used to detect automated traffic. Not used for advertising. | Session |
| `cnv` | Local storage | Stores a random key used in security checks. | Persistent |
| `csr` | Local storage | Stores a random key used in security checks. | Persistent |
| `cnfc` | Cookie | Stores temporary data used to verify a CAPTCHA. | Short-lived |
| `pvstr` | Cookie | Stores temporary data used to verify a CAPTCHA. | Short-lived |
| `SPC` | Cookie | Stores encrypted data used to verify a CAPTCHA. | Short-lived |
| `sbtsck` | Cookie | Stores encrypted data used to confirm that a security check was completed. | Short-lived |
| `DGCC` | Cookie | Stores the result of a DDoS protection check. | Short-lived |
| `DCSS` | Cookie | Stores a random identifier used for DDoS protection. | Session |
| `DSR` | Cookie | Stores encrypted data used for DDoS protection, including the visitor's IP address. | Session |
| `DCST` | Cookie | Stores technical data used for DDoS protection. | Session |
| `spcsrf` | Cookie | Stores a random token used to protect website forms against cross-site request forgery. | Short-lived |

### Duration

- **Session**: deleted when the browser is closed.
- **Short-lived**: kept for up to 24 hours.
- **Persistent**: cookies are kept for up to 6 months. Local storage entries are kept until the visitor clears the browser data.

## Recommendations

- Do not block, modify, or delete these cookies and local storage entries, for example in your application, a cookie consent tool, or a proxy in front of WAAP. Otherwise, visitors may be challenged more often or blocked.
- If you use a cookie consent tool, classify these entries as strictly necessary so that they are set before the visitor gives consent.
