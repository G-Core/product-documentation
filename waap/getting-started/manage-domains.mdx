<p>After [adding a domain to WAAP protection](/waap/getting-started/configure-waap-for-a-domain), it appears on the **Domains** page in the [Gcore Customer Portal](https://portal.gcore.com/). This page displays all domains and their statuses, provides access to CDN settings, and allows deletion of Disabled domains.</p>

<Frame>![Domains page in the Customer Portal](/images/docs/waap/getting-started/configure-waap-for-a-domain/waap-domains.png)</Frame>

<p>A domain in WAAP can have the following statuses: </p>

  * **Monitoring**: WAAP monitors all traffic to the domain but does not enforce any actions on requests.

  * **Protection**: WAAP enforces all configured security settings for the domain.

  * **Disabled**: The domain is not protected because WAAP is disabled. You can always [enable WAAP](/waap/getting-started/configure-waap-for-a-domain) for Disabled domains from the WAAP Domains page. Note that Disabled domains are billed for the current billing month.


## WAAP protection disabling

<Info>
A Disabled domain is counted for the current billing month. Starting from the next billing month, it no longer appears in usage metrics. To avoid being billed for a domain in a given month, disable it before that billing month begins.
</Info>

<p>To disable WAAP protection for a domain:</p>

<Steps>
  <Step>
    In the [Gcore Customer Portal](https://portal.gcore.com/), navigate to **WAAP** > **Domains**.
  </Step>
  <Step>
    Find the domain in the list.
  </Step>
  <Step>
    In the **WAAP domain mode** column, click the mode dropdown and select **Disabled**.

    <Frame>![WAAP modes dropdown on Domains page](/images/docs/waap/getting-started/configure-waap-for-a-domain/domains-waap-protection.png)</Frame>
  </Step>
</Steps>

Deactivating a domain can take up to 20 minutes as this ensures that all changes are consistently applied across our system.

<p>After you disable WAAP protection for a domain, requests continue through the CDN and its cache but bypass WAAP inspection. The domain status on the Domains page in WAAP changes to **Disabled**. All WAAP settings and configured rules remain intact and can be modified. The settings do not take effect while WAAP is disabled.</p>

<p>To activate WAAP protection again:</p>

<Steps>
  <Step>
    Navigate to **WAAP** > **Domains**.
  </Step>
  <Step>
    Click the mode dropdown next to the domain.
  </Step>
  <Step>
    Select **Monitoring** or **Protection**.
  </Step>
</Steps>

<Warning>
If you disable WAAP protection for a domain and later re-enable it, WAAP mode will be set to **Monitoring**. If you had **Protection** mode before deactivating a domain, you need to enable it again.
</Warning>

## Domain removal from WAAP

<Warning>
Deleting a domain permanently removes it from WAAP, including all configured rules, firewall settings, and other WAAP settings. This action cannot be undone.
</Warning>

<p>A domain cannot be deleted while WAAP protection is enabled. To delete the domain, disable WAAP from the **WAAP domain mode** dropdown first. The domain status must change to **Disabled**.</p>

<p>To delete a Disabled domain:</p>

<Steps>
  <Step>
    In the [Gcore Customer Portal](https://portal.gcore.com/), navigate to **WAAP** > **Domains**.
  </Step>
  <Step>
    Click the three-dot icon next to the domain that you want to remove.
  </Step>
  <Step>
    Select **Delete**.
  </Step>
  <Step>
    Confirm your action by clicking **Delete**.
  </Step>
</Steps>

<p>The domain has been successfully removed from WAAP.</p>

## CDN resource suspension

<p>If you suspend a CDN resource with enabled WAAP, the domain status changes to **Disabled**. The CDN resource is no longer serving traffic, so content is unavailable to customers.</p>

<Info>
A Disabled domain is counted for the current billing month. Starting from the next billing month, it no longer appears in usage metrics. To avoid being billed for a domain in a given month, disable it before that billing month begins.
</Info>

<p>While the CDN resource is [suspended](/cdn/cdn-resource-options/general/suspend-a-cdn-resource-automatically-or-manually), WAAP settings remain intact. You can reactivate both CDN and WAAP at any time.</p>

## CDN resource deletion

<p>If you delete a CDN resource that has enabled WAAP protection, your domain and all relevant settings will be automatically removed from WAAP.</p>

<p>For instructions on how to delete a CDN resource, check our [dedicated guide](/cdn/about-cdn-resources-interface-how-it-is-arranged#delete-a-resource).</p>

<MethodSection id="api" label="REST API">

<p>The [Domains](/api-reference/waap#domains) endpoints cover checking a domain's protection status and deleting a Disabled domain. Switching between Monitoring and Protection modes is covered in the [domain setup guide](/waap/getting-started/configure-waap-for-a-domain). The response example includes only the fields used in this procedure.</p>

<Info>
An [API token](/account-settings/api-tokens) is required. Use <code>GET /waap/v1/domains</code> to retrieve the domain ID.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export WAAP_DOMAIN_ID="{YOUR_DOMAIN_ID}"
```

## Domain status

<p>Retrieve the current protection status and basic details of a specific domain. The API uses different names for statuses than the Customer Portal:</p>

| Customer Portal | API value |
|---|---|
| Protection | `active` |
| Monitoring | `monitor` |
| Disabled | `bypass` |

<Tabs>
  <Tab title="Python SDK">
    ```python
    import gcore
    import os

    client = gcore.Gcore()
    domain_id = int(os.environ["WAAP_DOMAIN_ID"])

    domain = client.waap.domains.get(domain_id)
    print(f"id={domain.id}  name={domain.name}  status={domain.status}")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
    )

    func main() {
        client := gcore.NewClient()
        domainID, err := strconv.ParseInt(os.Getenv("WAAP_DOMAIN_ID"), 10, 64)
        if err != nil {
            panic(fmt.Errorf("invalid WAAP_DOMAIN_ID: %w", err))
        }

        domain, err := client.Waap.Domains.Get(context.Background(), domainID)
        if err != nil {
            panic(err)
        }
        fmt.Printf("id=%d  name=%s  status=%s\n", domain.ID, domain.Name, domain.Status)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X GET "https://api.gcore.com/waap/v1/domains/${WAAP_DOMAIN_ID}" \
      -H "Authorization: APIKey ${GCORE_API_KEY}"
    ```

    Response:

    ```json
    {
      "id": 12345,
      "name": "example.com",
      "status": "monitor"
    }
    ```
  </Tab>
</Tabs>

<p>The `status` field returns the API value from the table above. The `bypass` state is set by selecting **Disabled** from the mode dropdown on the **WAAP** > **Domains** page. The WAAP API only supports switching between `active` and `monitor`.</p>

## Domain deletion

<Warning>
Deleting a domain permanently removes it from WAAP, including all configured rules, firewall settings, and other WAAP settings. This action cannot be undone.
</Warning>

<Warning>
The domain must have Disabled status before deletion. To disable a domain, select **Disabled** from the mode dropdown on the **WAAP** > **Domains** page. The WAAP API only supports switching between `active` and `monitor` and cannot set the Disabled state.
</Warning>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import gcore
    import os

    client = gcore.Gcore()
    domain_id = int(os.environ["WAAP_DOMAIN_ID"])

    client.waap.domains.delete(domain_id)
    print("Domain deleted")
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
    )

    func main() {
        client := gcore.NewClient()
        domainID, err := strconv.ParseInt(os.Getenv("WAAP_DOMAIN_ID"), 10, 64)
        if err != nil {
            panic(fmt.Errorf("invalid WAAP_DOMAIN_ID: %w", err))
        }

        err = client.Waap.Domains.Delete(context.Background(), domainID)
        if err != nil {
            panic(err)
        }
        fmt.Println("Domain deleted")
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X DELETE "https://api.gcore.com/waap/v1/domains/${WAAP_DOMAIN_ID}" \
      -H "Authorization: APIKey ${GCORE_API_KEY}"
    ```
  </Tab>
</Tabs>

<p>The API returns `204` with an empty body on success. Attempting to delete a domain that is not in Disabled status returns `422`.</p>
