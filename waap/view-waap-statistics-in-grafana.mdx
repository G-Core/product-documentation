WAAP request and traffic totals for the account can be shown as Grafana time-series panels. The [Grafana&nbsp;plugin](/developer-tools/grafana/install-the-grafana-plugin) adds the **Gcore Platform-EN** data source.
<Warning>
The previous WAAP-only plugin ([Waap](https://github.com/G-Core/waap-stats-datasource-plugin)) is deprecated. Migrate existing dashboards to **Gcore Platform-EN**.
</Warning>

## Configure a dashboard

The panel uses the connected **Gcore Platform-EN** data source.

1. In the top bar, click **+**, then **New dashboard**.

<Frame>![Plus menu open on New dashboard](/images/docs/waap/view-waap-statistics-in-grafana/new-dashboard-menu.png)</Frame>

2. The **Add** drawer opens on the right. Click **Panel**.

<Frame>![Add drawer with the Panel control](/images/docs/waap/view-waap-statistics-in-grafana/add-panel.png)</Frame>

3. Click **Edit visualization**.

4. Under **Data source**, select **Gcore Platform-EN**.

5. Under **Edge Network**, set **Service** to **WAAP**.

6. Under **Query Props**, set **Metric** and **Granularity**. **Legend Format** is optional.

7. Click **Save**. In **Save dashboard**, enter a title and click **Save**.

The saved dashboard shows the title and the panel.

<Frame>![Saved dashboard with the Total requests panel](/images/docs/waap/view-waap-statistics-in-grafana/saved-dashboard.png)</Frame>

## Query fields

A WAAP query returns one series for the account. The editor has no group-by control and no domain filter. An [alert&nbsp;rule](/developer-tools/grafana/create-an-alert-rule) on that series changes state when requests or traffic cross a threshold.

| Metric | Description |
|---|---|
| `total_requests` | Number of HTTP requests processed by WAAP |
| `total_bytes` | Traffic volume, shown in kilobytes |

**Granularity:** `1h` or `1d`. The series has one point per hour or per day.

**Legend Format:** optional series name. The default legend is the metric name.
