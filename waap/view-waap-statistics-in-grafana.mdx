The [Grafana&nbsp;plugin](/developer-tools/grafana/install-the-grafana-plugin) adds the Gcore Platform-EN data source. Set **Service** to **WAAP** and build time-series panels for the account totals.

<Warning>
The previous WAAP-only plugin ([Waap](https://github.com/G-Core/waap-stats-datasource-plugin)) is deprecated. Migrate existing dashboards to **Gcore Platform-EN**.
</Warning>

## Configure a dashboard

With the data source connected, create a panel for WAAP statistics.

1. In the Grafana main menu, click **New** > **New dashboard**.

2. Click **Add** > **Panel**, then **Configure visualization**.

3. In the data source dropdown, select **Gcore Platform-EN**.

4. In the query editor, under **Edge Network**, set **Service** to **WAAP**.

5. Under **Query Props**, set **Metric** and **Granularity**. **Legend Format** is optional.

6. Click **Save** to keep the panel, then **Save** the dashboard and enter a name.

## Query fields

A WAAP query returns one series for the account. The editor has no group-by control and no domain filter.

| Metric | Description |
|---|---|
| `total_requests` | Number of HTTP requests processed by WAAP |
| `total_bytes` | Traffic volume, shown in kilobytes |

**Granularity:** `1h` or `1d`. The series has one point per hour or per day.

**Legend Format:** optional series name. The default legend is the metric name.

## Grafana Alerting

Gcore Platform-EN is a backend data source with alerting enabled, so WAAP panel queries can be used in [Grafana&nbsp;Alerting](https://grafana.com/docs/grafana/latest/alerting/) rules. Create an alert rule from the query and use Grafana expressions (Reduce, Math, Threshold) to turn the time series into a condition.
