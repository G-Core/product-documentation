Gcore AI is four products. Train and fine-tune on GPU Cloud, serve a trained model from edge nodes with Everywhere Inference, take a region that Gcore operates, or install the platform on your own site.

## Train a model

GPU Cloud provides GPU virtual machines and bare metal servers for training and fine-tuning. [Create a virtual GPU cluster](/edge-ai/ai-infrastructure/create-a-virtual-gpu-cluster) for a virtual machine, or [create a bare metal GPU cluster](/edge-ai/ai-infrastructure/create-a-bare-metal-gpu-cluster) when the job needs dedicated machines. The [GPU Cloud API](/api-reference/cloud/gpu-virtual/list-virtual-gpu-clusters) creates and lists those clusters.

## Serve a model

Everywhere Inference runs a trained model on edge nodes and sends each request to the nearest node. [Deploy a model from the catalog](/edge-ai/everywhere-inference/ai-models/deploy-from-catalog) to serve an open-source model or a model trained on GPU Cloud. The [Everywhere Inference API](/api-reference/cloud/everywhere-inference/list-inference-deployments) creates and lists deployments.

## Take a managed region

[CloudStack](/edge-ai/cloudstack) is a region Gcore operates. The account receives a reseller panel and does not install the stack. [Contact us](https://gcore.com/contact-us) to discuss a region.

## Install on your own site

[Everywhere AI](/edge-ai/everywhere-ai) is the platform installed in your own environment. [User documentation](/everywhere-ai/user/overview/portal-overview) covers the interface end users open. [Admin documentation](/everywhere-ai/admin/overview/admin-panel-overview) covers installation and the admin panel.
