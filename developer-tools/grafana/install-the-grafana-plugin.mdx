Grafana lets you bring metrics from different services into dashboards to monitor performance and analyze trends. To include statistics from Gcore CDN, DNS, FastEdge, and WAAP, install the **Gcore Platform-EN** plugin.

The plugin requires Grafana 12.0.0 or later and a Gcore [API&nbsp;token](/account-settings/api-tokens).

<Warning>
The CDN-only plugin ([cdn-stats](https://github.com/G-Core/cdn-stats-datasource-plugin)) and the WAAP-only plugin ([Waap](https://github.com/G-Core/waap-stats-datasource-plugin)) are deprecated. Migrate existing dashboards to **Gcore Platform-EN**.
</Warning>

## Download and install the plugin

Install the plugin from the [GitHub&nbsp;repository](https://github.com/G-Core/gcore-stats-datasource-plugin), then restart Grafana so it can load the data source.

1. Download the latest [plugin&nbsp;archive](https://github.com/G-Core/gcore-stats-datasource-plugin/raw/main/release/gcore-stats-datasource-plugin.zip) from the repository `release` folder.

2. Extract the archive into the Grafana plugins directory. Default locations:
   - Linux and macOS: `/var/lib/grafana/plugins`
   - Windows: `C:\Program Files\GrafanaLabs\grafana\data\plugins`

   The plugin folder name must be `gcore-stats-datasource-plugin`.

3. If Grafana blocks unsigned plugins, allow this plugin ID in the Grafana configuration file (`custom.ini` or `grafana.ini`):

   ```ini
   [plugins]
   allow_loading_unsigned_plugins = gcore-stats-datasource-plugin
   ```

4. [Restart&nbsp;Grafana](https://grafana.com/docs/grafana/latest/setup-grafana/restart-grafana/) and sign in.

## Configure the data source

After installation, add **Gcore Platform-EN** as a data source and authenticate it with a Gcore API token.

1. In the Grafana main menu, navigate to **Connections** > **Data sources**.

2. Click **Add new data source**.

3. Search for `Gcore` and select **Gcore Platform-EN**.

4. Configure the connection fields:

   - **URL**: leave the field empty to call `https://api.gcore.com`. A custom value is a hostname only, with no scheme or path, and `api.gcore.com` is the production host written that way.
   - **API key**: paste an API token from the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com) (**Profile** > **API tokens** > **Create**). The raw token is enough; the plugin adds the `APIKey` prefix when needed. A value that already includes `APIKey` or `Bearer` is also accepted.

5. Click **Save & Test**.

A successful test confirms authentication with the account name. If the test fails, verify the token and that the URL is a hostname only.

The data source charts [CDN&nbsp;statistics](/cdn/grafana/view-cdn-statistics-in-grafana), [DNS&nbsp;statistics](/dns/grafana/view-dns-statistics-in-grafana), [FastEdge&nbsp;statistics](/fastedge/grafana/view-fastedge-statistics-in-grafana), and [WAAP&nbsp;statistics](/waap/analytics/view-waap-statistics-in-grafana). An [alert&nbsp;rule](/developer-tools/grafana/create-an-alert-rule) on one of those queries changes state when a value crosses a threshold.
