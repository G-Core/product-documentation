title: Connect Cursor IDE to Gcore MCP Server
sidebarTitle: Connect Cursor IDE

Cursor IDE connects to Gcore MCP Server in dynamic mode. Leave `GCORE_TOOLS` unset. The client receives six tools and can reach every operation. Pattern rules for a narrower set are in [Tool&nbsp;filtering](/developer-tools/mcp-server/filter-tools-with-gcore-tools).

- [Gcore&nbsp;API&nbsp;token](/account-settings/api-tokens) with permissions for the operations to perform
- [uv&nbsp;package&nbsp;manager](https://docs.astral.sh/uv/getting-started/installation/) installed
- Cursor IDE 0.40 or later

## Step 1. Add Gcore MCP Server to Cursor

Open the Cursor MCP configuration file:

<Tabs>
<Tab title="Windows">

```powershell
notepad $env:USERPROFILE\.cursor\mcp.json
```

</Tab>
<Tab title="macOS/Linux">

```bash
nano ~/.cursor/mcp.json
```

</Tab>
</Tabs>

Add the `gcore-mcp-server` entry to the `mcpServers` object. If the file is empty, create it with the full structure shown below.

```json
{
  "mcpServers": {
    "gcore-mcp-server": {
      "command": "uvx",
      "args": [
        "--from",
        "gcore-mcp-server@git+https://github.com/G-Core/gcore-mcp-server.git",
        "gcore-mcp-server"
      ],
      "env": {
        "GCORE_API_KEY": "API_TOKEN"
      }
    }
  }
}
```

Replace `API_TOKEN` with the [Gcore&nbsp;API&nbsp;token](/account-settings/api-tokens). Setting `GCORE_TOOLS` without `GCORE_MCP_MODE` selects direct mode. A value that matches nothing exits with status 2.

If the file already contains other MCP servers, add the `gcore-mcp-server` block inside the existing `mcpServers` object without removing other entries.

## Step 2. Verify the connection

Restart Cursor to load the new configuration. Open **Settings** and navigate to **Features → MCP**. The `gcore-mcp-server` entry appears with a green indicator and lists the loaded tools.

<Info>
If the server does not appear in MCP settings, verify that the `mcp.json` file has valid JSON syntax. A missing comma or bracket prevents loading. Check that `uv` is installed (`uv --version`). Quit Cursor and open it again. Reloading the window does not load the server.
</Info>

## Step 3. Test with a query

Open a Cursor chat and ask:

```
List my DNS zones
```

A successful response lists DNS zones with the zone name, record count, and status:

```json
{
  "zones": [
    {
      "name": "example.com",
      "status": "non-delegated",
      "enabled": true,
      "rrsets_amount": {
        "dynamic": {
          "healthcheck": 0,
          "total": 0
        },
        "static": 3,
        "total": 3
      }
    }
  ],
  "total_amount": 8
}
```

<Info>
If tools are not available in chat, confirm the `GCORE_API_KEY` value has no extra spaces or quotes, and verify the token is active in the [Gcore Customer Portal](/account-settings/api-tokens). Requests returning "401 Unauthorized" indicate an invalid or expired token. Required roles are in [API&nbsp;token&nbsp;permissions](/developer-tools/mcp-server/gcore-mcp-server-overview#api-token-permissions).
</Info>
