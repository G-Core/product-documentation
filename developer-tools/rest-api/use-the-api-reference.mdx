---
title: How to use the API Reference
description: Find an endpoint in the reference, send it in the browser, and read the status code and response.
---

The Gcore API Reference allows API requests to be sent directly from the browser. This guide uses the **Get profile templates** endpoint to demonstrate how to configure a request, send it, and interpret the response.

<Steps>
  <Step title="Open the endpoint">
    In the left sidebar:

    1. Open **DDoS Protection**.
    2. Open **Templates**.
    3. Select [Get&nbsp;profile&nbsp;templates](/api-reference/ddos-protection/templates/get-profile-templates).

    <Frame>![DDoS Protection sidebar with Get profile templates selected](/images/docs/developer-tools/use-the-api-reference/find-the-endpoint.png)</Frame>
  </Step>
  <Step title="Review the request">
    GET `/security/iaas/profile-templates` returns the profile templates and does not change the configuration.

    It requires an **Authorization** header and sends no body.

    The cURL block shows the same call as `https://api.gcore.com/security/iaas/profile-templates`.

    <Frame>![GET method, the profile-templates path, and the Try it button](/images/docs/developer-tools/use-the-api-reference/method-and-url.png)</Frame>

    <Frame>![cURL request for profile templates](/images/docs/developer-tools/use-the-api-reference/request-url.png)</Frame>
  </Step>
  <Step title="Open Try it">
    The panel shows the same method and path, and the **Send** button.

    <Frame>![Try it panel with the GET path and the Send button](/images/docs/developer-tools/use-the-api-reference/try-it-send.png)</Frame>
  </Step>
  <Step title="Enter the token">
    In **Authorization**, enter `apikey`, a space, and the [API&nbsp;token](/account-settings/api-tokens), replacing `1234_abcdef`.

    Leave `accepts_ip_address` empty to return every template. `true` keeps templates that require a protected `ip_address` per profile, and `false` keeps templates whose protected addresses are hardcoded.

    <Frame>![Authorization field filled with apikey 1234_abcdef](/images/docs/developer-tools/use-the-api-reference/try-it-authorization.png)</Frame>

    <Frame>![Query Parameters section for accepts_ip_address](/images/docs/developer-tools/use-the-api-reference/query-parameter.png)</Frame>
  </Step>
  <Step title="Send the request">
    The panel returns a status code and a response body.
  </Step>
  <Step title="Read the response">
    The number beside **Response** is the status code, and 200 means the request succeeded.

    The response contains a list of templates, so find the item named `universal_v6` and keep its `id`.

    Angle brackets mark placeholders, while the response after **Send** contains the values the API returns.

    <Frame>![Response section showing status 200 and application/json](/images/docs/developer-tools/use-the-api-reference/status-code.png)</Frame>

    <Frame>![Profile template JSON with id, name, and angle-bracket placeholders](/images/docs/developer-tools/use-the-api-reference/response.png)</Frame>
  </Step>
</Steps>
