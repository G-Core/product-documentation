<p>A certificate is ready to upload when it covers the [custom&nbsp;domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) of the CDN resource (`cdn.example.com`).</p>

<p>A certificate for `*.example.com` covers one DNS label under that domain (`cdn.example.com`). It does not cover the apex domain `example.com` or a nested hostname `assets.cdn.example.com`. Every required hostname belongs in the certificate's Subject Alternative Name (SAN) extension. Wildcard matching follows [RFC&nbsp;9525](https://www.rfc-editor.org/rfc/rfc9525).</p>

<p>Upload the certificate in the [Gcore Customer Portal](https://portal.gcore.com), then attach it to an existing CDN resource, because custom SSL is not selected on the resource creation form.</p>

## Upload an SSL certificate

<Steps>
  <Step title="Open SSL certificates">
    In the Customer Portal, navigate to **CDN** > **SSL certificates**.

    <Frame>![SSL certificates list with Add SSL certificate](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image1.png)</Frame>
  </Step>
  <Step title="Open the create form">
    Click **Add SSL certificate**. The **Create SSL Certificate** form opens.

    <Frame>![Create SSL Certificate form with Name, Certificate, and Private key](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image2.png)</Frame>
  </Step>
  <Step title="Enter the certificate data">
    Enter the values from the certificate authority:

    - **Name**: a label used only in the Customer Portal.
    - **Certificate**: the certificate chain in [PEM](https://en.wikipedia.org/wiki/Privacy-Enhanced_Mail) format (leaf certificate, intermediate CA, root CA).
    - **Private key**: the matching private key.

    Paste the chain and key as described in [Certificate&nbsp;chain](#certificate-chain-and-key). Leave **Signed by a trusted CA.** checked when the certificate is from a trusted CA. Clear the checkbox when it is not.

    <Frame>![Create SSL Certificate form filled with name, certificate chain, and private key](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image3.png)</Frame>
  </Step>
  <Step title="Create the certificate">
    Click **Create SSL Certificate**. The certificate appears in the SSL certificates list.

    <Frame>![SSL certificate in the certificates list](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image1.png)</Frame>
  </Step>
</Steps>

<p>Attach the certificate to a CDN resource after upload, because an uploaded certificate is not used until it is selected on a resource.</p>

### Certificate chain and key

<p>Open the certificate file in PEM format (`.pem`, `.crt`, or `.cer`) in a text editor.</p>

<p>Copy the chain in this order: leaf certificate, intermediate CA, root CA. Paste the full contents into **Certificate**, including the `-----BEGIN CERTIFICATE-----` and `-----END CERTIFICATE-----` tags. Do not leave blank lines between certificates.</p>

<Frame>![Certificate chain pasted into the Certificate field](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image4.png)</Frame>

<p>Add a new line at the end of the chain.</p>

<p>Open the private key file (`.key`) in a text editor. Paste the full contents into **Private key**, and keep the exact `BEGIN` and `END` lines from the key file. Common delimiters include `-----BEGIN PRIVATE KEY-----` and `-----BEGIN RSA PRIVATE KEY-----`.</p>

      <Frame>![Add SSL certificate dialog on an existing resource](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image8.png)</Frame>

  </Step>

## Certificate management

<p>Uploaded certificates are available under **CDN** > **SSL certificates**. In the Customer Portal, only the certificate name can be changed after upload — use **Settings** on the certificate row. To change the certificate or private key, upload a replacement and attach it on every resource listed under **CDN resources**.</p>

<Frame>![SSL certificates table with ID, name, resources, start, and expire](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image1.png)</Frame>

### SSL certificate renewal

<p>Before expiration, upload a replacement certificate and select it on every resource listed under **CDN resources** for the old certificate.</p>

<Steps>
  <Step title="Upload a replacement certificate">
    Add the replacement in [SSL&nbsp;certificates](#upload-an-ssl-certificate). Do not delete the old certificate yet.
  </Step>
  <Step title="Replace it on every connected resource">
    On the old certificate row, note every resource under **CDN resources**. For each listed resource, open **SSL** settings, select the new certificate, and click **Save changes**.
  </Step>
  <Step title="Wait for HTTPS to use the new certificate">
    Wait at least 15 minutes after the last resource is saved.
  </Step>
  <Step title="Verify each hostname">
    For each hostname, open the site over HTTPS and inspect the certificate presented by the browser. The subject, SAN, and validity dates should match the replacement certificate.
  </Step>
  <Step title="Delete the old certificate">
    After every hostname matches the new certificate, [delete](#delete-an-ssl-certificate) the old certificate. Removing it earlier interrupts HTTPS delivery on any resource that still selects it.
  </Step>
</Steps>

### Expiration notifications

<p>Notification emails are sent to the administrator and engineer addresses 14 days before expiration, seven days before expiration, and on the expiration date. A reminder also appears on login during those 14 days and after expiration. **SSL certificates** in the side panel shows an exclamation mark when a certificate is expired or will expire within 14 days.</p>

<p>A red exclamation mark marks an expired certificate, while a yellow warning marks a certificate that expires in 14 days or fewer.</p>

### Delete an SSL certificate

<p>A certificate that is selected on a CDN resource cannot be deleted. Replace it on every connected resource first.</p>

<Warning>
Turning off **Enable HTTPS** stops HTTPS delivery on that resource. To detach a certificate, select a replacement certificate on every connected resource. Turn off **Enable HTTPS** only when HTTPS delivery is being removed.
</Warning>

<Steps>
  <Step title="Detach the certificate from every resource">
    On the certificate row, note every resource under **CDN resources**. For each listed resource, open **SSL** settings and select a replacement certificate, then click **Save changes**. Turn off **Enable HTTPS** only when HTTPS delivery is being removed from that resource.
  </Step>
  <Step title="Open the delete action">
    Click the three dots next to the certificate, then click **Delete**. The same menu includes **Settings**.

    <Frame>![Settings and Delete actions on an SSL certificate row](/images/docs/cdn/ssl-certificates/configure-your-own-ssl-certificate/configure-your-own-ssl-certificate-image5.png)</Frame>
  </Step>
  <Step title="Confirm deletion">
    In the confirmation dialog, click **Yes, delete**.
  </Step>
</Steps>

<p>Upload a custom SSL certificate in PEM format, attach it to an existing [CDN resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource), and replace or delete it when the certificate changes. The certificate must cover the resource [custom domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) in its Subject Alternative Name (SAN) extension.</p>

<Info>
An [API token](/account-settings/api-tokens) is required. The CDN resource ID is visible under **CDN** → **CDN Resources**, or from the [resources list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

<p>Open a terminal and export the required variables. `SSL_CERTIFICATE` and `SSL_PRIVATE_KEY` are the PEM chain and key with a newline after every line, including the final `END` line:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
export SSL_CERTIFICATE="$(cat ./fullchain.pem)"
export SSL_PRIVATE_KEY="$(cat ./privkey.pem)"
```

## Upload a custom certificate

<p>Create the certificate object first. HTTPS does not use it until the ID is set on a CDN resource. `validate_root_ca` is `true` when a trusted CA signed the chain. Set it to `false` for a private or self-signed chain — otherwise the API returns HTTP 400.</p>

| Parameter | Required | Description |
|-----------|----------|-------------|
| `name` | Yes | Unique label for the certificate object |
| `sslCertificate` | Yes | PEM chain: leaf, intermediates, root, separated by `\n` |
| `sslPrivateKey` | Yes | Matching private key in PEM |
| `validate_root_ca` | No | Set to `true` for a trusted CA chain, `false` for a private or self-signed chain |

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()

    client.cdn.certificates.create(
        name="cdn.example.com",
        ssl_certificate=os.environ["SSL_CERTIFICATE"],
        ssl_private_key=os.environ["SSL_PRIVATE_KEY"],
        validate_root_ca=True,
    )

    uploaded = next(
        item
        for item in client.cdn.certificates.list(automated=False)
        if item.name == "cdn.example.com"
    )
    print(uploaded.id, uploaded.cert_subject_cn, uploaded.validity_not_after)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        err := client.CDN.Certificates.New(ctx, cdn.CertificateNewParams{
            OfOwnCertificate: &cdn.CertificateNewParamsBodyOwnCertificate{
                Name:           "cdn.example.com",
                SslCertificate: os.Getenv("SSL_CERTIFICATE"),
                SslPrivateKey:  os.Getenv("SSL_PRIVATE_KEY"),
                ValidateRootCa: gcore.Bool(true),
            },
        })
        if err != nil {
            panic(err)
        }

        page, err := client.CDN.Certificates.List(ctx, cdn.CertificateListParams{
            Automated: gcore.Bool(false),
        })
        if err != nil {
            panic(err)
        }
        for _, item := range page.Results {
            if item.Name == "cdn.example.com" {
                fmt.Println(item.ID, item.CertSubjectCn, item.ValidityNotAfter)
            }
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    jq -n \
      --arg name "cdn.example.com" \
      --arg sslCertificate "$SSL_CERTIFICATE" \
      --arg sslPrivateKey "$SSL_PRIVATE_KEY" \
      '{
        name: $name,
        sslCertificate: $sslCertificate,
        sslPrivateKey: $sslPrivateKey,
        validate_root_ca: true
      }' \
    | curl -X POST "https://api.gcore.com/cdn/sslData" \
        -H "Authorization: APIKey $GCORE_API_KEY" \
        -H "Content-Type: application/json" \
        -d @-
    ```

    <p>The API returns HTTP 201:</p>

    ```json
    {
      "id": 312679,
      "name": "cdn.example.com",
      "deleted": false,
      "cert_issuer": "Example CA",
      "cert_subject_cn": "cdn.example.com",
      "cert_subject_alt": "DNS:cdn.example.com",
      "validity_not_before": "2026-09-24T09:15:27Z",
      "validity_not_after": "2026-12-23T09:15:27Z",
      "sslCertificateChain": "",
      "hasRelatedResources": false,
      "automated": false
    }
    ```
  </Tab>
</Tabs>

<p>The [upload endpoint](/api-reference/cdn/ssl-certificates/add-ssl-certificate) creates the certificate object. Use the returned `id` to attach it to a CDN resource. If the SDK create method does not return the object, retrieve the certificate by name from the certificate list.</p>

## Attach a certificate to a CDN resource

<p>Set `sslEnabled` to `true` and `sslData` to the certificate ID on the resource. An uploaded certificate is unused until this call succeeds. Wait at least 15 minutes after the last attach before checking HTTPS in a browser.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()

    resource = client.cdn.cdn_resources.update(
        resource_id=int(os.environ["CDN_RESOURCE_ID"]),
        ssl_enabled=True,
        ssl_data=312679,
    )
    print(resource.id, resource.ssl_enabled, resource.ssl_data)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        resource, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            SslEnabled: gcore.Bool(true),
            SslData:    gcore.Int(312679),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(resource.ID, resource.SslEnabled, resource.SslData)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "sslEnabled": true,
        "sslData": 312679
      }'
    ```

    <p>The API returns the CDN resource. The SSL fields are:</p>

    ```json
    {
      "id": 101,
      "cname": "cdn.example.com",
      "sslEnabled": true,
      "sslData": 312679
    }
    ```
  </Tab>
</Tabs>

## Rename a certificate

<p>The certificate name is a unique label. A curl `PUT` can send `name` alone. The REST API can also replace the uploaded chain and key on the existing certificate object — the Customer Portal cannot edit that material after create. The Python and Go replace methods send `name` together with the PEM files: pass the same files to change only the label, or a new chain to replace the uploaded material.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()

    detail = client.cdn.certificates.replace(
        ssl_id=312679,
        name="cdn.example.com-2026",
        ssl_certificate=os.environ["SSL_CERTIFICATE"],
        ssl_private_key=os.environ["SSL_PRIVATE_KEY"],
        validate_root_ca=True,
    )
    print(detail.id, detail.name)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        detail, err := client.CDN.Certificates.Replace(ctx, 312679, cdn.CertificateReplaceParams{
            Name:           "cdn.example.com-2026",
            SslCertificate: os.Getenv("SSL_CERTIFICATE"),
            SslPrivateKey:  os.Getenv("SSL_PRIVATE_KEY"),
            ValidateRootCa: gcore.Bool(true),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(detail.ID, detail.Name)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PUT "https://api.gcore.com/cdn/sslData/312679" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "cdn.example.com-2026"}'
    ```

    <p>The API returns the certificate with the new `name`. The subject, issuer, and validity dates stay the same when only `name` is sent.</p>
  </Tab>
</Tabs>

## Replace a certificate on a CDN resource

<p>Upload the replacement certificate, then set `sslData` to the new ID on every connected resource.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()
    old_id = 312679
    new_id = 312680

    for resource in client.cdn.cdn_resources.list(ssl_data=old_id):
        updated = client.cdn.cdn_resources.update(
            resource_id=resource.id,
            ssl_enabled=True,
            ssl_data=new_id,
        )
        print(updated.id, updated.ssl_data)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        oldID := int64(312679)
        newID := int64(312680)

        page, err := client.CDN.CDNResources.List(ctx, cdn.CDNResourceListParams{
            SslData: gcore.Int(oldID),
        })
        if err != nil {
            panic(err)
        }
        for _, item := range page.Results {
            updated, err := client.CDN.CDNResources.Update(ctx, item.ID, cdn.CDNResourceUpdateParams{
                SslEnabled: gcore.Bool(true),
                SslData:    gcore.Int(newID),
            })
            if err != nil {
                panic(err)
            }
            fmt.Println(updated.ID, updated.SslData)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/cdn/sslData/312679/usage" \
      -H "Authorization: APIKey $GCORE_API_KEY"

    curl -X PATCH "https://api.gcore.com/cdn/resources/101" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "sslEnabled": true,
        "sslData": 312680
      }'
    ```

    <p>The API returns the CDN resource with `sslData` set to the replacement ID. Repeat the PATCH for every resource in the usage list.</p>
  </Tab>
</Tabs>

<p>Wait at least 15 minutes after the last resource update. For each hostname, open the site over HTTPS and inspect the certificate presented by the browser. The subject, SAN, and validity dates should match the replacement certificate. Keep the old certificate until that check succeeds.</p>

### Stop HTTPS delivery

<p>When HTTPS delivery is being removed from a resource, set `sslEnabled` to `false` and `sslData` to `null` before deleting the unused certificate. That stops HTTPS on the resource.</p>

<Warning>
Setting `sslEnabled` to `false` stops HTTPS delivery on that resource.
</Warning>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()

    client.cdn.cdn_resources.update(
        resource_id=int(os.environ["CDN_RESOURCE_ID"]),
        ssl_enabled=False,
        ssl_data=None,
    )
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        _, err = client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            SslEnabled: gcore.Bool(false),
            SslData:    param.Null[int64](),
        })
        if err != nil {
            panic(err)
        }
    }
    ```
  </Tab>
