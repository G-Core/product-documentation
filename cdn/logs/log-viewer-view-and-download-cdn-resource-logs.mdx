  <MethodSection id="portal" label="Customer Portal">
  <p>Log viewer shows request logs for CDN resources from the last three days. Each query covers at most six hours, and a download can include up to 10,000 records. For continuous export to storage, use [Logs&nbsp;uploader](/cdn/logs/logs-uploader).</p>
  <Steps>
    <Step title="Open Log viewer">
      In the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com), navigate to **CDN** > **Logs** > **Log viewer**.

      <Frame>
        ![Log viewer table with filters, status codes, and sample request rows](/images/docs/cdn/logs/log-viewer-view-and-download-cdn-resource-logs/image_1330-2.png)
      </Frame>
    </Step>
    <Step title="Filter the log table">
      In **Search by CNAME or ID**, enter a resource CNAME or ID. The **CDN resource is** filter is applied. Click the time range to pick any interval of up to six hours within the last three days. Click **Add filter** to narrow results by client IP address, HTTP method, status code, data center, or cache status. Click **Reset all** to clear filters.
    </Step>
    <Step title="Read a log row">
      The table columns are **Client IP address**, **Timestamp (UTC)**, **HTTP method**, **Request URL**, **Status code**, **CDN resource (ID)**, and **Details**. Hover the **i** icon in **Details** for the remaining request fields: referer, size, data center, User-Agent, cache status, resource ID, and CNAME. HIT means the response came from cache, while MISS means the response was fetched from the origin.
    </Step>
    <Step title="Export logs">
      Click **Export**. In **Export settings**, keep **Current** to use the active filters and time range, or select **Custom period** to set a different interval. Select **CSV** or **TSV**, then click **Export**. The file is saved to the browser download location. An export is limited to 10,000 records.

      <Frame>
        ![Export settings dialog with current period, CSV format, and Export](/images/docs/cdn/logs/log-viewer-view-and-download-cdn-resource-logs/image_1334.png)
      </Frame>
    </Step>
  </Steps>
</MethodSection>
  <MethodSection id="api" label="REST API">
  <p>The Log viewer API lists request logs in JSON and downloads the same log fields as CSV or TSV. JSON list requests return at most 1,000 rows. Downloads return at most 10,000 rows.</p>
  ### Authentication
  <p>All requests authenticate with an [API&nbsp;token](/account-settings/api-tokens). Set it as an environment variable before running the examples:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

  ### Filters and limits
  <p><code>from</code> and <code>to</code> are required, must be UTC in ISO 8601 or RFC 3339 format, and cannot span more than six hours. Logs are available for the last three days. Filter operators and field names are in the [Log&nbsp;viewer](/api-reference/cdn/log-viewer/get-cdn-logs) API reference. In the examples below, replace <code>FROM_TIME</code> and <code>TO_TIME</code> with UTC timestamps from the last three days, for example <code>2026-09-06T00:00:00Z</code> and <code>2026-09-06T06:00:00Z</code>.</p>
  ### JSON list
  <p>GET <code>https://api.gcore.com/cdn/advanced/v1/logs</code> returns matching log rows. The <code>limit</code> default is 100 and the maximum is 1,000.</p>

  <Tabs>
    <Tab title="Python SDK">

```python
import os
from gcore import Gcore

client = Gcore(
    api_key=os.environ.get("GCORE_API_KEY"),
)
page = client.cdn.logs.list(
    from_="FROM_TIME",
    to="TO_TIME",
)
if page.data:
    print(page.data[0].resource_id)
```

    </Tab>

```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/cdn"
	"github.com/G-Core/gcore-go/option"

func main() {
	client := gcore.NewClient(
		option.WithAPIKey(os.Getenv("GCORE_API_KEY")),
	)
	page, err := client.CDN.Logs.List(context.TODO(), cdn.LogListParams{
		From: "FROM_TIME",
		To:   "TO_TIME",
	})
	if err != nil {
		panic(err.Error())
	}
	fmt.Printf("%+v\n", page)
}
```

  ### Download
  <p>GET <code>https://api.gcore.com/cdn/advanced/v1/logs/download</code> returns a zip file. <code>format</code> is required (<code>csv</code> or <code>tsv</code>). The <code>limit</code> default and maximum is 10,000.</p>

  <Tabs>
    <Tab title="Python SDK">

```python
import os
from gcore import Gcore

client = Gcore(
    api_key=os.environ.get("GCORE_API_KEY"),
)
response = client.cdn.logs.download(
    format="csv",
    from_="FROM_TIME",
    to="TO_TIME",
)
with open("cdn-logs.zip", "wb") as f:
    f.write(response.read())
```

    </Tab>
    <Tab title="Go SDK">

```go
package main

import (
	"context"
	"io"
	"os"

	"github.com/G-Core/gcore-go"
	"github.com/G-Core/gcore-go/cdn"
	"github.com/G-Core/gcore-go/option"
)

func main() {
	client := gcore.NewClient(
		option.WithAPIKey(os.Getenv("GCORE_API_KEY")),
	)
	response, err := client.CDN.Logs.Download(context.TODO(), cdn.LogDownloadParams{
		Format: "csv",
		From:   "FROM_TIME",
		To:     "TO_TIME",
	})
	if err != nil {
		panic(err.Error())
	}
	defer response.Body.Close()
	f, err := os.Create("cdn-logs.zip")
	if err != nil {
		panic(err.Error())
	}
	defer f.Close()
	if _, err := io.Copy(f, response.Body); err != nil {
		panic(err.Error())
	}
}
```
