Gcore CDN Edge Network servers use these timeout defaults when proxying to origins and handling client requests. Several values differ from stock Nginx defaults.

CDN resources can use lower [connection&nbsp;timeouts](/cdn/cdn-resource-options/general/customize-connection-and-read-timeouts) in the [Gcore Customer Portal](https://portal.gcore.com). Other timeouts below apply across the Edge Network. On an Enterprise plan, [Gcore&nbsp;Support](mailto:support@gcore.com) can change defaults that the Customer Portal does not expose.

| Directive | Definition | Value |
|-----------|------------|-------|
| [proxy_read_timeout](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_read_timeout) | Time limit for receiving a partial response from a proxied origin. If no response arrives within this time, the connection closes. | 30s |
| [proxy_connect_timeout](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_connect_timeout) | Time limit for establishing a connection with a proxied origin. | 5s |
| [proxy_send_timeout](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_send_timeout) | Time limit for transmitting a request to a proxied origin. If the origin does not accept data within this time, the connection closes. | 30s |
| [client_header_timeout](https://nginx.org/en/docs/http/ngx_http_core_module.html#client_header_timeout) | Time limit for reading the client request header. If the full header is not received in time, the client receives `408 Request Timeout`. | 10s |
| [client_body_timeout](https://nginx.org/en/docs/http/ngx_http_core_module.html#client_body_timeout) | Time limit for reading the client request body. If no data is sent within this time, the client receives `408 Request Timeout`. | 30s |
| [resolver_timeout](https://nginx.org/en/docs/http/ngx_http_core_module.html#resolver_timeout) | Time limit for DNS name resolution. | 5s |
| [ssl_session_timeout](https://nginx.org/en/docs/http/ngx_http_ssl_module.html#ssl_session_timeout) | How long a client can reuse SSL session parameters. | 2h |
| [keepalive_timeout](https://nginx.org/en/docs/http/ngx_http_core_module.html#keepalive_timeout) | Idle time after which a keep-alive connection closes. Replaces the removed Nginx `http2_idle_timeout` directive. | 15s |
