A CDN resource connects an origin to Gcore edge servers, which cache content and deliver it from locations closer to visitors. The same creation flow supports websites, static assets, and prepared video streams.

## Delivery use cases

Select a setup based on the content served from the origin:

- Website and asset acceleration delivers websites, images, CSS, JavaScript, or fonts using a CNAME record or Gcore Managed DNS delegation. Configure a [CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) and optionally enable WAAP for web application and API protection.

- Prepared video delivery distributes live streams and video-on-demand content in HLS, MPEG-DASH, HTTP-FLV, or MP4 format without transcoding. A paid CDN plan and activation by Gcore Support are required before following the [Video&nbsp;CDN&nbsp;setup](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource-for-video-streaming).

<Info>
For raw RTMP or SRT inputs, automatic transcoding, or adaptive bitrate output, use [Video&nbsp;Streaming](/streaming) instead of Video CDN.
</Info>

## Quick comparison

Both use cases follow the same CDN resource creation flow, but prepared video delivery has additional activation requirements.

| Feature | Website and asset acceleration | Prepared video delivery |
|---------|--------------------------------|-------------------------|
| Best for | Websites and static assets | Live streams and video-on-demand content |
| Content examples | HTML, CSS, JavaScript, images, and fonts | HLS, MPEG-DASH, HTTP-FLV, and MP4 |
| DNS setup | Gcore Managed DNS delegation or a CNAME record | Gcore Managed DNS delegation or a CNAME record |
| Activation | Active CDN subscription | Paid CDN plan and Gcore Support approval |

<Note>
An account can have up to 30 CDN resources across all use cases. For a higher limit, contact the account manager or [Gcore&nbsp;Support](mailto:support@gcore.com).
</Note>
