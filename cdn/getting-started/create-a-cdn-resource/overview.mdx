A CDN resource is the configuration for delivering one or more custom domains (a primary domain and optional aliases) through Gcore CDN. It maps these domains to one or several origins and defines all delivery settings — caching rules, SSL certificates, HTTP headers, and security options. Domains that need different settings require separate CDN resources. The [delivery&nbsp;model](/cdn/how-cdn-works) shows how a request travels from the viewer through the resource to the origin.

## Resource types

What the resource delivers decides which creation guide applies:

- **Standard CDN resource**: accelerates a website or specific assets using either a CNAME record or Gcore Managed DNS delegation, and supports an optional WAAP integration for Layer 7 DDoS and web application protection. The [creation&nbsp;guide](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) covers the steps.
- **Video delivery**: delivers live streams and video-on-demand content globally, best for HLS, DASH, or FLV video delivery without transcoding. The [video&nbsp;guide](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource-for-video-streaming) covers the activation requirements and the steps.

<Info>
Need transcoding? To transcode raw video inputs (RTMP, SRT) or generate adaptive bitrate ladders automatically, use [Gcore&nbsp;Video&nbsp;Streaming](/streaming) instead of video delivery through CDN.
</Info>

## Comparison

The two types differ in the content they suit and in what must be in place before the resource is created:

| Feature | Standard CDN resource | Video delivery |
|---------|----------------------|----------------|
| Best for | Websites and asset acceleration | Live streams and VOD |
| Typical use case | E-commerce, blogs, apps | Broadcasting, OTT |
| DNS management | CNAME or Gcore Managed DNS | Manual |
| WAAP support | Yes | No |
| Required before creation | An origin and access to the domain's DNS provider | A paid CDN plan, Support approval for HLS and DASH, and a sales agreement for HTTP-FLV Live |

<Note>
An account can have up to 30 CDN resources of all types combined. To raise this limit, contact the Account Manager or [Gcore&nbsp;Support](mailto:support@gcore.com).
</Note>
