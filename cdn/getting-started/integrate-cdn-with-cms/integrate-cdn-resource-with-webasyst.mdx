title: Integrate a CDN resource with Webasyst
sidebarTitle: Webasyst

---

Webasyst can rewrite image, CSS, and JavaScript URLs to a Gcore CDN [custom&nbsp;domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) through the Site app **CDN** field. Create a&nbsp;[CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) before starting the integration.

<Warning>
Back up the site files and database before making changes. These steps assume the default Site app settings layout — a custom theme or modified URL patterns might not rewrite assets correctly.
</Warning>

Before configuring Webasyst, collect the **custom domain** value to enter in the **CDN** field — it typically looks like `https://cdn.site.com`:

<Steps>
  <Step title="Open the CDN resource">
    In the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com), navigate to **CDN** > **CDN resources** and open the resource.
  </Step>
  <Step title="Copy the custom domain">
    Note the **custom domain** shown for the resource — this is the hostname to enter in the Webasyst **CDN** field, usually with the `https://` prefix.
  </Step>
  <Step title="Confirm the DNS CNAME">
    Confirm that the custom domain has a CNAME record pointing to the Gcore target hostname shown in the Customer Portal (`cl-****.gcdn.co`). Do not put the `gcdn.co` hostname in Webasyst.
  </Step>
  <Step title="Confirm SSL">
    Confirm the custom domain has a valid SSL certificate so assets can load over HTTPS.
  </Step>
</Steps>

Then configure Webasyst:

<Steps>
  <Step title="Open the Site settings">
    Log in to the Webasyst administration area, open the **Site** app, and select **Settings**.
  </Step>
  <Step title="Enter the CDN URL">
    In the **CDN** field, enter the custom domain URL copied from the Customer Portal — typically `https://cdn.site.com`.
  </Step>
  <Step title="Save the configuration">
    Save the settings.
  </Step>
  <Step title="Confirm the integration">
    1. Open the browser developer tools.
    2. Select the **Network** tab.
    3. Refresh the page.
    4. Confirm that static files load from the custom domain instead of the original domain.
  </Step>
</Steps>
