<Warning>
Back up site files and the database before making changes. These steps work only with the default IPB pattern — a manually modified pattern might not integrate correctly.
</Warning>

Invision Power Board (IPB) 3.2 and later, including current Invision Community, support CDN integration by rewriting static asset URLs to a custom domain.

Create a&nbsp;[CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) before starting the integration, and confirm the [CNAME&nbsp;record](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) is configured.

1. Log in to the IPB / Invision Community Admin Control Panel.
2. Navigate to **System** > **System Settings** > **General Configuration**.
3. Scroll to **CDN Settings**.
4. Enter the CNAME configured for the CDN resource in the [Gcore Customer Portal](https://portal.gcore.com/cdn/resources/list); it typically looks like `cdn.site.com`.
5. Save the settings.
6. Confirm the integration by opening the browser's developer tools (press **F12**), selecting the **Network** tab, and refreshing the page — static files should now load from the CNAME instead of the original domain.
