title: Integrate CDN resource with PyroCMS
sidebarTitle: PyroCMS

---

<Warning>
Back up site files and the database before making changes. These steps work only with the default PyroCMS pattern — a manually modified pattern might not integrate correctly.
</Warning>

Create a&nbsp;[CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) before starting the integration, and confirm the [CNAME&nbsp;record](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) is configured.

**PyroCMS 3.x (current)**

Current PyroCMS is Laravel-based. Set the asset base URL in `.env` to the CNAME from the [Gcore Customer Portal](https://portal.gcore.com/cdn/resources/list); it typically looks like `cdn.site.com`:

1. Open the application `.env` file.
2. Set:

   ```bash
   ASSET_URL=https://cdn.site.com
   ```

3. If configuration caching is used in production, refresh it:

   ```bash
   php artisan config:cache
   ```

4. Confirm the integration by opening the browser's developer tools (press **F12**), selecting the **Network** tab, and refreshing the page — static files should now load from the CNAME instead of the original domain.

**PyroCMS 2.x**

Older PyroCMS 2.x installations expose a CDN field in the admin UI:

1. Log in to the PyroCMS admin panel.
2. Navigate to **Settings** > **Integration**.
3. Enter the CNAME configured for the CDN resource.
4. Save the settings.
5. Confirm static files load from the CNAME in the browser **Network** tab as described above.
