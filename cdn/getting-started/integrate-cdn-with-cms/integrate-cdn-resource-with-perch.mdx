---
title: Integrate CDN resource with Perch
sidebarTitle: Perch
ai-navigation: Configure Perch PERCH_RESPATH and bucket web_path values to serve resources through the Gcore CDN CNAME.
---

<Warning>
Back up site files and the database before making changes. These steps work only with the default Perch pattern — a manually modified pattern might not integrate correctly.
</Warning>

Create a&nbsp;[CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) before starting the integration, and confirm the [CNAME&nbsp;record](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) is configured.

1. In the [Gcore Customer Portal](https://portal.gcore.com/cdn/resources/list), note the CNAME configured for the CDN resource; it typically looks like `cdn.site.com`.
2. Open `perch/config/config.php` on the server and find:

   ```php
   define('PERCH_RESPATH', PERCH_LOGINPATH . '/resources');
   ```

3. Replace it with the CNAME as the host prefix:

   ```php
   define('PERCH_RESPATH', 'https://cdn.site.com' . PERCH_LOGINPATH . '/resources');
   ```

4. Optional — for custom resource buckets, open `perch/config/buckets.php` and prefix each `web_path` with the same CNAME, keeping the original path:

   ```php
   // Before
   'web_path' => '/my/bucket/path',

   // After
   'web_path' => 'https://cdn.site.com/my/bucket/path',
   ```

5. Save the configuration files.
6. Confirm the integration by opening the browser's developer tools (press **F12**), selecting the **Network** tab, and refreshing the page — resource URLs should now load from the CNAME instead of the original domain.
