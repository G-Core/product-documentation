---
title: Integrate CDN resource with Kirby
sidebarTitle: Kirby
ai-navigation: Configure Kirby media and assets URLs in index.php to serve static files through the Gcore CDN CNAME.
---

<Warning>
Back up site files and the database before making changes. These steps work only with the default Kirby pattern — a manually modified pattern might not integrate correctly.
</Warning>

[Kirby](https://getkirby.com) can serve `media` and `assets` from a CDN by setting custom URLs when Kirby is initialized. Create a&nbsp;[CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) before starting the integration, and confirm the [CNAME&nbsp;record](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) is configured.

1. In the [Gcore Customer Portal](https://portal.gcore.com/cdn/resources/list), note the CNAME configured for the CDN resource; it typically looks like `cdn.site.com`.
2. Open the site `index.php` and set the `media` and `assets` URLs to that CNAME:

   ```php
   <?php

   include __DIR__ . '/kirby/bootstrap.php';

   $kirby = new Kirby([
       'urls' => [
           'media'  => 'https://cdn.site.com/media',
           'assets' => 'https://cdn.site.com/assets',
       ]
   ]);

   echo $kirby->render();
   ```

3. Save `index.php`.
4. Confirm the integration by opening the browser's developer tools (press **F12**), selecting the **Network** tab, and refreshing the page — media and asset files should now load from the CNAME instead of the original domain.

A plugin-based approach that rewrites only selected paths is described in the Kirby cookbook [Kirby&nbsp;loves&nbsp;CDN](https://getkirby.com/docs/cookbook/performance/kirby-loves-cdn).
