title: Integrate CDN resource with Concrete5
sidebarTitle: Concrete5
ai-navigation: Configure the Use CDN add-on in Concrete CMS to serve static assets through the Gcore CDN CNAME.
---

<Warning>
Back up site files and the database before making changes. These steps work only with the default Concrete CMS pattern — a manually modified pattern might not integrate correctly.
</Warning>

Create a&nbsp;[CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) before starting the integration, and confirm the [CNAME&nbsp;record](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) is configured.

1. Install the [Use&nbsp;CDN](https://market.concretecms.com/products/use-cdn/81cb661d-2dd1-11ef-951f-0a97d4ce16b9) add-on from the Concrete CMS Marketplace.
2. In the Concrete CMS dashboard, navigate to **System & Settings** > **Optimization** > **CDN Settings**.
3. Enter the CNAME configured for the CDN resource in the [Gcore Customer Portal](https://portal.gcore.com/cdn/resources/list); it typically looks like `cdn.site.com`.
4. Save the settings.
5. Confirm the integration by opening the browser's developer tools (press **F12**), selecting the **Network** tab, and refreshing the page — static files should now load from the CNAME instead of the original domain.
