CDN integration rewrites static asset URLs to use the CDN resource domain. For production delivery, configure a [custom&nbsp;domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) first.

For custom applications without built-in CDN support, rewrite asset URLs in the application code or with a script. Contact a developer or [Gcore&nbsp;Support](mailto:support@gcore.com) for assistance.

After the relevant plugin or integration is configured, it rewrites asset URLs to the CDN domain automatically. Choose a guide below by platform type.
