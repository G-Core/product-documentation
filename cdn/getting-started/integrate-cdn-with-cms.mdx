Using a CDN requires replacing the domain of the application in content links with the CDN resource's [custom&nbsp;domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn). Without a CMS or off-the-shelf solution — AWS S3, for instance — this replacement can be done using a script; contact a developer or [Gcore&nbsp;Support](mailto:support@gcore.com).

For a CMS or cloud storage service, plugins or dedicated functionality handle the domain replacement automatically. Gcore CDN integrates with:
