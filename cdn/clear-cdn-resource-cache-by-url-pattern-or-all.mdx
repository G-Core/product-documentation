  <MethodSection id="portal" label="Customer Portal">

<p>[Purge](https://portal.gcore.com/cdn/purge/purge-request) clears the CDN resource cache. Use it when content on the origin is updated and waiting for natural cache expiration is not acceptable, or when CDN servers are serving stale content.</p>

<p>Three purge methods are available:</p>

1. **Purge by URL** to remove specific cached files without affecting other content.
2. **Purge all** to remove all data from the cache.
3. **Purge by pattern** to remove content selectively by specifying path patterns with the `*` operator.

## Customer Portal cache purge

<Steps>
  <Step title="Open Purge request">
    In the Customer Portal, navigate to **CDN** → **Purge** → **Purge request**.
  </Step>
  <Step title="Select a CDN resource">
    Select the relevant CDN resource from the dropdown menu.
  </Step>
  <Step title="Select a purge method">
    Click the radio button next to the purge method, configure it as described below, then click **Purge**.
  </Step>
</Steps>

<Frame>
  ![Purge request page with CDN resource dropdown and purge type selection](/images/docs/cdn/clear-cdn-resource-cache-by-url-pattern-or-all/purge-section-overview.png)
</Frame>

<Tabs>
  <Tab title="Purge by URL">
    <Warning>
      Two purge requests per resource per minute are allowed. One purge request is limited to 100 URLs, so up to 200 files can be removed from the cache per minute.
    </Warning>
    <p>In the text area, specify one or more content URLs to purge, entering one URL per line. Links must:</p>

    - Start with a slash (/).
    - Not include a protocol, domain name, or wildcard (\*).
    - Include query strings if the CDN resource cache is configured to consider the query string.

    <p>To purge `https://www.example.com/pictures/icon.jpg?size=small`, enter `/pictures/icon.jpg?size=small`.</p>

    <Frame>
      ![Purge by URL section with text area for entering URLs](/images/docs/cdn/clear-cdn-resource-cache-by-url-pattern-or-all/purge-by-url.png)
    </Frame>
    <p>Click **Show more** under the text area to see additional recommendations.</p>

    <p>Avoid this method in the cases below:</p>

    - **A Vary HTTP response header is present on the origin**. Purge by URL deletes only one version of the file.
    - When Large files delivery optimization is enabled, Purge by URL removes only the first cached byte-range slice, which starts at byte 0.

    <p>The behavior of Purge by URL also depends on the **Ignore Query string** option:</p>

    - If the value is **Ignore All**, do not include query parameters in the purge request.
    - If the value is **Ignore All Except**, only files with the parameters listed in the option are cached as different objects. Files with other parameters are cached as one object. In this case, include the listed parameters in any order. Do not include other parameters.
    - If the value is **Ignore Only**, files with the parameters listed in the option are cached as one object. Files with other parameters are cached as different objects. In this case, include other parameters (if any) besides the listed ones in any order.

    <p>Click **Purge** to apply.</p>
  </Tab>
  <Tab title="Purge all">
    <Warning>
      One purge request per resource per minute is allowed. After a full purge, subsequent cache misses cause CDN servers to fetch content from the origin, which can sharply increase origin load. For large amounts of content, use Purge by URL or pattern instead.
    </Warning>
    <p>Select **Purge all** and click **Purge**.</p>
  </Tab>
  <Tab title="Purge by pattern">
    <Warning>
      One purge request per resource per minute is allowed. One purge request is limited to 10 patterns.
    </Warning>
    <p>In the input field, enter path patterns without a domain name. Use the `*` operator to match any number of characters. Each path must start with `/` and be on a separate line. If a query string is not included in a pattern, the purge covers all query string variants of matching files.</p>

    <Frame>
      ![Purge by pattern radio button selected with pattern text area](/images/docs/cdn/clear-cdn-resource-cache-by-url-pattern-or-all/purge-by-pattern.png)
    </Frame>

    <p>For example:</p>

    | Target | Pattern |
    | ------ | ------- |
    | One file (all query string variants) | `/static/image.jpg` |
    | All files in a folder | `/static/*` |
    | Files by extension | `/static/*.jpg` |
    | Files under a matching path segment | `/img/*/files` |
    | Files by extension under a path | `/img/static/*.jpg` |

    <p>To target a file with a specific query string, include it in the path: `/static/image.jpg?VERSION`.</p>

    <p>Click **Purge** to apply.</p>
  </Tab>
</Tabs>

## Purge history

<Note>
  Purge history stores requests for the past month only.
</Note>

<p>Navigate to the [Purge&nbsp;history](https://portal.gcore.com/cdn/purge/purge-history) page. Filter requests by:</p>

- **Search by CNAME.** CNAME of the CDN resource.
- **Type.** Purge type: Purge by URL, Purge all, or Purge by pattern.
- **Status.** Request status: In progress, Successful, Failed, or Status report disabled.
- **Date.** Time period up to one month.

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Purge the CDN cache by URL, pattern, or all, and retrieve purge history via the REST API.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Set the required environment variables. The CDN resource ID is available in the [Customer Portal](https://portal.gcore.com/cdn/resources) under **CDN** → **CDN Resources**, or via the [List CDN resources](/api-reference/cdn/cdn-resources/list-cdn-resources) API call.</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_RESOURCE_ID}"
```

## Purge by URL

<p>Remove specific files from the CDN cache. Two purge requests per resource per minute are allowed; one request is limited to 100 URLs. URLs must start with `/` and must not include the protocol or domain name. Include query strings if the CDN resource caches content per query string.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()  # Reads GCORE_API_KEY from env

    client.cdn.cdn_resources.purge(
        12345,  # CDN resource ID
        urls=["/images/logo.png", "/css/style.css?ver=2.0"],
    )
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()  // Reads GCORE_API_KEY from env
        ctx := context.Background()

        err := client.CDN.CDNResources.Purge(ctx, 12345, cdn.CDNResourcePurgeParams{
            OfPurgeByURL: &cdn.CDNResourcePurgeParamsBodyPurgeByURL{
                URLs: []string{"/images/logo.png", "/css/style.css?ver=2.0"},
            },
        })
        if err != nil {
            fmt.Printf("error: %v\n", err)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/purge" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "urls": [
          "/images/logo.png",
          "/css/style.css?ver=2.0"
        ]
      }'
    ```

    <p>A successful request returns HTTP 201 with the list of purged URLs:</p>

    ```json
    {
      "urls": ["/css/style.css?ver=2.0", "/images/logo.png"]
    }
    ```
  </Tab>
</Tabs>

## Purge by pattern

<p>Remove files matching a path pattern. Use the `*` operator to match any number of characters. Patterns must start with `/`. One request is limited to 10 patterns; one purge request per resource per minute is allowed.</p>

## Purge all

<p>Remove all cached content for a CDN resource. One purge request per resource per minute is allowed. After a full purge, CDN servers must re-fetch all content from the origin, which can sharply increase origin load — use purge by URL or pattern for large content sets.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    client.cdn.cdn_resources.purge(
        12345,
        paths=[],
    )
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        err := client.CDN.CDNResources.Purge(ctx, 12345, cdn.CDNResourcePurgeParams{
            OfPurgeAllCache: &cdn.CDNResourcePurgeParamsBodyPurgeAllCache{
                Paths: []string{},
            },
        })
        if err != nil {
            fmt.Printf("error: %v\n", err)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/purge" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"paths": []}'
    ```

    <p>A successful request returns HTTP 201 with an empty paths array:</p>

    ```json
    {
      "paths": []
    }
    ```
  </Tab>
</Tabs>

## Purge history

<p>Retrieve the history of purge requests for the past month. Filter by CNAME, purge type, status, or date range.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    history = client.cdn.list_purge_statuses(
        cname="cdn.example.com",
        purge_type="purge_by_url",
        limit=50,
    )
    for entry in history:
        print(entry.purge_id, entry.purge_type, entry.status, entry.created)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        page, err := client.CDN.ListPurgeStatuses(ctx, cdn.CDNListPurgeStatusesParams{
            Cname: gcore.String("cdn.example.com"),
        })
        if err != nil {
            fmt.Printf("error: %v\n", err)
            return
        }
        for _, entry := range page.Results {
            fmt.Printf("%v  %v  %v  %v\n",
                entry.PurgeID, entry.PurgeType, entry.Status, entry.Created)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X GET "https://api.gcore.com/cdn/purge_statuses?cname=cdn.example.com&purge_type=purge_by_url" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns an array of purge status objects:</p>

    ```json
    [
      {
        "purge_id": 10001,
        "status": "Successful",
        "purge_type": "purge_by_url",
        "created": "2024-06-10T10:15:00Z",
        "resource": {
          "id": 12345,
          "cname": "cdn.example.com"
        },
        "payload": {
          "urls": ["/images/logo.png"]
        }
      }
    ]
    ```
  </Tab>
</Tabs>
