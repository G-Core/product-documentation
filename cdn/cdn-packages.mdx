CDN plans are PAYG and Enterprise. PAYG sets monthly limits for traffic, requests, and image optimization, and it includes basic Origin Shielding, while Enterprise replaces those limits with custom ones. Prices and overage rates are on the [pricing&nbsp;page](https://gcore.com/pricing/edge-network), and charges past those amounts follow [CDN&nbsp;billing](/cdn/how-the-cdn-service-and-its-additional-options-are-billed).

## Package comparison

PAYG and Enterprise differ in those limits and in which delivery and security options belong to the plan.

| Package | PAYG | Enterprise |
| --- | --- | --- |
| Plan fee | €0 per month | Custom |
| Network | 210+ PoPs | 210+ PoPs |
| On-demand PoPs | Not included | Included |
| Included traffic | 1 TB per month | Custom |
| Included requests | 1 billion per month | Custom |
| Traffic overage | €0.01 per GB | Custom |
| Request overage | €0.75 per 1,000,000 | Custom |
| Origin Shielding | Basic | Custom |
| Image optimization | 10,000 per month | Custom |
| Optimization overage | €1 per 10,000 | Custom |
| DDoS protection | Basic L3/L4 DDoS | Custom L3/L4 DDoS |
| WAAP | On-demand | Included |
| Live streaming | On-demand | Included |
| Log viewer | Included | Included |
| Free SSL certificate | Included | Included |
| Custom SSL certificate | Included | Included |
| Technical support | 24/7 email and chat | 24/7 email, chat, and phone |
| Direct origin connection (PNI) | Not included | On-demand |
| BYOIP or dedicated IP | Not included | On-demand |

Included comes with the PAYG or Enterprise plan, while On-demand and Custom are arranged with [Gcore&nbsp;Sales](https://gcore.com/contact-sales).
