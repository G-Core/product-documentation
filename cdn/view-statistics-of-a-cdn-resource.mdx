CDN reporting combines an account-level health overview with detailed resource statistics and optional analytics reports.

## CDN Overview

The **Overview** page is the default CDN landing page in the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com). It summarizes CDN health and traffic across all resources or a selected resource for a specified period.

<Steps>
  <Step title="Open CDN Overview">
    In the Customer Portal, navigate to **CDN** > **Overview**.
  </Step>
  <Step title="Filter dashboard data">
    Select all resources or a specific CDN resource, then select a predefined or custom period.

    <Frame><img src="/images/docs/cdn/view-statistics-of-a-cdn-resource/view-statistics-of-a-cdn-resource-image1.png" alt="CDN Overview with resource and period filters and traffic by geography" width="70%" /></Frame>
  </Step>
</Steps>

The dashboard groups the metrics into cards that support a quick account-level assessment:

| Card | Information |
|---|---|
| Health status and traffic summary | Overall health, requests, data transfer in bytes, response time, and trends compared with the previous period |
| Traffic by geography | Request distribution by country |
| Cache performance | Cache hit and miss rates |
| Errors | Client-side 4xx and server-side 5xx response rates |
| Security | Encrypted and unencrypted request rates |
| Network protocols | HTTP versions and content types |

<Frame><img src="/images/docs/cdn/view-statistics-of-a-cdn-resource/view-statistics-of-a-cdn-resource-image2.png" alt="CDN Overview cards for cache performance, errors, security, and network protocols" width="70%" /></Frame>

### Metric status rules

Health status combines the 5xx response rate with the response-time baseline:

- Healthy — the 5xx rate is below two percent and latency is below 1.25 times the baseline
- Degraded — the 5xx rate is between two and five percent, or latency is between 1.25 and two times the baseline
- Unhealthy — the 5xx rate is at least five percent, or latency is at least two times the baseline

The status appears only when the selected period contains more than one thousand requests and the latest 15-minute window contains more than 20 requests. Otherwise, the dashboard displays **Insufficient data**.

Cache hit rates above 90 percent appear in green, rates from 70 through 90 percent appear as degraded, and rates below 60 percent appear in red. Encryption rates above 90 percent appear in green, while other encryption rates use a neutral state. The 4xx rate is neutral, while the 5xx rate appears in red.

## Statistics

The **Statistics** report provides traffic, bandwidth, response, cache, request, and timing metrics for selected CDN resources. Basic reports are available on all plans.

<Note>
For complete data, request statistics at least two days after the required period ends. Recently completed periods may contain incomplete data.
</Note>

<Steps>
  <Step title="Open Statistics">
    Navigate to the [Statistics](https://portal.gcore.com/cdn/reports/statistics) page.

    <Frame><img src="/images/docs/cdn/view-statistics-of-a-cdn-resource/reports-10.png" alt="Statistics report with resource, report type, and period controls" width="70%" /></Frame>
  </Step>
  <Step title="Select resources and report">
    In the **CDN resource** field, select one or more resources, then select a report:

    - **Aggregated data** — traffic volume and bandwidth for the previous three months
    - **Traffic**
    - **Bandwidth**
    - **Response codes**
    - **Cache hit ratio**
    - **Requests**
    - **Traffic by region** — traffic from servers in each region
    - **Traffic by country** — traffic from the five countries with the highest traffic
    - **Image optimization** — hourly WebP conversion count
    - **Request time** — time from processing the first request bytes until logging after the last response bytes are sent
    - **Upstream response times** — time to receive an origin response
  </Step>
  <Step title="Set the reporting period">
    Select a time interval and an auto-refresh period.
  </Step>
  <Step title="Review the report">
    The chart and summary metrics adapt to the selected report. An **Image optimization** report displays WebP conversions over time:

    <Frame><img src="/images/docs/cdn/view-statistics-of-a-cdn-resource/reports-20.png" alt="Image optimization report with WebP conversions over time" width="70%" /></Frame>

    A **Response codes** report separates the returned HTTP status codes:

    <Frame><img src="/images/docs/cdn/view-statistics-of-a-cdn-resource/reports-30.png" alt="Response codes report with status code trends" width="70%" /></Frame>
  </Step>
</Steps>

## Advanced Analytics

Advanced Analytics adds reports for requests, traffic, and unique visitors, with filters for geography, directories, browsers, devices, and operating systems. This paid option requires activation through [Gcore&nbsp;Support](mailto:support@gcore.com) or an account manager.

After activation, allow approximately 24 hours for data collection. Until data is available, the page displays an example report with random data.

<Steps>
  <Step title="Open Advanced Analytics">
    Navigate to the [Advanced&nbsp;Analytics](https://portal.gcore.com/cdn/reports/advanced) page.

    <Frame><img src="/images/docs/cdn/view-statistics-of-a-cdn-resource/reports-40.png" alt="Advanced Analytics controls and report filters" width="70%" /></Frame>
  </Step>
  <Step title="Select report criteria">
    Select a CDN resource, a metric type, a reporting period, and UTC or local time.

    <Note>
    Unique visitors are identified by the combination of IP address and user agent.
    </Note>
  </Step>
  <Step title="Filter the report">
    Select **Geography**, **Directories**, **Browsers**, **Devices**, or **OS**, then select the values to include in the chart.
  </Step>
</Steps>

### Report calculation

Gcore calculates billing and portal reports from different data sources:

- Billing statistics use NGINX access logs because invoice calculation prioritizes accuracy over processing speed
- Customer Portal reports use the NGINX virtual host traffic status module to provide current resource statistics

<Note>
All statistics use the UTC time zone.
</Note>
