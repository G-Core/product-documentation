CDN reporting combines an account-level performance overview with detailed resource statistics and optional analytics reports.

## CDN Overview in the portal

The **Overview** page is the default CDN landing page in the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com). It summarizes CDN performance and traffic across all resources or a selected resource for a specified period.

<Steps>
  <Step title="Open CDN Overview">
    In the Customer Portal, navigate to **CDN** > **Overview**.
  </Step>
  <Step title="Filter dashboard data">
    Select all resources or a specific CDN resource, then select a predefined or custom period.

    <Frame>![CDN Overview with resource and period filters and traffic by geography](/images/docs/cdn/view-statistics-of-a-cdn-resource/view-statistics-of-a-cdn-resource-image1.png)</Frame>
  </Step>
</Steps>

When the selected period does not contain enough traffic, the dashboard shows Insufficient data. With enough traffic, a health status appears above the summary metrics: Total Requests, Data Transfer, Visits, and Page Views, with Cache Hit, Encryption, Error Rate, and Countries underneath.

The remaining cards are:

| Card | Information |
|---|---|
| Traffic by geography | Request distribution by country |
| Cache performance | Cached requests, cache hit rate, cached data transfer, and data transfer hit rate |
| Errors | 4xx and 5xx counts and rates |
| Security | Encrypted requests and encrypted data transfer |
| Network protocols | HTTP version and content type |

<Frame>![CDN Overview cards for cache performance, errors, security, and network protocols](/images/docs/cdn/view-statistics-of-a-cdn-resource/view-statistics-of-a-cdn-resource-image2.png)</Frame>

Cache hit rates below 60% appear in red as a visual highlight on Overview. That color marks the metric on the dashboard. It is not the troubleshooting threshold used in [low cache hit ratio](/cdn/troubleshooting/cache-percentage-is-low-how-to-solve-the-issue). Encryption rates above 90% appear in green.

## Statistics reports for CDN resources

The **Statistics** report provides traffic, bandwidth, response, cache, request, and timing metrics for selected CDN resources. Basic reports are available on all plans.

<Note>
For complete data, request statistics at least two days after the required period ends. Recently completed periods may contain incomplete data.
</Note>

<Steps>
  <Step title="Open Statistics">
    Navigate to **CDN** > **Reports** > **Statistics**.

    <Frame>![Statistics report with resource and Aggregated data selected](/images/docs/cdn/view-statistics-of-a-cdn-resource/view-statistics-of-a-cdn-resource-image3.png)</Frame>
  </Step>
  <Step title="Select resources and the report">
    In **CDN resource**, select one or more resources, then select a report.

    **Aggregated data** shows traffic and bandwidth for the previous three months, with **MAX**, **MIN**, and 95th-percentile bandwidth. Other reports include a time interval and an auto-refresh period. Auto-refresh reloads the selected chart on a timer while the page stays open.

    The report menu includes:

    * Aggregated data
    * Traffic
    * Bandwidth
    * Response classes
    * Response codes
    * Cache hit ratio
    * Requests
    * Traffic by region
    * Traffic by country
    * Image optimization
    * Request time
    * Upstream response time

    Traffic by region is traffic from servers in each region. Traffic by country is traffic from the five countries with the highest traffic. Image optimization is the hourly WebP conversion count. Request time is the time from processing the first request bytes until logging after the last response bytes are sent. Upstream response time is the time to receive an origin response.
  </Step>
  <Step title="Review the report">
    The chart and summary metrics adapt to the selected report.

    Charts on this page update while the selected period is still in progress, so they are useful for live monitoring. Complete data for a finished period is available at least two days later, and live charts can still differ from invoice totals because the two sources use different granularity periods.
  </Step>
</Steps>

## Advanced Analytics for CDN resources

Advanced Analytics adds reports for requests, traffic, and unique visitors, with filters for geography, directories, browsers, devices, and operating systems. This paid option requires activation through [Support](mailto:support@gcore.com) or an account manager.

Until the option is activated, the page shows that Advanced Analytics is not available and an example report with random data. After activation, allow 24 hours for data collection.

<Steps>
  <Step title="Open Advanced Analytics">
    Navigate to **CDN** > **Reports** > **Advanced Analytics**.

    <Frame>![Advanced Analytics example report with unavailable banner](/images/docs/cdn/view-statistics-of-a-cdn-resource/view-statistics-of-a-cdn-resource-image4.png)</Frame>
  </Step>
  <Step title="Select report criteria">
    Select a CDN resource, a metric type (**Requests**, **Traffic**, or **Unique visitors**), a reporting period, and **UTC** or local time. Local time only changes how the chart labels timestamps. The stored values remain UTC, which is also the time zone for Overview and Statistics.
  </Step>
  <Step title="Filter the report">
    Select **Geography**, **Directories**, **Browsers**, **Devices**, or **OS**, then select the values to include in the chart.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="Geography">
    The **Geography** filter maps traffic by country and compares selected countries in a chart. Search for a country to locate it in the list.
  </Accordion>
  <Accordion title="Directories">
    The **Directories** filter compares requested paths. Search for a path to locate it in the list.
  </Accordion>
  <Accordion title="Browsers">
    The **Browsers** filter compares requests or unique visitors by browser. Search for a browser to locate it in the list.
  </Accordion>
  <Accordion title="Devices">
    The **Devices** filter compares requests or unique visitors by device class. Search for a device to locate it in the list.
  </Accordion>
  <Accordion title="OS">
    The **OS** filter compares requests or unique visitors by operating system. Search for an operating system to locate it in the list.
  </Accordion>
</AccordionGroup>

### Billing and portal report sources

Invoice totals can differ from the charts above because billing and the Customer Portal read different NGINX sources.

Gcore calculates billing and portal reports from different data sources:

* Billing statistics use NGINX access logs because invoice calculation prioritizes accuracy over processing speed.
* Customer Portal reports use the NGINX virtual host traffic status module to provide current resource statistics.
