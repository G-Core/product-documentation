Provider v2 manages Gcore CDN as separate Terraform resources. An origin group holds the source hostnames, and the CDN resource, certificates, rules, and rule templates sit beside it, with delivery behavior in an `options` map.

An [API&nbsp;token](/account-settings/api-tokens) and provider installation are in the [Terraform&nbsp;overview](/developer-tools/terraform/overview). A v0 configuration moves through the [migration&nbsp;guide](/developer-tools/terraform/migrate-v0-to-v2).

## Provider v0 and v2

Provider v2 keeps the same CDN objects and changes how Terraform names them and stores their settings.

| Area | Provider v0 | Provider v2 |
|---|---|---|
| Authentication | `permanent_api_token` | `api_key` |
| SSL certificate | `gcore_cdn_sslcert` | `gcore_cdn_certificate` |
| CA certificate | `gcore_cdn_cacert` | `gcore_cdn_trusted_ca_certificate` |
| Rule | `gcore_cdn_rule` | `gcore_cdn_resource_rule` |
| Origin group sources | Nested `origin` blocks | `sources` list |
| Delivery options | Nested `options` blocks | `options` map |
| S3 credentials | Stored in state | Write-only |
| SSL certificate body | `cert`, `private_key` | `ssl_certificate_wo`, `ssl_private_key_wo` |
| Origin shielding | `gcore_cdn_originshielding` | `gcore_cdn_origin_shielding` |
| Account CDN settings | `gcore_cdn_client_config` resource | `gcore_cdn_client_config` data source |

The account data source is read-only, and its `cname` attribute is the account CDN hostname. DNS for one resource uses that resource's id with `.gcdn.co` appended, which [CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) prints after apply.

Provider 2.0.0-rc.2 adds `gcore_cdn_applied_preset` and data source `gcore_cdn_presets`, while provider 2.0.0-rc.1 includes the resources in the table above.

## Delivery options

Many option objects contain `enabled` and `value`. Setting `enabled` to false turns that setting off and leaves `value` in the configuration.

Leaving such a key out of `options` does not change the stored value, and assigning the key `null` does not clear it either. `image_stack` carries quality and format fields, `fastedge` names the apps for each request phase, and other keys add fields beside `enabled`.

`http3_enabled` uses `enabled` and `value`. The provider accepts it only when `ssl_enabled` is true on the same resource, which [HTTPS&nbsp;delivery](/cdn/ssl-certificates/add-an-ssl-certificate-to-deliver-content-over-https) sets.

## Presets

A preset is a read-only bundle of settings for a CDN resource or a rule. Data source `gcore_cdn_presets` returns each preset `id`, `name`, and `object_type`, which is `CDNResource` or `Rule`.

`gcore_cdn_applied_preset` binds `preset_id` to `object_id`. While that binding exists, an apply that changes an option the preset owns returns HTTP 400 and names the preset.

Removing the `gcore_cdn_applied_preset` block removes the binding. The next refresh records `preset_applied` as false and clears the options the preset had written.

LIVE STREAMING is the preset for live video, and it owns `stale`. [Video&nbsp;streaming](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource-for-video-streaming) leaves that option unset while the preset is on.

## Task articles

Presets and options are the shared mechanism. Each task has its own article with portal, API, and Terraform steps.

[Origin&nbsp;group](/cdn/add-an-origin-group) creates the set of source hostnames. A private bucket adds storage credentials on the same resource in [private&nbsp;bucket](/cdn/cdn-resource-options/general/use-a-private-bucket-as-an-origin), [Amazon&nbsp;S3](/cdn/getting-started/integrate-cdn-with-cms/integrate-cdn-resource-with-aws-s3), or [Cloud&nbsp;Storage](/cdn/getting-started/integrate-cdn-with-cms/integrate-cdn-resource-with-google-cloud-storage), and [origin&nbsp;protocol](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) sets the protocol on the pull.

The CDN resource attaches a domain to an origin group. Video streaming adds the live manifest rules, [custom&nbsp;domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) sets `cname` and `secondary_hostnames`, and [suspend&nbsp;resource](/cdn/cdn-resource-options/general/suspend-a-cdn-resource-automatically-or-manually) sets `active`.

Certificates are separate resources, then attached to the CDN resource. [Let's&nbsp;Encrypt](/cdn/ssl-certificates/configure-lets-encrypt-certificate) issues an automated certificate, [own&nbsp;certificate](/cdn/ssl-certificates/configure-your-own-ssl-certificate) uploads a certificate and private key, HTTPS delivery sets `ssl_enabled` and `ssl_data`, and [origin&nbsp;validation](/cdn/cdn-resource-options/general/enable-origin-ssl-validation) checks the origin certificate with a trusted CA.

[Origin&nbsp;Shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding) sends cache misses through one shield location. [Video&nbsp;shielding](/cdn/video-cdn/origin-shielding-for-video) uses the same resource and reads whether the shield is active.

A rule overrides `options` for one path. [Resource&nbsp;rule](/cdn/cdn-resource-options/rules-for-particular-files/create-a-rule-manually-or-from-a-template-to-configure-settings-for-particular-files) creates it on one CDN resource, [rule&nbsp;template](/cdn/cdn-resource-options/rules-for-particular-files/create-a-cdn-resource-rule-template-manually-or-use-a-system-one) stores a reusable rule, and [robots.txt](/cdn/cdn-resource-options/rules-for-particular-files/set-robots-txt-to-avoid-adding-to-index-by-web-crawlers) is one such rule.

[Logs&nbsp;uploader](/cdn/logs/logs-uploader) ships access logs to external storage. It uses a policy, a target, and a config.

Cache lifetime is [CDN&nbsp;cache](/cdn/cdn-resource-options/cache/specify-cache-lifetime-on-a-cdn-resource-or-origin) and [browser&nbsp;cache](/cdn/cdn-resource-options/cache/specify-cache-lifetime-for-user-browsers). Cookie and query handling is [cookie&nbsp;and&nbsp;query](/cdn/cdn-resource-options/cache/ignore-the-set-cookie-or-query-string-parameters-when-caching-content-on-cdn-servers), [cache&nbsp;key](/cdn/cdn-resource-options/cache/modify-cache-key), and [query&nbsp;forwarding](/cdn/cdn-resource-options/query-string-forwarding).

[Origin&nbsp;redirects](/cdn/cdn-resource-options/cache/set-up-a-cdn-resource-to-follow-origin-redirects) and [always&nbsp;online](/cdn/cdn-resource-options/cache/always-online-provide-the-stale-cache-if-the-origin-is-unavailable) decide what the CDN serves when the origin redirects or fails. Compression is [Gzip&nbsp;and&nbsp;Brotli](/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression) on the response and [fetch&nbsp;compression](/cdn/cdn-resource-options/compression/configure-fetch-compression) on the pull from the origin.

Access control is [HTTPS&nbsp;redirect](/cdn/cdn-resource-options/security/set-up-a-redirect-from-http-to-https), [TLS&nbsp;versions](/cdn/cdn-resource-options/security/choose-tls-versions), [HTTP&nbsp;methods](/cdn/cdn-resource-options/security/specify-http-methods-allowed-for-content-requests-from-the-cdn), [access&nbsp;policy](/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies), [secure&nbsp;token](/cdn/cdn-resource-options/security/use-a-secure-token/configure-and-use-secure-token), and [SNI&nbsp;hostname](/cdn/cdn-resource-options/security/set-the-hostname-passed-in-sni-requests-to-the-origin-server).

Header changes are [response&nbsp;headers](/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers), [request&nbsp;headers](/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin), [CORS&nbsp;header](/cdn/cdn-resource-options/http-headers/add-the-access-control-allow-origin-header-to-the-browser-response), and [host&nbsp;header](/cdn/cdn-resource-options/http-headers/configure-and-check-the-host-header). Connection and body behavior is [origin&nbsp;timeouts](/cdn/cdn-resource-options/general/customize-connection-and-read-timeouts), [WebSockets](/cdn/cdn-resource-options/websockets-allow-permanent-connections-with-the-origin), [path&nbsp;rewrite](/cdn/cdn-resource-options/rewrite-redirect-requests-from-the-cdn-to-the-origin), [status&nbsp;code](/cdn/cdn-resource-options/specify-custom-http-status-code-for-the-content-delivered-by-the-cdn), [bandwidth&nbsp;limit](/cdn/cdn-resource-options/network-limits-set-the-content-delivery-speed-to-end-users), and [large&nbsp;files](/cdn/cdn-resource-options/optimize-large-file-delivery).

Image processing uses the `image_stack` fields. [Image&nbsp;stack](/cdn/cdn-resource-options/image-optimization-paid/enable-image-stack) turns it on, and [crop&nbsp;images](/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images), [image&nbsp;quality](/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/change-image-quality), [image&nbsp;size](/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/reduce-image-size), and [WebP&nbsp;and&nbsp;AVIF](/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/configure-image-compression-to-webp-and-avif) set those fields.

[FastEdge&nbsp;app](/cdn/getting-started/integrate-cdn-with-fastedge) and [WAAP&nbsp;policy](/cdn/cdn-resource-options/cdn-security/protect-cdn-resources-with-waap) attach another Gcore product to the CDN resource. The [CDN&nbsp;resource&nbsp;schema](https://github.com/G-Core/terraform-provider-gcore/blob/v2/docs/resources/cdn_resource.md) also lists `grpc_passthrough`, `network_error_logging`, `tls_ciphers`, `disable_proxy_force_ranges`, `proxy_cache_methods_set`, and `redirect_https_to_http`.
