title: "3xx error: how to solve CDN issues with redirect"
sidebarTitle: 3xx error
ai-navigation: Resolve CDN 3xx redirects by matching Origin pull protocol, setting Change Host header, and pointing the origin at the redirect target.
---

If a request to CDN returns a redirect (HTTP 301 or 302) toward the origin, check the CDN resource settings below.

## Origin pull protocol

In the CDN resource settings, select an **Origin pull protocol** that matches redirect settings on the origin. The [Origin&nbsp;pull](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) option controls which scheme CDN uses when requesting content from the origin.

  * Select **HTTPS** if the origin redirects HTTP requests to HTTPS.
  * Select **HTTP** if the origin redirects HTTPS requests to HTTP.

## Host header

Usually, the Host header matches the origin domain. Enable **Change Host header** and set the correct value, or configure the origin to accept the Host header that CDN sends. The [Host&nbsp;header](/cdn/cdn-resource-options/http-headers/configure-and-check-the-host-header) option controls which virtual host the origin uses.

If the origin redirects requests to another domain, set that final domain as the origin in the **Origin group**.

If requests to *domain.com* are redirected to *www.domain.com*, use *www.domain.com* as the origin.

## Track 3xx responses and inspect logs

Open [Reports](/cdn/view-statistics-of-a-cdn-resource) → **Statistics** and select the **Response codes** report to track 3xx responses.

The [Log&nbsp;viewer](/cdn/logs/log-viewer-view-and-download-cdn-resource-logs) in the [Gcore Customer Portal](https://portal.gcore.com) shows recent request details. For long-term log export, [Logs&nbsp;uploader](/cdn/logs/logs-uploader) is a paid option that must be enabled by support. To activate it, contact the account manager or [Gcore&nbsp;Support](mailto:support@gcore.com).
