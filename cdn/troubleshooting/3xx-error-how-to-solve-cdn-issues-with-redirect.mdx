If a CDN request returns an unexpected `301` or `302` redirect to the origin domain, check the following settings.

## Origin pull protocol

In the CDN resource settings, select an **Origin pull protocol** that matches redirect settings on the origin. The [Origin&nbsp;pull](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) option controls which scheme the CDN uses when requesting content from the origin.

  * Select **HTTPS** if the origin redirects HTTP requests to HTTPS.
  * Select **HTTP** if the origin redirects HTTPS requests to HTTP.

## Host header

Usually, the Host header matches the origin domain. Enable **Change Host header** and set the correct value, or configure the origin to accept the Host header that the CDN sends. The [Host&nbsp;header](/cdn/cdn-resource-options/http-headers/configure-and-check-the-host-header) option controls which virtual host the origin uses.

If the origin redirects requests to another domain, set that final domain as the origin in the **Origin group**.

If requests to `domain.com` are redirected to `www.domain.com`, use `www.domain.com` as the origin.

After changing **Origin pull protocol**, **Change Host header**, or **Origin group**, click **Save changes**. [Purge](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) any cached redirect response, then retest the URL.

## 3xx response tracking and logs

The **Response codes** report tracks 3xx responses for CDN resources.

<Steps>
  <Step title="Open CDN">
    In the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com), select **CDN**.
  </Step>
  <Step title="Open CDN statistics">
    Navigate to **Reports** → **Statistics**.
  </Step>
  <Step title="View response codes">
    Select **Response codes**.
  </Step>
</Steps>

The [Log&nbsp;viewer](/cdn/logs/log-viewer-view-and-download-cdn-resource-logs) shows recent request details. For long-term log export, [Logs&nbsp;uploader](/cdn/logs/logs-uploader) is a paid option that must be enabled by support. To activate it, contact the account manager or [Gcore&nbsp;Support](mailto:support@gcore.com).
