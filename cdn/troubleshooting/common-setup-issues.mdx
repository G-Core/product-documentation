Common CDN setup problems and how to resolve them.

## 503 service unavailable

A 503 response means the CDN cannot reach the origin server.

Possible causes:

- The origin server is not accessible.
- The origin blocks CDN IP ranges.
- The origin port is incorrect.
- The resource has not fully propagated yet.

Solution:

- Verify that the origin server is reachable directly — with a browser or curl.
- [Allowlist&nbsp;CDN&nbsp;servers](/cdn/getting-started/configure-an-origin/add-cdn-servers-to-the-origin-acl-whitelist) in the origin firewall or ACL.
- Confirm that the origin port is correct (80 or 443).
- During initial setup, CDN resource propagation can take up to about 20 minutes. Wait for propagation to finish, then retry the request.

Related guide: [5xx&nbsp;server&nbsp;issues](/cdn/troubleshooting/5xx-error-how-to-solve-server-issues).

## ERR_TOO_MANY_REDIRECTS

This error occurs when both the CDN and the origin enforce redirects and create a loop.

Possible cause:

- Both the CDN and the origin redirect HTTP to HTTPS.

Solution:

- Disable the redirect on either the CDN or the origin. On the CDN side, open the resource settings, navigate to **Access**, and turn off **Enable redirect HTTP to HTTPS**.
- [HTTP&nbsp;to&nbsp;HTTPS](/cdn/cdn-resource-options/security/set-up-a-redirect-from-http-to-https)

## Website downloads as a file

This behavior usually means the origin returns incorrect response headers.

Possible cause:

- The origin returns an incorrect `Content-Type` header.

Solution:

- Check and correct the MIME type configuration on the origin server.

## SSL certificate errors (Let's Encrypt)

SSL issues with Let's Encrypt are often related to DNS configuration and domain validation.

Possible causes:

- The custom domain CNAME does not point to the `*.gcdn.co` value shown in the resource setup guide.
- A CDN rule overlaps the `/.well-known/acme-challenge/` path used for certificate issuance.
- DNS changes have not fully propagated.

Solution:

- Confirm the CNAME for the custom domain matches the value in the resource setup guide.
- Disable any rule that matches `/.well-known/acme-challenge/`, issue the certificate, then re-enable the rule if needed.
- After DNS changes, wait for propagation to finish, then retry certificate issuance.

Related guide: [SSL&nbsp;certificate&nbsp;issues](/cdn/troubleshooting/an-ssl-certificate-isn-t-working-how-to-solve-to-issue).
