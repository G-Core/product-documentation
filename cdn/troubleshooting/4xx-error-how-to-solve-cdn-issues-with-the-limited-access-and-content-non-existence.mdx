4xx errors can come from a malfunction on the origin or from incorrect CDN resource settings.

## Check content availability on the origin

Request the content from the origin and confirm an HTTP 200 response.

If the origin uses an IP allowlist or a DDoS Protection service, allowlist CDN edge IPs. Retrieve the current public IP list:

```sh
curl -i -X GET https://api.gcore.com/cdn/public-ip-list
```

The public IP list changes over time, so keep the allowlist updated with a recurring script. The [Origin&nbsp;ACL](/cdn/getting-started/configure-an-origin/add-cdn-servers-to-the-origin-acl-whitelist) guide covers allowlisting CDN edges. Authentication on the origin can also use [Request&nbsp;headers](/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin) that CDN adds when pulling content.

## Check CDN resource settings

  * Confirm that the CDN resource is active. After creating a new resource, wait until the configuration is applied on CDN edges — usually about 15 minutes.
  * Select an **Origin pull protocol** so the origin can respond to requests from CDN edges. The [Origin&nbsp;pull](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) option controls which scheme CDN uses when requesting content from the origin.
  * Enable **Change Host header** and set a value that matches the origin or the host configured on the origin. The [Host&nbsp;header](/cdn/cdn-resource-options/http-headers/configure-and-check-the-host-header) option controls which virtual host the origin uses.

Open [Reports](/cdn/view-statistics-of-a-cdn-resource) → **Statistics** and select the **Response codes** report to track 4xx responses.

The [Log&nbsp;viewer](/cdn/logs/log-viewer-view-and-download-cdn-resource-logs) in the [Gcore Customer Portal](https://portal.gcore.com) shows recent request details. For long-term log export, [Logs&nbsp;uploader](/cdn/logs/logs-uploader) is a paid option that must be enabled by support. To activate it, contact the account manager or [Gcore&nbsp;Support](mailto:support@gcore.com).
