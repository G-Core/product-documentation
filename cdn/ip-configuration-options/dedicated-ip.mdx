A dedicated IP assigns exclusive Gcore CDN addresses (a single IP or a subnet) to a CDN resource instead of shared CDN anycast addresses. CDN traffic will then be delivered through those dedicated addresses, reducing reputation risks caused by other customers' traffic on shared IPs.

Dedicated IP is a paid add-on for the Enterprise plan and is not available on PAYG. There is no setup fee.

## Request a dedicated IP

The Gcore team configures a dedicated IP manually. Contact [Gcore&nbsp;Support](mailto:support@gcore.com) or the chat in the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com) to request a dedicated IP or subnet for CDN. Provide:

- Whether the request is for one IP address or a subnet
- The CDN resource IDs or domains that should use the dedicated addresses

Dedicated IP uses Gcore-owned addresses reserved for one account. [BYOIP](/cdn/ip-configuration-options/byoip) announces customer-owned prefixes.
