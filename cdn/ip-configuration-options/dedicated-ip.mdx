A dedicated IP assigns exclusive Gcore CDN addresses (a single IP or a subnet) to a CDN resource instead of shared CDN anycast addresses. CDN traffic will then be delivered through those dedicated addresses, reducing reputation risks caused by other customers' traffic on shared IPs.

Dedicated IP differs from [BYOIP](/cdn/ip-configuration-options/byoip): Dedicated IP uses Gcore-owned addresses reserved for one account, while BYOIP announces customer-owned prefixes.

Dedicated IP is a paid CDN add-on configured manually by the Gcore team.

## Dedicated IP request

Contact [Gcore&nbsp;Support](mailto:support@gcore.com) or use the chat in the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com) to request a dedicated IP or subnet for CDN. Provide:

- Whether the request is for one IP address or a subnet
- The CDN resource IDs or domains that should use the dedicated addresses
