A dedicated IP assigns exclusive Gcore CDN addresses (a single IP or a subnet) to a CDN deployment instead of shared CDN anycast addresses. Delivery stays on that dedicated space, which reduces reputation risk from other customers' traffic on shared IPs.

Dedicated IP differs from [BYOIP](/cdn/ip-configuration-options/byoip): Dedicated IP uses Gcore-owned addresses reserved for one account, while BYOIP announces customer-owned prefixes.

Dedicated IP is not configured in the [Gcore Customer Portal](https://portal.gcore.com).

## Request a dedicated IP

Contact [Gcore&nbsp;Support](mailto:support@gcore.com) or use the chat in the Customer Portal to request a dedicated IP or subnet for CDN.
