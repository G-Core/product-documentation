BYOIP lets a CDN deployment use customer-owned public IP prefixes instead of shared Gcore CDN addresses. Content stays associated with that IP space for reputation, allowlists, and network identity.

## Announcement options

IP prefixes can be announced in either of these modes:

- **BYOIP** — Gcore announces the customer prefix from the Gcore ASN
- **BYOASN** — The prefix is announced from a customer ASN

Neither option is configured in the [Gcore Customer Portal](https://portal.gcore.com).

## Request BYOIP or BYOASN

Contact [Gcore&nbsp;Support](mailto:support@gcore.com) or use the chat in the Customer Portal to request BYOIP or BYOASN for CDN. Provide the prefixes to announce and whether the announcement should use the Gcore ASN or a customer ASN.
