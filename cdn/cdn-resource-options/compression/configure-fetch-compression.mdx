<p>The **Fetch compressed** option tells CDN servers to pull already-compressed content from the origin instead of requesting uncompressed files. The origin must support GZip compression.</p>

## Fetch compressed

<p>Turn the option on for the CDN resource.</p>

<Steps>
  <Step title="Open the CDN resource">
    In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN**. The **CDN resources** page opens.
  </Step>
  <Step title="Open resource settings">
    Click the CNAME of the resource to open its settings.
  </Step>
  <Step title="Open Fetch compressed">
    Open the **OPTIONS** tab and scroll to the **Content** section. Click **Fetch compressed** in the left sidebar.
  </Step>
  <Step title="Enable Fetch compressed">
    Turn on the **Enable fetch compressed** toggle.

    <Frame>![Fetch compressed section in CDN resource settings with the Enable fetch compressed toggle](/images/docs/cdn/cdn-resource-options/compression/configure-fetch-compression/configure-fetch-compression-image1.png)</Frame>
  </Step>
  <Step title="Save the resource">
    Click **Save changes**.
  </Step>
</Steps>

## Behavior when enabled

<p>With Fetch compressed enabled, the CDN stores and serves the encoded response from the origin without decompressing it. Clients receive that compressed response even when the browser does not accept the encoding.</p>

<p>The CDN requests a GZip-encoded response from the origin. An origin that compresses only with Brotli returns uncompressed content, so configure it to return a Brotli file for that GZip request.</p>

<p>Fetch compressed cannot be used together with [GZip&nbsp;compression](/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression#gzip), Brotli compression, or Slice.</p>

## Origin encoding

<p>Leave Fetch compressed disabled when each viewer needs a response that matches the Accept-Encoding header. Set `Vary: Accept-Encoding` on the origin, because without that header the CDN can cache the first version and serve it to a client that needed the other version.</p>

<p>When `fetch_compressed` is on, the CDN requests a GZip-encoded response from the origin and serves it without decompressing it. The origin must support GZip compression.</p>

<p>An origin that compresses only with Brotli returns uncompressed content, so configure it to return a Brotli file when the CDN requests GZip encoding.</p>

<p>Clients receive that compressed response even when the browser does not accept the encoding.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Export these variables. `CDN_RESOURCE_ID` is the `id` from [list&nbsp;CDN&nbsp;resources](/api-reference/cdn/cdn-resources/list-cdn-resources).</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_RESOURCE_ID}"
```

## Fetch compressed

<p>Enable Fetch compressed by setting both `enabled` and `value` to true.</p>

<p>The call returns HTTP 400 when `gzipOn`, `brotli_compression`, or `slice` is already enabled. Clear that option, then send `fetch_compressed`.</p>

<p>Leave `fetch_compressed` off when each viewer needs a response that matches Accept-Encoding. Set `Vary: Accept-Encoding` on the origin, because without that header the CDN can cache the first version and serve it to a client that needed the other version.</p>

<p>Send `fetch_compressed` with `enabled` and `value` set to true.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    resource = client.cdn.cdn_resources.update(
        12345,  # CDN resource ID
        options={
            "fetch_compressed": {"enabled": True, "value": True},
        },
    )
    print(resource.options.fetch_compressed.enabled, resource.options.fetch_compressed.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        resource, err := client.CDN.CDNResources.Update(ctx, 12345, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                FetchCompressed: cdn.CDNResourceUpdateParamsOptionsFetchCompressed{
                    Enabled: true,
                    Value:   true,
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(resource.Options.FetchCompressed.Enabled, resource.Options.FetchCompressed.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "fetch_compressed": {
            "enabled": true,
            "value": true
          }
        }
      }'
    ```

    <p>The API returns HTTP 200:</p>

    ```json
    {
      "id": 12345,
      "options": {
        "fetch_compressed": {
          "enabled": true,
          "value": true
        }
      }
    }
    ```
  </Tab>
