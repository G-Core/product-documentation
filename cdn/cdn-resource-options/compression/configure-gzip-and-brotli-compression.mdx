<p>Gcore CDN supports Gzip and Brotli edge compression. When Fetch Compressed does not apply to the request, the CDN requests uncompressed content from the origin, compresses it at the edge, and caches the compressed response. Browsers that support compression receive that response even when the origin does not compress it.</p>

<Note>
JPEG, PNG, video formats, and PDF are already compressed. These formats provide little or no size reduction from Gzip or Brotli and may increase file size.
</Note>

<p>Gzip and Brotli can be enabled together. When both are available, Brotli takes precedence for a client that sends `Accept-Encoding: br`. If the client does not support Brotli, CDN uses Gzip. A request without `Accept-Encoding`, or without `gzip` or `br` in that header, is delivered uncompressed.</p>

<p>Brotli requires [Origin&nbsp;Shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding). Enable Origin Shielding for the CDN resource before enabling Brotli. Without it, the Brotli option has no effect. The smallest file Brotli compresses is 128 bytes.</p>

<p>Gzip and Brotli cannot be enabled together with [Fetch&nbsp;Compressed](/cdn/cdn-resource-options/compression/configure-fetch-compression) or [large&nbsp;files optimization](/cdn/cdn-resource-options/optimize-large-file-delivery) in the same scope, whether that scope is the resource settings or one rule.</p>

<Note>
Gzip and Brotli in the resource settings can be combined with Fetch Compressed in a rule. Edge nodes then compress all requests, and the origin compresses the requests that match the rule.
</Note>

<Warning>
The reverse combination is not supported. When Fetch Compressed is enabled in the resource settings, Gzip and Brotli cannot be enabled in a rule.
</Warning>

## Configure Gzip and Brotli

<p>1. Navigate to the [CDN&nbsp;resources](https://portal.gcore.com/cdn/resources/list) list and click the CDN resource to configure.</p>

<Frame>![CDN resources list with a CDN resource row selected](/images/docs/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression/configure-gzip-and-brotli-compression-image1.png)</Frame>

<p>2. In the sidebar, under the **Content** section, click **GZip compression**. **Brotli compression** is on the same page.</p>

<Frame>![Compression settings with the Enable GZip compression and Enable Brotli compression toggles on one page](/images/docs/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression/configure-gzip-and-brotli-compression-image2.png)</Frame>

<p>3. Turn on the toggle for **Enable GZip compression** to enable the option.</p>

<p>4. Turn on the toggle for **Enable Brotli compression** to enable the option. In the **Content types** area, select the MIME types to compress. `text/html` stays selected.</p>

   * **application/javascript**. Selected by default.
   * **application/json**. Selected by default.
   * **application/x-javascript**. Selected by default.
   * **application/xml**. Selected by default.
   * **application/xml+rss**. Selected by default.
   * **text/css**. Selected by default.
   * **text/html**. Selected by default. Cannot be deselected.
   * **text/javascript**. Selected by default.
   * **text/plain**. Selected by default.
   * **text/xml**. Selected by default.
   * **application/vnd.ms-fontobject**. Not added by default.
   * **application/x-font-ttf**. Not added by default.
   * **image/x-icon**. Not added by default.
   * **image/svg+xml**. Not added by default.
   * **application/wasm**. Not added by default.

<p>5. Click **Save changes**.</p>

<p>6. [Purge](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) the CDN resource cache. Content cached before compression was enabled is not recompressed automatically.</p>

<p>7. Request a file with `Accept-Encoding` and read `Content-Encoding` in the response.</p>

```sh
curl -I -H "Accept-Encoding: br, gzip" https://cdn.example.com/file.css
```

<Accordion title="Gzip content types">
<p>For compressible text content, Gzip can reduce file size by 80% and up to 90%, depending on the content. The CDN compresses these MIME types with Gzip:</p>

  * application/dash+xml
  * application/javascript
  * application/json
  * application/x-javascript
  * application/xml
  * application/vnd.apple.mpegurl
  * application/xml+rss
  * application/wasm
  * text/css
  * text/html
  * text/javascript
  * text/plain
  * text/vtt
  * text/xml
  * image/svg+xml
</Accordion>

  <MethodSection id="api" label="REST API">

<p>Enable Gzip or Brotli compression for a CDN resource. Gzip is a boolean. Brotli takes the MIME types to compress, and that list must include `text/html`. Brotli compression requires [origin&nbsp;shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding).</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is visible under **CDN** → **CDN Resources**, or from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

<p>A [resource&nbsp;update](/api-reference/cdn/cdn-resources/change-cdn-resource) sets `options.gzipOn`, `options.brotli_compression`, or both in one request. Do not enable either option in the same scope as `fetch_compressed` or [large&nbsp;files optimization](/cdn/cdn-resource-options/optimize-large-file-delivery). That scope is the resource settings or one rule. Enabling either option while `fetch_compressed` is enabled in that scope returns HTTP 400. Gzip and Brotli on the resource can be combined with [Fetch&nbsp;Compressed](/cdn/cdn-resource-options/compression/configure-fetch-compression) in a rule. When `fetch_compressed` is enabled on the resource, Gzip and Brotli cannot be enabled in a rule.</p>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Enable Gzip

<p>Set `gzipOn.enabled` and `gzipOn.value` to `true`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"gzipOn": {"enabled": True, "value": True}},
    )
    gzip = updated.options.gzip_on
    print(gzip.enabled, gzip.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                GzipOn: cdn.CDNResourceUpdateParamsOptionsGzipOn{
                    Enabled: true,
                    Value:   true,
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.GzipOn.Enabled, updated.Options.GzipOn.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "gzipOn": {
            "enabled": true,
            "value": true
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": true
    }
    ```
  </Tab>
</Tabs>

## Enable Brotli

<p>Set `brotli_compression.value` to the MIME types to compress. `text/html` is required. A list without it returns HTTP 400. The saved list can come back in a different order.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "brotli_compression": {
                "enabled": True,
                "value": ["text/html", "text/css"],
            }
        },
    )
    brotli = updated.options.brotli_compression
    print(brotli.enabled, brotli.value)
    ```
  </Tab>

## Turn Gzip off

<p>Set `gzipOn.enabled` and `gzipOn.value` to `false`. The Go SDK omits a `false` boolean, so that call sends the JSON object explicitly.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"gzipOn": {"enabled": False, "value": False}},
    )
    gzip = updated.options.gzip_on
    print(gzip.enabled, gzip.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go

        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
    ```

<p>Set `gzip_on` and `brotli_compression` so the CDN compresses a response at the edge, using the [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2. A client that sends `Accept-Encoding: br` receives Brotli. A client that supports only Gzip receives Gzip. A request without `gzip` or `br` in `Accept-Encoding` is delivered uncompressed.</p>

<p>Brotli requires [origin&nbsp;shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding). `brotli_compression.value` must include `text/html`. A list without `text/html` returns HTTP 400. The saved list can come back in a different order. Do not set `gzip_on` or `brotli_compression` in the same scope as `fetch_compressed` or [large&nbsp;files optimization](/cdn/cdn-resource-options/optimize-large-file-delivery). That scope is the resource settings or one rule. Those options on the resource can be combined with [Fetch&nbsp;Compressed](/cdn/cdn-resource-options/compression/configure-fetch-compression) in a rule. When `fetch_compressed` is enabled on the resource, do not enable Gzip or Brotli in a rule. Run `terraform apply` after editing `options`. Content cached before compression was enabled is not recompressed. [Purge](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) the cache after the update.</p>

## Enable Gzip

<p>Set `enabled` and `value` to true. When Fetch Compressed does not apply to the request, the CDN requests uncompressed content from the origin and serves a Gzip response when the client accepts `gzip`.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    gzip_on = {
      enabled = true
      value   = true
    }
  }
}
```

## Enable Brotli

<p>Keep `gzip_on` enabled and set `brotli_compression` to the MIME types to compress. With `text/html` and `text/css`, a client that sends `Accept-Encoding: br` receives Brotli for those types.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    gzip_on = {
      enabled = true
      value   = true
    }

    brotli_compression = {
      enabled = true
      value   = ["text/html", "text/css"]
    }
  }
}
```

## Turn Gzip off

<p>Set `gzip_on.enabled` and `gzip_on.value` to false. Leave `brotli_compression` enabled, so a client that sends `Accept-Encoding: br` still receives Brotli.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    gzip_on = {
      enabled = false
      value   = false
    }

    brotli_compression = {
      enabled = true
      value   = ["text/html", "text/css"]
    }
  }
}
```

<p>Request a file with `Accept-Encoding` and read `Content-Encoding` in the response.</p>

```sh
curl -I -H "Accept-Encoding: br, gzip" https://cdn.example.com/file.css
```
