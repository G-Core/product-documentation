<p>Gcore CDN supports Gzip and Brotli edge compression. When enabled, content is requested in uncompressed format from the origin, compressed and cached at the edge, and served to browsers that support compression — even when the origin server does not.</p>

<Note>
Image formats (e.g., image/jpeg, image/png), video formats (e.g., video/mpeg), PDF, and other binary formats are already compressed. These formats provide little or no size reduction from Gzip or Brotli and may increase file size.
</Note>

<p>Gzip and Brotli can be enabled together. When both are available, Brotli takes precedence for a client that sends `Accept-Encoding: br`. If the client does not support Brotli, CDN uses Gzip. A request without `Accept-Encoding`, or without `gzip` or `br` in that header, is delivered uncompressed.</p>

<p>Brotli requires [Origin&nbsp;Shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding). Enable Origin Shielding for the CDN resource before enabling Brotli. Without it, the Brotli option has no effect. The smallest file Brotli compresses is 128 bytes.</p>

<p>Gzip and Brotli cannot be enabled together with [Fetch&nbsp;Compressed](/cdn/cdn-resource-options/compression/configure-fetch-compression) or [large&nbsp;files optimization](/cdn/cdn-resource-options/optimize-large-file-delivery) in the same scope, whether that scope is the resource settings or one rule.</p>

<Note>
Gzip and Brotli in the resource settings can be combined with Fetch Compressed in a rule. Edge nodes then compress all requests, and the origin compresses the requests that match the rule.
</Note>

<Warning>
The reverse combination is not supported. When Fetch Compressed is enabled in the resource settings, Gzip and Brotli cannot be enabled in a rule.
</Warning>

## Configure Gzip and Brotli

1. Navigate to the [CDN&nbsp;resources](https://portal.gcore.com/cdn/resources/list) list and click the CDN resource to configure.

<Frame>![CDN resources list with a CDN resource row selected](/images/docs/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression/configure-gzip-and-brotli-compression-image1.png)</Frame>

2. In the sidebar, under the **Content** section, click **GZip compression** or **Brotli compression**.

<Frame>![Resource settings sidebar with Content section expanded showing GZip compression and Brotli compression items](/images/docs/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression/configure-gzip-and-brotli-compression-image2.png)</Frame>

3. Turn on the toggle for **Enable GZip compression** to enable the option.

4. Turn on the toggle for **Enable Brotli compression** to enable the option. In the **Content types** area, select the MIME types to compress. `text/html` stays selected.

   * **application/javascript**. Selected by default.
   * **application/json**. Selected by default.
   * **application/x-javascript**. Selected by default.
   * **application/xml**. Selected by default.
   * **application/xml+rss**. Selected by default.
   * **text/css**. Selected by default.
   * **text/html**. Selected by default. Cannot be deselected.
   * **text/javascript**. Selected by default.
   * **text/plain**. Selected by default.
   * **text/xml**. Selected by default.
   * **application/vnd.ms-fontobject**. Not added by default.
   * **application/x-font-ttf**. Not added by default.
   * **image/x-icon**. Not added by default.
   * **image/svg+xml**. Not added by default.
   * **application/wasm**. Not added by default.

5. Click **Save changes**.

6. [Purge](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) the CDN resource cache. Content cached before compression was enabled is not recompressed automatically.

7. Request a file with `Accept-Encoding` and read `Content-Encoding` in the response.

```sh
curl -I -H "Accept-Encoding: br, gzip" https://cdn.example.com/file.css
```

<Accordion title="Gzip content types">
<p>For compressible text content, Gzip can reduce file size by 80% and up to 90%, depending on the content. The CDN compresses these MIME types with Gzip:</p>

  * application/dash+xml
  * application/javascript
  * application/json
  * application/x-javascript
  * application/xml
  * application/vnd.apple.mpegurl
  * application/xml+rss
  * application/wasm
  * text/css
  * text/html
  * text/javascript
  * text/plain
  * text/vtt
  * text/xml
  * image/svg+xml
</Accordion>

  <MethodSection id="api" label="REST API">

<p>Enable Gzip or Brotli compression for a CDN resource. Gzip is a boolean. Brotli takes the MIME types to compress, and that list must include `text/html`. Brotli compression requires [origin shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding).</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is visible under **CDN** → **CDN Resources**, or from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

<p>A [resource update](/api-reference/cdn/cdn-resources/change-cdn-resource) sets `options.gzipOn`, `options.brotli_compression`, or both in one request. Do not enable either option while `fetch_compressed` is enabled. The API returns HTTP 400.</p>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Enable Gzip

<p>Set `gzipOn.enabled` and `gzipOn.value` to `true`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"gzipOn": {"enabled": True, "value": True}},
    )
    gzip = updated.options.gzip_on
    print(gzip.enabled, gzip.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                GzipOn: cdn.CDNResourceUpdateParamsOptionsGzipOn{
                    Enabled: true,
                    Value:   true,
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.GzipOn.Enabled, updated.Options.GzipOn.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "gzipOn": {
            "enabled": true,
            "value": true
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": true
    }
    ```
  </Tab>
</Tabs>

## Enable Brotli

<p>Set `brotli_compression.value` to the MIME types to compress. `text/html` is required. A list without it returns HTTP 400. The saved list can come back in a different order.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "brotli_compression": {
                "enabled": True,
                "value": ["text/html", "text/css"],
            }
        },
    )
    brotli = updated.options.brotli_compression
    print(brotli.enabled, brotli.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"

    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                BrotliCompression: cdn.CDNResourceUpdateParamsOptionsBrotliCompression{
                    Enabled: true,
                    Value:   []string{"text/html", "text/css"},

        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.BrotliCompression.Enabled, updated.Options.BrotliCompression.Value)
    }
    ```

## Turn Gzip off

<p>Set `gzipOn.enabled` and `gzipOn.value` to `false`. The Go SDK omits a `false` boolean, so that call sends the JSON object explicitly.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"gzipOn": {"enabled": False, "value": False}},
    )
    gzip = updated.options.gzip_on
    print(gzip.enabled, gzip.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "encoding/json"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                GzipOn: param.Override[cdn.CDNResourceUpdateParamsOptionsGzipOn](
                    json.RawMessage(`{"enabled":false,"value":false}`),
                ),
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.GzipOn.Enabled, updated.Options.GzipOn.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "gzipOn": {
            "enabled": false,
            "value": false
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": false,
      "value": false
    }
    ```
  </Tab>
</Tabs>
