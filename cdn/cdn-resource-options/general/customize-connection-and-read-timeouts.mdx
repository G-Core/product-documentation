<p>Custom connection and read timeouts control how long Gcore edge nodes wait when communicating with an origin server.</p>

- A custom connection timeout sets the maximum duration allowed for establishing a connection.

- A custom read timeout sets the maximum duration for receiving a response from the origin server. This timeout applies between two successive read operations, not to the entire response transmission.

<p>When designated timeouts are exceeded, users receive a "504 Gateway Timeout" error.</p>

## Configure custom timeouts

<p>Timeouts are configured per CDN resource and apply to all requests handled by that resource.</p>

<p>1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** > **CDN resources**.</p>

<Frame>![CDN resources list page](/images/docs/cdn/cdn-resource-options/general/customize-connection-and-read-timeouts/cdn-resources.png)</Frame>

<p>2. Click the CNAME of the required CDN resource to open **Resource settings**.</p>

<Frame>![Custom connection timeout and Custom read timeout options in the resource settings](/images/docs/cdn/cdn-resource-options/general/customize-connection-and-read-timeouts/resource-settings.png)</Frame>

<p>3. Click **Custom connection timeout** or **Custom read timeout**, depending on the timeout to configure.</p>

<p>4. Enable the **Customize connection timeout** or **Customize read timeout** toggle.</p>

<p>5. Enter the timeout value. The allowed range is `1–5 seconds` for connection timeout and `1–30 seconds` for read timeout. To configure both timeouts, repeat steps 3–5 for the other option before saving.</p>

<Info>
For Enterprise plans, the upper limits can be raised beyond 5 seconds (connection) and 30 seconds (read). Contact [Gcore&nbsp;Support](https://support.gcore.com/hc/en-us/requests/new) to request higher values.
</Info>

<Frame>![Resource settings showing both custom timeout toggles enabled with values entered](/images/docs/cdn/cdn-resource-options/general/customize-connection-and-read-timeouts/enable-connection-read-timeouts.png)</Frame>

<p>6. Click **Save changes**.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>`proxy_connect_timeout` is how long Gcore CDN waits to open a connection to the origin, and `proxy_read_timeout` is how long it waits between successive reads of the origin response. Past either limit, the viewer receives 504 Gateway Timeout.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is the `id` from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Set the connection timeout

<p>Set `value` to a duration from 1 second through 5 seconds. `enabled` and `value` are both required.</p>

<p>The API accepts `4s` and `4`. `0s`, `6s`, `4S`, `4sec`, and `4000ms` return HTTP 400.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"proxy_connect_timeout": {"enabled": True, "value": "4s"}},
    )
    print(updated.options.proxy_connect_timeout.enabled, updated.options.proxy_connect_timeout.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                ProxyConnectTimeout: cdn.CDNResourceUpdateParamsOptionsProxyConnectTimeout{
                    Enabled: true,
                    Value:   "4s",
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.ProxyConnectTimeout.Enabled, updated.Options.ProxyConnectTimeout.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "proxy_connect_timeout": {"enabled": true, "value": "4s"}
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": "4s"
    }
    ```
  </Tab>
</Tabs>

## Set both timeouts

<p>Send both options in one request. The call sets the connection timeout to `4s` and the read timeout to `10s`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "proxy_connect_timeout": {"enabled": True, "value": "4s"},
            "proxy_read_timeout": {"enabled": True, "value": "10s"},
        },
    )
    print(
        updated.options.proxy_connect_timeout.value,
        updated.options.proxy_read_timeout.value,
    )
    ```
  </Tab>
  <Tab title="Go SDK">

## Turn the timeouts off

<p>Set both options to `null`. The saved resource then has neither timeout. `enabled` set to `false` keeps the duration and turns that timeout off.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"proxy_connect_timeout": None, "proxy_read_timeout": None},
    )
    print(updated.options.proxy_connect_timeout, updated.options.proxy_read_timeout)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        options := cdn.CDNResourceUpdateParamsOptions{}
        options.SetExtraFields(map[string]any{
            "proxy_connect_timeout": nil,
            "proxy_read_timeout":    nil,
        })
        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: options,
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.ProxyConnectTimeout.RawJSON(), updated.Options.ProxyReadTimeout.RawJSON())
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "proxy_connect_timeout": null,
          "proxy_read_timeout": null
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved options are:</p>

    ```json
    {
      "proxy_connect_timeout": null,
      "proxy_read_timeout": null
    }
    ```
  </Tab>
