---
title: Enable origin SSL validation
sidebarTitle: Enable SSL validation
ai-navigation: Enable origin SSL validation on a CDN resource via REST API with a trusted CA and an SSL certificate.
---

Origin SSL validation makes CDN edge servers verify the origin TLS certificate before completing an HTTPS pull. Without it, CDN-to-origin HTTPS traffic can still be exposed to a [man-in-the-middle](https://en.wikipedia.org/wiki/Man-in-the-middle_attack) attack because edge servers do not check that the origin certificate is valid and issued for the expected host.

Set the [origin&nbsp;pull&nbsp;protocol](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) to HTTPS before enabling validation.

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required, along with an existing CDN resource and an uploaded [SSL&nbsp;certificate](/cdn/ssl-certificates/configure-your-own-ssl-certificate).
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
```

## Add a trusted CA certificate

A [trusted&nbsp;CA](/api-reference/cdn/ca-certificates/add-trusted-ca-certificate) request stores the public certificate and returns its id, so use that id as `proxy_ssl_ca`.

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()  # Reads GCORE_API_KEY from env

    ca = client.cdn.trusted_ca_certificates.create(
        name="origin.mywebsite.com",
        ssl_certificate=open("ca.pem", encoding="ascii").read(),
    )
    print(ca.id)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient() // Reads GCORE_API_KEY from env
        ctx := context.Background()

        pem, err := os.ReadFile("ca.pem")
        if err != nil {
            panic(err)
        }
        ca, err := client.CDN.TrustedCaCertificates.New(ctx, cdn.TrustedCaCertificateNewParams{
            Name:           "origin.mywebsite.com",
            SslCertificate: string(pem),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(ca.ID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/cdn/sslCertificates" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "origin.mywebsite.com",
        "sslCertificate": "-----BEGIN CERTIFICATE-----\n-----END CERTIFICATE-----\n"
      }'
    ```

    <p>The API returns:</p>

    ```json
    {
      "id": 1004,
      "name": "origin.mywebsite.com"
    }
    ```
  </Tab>
</Tabs>

## Select the uploaded SSL certificate

The [certificate&nbsp;list](/api-reference/cdn/ssl-certificates/get-ssl-certificates-list) returns each SSL certificate id, so select the certificate by name and use that id as `proxy_ssl_data`. Sending that id as `proxy_ssl_ca`, or a trusted CA id as `proxy_ssl_data`, returns HTTP 400 with the message `Invalid pk "1003" - object does not exist.`

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    certificates = client.cdn.certificates.list()
    cert_id = next(item.id for item in certificates if item.name == "client.mywebsite.com")
    print(cert_id)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        page, err := client.CDN.Certificates.List(ctx, cdn.CertificateListParams{})
        if err != nil {
            panic(err)
        }
        var certID int64
        for _, item := range page.Results {
            if item.Name == "client.mywebsite.com" {
                certID = item.ID
                break
            }
        }
        fmt.Println(certID)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/cdn/sslData?limit=1000" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns:</p>

    ```json
    {
      "results": [
        {
          "id": 1003,
          "name": "client.mywebsite.com"
        }
      ]
    }
    ```
  </Tab>
</Tabs>

## Enable validation on the resource

A [resource&nbsp;update](/api-reference/cdn/cdn-resources/change-cdn-resource) sets `proxy_ssl_enabled` to `true` together with `proxy_ssl_ca` and `proxy_ssl_data`. A request that sets `proxy_ssl_enabled` to `true` without both ids returns HTTP 400 with the message `Can not enable proxy_ssl feature while both proxy CA certificate and proxy ssl data not specified.`

A full replace uses PUT and requires `originGroup`, so a replace that omits `originGroup` returns HTTP 400 with the message `This field is required.`

| Parameter | Required | Description |
|-----------|----------|-------------|
| `proxy_ssl_enabled` | No | Optional in the API. Set to `true` to enable origin SSL validation |
| `proxy_ssl_ca` | No | Optional in the API. Required with `proxy_ssl_data` the first time validation is enabled. Trusted CA certificate id |
| `proxy_ssl_data` | No | Optional in the API. Required with `proxy_ssl_ca` the first time validation is enabled. SSL certificate id |

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    resource = client.cdn.cdn_resources.update(
        1001,
        proxy_ssl_enabled=True,
        proxy_ssl_ca=1004,
        proxy_ssl_data=1003,
    )
    print(resource.proxy_ssl_enabled, resource.proxy_ssl_ca, resource.proxy_ssl_data)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        resource, err := client.CDN.CDNResources.Update(ctx, 1001, cdn.CDNResourceUpdateParams{
            ProxySslEnabled: gcore.Bool(true),
            ProxySslCa:      gcore.Int(1004),
            ProxySslData:    gcore.Int(1003),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(resource.ProxySslEnabled, resource.ProxySslCa, resource.ProxySslData)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/1001" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "proxy_ssl_enabled": true,
        "proxy_ssl_ca": 1004,
        "proxy_ssl_data": 1003
      }'
    ```

    <p>The API returns:</p>

    ```json
    {
      "id": 1001,
      "proxy_ssl_enabled": true,
      "proxy_ssl_ca": 1004,
      "proxy_ssl_data": 1003
    }
    ```
  </Tab>
</Tabs>

## Disable validation on the resource

The same update turns validation off when `proxy_ssl_enabled` is `false` and keeps both certificate ids. A later update can set `proxy_ssl_enabled` to `true` alone, because those ids are already stored.

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    resource = client.cdn.cdn_resources.update(1001, proxy_ssl_enabled=False)
    print(resource.proxy_ssl_enabled, resource.proxy_ssl_ca, resource.proxy_ssl_data)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        resource, err := client.CDN.CDNResources.Update(ctx, 1001, cdn.CDNResourceUpdateParams{
            ProxySslEnabled: gcore.Bool(false),
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(resource.ProxySslEnabled, resource.ProxySslCa, resource.ProxySslData)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/1001" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"proxy_ssl_enabled": false}'
    ```

    <p>The API returns:</p>

    ```json
    {
      "id": 1001,
      "proxy_ssl_enabled": false,
      "proxy_ssl_ca": 1004,
      "proxy_ssl_data": 1003
    }
    ```
  </Tab>
</Tabs>
