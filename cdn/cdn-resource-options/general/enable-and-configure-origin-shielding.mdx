<p>Origin Shielding places a shield server between CDN edge servers and the origin. The shield server, called the precache server in the Customer Portal, serves edge requests from its cache when possible, so the origin is contacted only on a cache miss. This reduces the number of requests reaching the origin during traffic bursts.</p>

<p>The shield uses the pull protocol configured on the CDN resource — HTTP or HTTPS. Selecting the shield location closest to the origin minimizes the distance on the shield-to-origin connection.</p>

<Frame>![Diagram showing the shield server positioned between CDN edge servers and the origin server](/images/docs/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding/Shield_server.jpeg)</Frame>

## Enable Origin Shielding

<Info>
Origin Shielding is a paid option. To make it available for a CDN resource, contact [Gcore&nbsp;support](mailto:support@gcore.com) or the account manager.
</Info>

<Steps>
  <Step title="Open the CDN resource settings">
    <p>In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** > **CDN resources** and click the CNAME of the resource to configure.</p>
  </Step>
  <Step title="Open Origin Shielding">
    <p>In the resource settings sidebar, click **Origin Shielding**.</p>

    <Frame>![CDN resource settings with the Origin Shielding section showing the disabled Enable Origin Shielding toggle](/images/docs/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding/enable-and-configure-origin-shielding-image2.png)</Frame>
  </Step>
  <Step title="Enable the toggle">
    <p>Turn on the **Enable Origin Shielding** toggle.</p>
  </Step>
  <Step title="Select the shield location">
    <p>In the **Data center** dropdown, select the location for the precache server. The location closest to the origin server minimizes the shield-to-origin latency.</p>
  </Step>
  <Step title="Save">
    <p>Click **Save changes**.</p>
  </Step>
</Steps>

<p>Activation begins immediately and completes in under 15 minutes. The following notification appears:</p>

<Frame>![Activation notification indicating Origin Shielding is being activated](/images/docs/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding/Activation.png)</Frame>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Route CDN edge requests for one resource through a shield location so the origin is contacted only on a cache miss.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is visible under **CDN** → **CDN Resources**, or from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

<p>Origin shielding is a paid option. To make it available for a CDN resource, contact [Gcore&nbsp;Support](https://support.gcore.com/hc/en-us/requests/new).</p>

<p>Choose the shield location closest to the origin. The shield uses the HTTP or HTTPS pull protocol already configured on the CDN resource.</p>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
export SHIELDING_POP="{YOUR_SHIELDING_LOCATION_ID}"
```

<p>`shielding_pop` is the shield location ID. A value of `null` disables origin shielding.</p>

## List shield locations

<p>List the available locations first, then use the ID of the location closest to the origin as `SHIELDING_POP`. Each location includes a datacenter name, a city, and a country.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()
    locations = client.cdn.shielding_location.list()
    for item in locations:
        print(item.id, item.datacenter, item.city, item.country)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        page, err := client.CDN.ShieldingLocation.List(ctx, cdn.ShieldingLocationListParams{})
        if err != nil {
            panic(err)
        }
        for _, item := range page.Results {
            fmt.Println(item.ID, item.Datacenter, item.City, item.Country)
        }
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl "https://api.gcore.com/cdn/shieldingpop_v2" \
      -H "Authorization: APIKey $GCORE_API_KEY"
    ```

    <p>The API returns HTTP 200:</p>

    ```json
    [
      {
        "id": 172,
        "datacenter": "dc3",
        "city": "Ashburn",
        "country": "USA"
      }
    ]
    ```
  </Tab>
</Tabs>

## Enable origin shielding

<p>Set `shielding_pop` to a location id. The response returns that id immediately. Activation completes in under 15 minutes.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])
    shielding_pop = int(os.environ["SHIELDING_POP"])

    updated = client.cdn.cdn_resources.shield.replace(
        resource_id,
        shielding_pop=shielding_pop,
    )
    print(updated["shielding_pop"])
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }
        shieldingPop, err := strconv.ParseInt(os.Getenv("SHIELDING_POP"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Shield.Replace(ctx, resourceID, cdn.CDNResourceShieldReplaceParams{
            OriginShielding: cdn.OriginShieldingParam{
                ShieldingPop: gcore.Int(shieldingPop),
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println((*updated).(map[string]any)["shielding_pop"])
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PUT "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/shielding_v2" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d "{\"shielding_pop\": $SHIELDING_POP}"
    ```

    <p>The API returns HTTP 200:</p>

    ```json
    {
      "shielding_pop": 172
    }
    ```
  </Tab>
</Tabs>

## Disable origin shielding

<p>Set `shielding_pop` to `null`. The resource stops sending edge requests through a shield.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.shield.replace(
        resource_id,
        shielding_pop=None,
    )
    print(updated["shielding_pop"])
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Shield.Replace(ctx, resourceID, cdn.CDNResourceShieldReplaceParams{
            OriginShielding: cdn.OriginShieldingParam{
                ShieldingPop: param.Null[int64](),
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println((*updated).(map[string]any)["shielding_pop"])
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PUT "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/shielding_v2" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"shielding_pop": null}'
    ```

    <p>The API returns HTTP 200:</p>

    ```json
    {
      "shielding_pop": null
    }
    ```
  </Tab>
</Tabs>
