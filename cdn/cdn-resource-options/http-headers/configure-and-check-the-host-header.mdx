<p>The Host header is a mandatory HTTP request header. CDN servers include it in every request sent to the origin. The origin uses the Host header to identify which website or application to serve — this matters when multiple sites share the same server.</p>

<p>The **Change Host header** option in CDN resource settings controls the value CDN servers send. When enabled, it offers two modes:</p>

- **Custom Host header** — CDN servers send a fixed domain or IP address as the Host header on every origin request.
- **Forward Host header** — CDN servers forward the Host header received in the end-user request to the origin unchanged.

## Configure the host header

<p>When the origin source changes after resource creation, the **Change Host header** value does not update automatically. CDN servers continue using the old value, sending requests to the new origin with an incorrect Host header and returning errors to end users.</p>

<p>To configure the option:</p>

<p>1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** → **CDN resources**.</p>

<p>2. Click the resource to open its settings.</p>

<p>3. In the left panel, click **HTTP headers** to expand the section, then click **Host header**.</p>

<Frame>![CDN resource settings, Host header section with Change Host header toggle enabled and Forward Host header selected](/images/docs/cdn/cdn-resource-options/http-headers/configure-and-check-the-host-header/configure-and-check-the-host-header-image1.png)</Frame>

<p>4. Enable the **Change Host header** toggle.</p>

<p>5. Select one of the two modes:</p>

- **Custom Host header** — enter the domain or IP address CDN servers will send as the Host header. Use this when the origin serves a single site with a fixed host name.
- **Forward Host header** — CDN servers forward the Host header from the end-user request. Use this when the origin validates the incoming Host header against the request domain.

<Frame>![Host header section with Custom Host header selected, showing an input field for the host header value](/images/docs/cdn/cdn-resource-options/http-headers/configure-and-check-the-host-header/configure-and-check-the-host-header-image2.png)</Frame>

<p>6. Click **Save changes**.</p>

<p>After saving, [clear&nbsp;the&nbsp;cache](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) to apply the change to cached content.</p>

## Disable the host header

<p>Disabling **Change Host header** causes CDN servers to send the CDN resource's CNAME as the Host header. Most origin servers cannot process this value and return 4xx or 5xx errors to end users. The option must remain enabled in all standard configurations.</p>

<p>When using a `*.gvideo.io` CDN resource for [streaming](/streaming/interaction-with-cdn/get-started-streaming-cdn), disabling the option sets the Host header to the CDN resource's CNAME — this is the expected behavior for that use case.</p>

## Check whether the origin accepts the Host header

<p>To check whether the origin accepts the Host header configured for the CDN resource, send a request directly to the origin with that value:</p>

```sh
curl -H "Host: example.com" -I https://10.0.0.1/file.txt
```

<p>Where:</p>

- **`example.com`** — the expected Host header value
- **`https`** — the protocol used by the origin; replace with `http` if the origin does not use TLS
- **`10.0.0.1`** — the IP address of the origin server
- **`file.txt`** — any static file delivered via CDN

<p>A `200 OK` response confirms that the origin accepts the specified Host header. If the request returns `400 Bad Request` or `403 Forbidden`, verify that the origin accepts this value.</p>

<p>The origin uses the Host header to select which site to serve, so `hostHeader` stores a fixed hostname and `forward_host_header` copies the Host header from the viewer request. Gcore CDN puts that value on the request it sends to the origin. Only one of the two options can be enabled.</p>

An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is the `id` from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.

## Set a custom host

<p>Set `hostHeader` to the hostname Gcore CDN should send, and set `forward_host_header` to `null` in the same request. A request that enables both options returns HTTP 400.</p>

<p>In the JSON body the field name is `hostHeader`. A body that sends `host_header` does not change the saved value. `enabled` and `value` are both required, and the API stores `value` in lowercase.</p>

<p>The value can contain letters, numbers, and `.` `-` `_` `:`, up to 2048 characters. A blank value, a missing field, any other character, or a longer value returns HTTP 400. A hostname, an IP address, and a hostname with a port are all accepted.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "host_header": {"enabled": True, "value": "origin.example.com"},
            "forward_host_header": None,
        },
    )
    print(updated.options.host_header.enabled, updated.options.host_header.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        options := cdn.CDNResourceUpdateParamsOptions{
            HostHeader: cdn.CDNResourceUpdateParamsOptionsHostHeader{
                Enabled: true,
                Value:   "origin.example.com",
            },
        }
        options.SetExtraFields(map[string]any{"forward_host_header": nil})
        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: options,
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.HostHeader.Enabled, updated.Options.HostHeader.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "hostHeader": {"enabled": true, "value": "origin.example.com"},
          "forward_host_header": null
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved options are:</p>

    ```json
    {
      "hostHeader": {
        "enabled": true,
        "value": "origin.example.com"
      },
      "forward_host_header": null
    }
    ```
  </Tab>
</Tabs>

## Forward the request host

<p>Set `forward_host_header` to enabled with `value` `true`, and set `hostHeader` to `null` in the same request. Gcore CDN then copies the Host header from the viewer request. `enabled` and `value` are both required.</p>

    ```python
    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "host_header": None,
            "forward_host_header": {"enabled": True, "value": True},
        },
    )
    print(
        updated.options.forward_host_header.enabled,
        updated.options.forward_host_header.value,
    ```

## Turn off the host header

<p>Set `hostHeader` and `forward_host_header` to `null`. The saved resource then has neither option, and a null `hostHeader` means the Host value is the first CNAME of the resource.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"host_header": None, "forward_host_header": None},
    )
    print(updated.options.host_header, updated.options.forward_host_header)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go

        "context"
        "fmt"

    )

    func main() {
    ```

## Set a custom host on a file rule

<p>A resource rule stores `hostHeader` only where `rule` matches. `ruleType` `0` is a regular expression and must start with `^/` or `/`.</p>

<p>The call applies the Host header on paths under `/assets/`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    rule = client.cdn.cdn_resources.rules.create(
        resource_id,
        name="host-assets",
        rule="^/assets/.*",
        rule_type=0,
        options={"host_header": {"enabled": True, "value": "assets.example.com"}},
    )
    print(rule.id, rule.rule, rule.options.host_header.enabled, rule.options.host_header.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        rule, err := client.CDN.CDNResources.Rules.New(ctx, resourceID, cdn.CDNResourceRuleNewParams{
            Name:     "host-assets",
            Rule:     "^/assets/.*",
            RuleType: 0,
            Options: cdn.CDNResourceRuleNewParamsOptions{
                HostHeader: cdn.CDNResourceRuleNewParamsOptionsHostHeader{
                    Enabled: true,
                    Value:   "assets.example.com",
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(rule.ID, rule.Rule, rule.Options.HostHeader.Enabled, rule.Options.HostHeader.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/rules" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "host-assets",
        "rule": "^/assets/.*",
        "ruleType": 0,
        "options": {
          "hostHeader": {"enabled": true, "value": "assets.example.com"}
        }
      }'
    ```

    <p>The API returns HTTP 201. The saved rule includes these fields:</p>

    ```json
    {
      "id": 704011,
      "rule": "^/assets/.*",
      "ruleType": 0,
      "options": {
        "hostHeader": {
          "enabled": true,
          "value": "assets.example.com"
        }
      }
    }
    ```
  </Tab>
</Tabs>
