<p>Gcore CDN provides two options for controlling response headers: **Response headers (add)** adds custom HTTP headers to CDN server responses, and **Response headers (hide)** removes specific origin headers before delivery.</p>

## Add response headers

<p>The **Response headers (add)** option sets custom HTTP headers that CDN servers include in responses to end users. If the same header is already configured on the origin server, the CDN server overrides its value.</p>

<p>To configure the option:</p>

1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** → **CDN resources**.

2. Click the resource to open its settings.

3. In the left panel, click **HTTP headers** to expand the section, then click **Response headers (add)** to jump to the option.

4. Enable the **Add response headers** toggle.

<Info>Up to 50 response headers can be added per resource.</Info>

<Frame>![CDN resource settings with the Response headers add option expanded, showing Header name and Value fields](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image1.png)</Frame>

5. In the **Header name** field, enter a header name.

6. In the **Value** field, enter the header value.

7. The **Always add the header to response from CDN regardless of response code** checkbox is enabled by default, which adds the header to all responses. To add the header only to responses with codes 200, 201, 204, 206, 301, 302, 303, 304, 307, and 308, uncheck the box.

8. Click **Add header** to add more headers. Fill in the fields for each additional header.

9. Click **Save changes**.

### Add multiple header values

<p>To add more than one value to the same header, enter them in the **Value** field in one of two ways:</p>

- **Separate header values:** enter a value and press Enter before adding the next one.

<Frame>![Response headers add form with multiple values entered on separate lines in the Value field](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image2.png)</Frame>

<p>The response header appears as:</p>

```
Example: one   
Example: two   
Example: three 
```

- **Comma-separated value:** enter multiple values separated by commas without pressing Enter.

<Frame>![Response headers add form with comma-separated values in the Value field](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image3.png)</Frame>

<p>The response header appears as:</p>

<p>`Example: one, two, three`</p>

<p>Both methods can be combined: enter comma-separated values, press Enter, and then add another value.</p>

<Frame>![Response headers add form with combined comma-separated and multi-line values in the Value field](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image4.png)</Frame>

<p>The response header appears as:</p>

```
Example: one, two   
Example: three 
```

<p>**Valid characters for fields:**</p>

- **Header name**: Latin letters (A–Z, a–z), numbers (0–9), underscore (_) and hyphen (-)
- **Value**: Latin letters (A–Z, a–z), numbers (0–9), a space and the following special characters: `~!@#%^&*()-_=+ /|";:?.><{}[]`

<p>**Value field restrictions:**</p>

- Invalid characters: `$'`
- The value must start with a letter, number, asterisk (*), or opening brace ({)
- Cannot contain only special characters

### Check headers

<p>After saving the configuration, verify the header appears in CDN responses.</p>

1. [Clear&nbsp;the&nbsp;cache](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) of the CDN resource or files for which the header was added.

2. Run the following cURL command, substituting the file URL:

```bash
curl -I https://cdn.site.com/images/1.jpg
```

```text
HTTP/2 200
X-Custom-Header: header-value
```

3. If the response contains the configured header, the setup is complete.

## Hide response headers

<p>By default, a CDN server passes all HTTP headers it receives from the origin server to end users. To control which headers are included in responses:</p>

1. In the Customer Portal, navigate to **CDN** → **CDN resources**.

2. Click the resource to open its settings.

3. In the left panel, click **HTTP headers** to expand the section, then click **Response headers (hide)** to jump to the option.

4. Enable the **Hide response headers** toggle.

<Frame>![CDN resource settings with the Response headers hide option enabled, showing Hide all except and Hide only radio buttons](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image5.png)</Frame>

5. Select a mode:

- **Hide all except** — set the headers to keep in the response; all other headers are hidden. After enabling, the most common headers appear pre-filled. Remove headers by clicking the × icon, or add headers by clicking the **HTTP headers** row and selecting from the list or entering a name. Header names accept letters (a–z), numbers (0–9), dashes (-), and underscores (_).

<Frame>![Hide all except mode with pre-populated common response headers shown as removable tags](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image6.png)</Frame>

- **Hide only** — set the headers to hide from the response; all other headers are kept. Click the **HTTP headers** row and select from the list or enter custom header names.

<Frame>![Hide only mode with an empty field for entering headers to hide from responses](/images/docs/cdn/cdn-resource-options/http-headers/add-or-hide-response-headers/add-or-hide-response-headers-image7.png)</Frame>

<Info>The following headers are mandatory and cannot be hidden: _connection, content-length, content-type, server,_ and _date_.</Info>

6. Click **Save changes**.

<p>Add custom headers to CDN responses, or hide selected origin headers before the response is delivered.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is visible under **CDN** → **CDN Resources**, or from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.

<p>Use `static_response_headers` to add headers. The older `staticHeaders` field is not used for new configurations. Use `response_headers_hiding_policy` to hide origin headers. Set `enabled` to `false` to turn either option off.</p>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Add response headers

<p>Set `options.static_response_headers`. Each item in `value` is one header. Strings in that item's `value` array are separate header values. A comma inside one string stays part of that single value. `always` set to `false` adds the header only to responses with codes 200, 201, 204, 206, 301, 302, 303, 304, 307, and 308. `always` set to `true` adds it to every response. A resource accepts up to 50 headers. The name uses letters, numbers, hyphens, and underscores. The value must start with a letter, number, asterisk (*), or opening brace ({).</p>

<p>After the option is saved, [clear&nbsp;the&nbsp;cache](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) and request the file. The header is present when the CDN response includes it.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "static_response_headers": {
                "enabled": True,
                "value": [
                    {
                        "name": "X-Custom-Header",
                        "value": ["one", "two"],
                        "always": False,
                    }
                ],
            }
        },
    )
    header = updated.options.static_response_headers.value[0]
    print(header.name, header.value, header.always)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                StaticResponseHeaders: cdn.CDNResourceUpdateParamsOptionsStaticResponseHeaders{
                    Enabled: true,
                    Value: []cdn.CDNResourceUpdateParamsOptionsStaticResponseHeadersValue{{
                        Name:   "X-Custom-Header",
                        Value:  []string{"one", "two"},
                        Always: gcore.Bool(false),
                    }},
                },
            },
        })
        if err != nil {
            panic(err)
        }
        header := updated.Options.StaticResponseHeaders.Value[0]
        fmt.Println(header.Name, header.Value, header.Always)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "static_response_headers": {
            "enabled": true,
            "value": [
              {
                "name": "X-Custom-Header",
                "value": ["one", "two"],
                "always": false
              }
            ]
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": [
        {
          "name": "X-Custom-Header",
          "value": ["one", "two"],
          "always": false
        }
      ]
    }
    ```
  </Tab>
</Tabs>

## Hide response headers

<p>Choose one policy. The API `mode` name does not match the Portal label.</p>

| Portal mode | API `mode` | `excepted` contains |
| --- | --- | --- |
| Hide all except | `hide` | Headers to keep |
| Hide only | `show` | Headers to remove |

### Hide all except selected headers

<p>Set `mode` to `hide`. `excepted` lists the headers that stay. The API also keeps `connection`, `content-length`, `content-type`, `date`, and `server`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "response_headers_hiding_policy": {
                "enabled": True,
                "mode": "hide",
                "excepted": ["etag"],
            }
        },
    )
    policy = updated.options.response_headers_hiding_policy
    print(policy.mode, policy.excepted)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                ResponseHeadersHidingPolicy: cdn.CDNResourceUpdateParamsOptionsResponseHeadersHidingPolicy{
                    Enabled:  true,
                    Mode:     "hide",
                    Excepted: []string{"etag"},
                },
            },
        })
        if err != nil {
            panic(err)
        }
        policy := updated.Options.ResponseHeadersHidingPolicy
        fmt.Println(policy.Mode, policy.Excepted)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \

      -d '{
        "options": {
          "response_headers_hiding_policy": {
            "enabled": true,
            "mode": "hide",
            "excepted": ["etag"]
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option keeps the requested header and the headers that cannot be hidden:</p>

    ```json
    {
      "enabled": true,
      "mode": "hide",
      "excepted": ["etag", "content-type", "content-length", "connection", "date", "server"]
    }
    ```
