  <MethodSection id="portal" label="Customer Portal">

<p>A viewer calls the CDN hostname, and the origin only sees the request Gcore CDN opens next. **Request headers** are the names and values added to that origin request, because the viewer request does not include them. Gcore CDN attaches the saved headers on every call to the origin.</p>

## Add request headers

<p>To configure request headers via the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com):</p>

<Steps>
  <Step title="Open the resource">
    Navigate to **CDN** → **CDN resources** and click the CDN resource to configure.

    <Frame>![CDN resources list showing active resources](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image1.png)</Frame>
  </Step>
  <Step title="Open request headers">
    In the resource settings panel, click **HTTP headers** to expand the section, then click **Request headers**.

    <Frame>![HTTP headers section expanded in the left panel with Request headers active](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image2.png)</Frame>
  </Step>
  <Step title="Enable the option">
    Enable the **Add request headers** toggle.

    <Frame>![Resource settings OPTIONS tab showing the HTTP headers section with the Add request headers toggle](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image3.png)</Frame>
  </Step>
  <Step title="Enter the header">
    In the form that appears, enter the name and value for the request header.

    - **Header name**: Accepts letters (A-Z, a-z), numbers (0-9), dashes (-), and underscores (_).
    - **Value**: Accepts letters (A-Z, a-z), numbers (0-9), dashes (-), underscores (_), slashes (/), colons (:), equals (=), dots (.), and spaces.

    <Info>The Value field accepts spaces between words but cannot begin or end with a space.</Info>

    <Frame>![Request headers form with Header name and Value fields and the + Add header button](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image4.png)</Frame>
  </Step>
  <Step title="Add another header">
    To add more headers, click **+ Add header** and repeat step 4.

    <Frame>![Multiple request header rows with filled Header name and Value fields](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image5.png)</Frame>
  </Step>
  <Step title="Save changes">
    Click **Save changes**.
  </Step>
</Steps>

<p>Confirm the header on the origin. Check the origin request logs, or configure the origin to return the received header value. The request from CDN servers includes each saved header name and value.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Add headers to the request Gcore CDN sends to the origin. The viewer request ends at the CDN hostname, so `staticRequestHeaders` stores the names and values the origin should receive. Gcore CDN adds that map to every origin request.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is the `id` from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Add request headers

<p>Set `options.staticRequestHeaders`. Both `enabled` and `value` are required. A request that omits either field returns HTTP 400. A resource accepts up to 50 headers.</p>

<p>Each header name can contain up to 255 characters: letters, numbers, dashes, and underscores. Each value can contain up to 512 characters. It must start with a letter, number, asterisk (`*`), or an opening brace. After the first character, the API accepts letters, numbers, spaces, and `` `~!@#%^&*()-_=+/|\";:?.,><{}[] ``. The API removes leading and trailing spaces.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "static_request_headers": {
                "enabled": True,
                "value": {
                    "X-Custom-Header": "cdn-origin",
                    "X-Request-Source": "gcore cdn",
                },
            }
        },
    )
    headers = updated.options.static_request_headers
    print(headers.enabled, headers.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                StaticRequestHeaders: cdn.CDNResourceUpdateParamsOptionsStaticRequestHeaders{
                    Enabled: true,
                    Value: map[string]string{
                        "X-Custom-Header":  "cdn-origin",
                        "X-Request-Source": "gcore cdn",
                    },
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.StaticRequestHeaders.Enabled, updated.Options.StaticRequestHeaders.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "staticRequestHeaders": {
            "enabled": true,
            "value": {
              "X-Custom-Header": "cdn-origin",
              "X-Request-Source": "gcore cdn"
            }
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": {
        "X-Custom-Header": "cdn-origin",
        "X-Request-Source": "gcore cdn"
      }
    }
    ```
  </Tab>
</Tabs>

## Turn off request headers

<p>Set `enabled` to `false` to stop adding headers to origin requests. `value` is still required. An empty `value` stores no headers.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "static_request_headers": {
                "enabled": False,
                "value": {},
            }
        },
    )
    headers = updated.options.static_request_headers
    print(headers.enabled, headers.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                StaticRequestHeaders: cdn.CDNResourceUpdateParamsOptionsStaticRequestHeaders{
                    Enabled: false,
                    Value:   map[string]string{},
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.StaticRequestHeaders.Enabled, updated.Options.StaticRequestHeaders.Value)
    }
    ```


    <p>The API returns HTTP 200:</p>

    ```json

      "enabled": false,
      "value": {}
    }
    ```

  <MethodSection id="terraform" label="Terraform">

<p>Add headers to the request CDN servers send to the origin with the [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2. When `static_request_headers` is enabled, CDN servers add each name and value on every origin request. A resource accepts up to 50 headers. Run `terraform apply` after editing `options`.</p>

## Request headers

<p>Set `enabled` to `true`. `value` maps each header name to one header value. `X-Request-Source` is `gcore cdn`, with a space between the words. Set `enabled` to `false` and `value` to an empty map to stop adding headers. The empty map stores no headers.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    static_request_headers = {
      enabled = true
      value = {
        "X-Custom-Header"  = "cdn-origin"
        "X-Request-Source" = "gcore cdn"
      }
    }
  }
}
```
