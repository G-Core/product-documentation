Use the Request Headers option to add custom HTTP headers to CDN requests before they reach the origin.

To configure request headers via the Gcore Customer Portal:

1. Navigate to **CDN** > **CDN resources** and click the CDN resource you want to configure.

<Frame>![CDN resources list showing active resources](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image1.png)</Frame>

2. In the resource settings panel, click **HTTP headers** to expand the section, then click **Request headers**.

<Frame>![HTTP headers section expanded in the left panel with Request headers active](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image2.png)</Frame>

3. Enable the **Add request headers** toggle.

<Frame>![Resource settings OPTIONS tab showing the HTTP headers section with the Add request headers toggle](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image3.png)</Frame>

4. In the form that appears, enter the name and value for the request header.

   * **Header name**: Accepts letters (A-Z, a-z), numbers (0-9), dashes (-), and underscores (_).
   * **Value**: Accepts letters (A-Z, a-z), numbers (0-9), dashes (-), underscores (_), slashes (/), colons (:), equals (=), dots (.), and spaces.

<Info>The Value field accepts spaces between words but cannot begin or end with a space.</Info>

<Frame>![Request headers form with Header name and Value fields and the + Add header button](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image4.png)</Frame>

5. To add more headers, click **+ Add header** and repeat step 4.

<Frame>![Multiple request header rows with filled Header name and Value fields](/images/docs/cdn/cdn-resource-options/http-headers/specify-http-headers-that-cdn-adds-to-requests-to-the-origin/specify-http-headers-that-cdn-adds-to-requests-to-the-origin-image5.png)</Frame>

6. Click **Save changes**.
