<p>When the same website content is available through both the origin domain and a [CDN&nbsp;custom&nbsp;domain](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn), web crawlers can discover and index both URLs. Block crawling on the CDN domain with a dedicated robots.txt response so that domain stays out of search results.</p>

<p>Create a [CDN&nbsp;rule](/cdn/cdn-resource-options/rules-for-particular-files/create-a-rule-manually-or-from-a-template-to-configure-settings-for-particular-files) that matches `/robots.txt` and returns a `Disallow: /` directive. The rule changes only that response, so other CDN URLs keep serving their configured content while compliant crawlers do not crawl them.</p>

## CDN domain crawling

<p>Open the resource and set the path, the status code, and the disallow body.</p>

<Steps>
  <Step title="Open the CDN resource">
    In the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com), navigate to **CDN** → **CDN resources** and click the CNAME of the resource.

    <Frame>![CDN resources list with CNAME links](/images/docs/cdn/cdn-resource-options/rules-for-particular-files/set-robots-txt-to-avoid-adding-to-index-by-web-crawlers/web-crawlers-10.png)</Frame>
  </Step>
  <Step title="Start a blank rule">
    1. Navigate to the **RULES** tab.
    2. Click **Create rule**.
    3. Select **Create blank rule**.
  </Step>
  <Step title="Set the name and path">
    1. In the **Rule name** field, enter `Block CDN crawling`.
    2. In the **Rule pattern** field, enter `^/robots\.txt$`.
  </Step>
  <Step title="Return the disallow text">
    1. Click **Add option**.
    2. Under **Content**, click **Add** next to **Status code**, then close the panel.
    3. In the **Status code** section, enable the **Set status code** option.
    4. In the **Status code** field, enter `200`.
    5. In the **URL or code text (optional)** field, enter:

    ```text
    User-agent: *\nDisallow: /\n
    ```

    6. Click **Create rule**.

    <Frame>![Create rule form with Status code section configured: status 200 and robots.txt disallow directive](/images/docs/cdn/cdn-resource-options/rules-for-particular-files/set-robots-txt-to-avoid-adding-to-index-by-web-crawlers/web-crawlers-20.png)</Frame>
  </Step>
</Steps>

<p>The origin website keeps serving its own files and its own robots.txt. Crawlers that request the origin domain follow that file, while the CDN rule applies only when the request uses the CDN custom domain.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Create a CDN rule for `/robots.txt` that returns a disallow directive. The exact `^/robots\.txt$` match limits the override to that path, so other responses stay as configured on the resource.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required, along with a CDN resource ID from [list&nbsp;CDN&nbsp;resources](/api-reference/cdn/cdn-resources/list-cdn-resources).
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_RESOURCE_ID}"
```

## Robots.txt rule

<p>Send `rule` `^/robots\.txt$` and `ruleType` `0`. Set `options.force_return` to status `200` and body `User-agent: *\nDisallow: /\n`, and leave `time_interval` out of the request.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    from gcore import Gcore

    client = Gcore()

    rule = client.cdn.cdn_resources.rules.create(
        12345,  # CDN resource ID
        name="Block CDN crawling",
        rule=r"^/robots\.txt$",
        rule_type=0,
        options={
            "force_return": {
                "enabled": True,
                "code": 200,
                "body": "User-agent: *\\nDisallow: /\\n",
            },
        },
    )
    print(rule.id, rule.rule, rule.options.force_return.body)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()

        rule, err := client.CDN.CDNResources.Rules.New(ctx, 12345, cdn.CDNResourceRuleNewParams{
            Name:     "Block CDN crawling",
            Rule:     `^/robots\.txt$`,
            RuleType: 0,
            Options: cdn.CDNResourceRuleNewParamsOptions{
                ForceReturn: cdn.CDNResourceRuleNewParamsOptionsForceReturn{
                    Enabled: true,
                    Code:    200,
                    Body:    "User-agent: *\\nDisallow: /\\n",
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(rule.ID, rule.Rule, rule.Options.ForceReturn.Body)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/rules" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Block CDN crawling",
        "rule": "^/robots\\.txt$",
        "ruleType": 0,
        "options": {
          "force_return": {
            "enabled": true,
            "code": 200,
            "body": "User-agent: *\\nDisallow: /\\n"
          }
        }
      }'
    ```

    <p>The API returns HTTP 201:</p>

    ```json
    {
      "id": 10001,
      "name": "Block CDN crawling",
      "rule": "^/robots\\.txt$",
      "ruleType": 0,
      "active": true,
      "options": {
        "force_return": {
          "enabled": true,
          "code": 200,
          "body": "User-agent: *\\nDisallow: /\\n",
          "time_interval": null
        }
      }
    }
    ```
  </Tab>
