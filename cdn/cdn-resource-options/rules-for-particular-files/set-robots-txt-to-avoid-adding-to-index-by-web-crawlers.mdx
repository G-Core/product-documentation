When a [CDN&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/create-a-cdn-resource) is set up for a website, its content becomes accessible from both the origin domain (e.g., website-example.com/image.png) and [CDN&nbsp;custom&nbsp;domains](/cdn/cdn-resource-options/general/create-and-set-a-custom-domain-for-the-content-delivery-via-cdn) (e.g., cdn.website-example.com/image.png). Search engines treat the same content at two different URLs as duplicate content, which degrades the site's search ranking. The [Status&nbsp;code](/cdn/cdn-resource-options/specify-custom-http-status-code-for-the-content-delivered-by-the-cdn) option on a CDN resource makes the custom domain return a robots.txt disallow directive to web crawlers, preventing this duplication.

## Block CDN domain indexing

The Status code option applies resource-wide — all URLs on the CDN custom domain return the configured status code and body text, which web crawlers interpret as a robots.txt disallow directive.

1\. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** → **CDN resources** and click the CNAME of the CDN resource to prohibit from indexing.


<Frame>![CDN resources list with CNAME links](/images/docs/cdn/cdn-resource-options/rules-for-particular-files/set-robots-txt-to-avoid-adding-to-index-by-web-crawlers/web-crawlers-10.png)</Frame>



The resource settings page opens.


<Frame>![CDN resource settings page with options navigation on the left](/images/docs/cdn/cdn-resource-options/rules-for-particular-files/set-robots-txt-to-avoid-adding-to-index-by-web-crawlers/web-crawlers-20.png)</Frame>



2\. Click **Content**, then **Status code**.

3\. In the **Status code** section, enable the **Set status code** option.

4\. In the **Status code** field, enter `200`.

5\. In the **URL or code text (optional)** field, enter the following directive:

```
User-agent: *\nDisallow: /\n
```

6\. Select **Save changes**.

Once configured, web crawlers receive a `Disallow: /` directive for the CDN domain and stop indexing it.

<Note>This configuration applies to all URLs on the CDN custom domain and does not affect the origin website.</Note>
