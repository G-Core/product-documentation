Geobalancer is available on paid CDN plans and limits which CDN regions deliver content. [Gcore&nbsp;Support](mailto:support@gcore.com) configures it at account level.

## Delivery regions

CDN edge servers are grouped into these regions:

- North America
- Latin America
- Asia
- Middle East
- Australia
- Africa
- Europe
- CIS
- World

World uses anycast addressing, so content can be served from any region in the global network when that region can deliver it most efficiently. When excluding specific regions, World must also be disabled — otherwise requests can still be served from excluded regions through anycast.

## Default location handler

Requests from disabled regions are routed to the default location handler, which can increase latency when clients are sent to a more distant enabled region. Any region still enabled for delivery can be selected as the handler.

The region selected as the default location handler cannot be disabled.

## Geobalancer configuration

Contact Gcore Support or use chat in the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com). Provide the regions to enable or disable and the preferred default location handler.
