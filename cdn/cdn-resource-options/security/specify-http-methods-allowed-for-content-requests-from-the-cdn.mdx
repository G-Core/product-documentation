<p>By default, a CDN resource accepts all standard HTTP methods. The **Enable HTTP methods** option restricts which methods the CDN accepts, returning `405 Method Not Allowed` for all others before the request reaches the origin.</p>

## Allowed HTTP methods

<p>To configure allowed HTTP methods:</p>

<p>1. Log in to the [Gcore Customer Portal](https://portal.gcore.com) and navigate to **CDN** > **CDN resources**.</p>

<p>2. Click the CNAME of the resource to open its settings.</p>

<Frame>
  <img src="/images/docs/cdn/cdn-resource-options/security/specify-http-methods-allowed-for-content-requests-from-the-cdn/specify-http-methods-image1.png" alt="CDN resources list with CNAME links" width="70%" />
</Frame>

<p>3. On the **OPTIONS** tab, scroll to **HTTP methods** and click the **Enable HTTP methods** toggle.</p>

<p>4. In the **Choose HTTP methods** field, add the methods the CDN should accept. Remove any method tag to block that method.</p>

<Frame>
  <img src="/images/docs/cdn/cdn-resource-options/security/specify-http-methods-allowed-for-content-requests-from-the-cdn/specify-http-methods-image2.png" alt="HTTP methods section with Enable HTTP methods toggle on and selected methods shown" width="70%" />
</Frame>

<p>5. Click **Save changes**.</p>

<p>For most static content delivery, GET and HEAD are sufficient. Allow POST as well if the resource serves dynamic requests, form submissions, or API calls.</p>

<p>6. Confirm a method that is not in the list:</p>

```bash
curl -I -X POST https://cdn.example.com/file.css
```

<p>The CDN returns `405 Method Not Allowed` and does not forward the request to the origin. A GET request is accepted, and its status is the origin response.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>When `allowedHttpMethods` is enabled, the CDN accepts only the methods in `value`, so any other method returns HTTP 405.</p>

<p>When the field is absent, the CDN does not apply this limit.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Export these variables. `CDN_RESOURCE_ID` is the `id` from [list&nbsp;CDN&nbsp;resources](/api-reference/cdn/cdn-resources/list-cdn-resources).</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_RESOURCE_ID}"
```

## HTTP methods

<p>`value` accepts `GET`, `HEAD`, `POST`, `PUT`, `PATCH`, `DELETE`, and `OPTIONS`. The names are case sensitive.</p>

<p>`GET` and `HEAD` cover static delivery. Add `POST` when the resource serves dynamic requests, form submissions, or API calls.</p>

<p>Both `enabled` and `value` are required. When `enabled` is true, an empty `value` returns HTTP 400.</p>

<p>The JSON field is `allowedHttpMethods`. The Python SDK attribute is `allowed_http_methods`.</p>

<p>Send `allowedHttpMethods` with `enabled` true and `value` set to `GET` and `HEAD`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    resource = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "allowed_http_methods": {"enabled": True, "value": ["GET", "HEAD"]},
        },
    )
    print(resource.options.allowed_http_methods.enabled, resource.options.allowed_http_methods.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        resource, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                AllowedHTTPMethods: cdn.CDNResourceUpdateParamsOptionsAllowedHTTPMethods{
                    Enabled: true,
                    Value:   []string{"GET", "HEAD"},
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(resource.Options.AllowedHTTPMethods.Enabled, resource.Options.AllowedHTTPMethods.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "allowedHttpMethods": {
            "enabled": true,
            "value": ["GET", "HEAD"]
          }
        }
      }'
    ```

    <p>The API returns HTTP 200:</p>

    ```json
    {
      "id": 12345,
      "options": {
        "allowedHttpMethods": {
          "enabled": true,
          "value": ["GET", "HEAD"]
        }
      }
    }
    ```
  </Tab>

  <MethodSection id="terraform" label="Terraform">

<p>Restrict the HTTP methods a CDN resource accepts with the [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2. When `allowed_http_methods` is enabled, the CDN accepts only the methods in `value`, so any other method returns `405 Method Not Allowed` before the request reaches the origin.</p>

<p>`value` accepts `GET`, `HEAD`, `POST`, `PUT`, `PATCH`, `DELETE`, and `OPTIONS`. The names are case sensitive. `GET` and `HEAD` cover static delivery. Add `POST` when the resource serves dynamic requests, form submissions, or API calls. An empty `value` while `enabled` is true returns HTTP 400 and the message `This list should not be empty while option is enabled.` Run `terraform apply` after editing `options`.</p>

## Allow GET and HEAD

<p>Set `enabled` to `true` and `value` to `GET` and `HEAD`. A client that sends another method receives `405 Method Not Allowed`.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    allowed_http_methods = {
      enabled = true
      value   = ["GET", "HEAD"]
    }
  }
}
```
