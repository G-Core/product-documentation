  <MethodSection id="portal" label="Customer Portal">

<p>HTTP to HTTPS redirect sends all HTTP requests for a CDN resource to HTTPS. The redirect can be turned on only after HTTPS is enabled and an SSL certificate is issued.</p>

## Enable the redirect

<p>1. Log in to the [Gcore Customer Portal](https://portal.gcore.com) and navigate to **CDN** > **CDN resources**. Open the resource.</p>

<p>2. On the **OPTIONS** tab, navigate to **General** > **SSL**.</p>

<p>3. If HTTPS isn't enabled for the resource, turn on **Enable HTTPS** and select **Free Let's Encrypt certificate** or **Custom SSL certificate**.</p>

   Let's Encrypt issuance takes up to 15 minutes. Certificate setup is covered in [SSL&nbsp;certificates](/cdn/ssl-certificates/add-an-ssl-certificate-to-deliver-content-over-https).

   <Frame>
     <img src="/images/docs/cdn/cdn-resource-options/security/set-up-a-redirect-from-http-to-https/set-up-a-redirect-from-http-to-https-image1.png" alt="SSL section with Enable HTTPS and Free Let's Encrypt certificate selected" width="70%" />
   </Frame>

<p>4. Navigate to **Access** > **Redirect HTTP to HTTPS**.</p>

<p>5. Turn on **Enable redirect HTTP to HTTPS** and click **Save changes**.</p>

   If the resource uses a custom CNAME, the SSL certificate must include that hostname.

   <Frame>
     <img src="/images/docs/cdn/cdn-resource-options/security/set-up-a-redirect-from-http-to-https/set-up-a-redirect-from-http-to-https-image2.png" alt="Access section with Redirect HTTP to HTTPS option" width="70%" />
   </Frame>

<Info>
The **Enable redirect HTTP to HTTPS** toggle stays disabled until HTTPS and a certificate are active.
</Info>

<p>6. Confirm the redirect:</p>

   ```bash
   curl -I http://cdn.example.com/path/file.css
   ```

   <p>The response includes a `Location` header with the same path on HTTPS.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>Send HTTP requests for a CDN resource to HTTPS. HTTPS must already be enabled and an SSL certificate must already be attached. With either missing, the API returns HTTP 400 and the message `You cannot enable redirect HTTP to HTTPS when HTTPS is disabled. Please enable HTTPS and add SSL certificate first`.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is visible under **CDN** → **CDN Resources**, or from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

<p>A [resource&nbsp;update](/api-reference/cdn/cdn-resources/change-cdn-resource) sets `options.redirect_http_to_https`. That option and `redirect_https_to_http` cannot be enabled at the same time.</p>

<p>Open a terminal and export the required variables:</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Enable the redirect

<p>Set `enabled` and `value` to `true`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"redirect_http_to_https": {"enabled": True, "value": True}},
    )
    redirect = updated.options.redirect_http_to_https
    print(redirect.enabled, redirect.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                RedirectHTTPToHTTPS: cdn.CDNResourceUpdateParamsOptionsRedirectHTTPToHTTPS{
                    Enabled: true,
                    Value:   true,
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.RedirectHTTPToHTTPS.Enabled, updated.Options.RedirectHTTPToHTTPS.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "redirect_http_to_https": {
            "enabled": true,
            "value": true
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": true
    }
    ```
  </Tab>
</Tabs>

## Turn the redirect off

<p>Set `enabled` and `value` to `false`. The Go SDK omits a `false` boolean, so that call sends the JSON object explicitly.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"redirect_http_to_https": {"enabled": False, "value": False}},
    )
    redirect = updated.options.redirect_http_to_https
    print(redirect.enabled, redirect.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "encoding/json"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
        "github.com/G-Core/gcore-go/packages/param"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                RedirectHTTPToHTTPS: param.Override[cdn.CDNResourceUpdateParamsOptionsRedirectHTTPToHTTPS](
                    json.RawMessage(`{"enabled":false,"value":false}`),
                ),
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.RedirectHTTPToHTTPS.Enabled, updated.Options.RedirectHTTPToHTTPS.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "redirect_http_to_https": {
            "enabled": false,
            "value": false
          }
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": false,
      "value": false
    }
    ```
  </Tab>
</Tabs>

  <MethodSection id="terraform" label="Terraform">

<p>Send HTTP requests for a CDN resource to HTTPS with the [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2. The configuration enables HTTPS, attaches an SSL certificate, and sets `redirect_http_to_https`. An HTTP request receives HTTP 301, and the `Location` header keeps the same path on HTTPS.</p>

<p>The certificate includes the CDN hostname in its SAN extension. Set `validate_root_ca` to `false` for a self-signed certificate. `ssl_certificate_wo` is the certificate chain and `ssl_private_key_wo` is the private key. The PEM layout is on the [SSL&nbsp;certificate](/cdn/ssl-certificates/configure-your-own-ssl-certificate) page. Enabling `redirect_https_to_http` while `redirect_http_to_https` is enabled returns HTTP 400 and the message `You should enable only one option from [redirect_http_to_https, redirect_https_to_http] list`, so leave `redirect_https_to_http` unset. Run `terraform apply` after editing `options`.</p>

## Enable the redirect

<p>Set `enabled` and `value` to `true`. The CDN answers the HTTP request with HTTP 301 and a `Location` header for the same path on HTTPS.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_certificate" "example" {
  name                       = "cdn-certificate"
  automated                  = false
  ssl_certificate_wo         = file("fullchain.pem")
  ssl_private_key_wo         = file("privkey.pem")
  ssl_certificate_wo_version = 1
  validate_root_ca           = false
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"
  ssl_enabled     = true
  ssl_data        = gcore_cdn_certificate.example.id

  options = {
    redirect_http_to_https = {
      enabled = true
      value   = true
    }
  }
}
```

## Turn the redirect off

<p>Set `enabled` and `value` to `false` and run `terraform apply`. The HTTP response no longer redirects to HTTPS.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_certificate" "example" {
  name                       = "cdn-certificate"
  automated                  = false
  ssl_certificate_wo         = file("fullchain.pem")
  ssl_private_key_wo         = file("privkey.pem")
  ssl_certificate_wo_version = 1
  validate_root_ca           = false
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"
  ssl_enabled     = true
  ssl_data        = gcore_cdn_certificate.example.id

  options = {
    redirect_http_to_https = {
      enabled = false
      value   = false
    }
  }
}
```
