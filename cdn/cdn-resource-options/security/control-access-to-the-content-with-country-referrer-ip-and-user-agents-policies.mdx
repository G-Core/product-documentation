<p>Country, referrer, IP, and user agent policies limit which requests a CDN resource accepts. The list on each policy is the set of exceptions to the selected mode.</p>

## Access policies

<p>**Allow by default** accepts every request except the listed values, while **Block by default** accepts only the listed values.</p>

<Steps>
  <Step title="Open Access">
    In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN**:

    1. Open the resource.
    2. Select **Access**.
  </Step>
  <Step title="Set the policy mode">
    Turn on the policy, then select **Allow by default** or **Block by default**.
  </Step>
  <Step title="Save the resource">
    Click **Save changes**.
  </Step>
</Steps>

### Referrer

<p>A referrer policy checks the domain that sent the request. Turn on **Enable referrer access policy**.</p>

<Frame>![Referrer access policy with Allow by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-referrer-access-policy.png)</Frame>

<Frame>![Referrer access policy with Block by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-referrer-access-policy-block.png)</Frame>

<p>Enter a domain or a wildcard, with no scheme:</p>

* `www.domain.com` matches that domain
* `*.domain.com` matches every subdomain of domain.com

### Country

<p>Unlike a referrer, a country policy checks where the request comes from. Turn on **Enable country access policy**.</p>

<Frame>![Country access policy with Allow by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-country-access.png)</Frame>

<Frame>![Country access policy with Block by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-country-access-block.png)</Frame>

<p>The **Choose a country** field takes a two-letter uppercase ISO 3166-1 alpha-2 code.</p>

### IP address

<p>An IP policy checks the client address, and it accepts both IPv4 and IPv6. Turn on **Enable IP access policy**.</p>

<Frame>![IP access policy with Allow by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-ip-access-policy.png)</Frame>

<Frame>![IP access policy with Block by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-ip-access-policy-block.png)</Frame>

<p>Enter an address with a prefix in **IP with a subnet mask**. The CDN stores it as a network address, so `192.168.3.2` becomes `192.168.3.2/32`.</p>

### User agent

<p>A user agent policy checks the User-Agent header, and it also accepts an empty value or a pattern. Turn on **Enable user agents policy**.</p>

<Frame>![User agents policy with Block by default selected](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-user-agents-policy.png)</Frame>

<p>The **User-Agent** field accepts an **Empty value**, an exact string of at most 220 characters, or a pattern. **Empty value** matches a request that sends no User-Agent header.</p>

<Frame>![Empty value in the User-Agent field](/images/docs/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies/cdn-user-agents-policy-empty.png)</Frame>

<p>A pattern starts with `~` for case-sensitive matching, or with `~*` for case-insensitive matching. Select at least one entry, and allow 15 minutes for the change to take effect.</p>

</MethodSection>
  <MethodSection id="api" label="REST API">

<p>`country_acl`, `referrer_acl`, `ip_address_acl`, and `user_agent_acl` limit which requests a CDN resource accepts.</p>

<p>When `policy_type` is `allow`, every request is accepted except the values in `excepted_values`, while `deny` accepts only those values.</p>

<p>`allow` matches **Allow by default**, while `deny` matches **Block by default**.</p>

<p>`policy_type` accepts `allow` or `deny`, and any other value, including `block`, returns HTTP 400.</p>

<p>`enabled`, `policy_type`, and `excepted_values` are required. An empty `excepted_values` list returns HTTP 400.</p>

<p>Omit a field to leave that policy unset.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required.
</Info>

<p>Export these variables. `CDN_RESOURCE_ID` is the `id` from [list&nbsp;CDN&nbsp;resources](/api-reference/cdn/cdn-resources/list-cdn-resources).</p>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_RESOURCE_ID}"
```

## Policy values

<p>The four objects share `enabled`, `policy_type`, and `excepted_values`. Only the contents of `excepted_values` change.</p>

### Country codes

<p>`excepted_values` takes two-letter uppercase country codes, so `DE` is stored, while `de` and `USA` return HTTP 400.</p>

<p>Send `country_acl` with `policy_type` `allow` and `excepted_values` set to `DE`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    resource = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "country_acl": {
                "enabled": True,
                "policy_type": "allow",
                "excepted_values": ["DE"],
            },
        },
    )
    print(
        resource.options.country_acl.enabled,
        resource.options.country_acl.policy_type,
        resource.options.country_acl.excepted_values,
    )
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        resource, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                CountryACL: cdn.CDNResourceUpdateParamsOptionsCountryACL{
                    Enabled:        true,
                    PolicyType:     "allow",
                    ExceptedValues: []string{"DE"},
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(resource.Options.CountryACL.Enabled, resource.Options.CountryACL.PolicyType, resource.Options.CountryACL.ExceptedValues)
    }
    ```

    ```bash
      }'
    ```

<p>`none` together with a domain is stored, while a list that contains only `none` returns HTTP 400.</p>

<p>Send `referrer_acl` with `policy_type` `deny` and a wildcard in `excepted_values`.</p>

### User agent strings

<p>A user agent value can be an exact string, an empty string, or a pattern, unlike the names and addresses above.</p>

<p>A pattern starts with `~` for case-sensitive matching, or with `~*` for case-insensitive matching. Each value can contain at most 220 characters, so a value of 221 characters returns HTTP 400.</p>

<p>Send `user_agent_acl` with `policy_type` `deny` and `excepted_values` set to an empty string and `~*mozilla.*`.</p>

  <MethodSection id="terraform" label="Terraform">

<p>Limit which requests a CDN resource accepts with the [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2. When `policy_type` is `allow`, every request is accepted except the values in `excepted_values`, while `deny` accepts only those values. An empty `excepted_values` list returns HTTP 400 and the message `This list may not be empty.` Run `terraform apply` after editing `options`.</p>

## Access policy values

<p>The four objects use `enabled`, `policy_type`, and `excepted_values`. `country_acl` set to `allow` with `DE` accepts every country except `DE`, while `referrer_acl` set to `deny` accepts only the wildcard in `excepted_values`, and that value has no URL scheme. `ip_address_acl` set to `allow` with `192.168.3.2/32` accepts every address except that network, and a host address without a prefix is stored with `/32`, so `192.168.3.2` becomes `192.168.3.2/32`. `user_agent_acl` set to `deny` with an empty string and `~*mozilla.*` accepts a missing User-Agent header and a case-insensitive match of `mozilla.*`.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    country_acl = {
      enabled         = true
      policy_type     = "allow"
      excepted_values = ["DE"]
    }

    referrer_acl = {
      enabled         = true
      policy_type     = "deny"
      excepted_values = ["*.example.com"]
    }

    ip_address_acl = {
      enabled         = true
      policy_type     = "allow"
      excepted_values = ["192.168.3.2/32"]
    }

    user_agent_acl = {
      enabled         = true
      policy_type     = "deny"
      excepted_values = ["", "~*mozilla.*"]
    }
  }
}
```
