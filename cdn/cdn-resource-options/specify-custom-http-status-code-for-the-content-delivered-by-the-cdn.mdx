<p>The **Set status code** option returns a custom HTTP response for a CDN resource instead of the file from the origin. The response can be a short text or a redirect, and an **Apply from** and **Until** range limits the status to certain hours.</p>

<p>From 22:00 to 06:00, Gcore CDN can return 403 or redirect to another page, and deliver the original file outside that interval.</p>

## Status code

<p>In the [Gcore Customer Portal](https://portal.gcore.com), **Resource settings** return the status for every request on the CDN resource, and **Rules** return it only for requests that match the rule pattern.</p>

  <MethodSection id="api" label="REST API">

<p>Gcore CDN can answer a request with a chosen HTTP status instead of the file from the origin. The option is `force_return`. The response can include a short text or send the viewer to another URL.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is the `id` from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Return a status code

<p>Answer every request with status 403 and the text Forbidden.</p>

<p>`enabled`, `code`, and `body` are required. `body` is text or a redirect URL, and a value longer than 255 characters returns HTTP 400. A code below 100, above 599, or one of 408, 444, 477, 494, 495, 496, 497, and 499 returns HTTP 400.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"force_return": {"enabled": True, "code": 403, "body": "Forbidden"}},
    )
    saved = updated.options.force_return
    print(saved.enabled, saved.code, saved.body)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                ForceReturn: cdn.CDNResourceUpdateParamsOptionsForceReturn{
                    Enabled: true,
                    Code:    403,
                    Body:    "Forbidden",
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.ForceReturn.Enabled, updated.Options.ForceReturn.Code, updated.Options.ForceReturn.Body)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "force_return": {"enabled": true, "code": 403, "body": "Forbidden"}
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "code": 403,
      "body": "Forbidden"
    }
    ```
  </Tab>
</Tabs>

## Limit the status to certain hours

<p>Return 403 with the text Forbidden only from 22:00 to 06:00 in Europe/Luxembourg. Times use `HH:MM`. When `time_zone` is omitted, the API stores `UTC`. Omitting `time_interval`, or sending it as `null`, stores no schedule.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "force_return": {
                "enabled": True,
                "code": 403,
                "body": "Forbidden",
                "time_interval": {
                    "start_time": "22:00",
                    "end_time": "06:00",
                    "time_zone": "Europe/Luxembourg",
                },
            }
        },
    )
    saved = updated.options.force_return
    print(saved.code, saved.time_interval.start_time, saved.time_interval.end_time, saved.time_interval.time_zone)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"

    )

        client := gcore.NewClient()

            panic(err)
        }

            Options: cdn.CDNResourceUpdateParamsOptions{

                    Code:    403,
                    Body:    "Forbidden",
    ```

## Remove the status code

<p>Send `force_return` as JSON `null` to remove the option. The next read returns `null`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"force_return": None},
    )
    print(updated.options.force_return)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        options := cdn.CDNResourceUpdateParamsOptions{}
        options.SetExtraFields(map[string]any{
            "force_return": nil,
        })
        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: options,
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.ForceReturn.RawJSON())
    }
    ```
  </Tab>

    ```bash
      -d '{
        "options": {
          "force_return": null
        }
      }'
    ```

    ```json
    null
    ```

## Return the status for one path

<p>A resource rule returns 403 for requests under `/restricted/`. `ruleType` `0` is a regular expression and must start with `^/` or `/`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    rule = client.cdn.cdn_resources.rules.create(
        resource_id,
        name="status-restricted",
        rule="^/restricted/.*",
        rule_type=0,
        options={"force_return": {"enabled": True, "code": 403, "body": "Forbidden"}},
    )
    print(rule.id, rule.options.force_return.code, rule.options.force_return.body)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        rule, err := client.CDN.CDNResources.Rules.New(ctx, resourceID, cdn.CDNResourceRuleNewParams{
            Name:     "status-restricted",
            Rule:     "^/restricted/.*",
            RuleType: 0,
            Options: cdn.CDNResourceRuleNewParamsOptions{
                ForceReturn: cdn.CDNResourceRuleNewParamsOptionsForceReturn{
                    Enabled: true,
                    Code:    403,
                    Body:    "Forbidden",
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(rule.ID, rule.Options.ForceReturn.Code, rule.Options.ForceReturn.Body)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X POST "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID/rules" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "status-restricted",
        "rule": "^/restricted/.*",
        "ruleType": 0,
        "options": {
          "force_return": {"enabled": true, "code": 403, "body": "Forbidden"}
        }
      }'
    ```

    <p>The API returns HTTP 201. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "code": 403,
      "body": "Forbidden"
    }
    ```

<p>The [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2 returns a chosen HTTP status instead of the file from the origin. `body` holds the response text or a URL. Run `terraform apply` after editing `options`.</p>

## Return a status code

<p>Gcore CDN answers every request with status 403 and the text Forbidden. Set `enabled` to `true`. `code` and `body` are required. Codes 408, 444, 477, 494, 495, 496, 497, and 499 are not accepted.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    force_return = {
      enabled = true
      code    = 403
      body    = "Forbidden"
    }
  }
}
```

## Limit the status to certain hours

<p>Return 403 with the text Forbidden from 22:00 to 06:00 in Europe/Luxembourg. Times use `HH:MM`. When `time_zone` is omitted, the saved schedule uses `UTC`. An apply that omits `time_interval` keeps a schedule that is already saved. An API request that omits `time_interval` clears the schedule.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id

    force_return = {
      enabled = true
      code    = 403
      body    = "Forbidden"
      time_interval = {
        start_time = "22:00"
        end_time   = "06:00"
        time_zone  = "Europe/Luxembourg"
      }
    }
  }
}
```

## Return the status for one path

<p>A resource rule returns 403 for requests under `/restricted/`. The resource block is the CDN resource the rule belongs to. `rule_type` `0` is a regular expression.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"
}

resource "gcore_cdn_resource_rule" "example" {
  resource_id = gcore_cdn_resource.example.id
  name        = "status-restricted"
  rule        = "^/restricted/.*"
  rule_type   = 0

  options = {
    force_return = {
      enabled = true
      code    = 403
      body    = "Forbidden"
    }
  }
}
```
