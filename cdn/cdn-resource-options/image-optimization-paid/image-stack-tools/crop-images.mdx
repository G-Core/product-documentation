<p>Crop is a feature that trims original JPG or PNG images before delivery over the CDN. Add [crop&nbsp;query&nbsp;parameters](#crop-parameters) to image URLs in the website source code to specify the target area and its location. When a user requests a webpage, the CDN returns it with cropped images.</p>

<p>An origin server hosts a 750×1150 px image. With Crop configured, the CDN delivers a 500×400 cropped version to end users while the original 750×1150 image remains on the origin.</p>

## Enable the crop feature

<p>Crop is part of the paid Image Stack option. Image Stack also supports converting images to WebP or AVIF, resizing, and adjusting quality. To use Crop, activate Image Stack following the [Enable&nbsp;Image&nbsp;Stack](/cdn/cdn-resource-options/image-optimization-paid/enable-image-stack) guide.</p>

## Use crop

<p>1. Open the website source code.</p>

<p>2. Find the strings with the URLs of the images to crop.</p>

<p>3. Add the query strings to the URLs of the images as follows:</p>

```
image.jpg?parameter=values 
```


<p>where `image.jpg` is the image URL on the website. The [Crop&nbsp;parameters](#crop-parameters) section lists all available parameters.</p>

<p>4. Save the changes in the website source code.</p>

<p>After saving, the CDN delivers cropped images to users requesting the webpage.</p>

## Crop parameters

<p>Crop cuts out a section of an original image for delivery to users. Append a query string to the image URL to specify the target area and its location.</p>

### Crop an image by customizing its aspect ratio

<p>**Parameter:** `?crop=16:9`</p>

<p>where:</p>

  * `16` = the width component of the target aspect ratio
  * `9` = the height component of the target aspect ratio



<p>The tool crops an image evenly to fit the specified aspect ratio.</p>

<p>**Example.** An origin server hosts a 400×300 image with a 4:3 aspect ratio. To illustrate this, a grid has been placed on the picture.</p>


<Frame>![Crop an image by customizing its aspect ratio](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474366609.png)</Frame>



<p>Set a new aspect ratio (4:5) by adding the query parameter to the image URL:</p>
    
    
```
img.jpg?crop=4:5
```

<p>The tool selects a section with this aspect ratio at the center of the original image.</p>


<Frame>![Crop an image by customizing its aspect ratio](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474389521.png)</Frame>



<p>Then it cuts off the unwanted parts. The resulting image looks as follows:</p>


<Frame>![Crop an image by customizing its aspect ratio](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029483306129.png)</Frame>



<p>How the tool defines what to crop:</p>

<p>It compares the values in the aspect ratio (4 and 5, in this example) and chooses the greater one (5). This determines which side of the original image is not cropped. The value 5 corresponds to the height, so the height remains the same: 300 px.</p>

<p>It calculates the width to fit the aspect ratio by multiplying the original height by the ratio of 4:5: 300 × (4/5) = 240 px.</p>

<p>It places a 240×300 area at the center of the original image and crops it.</p>

### Crop an image at its center

<p>**Parameter:** `?crop=300,200`</p>

<p>where:</p>

  * `300` = the target width
  * `200` = the target height



<p>The tool keeps the target area at the center and cuts off the unwanted parts.</p>

<p>**Example.** An origin server hosts a 400×300 image. To keep only a 200×100 section at the center, add the desired parameter to the image URL:</p>
    
```
img.jpg?crop=200,100
```

<Frame>![Crop an image at its center](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029483307409.png)</Frame>



<p>The tool crops a 200×100 area from the center. The resulting image looks as follows:</p>


<Frame>![Crop an image at its center](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029483406225.png)</Frame>



### Crop from a specific location

<p>To cut out a section from a specific location, add the target width and height parameters (`?crop=(width),(height)`) and then the location of the section. The location can be specified in four ways, described in the subsections below.</p>

#### Specify a location with two offsets measured in pixels

<p>**Parameter:** `?crop=300,200,x100,y50`</p>

<p>where:</p>

  * `300` = the target width
  * `200` = the target height
  * `100` = the number of pixels to offset from the original left side
  * `50` = the number of pixels to offset from the original top


<p>The tool positions the target area so that its upper-left corner is at the specified coordinate, then cuts out the section.</p>

<p>**Example.** An origin server hosts a 400×300 image; the goal is to cut out a 200×100 section with the dog's muzzle.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474628113.png)</Frame>



<p>To crop an image, add the query parameter to the URL:</p>
    
```
img.jpg?crop=200,100,x107,y30
```

<p>Before being delivered to an end user, the image goes through the following conversions:</p>

<p>1. The target area is 200×100 (`crop=200,100`), so the tool selects this area in the picture.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474783121.png)</Frame>



<p>2. The coordinates of the starting point are 107 px from the left side and 30 pixels from the top (`x107,y30`). The tool drags the target area so that its upper-left corner is at this point.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474833169.png)</Frame>



<p>3. The tool cuts out the section. The cropped image looks as follows:</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474904721.png)</Frame>



#### Specify a location using two coordinates measured as a percentage of the original image

<p>**Parameter:** `?crop=300,200,x25p,y10p`</p>

<p>where:</p>

  * `300` = the target width
  * `200` = the target height
  * `25` = the percent of the original width to offset from the left side
  * `10` = the percent of the original height to offset from the top


<p>The tool positions the target area so that its upper-left corner is at the specified coordinate, then cuts out the section.</p>

<p>**Example.** An origin server hosts a 400×300 image; the goal is to cut out a 200×100 section with the dog's muzzle.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029483676177.png)</Frame>



<p>To crop an image, add the query parameter to the URL:</p>
    
```
img.jpg?crop=200,100,x25p,y10p
```

<p>Before being delivered to an end user, the image goes through the following conversions:</p>

<p>1. The target area is 200×100 (`crop=200,100`), so the tool selects this area in the picture.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475042705.png)</Frame>



<p>2. The starting point for cropping (`x25p,y10p`): offset 25% of the original width from the left side and 10% of the original height from the top. The tool drags the target area so that its upper-left corner is at this point.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475091729.png)</Frame>



<p>3. Then it cuts out the section. The cropped image looks as follows:</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029474904721.png)</Frame>



#### Specify a location using the ratio of unwanted areas

<p>**Parameter:** `?crop=300,200,offset-x20,offset-y40`</p>

<p>where:</p>

  * `300` = the target width
  * `200` = the target height
  * `20` = the percent of the unwanted width that should be cropped from the left side
  * `40` = the percent of the unwanted height that should be cropped from the top



<p>The tool positions the target area so that the specified percentage of unwanted area remains on the left and on the top, then crops the image.</p>

<p>**Example.** An origin server hosts a 400×300 image; the goal is to cut out a 100×100 section with the dog's paws.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029483884945.png)</Frame>



<p>To crop the image, add the query parameter to the URL:</p>
    
```
img.jpg?crop=100,100,offset-x50,offset-y81
```

<p>Before being delivered to an end user, the image goes through the following conversions:</p>

<p>1. The target area is 100×100 (`crop=100,100`). The tool selects the target area in the picture.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475244561.png)</Frame>



<p>2. The tool drags the target area to the right until 50% of the unwanted width remains on the left (`offset-x50`). Accordingly, 50% of the unwanted area remains on the right.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029484044049.png)</Frame>



<p>3. It moves the target area down until 81% of the unwanted height remains on the top (`offset-y81`). Accordingly, 19% of the unwanted height remains at the bottom.</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475395345.png)</Frame>



<p>4. The tool cuts out the target area. The cropped image looks as follows:</p>


<Frame>![Crop a section of an original image from a specific location](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475474321.png)</Frame>



#### Specify a location using one offset measured in pixels and one coordinate measured as a percentage of the original image

<p>The previous options can be combined to crop an original image from a specific place — set the horizontal coordinate in pixels and the percentage of unwanted vertical area, or vice versa.</p>

<p>Examples of combined query parameters:</p>

  * `?crop=width,height,x(x-axis value),offset-y(percentage of unwanted area to be cropped from the top)`
  * `?crop=width,height,offset-x(percentage of unwanted area to be cropped from the left),y(y-axis value)`
  * `?crop=width,height,x(percentage of original image width from the left),offset-y(percentage of unwanted area to be cropped from the top)`



<p>The cropping behavior for combined parameters follows the same rules as the individual options above.</p>

## Check HTTP headers

<p>Check the HTTP response headers to verify that the crop was applied. The `X-Img-Operations` header lists all conversions performed. If the value includes `crop`, the image has been cropped.</p>


<Frame>![Check HTTP headers](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475507985.png)</Frame>



<p>If `X-Img-Operations` does not include `crop` and the CDN returns the original uncropped image, check the `img-skip-reason` header. This explains why the conversion failed.</p>


<Frame>![Check HTTP headers](/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/crop-images/11029475548049.png)</Frame>

## Turn Image Stack on

<p>Gcore CDN reads `crop` from the image URL only when Image Stack is enabled. A `crop` key inside `image_stack` is not stored.</p>

<p>`enabled` is required. This call sets `quality` to 80 and turns WebP on. Send every field that should stay set, because a field left out of the request is stored as its default.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={
            "image_stack": {
                "enabled": True,
                "quality": 80,
                "webp_enabled": True,
                "avif_enabled": False,
                "png_lossless": False,
            }
        },
    )
    saved = updated.options.image_stack
    print(saved.enabled, saved.quality, saved.webp_enabled, saved.avif_enabled, saved.png_lossless)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                ImageStack: cdn.CDNResourceUpdateParamsOptionsImageStack{
                    Enabled:     true,
                    Quality:     gcore.Int(80),
                    WebpEnabled: gcore.Bool(true),
                    AvifEnabled: gcore.Bool(false),
                    PngLossless: gcore.Bool(false),
                },
            },
        })
        if err != nil {
            panic(err)
        }
        saved := updated.Options.ImageStack
        fmt.Println(saved.Enabled, saved.Quality, saved.WebpEnabled, saved.AvifEnabled, saved.PngLossless)
    }
    ```

## Crop the image URL

<p>`crop` is not an API field. Add it to the image URL:</p>

```
image.jpg?crop=16:9
image.jpg?crop=300,200
image.jpg?crop=300,200,x100,y50
image.jpg?crop=300,200,x25p,y10p
image.jpg?crop=300,200,offset-x20,offset-y40
```

<p>`16:9` keeps that aspect ratio at the center. `300,200` is the width and height, also from the center. `x100,y50` and `x25p,y10p` place the top-left corner in pixels or as a percent of the original. `offset-x20,offset-y40` leaves that percent of the trimmed-away area on the left and on the top.</p>
