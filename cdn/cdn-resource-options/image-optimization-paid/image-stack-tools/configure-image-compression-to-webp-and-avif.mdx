<p>Compression converts JPG and PNG images to WebP or AVIF format during CDN delivery, reducing file size without visible quality loss. WebP and AVIF use advanced compression algorithms — the painting by Wassily Kandinsky below demonstrates: sharpness and color rendering are the same across formats, but the WebP and AVIF files are smaller.</p>

<p>To apply compression, configure it in the [Gcore Customer Portal](https://portal.gcore.com) or add the `fmt` query string to individual image URLs.</p>

## Enable compression

<p>Compression is part of the paid Image Stack option, which also supports resizing, cropping, and quality adjustment. Before enabling compression, activate Image Stack — [Enable&nbsp;Image&nbsp;Stack](/cdn/cdn-resource-options/image-optimization-paid/enable-image-stack).</p>

## Use compression

<p>Two methods are available: the Gcore Customer Portal and query strings. The portal method applies compression to all images matching the rule's URL pattern. The query string method applies compression per individual image URL.</p>

### Use compression in the customer portal

<p>1. Navigate to **Rules** in the CDN resource and open the **Image optimization** rule.</p>

<Frame><img src="/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/configure-image-compression-to-webp-and-avif/configure-image-compression-image1.png" alt="Rules list showing the Image optimization rule" width="70%"/></Frame>

<p>2. Select **Enable WebP compression** and/or **Enable AVIF compression**. When both are enabled, the format is chosen based on browser support — browsers that support both receive AVIF.</p>

<Frame><img src="/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/configure-image-compression-to-webp-and-avif/configure-image-compression-image2.png" alt="Image Stack settings with Enable WebP compression and Enable AVIF compression checkboxes" width="70%"/></Frame>

<p>3. Click **Save changes** at the top right of the page. Saving the Image Stack rule clears the resource cache, and CDN servers request the images from the origin. Enable [Origin&nbsp;Shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding) first, or save the change during low-traffic hours.</p>

<p>Images are served in WebP or AVIF format to supported browsers.</p>

### Use compression via query parameters

<p>1. Open the website source code.</p>

<p>2. Find the URLs of the images to convert.</p>

<p>3. Add a query string to each image URL:</p>

```
image.jpg?fmt=value
```

<p>where `value` is one of:</p>

- `webp` — converts to WebP format
- `avif` — converts to AVIF format
- `avif,webp` — converts to WebP or AVIF based on browser support: `image.jpg?fmt=avif,webp`

<p>4. Save the changes. Images are served in the configured format.</p>

## Check HTTP headers

<p>After converting, an image does not change its URL or extension. Use the HTTP response headers to verify the conversion.</p>

<p>The `X-Img-Operations` header reflects all the conversions performed. If the value includes `convert`, the image format has been converted.</p>

<p>The `Content-Type` header shows the compression format. The value `image/webp` or `image/avif` confirms the image is in the new format.</p>

<Frame><img src="/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/configure-image-compression-to-webp-and-avif/11028965537425.png" alt="X-Img-Operations and Content-Type headers in a CDN response showing successful WebP conversion" width="70%"/></Frame>

<p>If the `X-Img-Operations` header contains no convert value and the CDN returns the original image, inspect the `Img-Skip-Reason` HTTP header for the skip reason. The value `converted image bigger than origin value` means the configured quality exceeds the source image quality — lower the quality setting in [Change&nbsp;image&nbsp;quality](/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/change-image-quality).</p>

<Frame><img src="/images/docs/cdn/cdn-resource-options/image-optimization-paid/image-stack-tools/configure-image-compression-to-webp-and-avif/11028973043857.png" alt="Img-Skip-Reason header showing why the image conversion was skipped" width="70%"/></Frame>

## Set WebP and AVIF for image paths

<p>A rule stores the compression choice for paths that match `/.*\.(jpg|jpeg|png)`. `ruleType` 0 is a regular expression and must start with `^/` or `/`.</p>

<p>`enabled` is required. This call turns WebP and AVIF on, sets `quality` to 80, and leaves `png_lossless` off.</p>

<p>A field left out of the request is stored as its default, so send every field that should stay set. The JSON field is `image_stack`; `imageStack` is ignored.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    rule = client.cdn.cdn_resources.rules.create(
        resource_id,
        name="image-compression",
        rule="/.*\\.(jpg|jpeg|png)",
        rule_type=0,
        options={
            "image_stack": {
                "enabled": True,
                "quality": 80,
                "webp_enabled": True,
                "avif_enabled": True,
                "png_lossless": False,
            }
        },
    )
    saved = rule.options.image_stack
    print(rule.id, saved.enabled, saved.quality, saved.webp_enabled, saved.avif_enabled, saved.png_lossless)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        rule, err := client.CDN.CDNResources.Rules.New(ctx, resourceID, cdn.CDNResourceRuleNewParams{
            Name:     "image-compression",
            Rule:     "/.*\\.(jpg|jpeg|png)",
            RuleType: 0,
            Options: cdn.CDNResourceRuleNewParamsOptions{
                ImageStack: cdn.CDNResourceRuleNewParamsOptionsImageStack{
                    Enabled:     true,
                    Quality:     gcore.Int(80),
                    WebpEnabled: gcore.Bool(true),
                    AvifEnabled: gcore.Bool(true),
                    PngLossless: gcore.Bool(false),
                },
            },
        })
        if err != nil {
            panic(err)
        }
        saved := rule.Options.ImageStack
        fmt.Println(rule.ID, saved.Enabled, saved.Quality, saved.WebpEnabled, saved.AvifEnabled, saved.PngLossless)
    }
    ```

## Set the format on one image URL

<p>`fmt` is not an API field. A `fmt` key inside `image_stack` is not stored. Add `fmt` to the image URL:</p>

```
image.jpg?fmt=webp
image.jpg?fmt=avif
image.jpg?fmt=avif,webp
```

<p>`webp` converts the image to WebP. `avif` converts it to AVIF. `avif,webp` follows browser support, and a browser that accepts both receives AVIF.</p>

## Check the delivered image

<p>After converting, the image URL and file extension stay the same. The `X-Img-Operations` header lists the conversions. If the value includes `convert`, the image format changed. `Content-Type` is `image/webp` or `image/avif` for the new format.</p>

<p>If `X-Img-Operations` does not contain `convert` and the CDN returns the original image, the `Img-Skip-Reason` header explains the skip. The value `converted image bigger than origin value` means the configured quality is higher than the original image quality.</p>

## Set WebP and AVIF for image paths

<p>A rule stores the compression choice for paths that match `/.*\.(jpg|jpeg|png)`. `rule_type` 0 is a regular expression and must start with `^/` or `/`. Set `enabled`, `quality` to 80, WebP on, AVIF on, and `png_lossless` off, then run `terraform apply`. A field left out of the object is stored as its default, so an omitted `quality` becomes 95 and omitted flags become false.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"
}

resource "gcore_cdn_resource_rule" "images" {
  resource_id = gcore_cdn_resource.example.id
  name        = "image-compression"
  rule        = "/.*\\.(jpg|jpeg|png)"
  rule_type   = 0

  options = {
    image_stack = {
      enabled      = true
      quality      = 80
      webp_enabled = true
      avif_enabled = true
      png_lossless = false
    }
  }
}
```
