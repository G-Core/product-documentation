<p>Large File Delivery Optimization is designed for CDN resources that serve files larger than 10 MB. When enabled, Gcore CDN requests content from the origin in 10 MB chunks using HTTP range requests, caches each chunk independently, and assembles the response from the cached portions.</p>

<p>A range request includes the `Range` HTTP header to indicate the byte or part of the content to be returned. If the request has a `Range: bytes=123537047-123545047` header, the CDN requests a 10 MB chunk (10,485,760 bytes, range 115343360-125829119) from the origin, caches this chunk, and serves the requested range (123537047-123545047) to the end user.</p>

<p>For this option to work, the origin server must support range requests.</p>

## Configuration guidelines

<p>Large File Delivery Optimization is set in Resource settings in the steps below. A rule can apply it to one path. Review these requirements and recommendations before configuring the option:</p>

  * The origin server must support HTTP Range Requests.
  * The `Content-Length` and `Etag` headers must be consistent across the origin.
  * When enabled in Resource settings, the option applies to all content in the CDN resource, which can increase the load on the origin. Consider activating [Origin&nbsp;Shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding) before enabling this feature, or enable it during off-peak hours.
  * Remember to [purge&nbsp;the&nbsp;cache](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) after enabling Large File Delivery Optimization.
  * Large File Delivery Optimization cannot be used in conjunction with [Fetch&nbsp;Compressed](/cdn/cdn-resource-options/compression/configure-fetch-compression), [Gzip&nbsp;Compression](/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression#gzip), and [Brotli&nbsp;Compression](/cdn/cdn-resource-options/compression/configure-gzip-and-brotli-compression#brotli) within the Resource Settings or within the same rule.
  * Large File Delivery Optimization is generally unnecessary for HLS and MPEG-DASH because these formats already split media into small segments that are cached independently.

## Configuration steps

<p>To enable Large File Delivery Optimization via the Gcore Customer Portal:</p>

<p>1. In the [Gcore Customer Portal](https://portal.gcore.com), navigate to **CDN** > **CDN resources**.</p>

<p>2. Click the CNAME of the required CDN resource to open **Resource settings**.</p>

<Frame>![CDN resources list](/images/docs/cdn/cdn-resource-options/optimize-large-file-delivery/optimize-large-file-image1.png)</Frame>

<p>3. Navigate to the **OPTIONS** tab.</p>

<p>4. In the left menu, click **Content** to scroll to the Content section.</p>

<Frame>![Resource settings with Content section](/images/docs/cdn/cdn-resource-options/optimize-large-file-delivery/optimize-large-file-image2.png)</Frame>

<p>5. Enable the **Large files delivery optimization** toggle.</p>

<Frame>![Large files delivery optimization toggle](/images/docs/cdn/cdn-resource-options/optimize-large-file-delivery/optimize-large-file-image3.png)</Frame>

<p>6. Click **Save changes**.</p>

<Warning>
When Large files delivery optimization is enabled, the HTTP `Etag` header is concealed in responses.
</Warning>

<p>A file larger than 10 MB keeps the origin busy when Gcore CDN fetches it in one piece. Slice fetches that file in parts no larger than 10 MB, caches each part, and sends the viewer the first bytes without waiting for the whole file. The origin must support HTTP range requests and send a consistent `Content-Length` and `Etag`. Responses conceal the HTTP `Etag` header. Purge the cache after turning slice on.</p>

<Info>
An [API&nbsp;token](/account-settings/api-tokens) is required. The CDN resource ID is the `id` from the [resources&nbsp;list](/api-reference/cdn/cdn-resources/list-cdn-resources) call.
</Info>

```bash
export GCORE_API_KEY="{YOUR_API_KEY}"
export CDN_RESOURCE_ID="{YOUR_CDN_RESOURCE_ID}"
```

## Turn slice on

<p>Gcore CDN requests each large file from the origin in parts of up to 10 MB. The origin must accept HTTP range requests.</p>

<p>`enabled` and `value` are required. Setting both to `true` turns slice on. The JSON field is `slice`; the key `Slice` is ignored. A request that also enables `gzipOn`, `brotli_compression`, or `fetch_compressed` returns HTTP 400.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    updated = client.cdn.cdn_resources.update(
        resource_id,
        options={"slice": {"enabled": True, "value": True}},
    )
    saved = updated.options.slice
    print(saved.enabled, saved.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        gcore "github.com/G-Core/gcore-go"
        "github.com/G-Core/gcore-go/cdn"
    )

    func main() {
        client := gcore.NewClient()
        ctx := context.Background()
        resourceID, err := strconv.ParseInt(os.Getenv("CDN_RESOURCE_ID"), 10, 64)
        if err != nil {
            panic(err)
        }

        updated, err := client.CDN.CDNResources.Update(ctx, resourceID, cdn.CDNResourceUpdateParams{
            Options: cdn.CDNResourceUpdateParamsOptions{
                Slice: cdn.CDNResourceUpdateParamsOptionsSlice{
                    Enabled: true,
                    Value:   true,
                },
            },
        })
        if err != nil {
            panic(err)
        }
        fmt.Println(updated.Options.Slice.Enabled, updated.Options.Slice.Value)
    }
    ```
  </Tab>
  <Tab title="curl">
    ```bash
    curl -X PATCH "https://api.gcore.com/cdn/resources/$CDN_RESOURCE_ID" \
      -H "Authorization: APIKey $GCORE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "options": {
          "slice": {"enabled": true, "value": true}
        }
      }'
    ```

    <p>The API returns HTTP 200. The saved option is:</p>

    ```json
    {
      "enabled": true,
      "value": true
    }
    ```
  </Tab>
</Tabs>

## Remove slice

<p>Send `slice` as JSON `null` to remove the option. The next read returns `null`.</p>

    ```python
        options={"slice": None},
    )
    print(updated.options.slice)
    ```
  </Tab>

## Slice one path

<p>A resource rule fetches files under `/video/` in parts. `ruleType` `0` is a regular expression and must start with `^/` or `/`.</p>

<Tabs>
  <Tab title="Python SDK">
    ```python
    import os

    from gcore import Gcore

    client = Gcore()
    resource_id = int(os.environ["CDN_RESOURCE_ID"])

    rule = client.cdn.cdn_resources.rules.create(
        resource_id,
        name="slice-large",
        rule="^/video/.*",
        rule_type=0,
        options={"slice": {"enabled": True, "value": True}},
    )
    print(rule.id, rule.options.slice.enabled, rule.options.slice.value)
    ```
  </Tab>
  <Tab title="Go SDK">
    ```go

    import (
        "context"
        "fmt"
        "os"
        "strconv"

        if err != nil {
            panic(err)
        }

        rule, err := client.CDN.CDNResources.Rules.New(ctx, resourceID, cdn.CDNResourceRuleNewParams{
    ```

  <MethodSection id="terraform" label="Terraform">

<p>**Large files delivery optimization** fetches a file larger than 10 MB from the origin in parts no larger than 10 MB, caches each part, and returns the requested bytes without waiting for the whole file. The origin must support HTTP range requests and send a consistent `Content-Length` and `Etag`. Responses conceal the HTTP `Etag` header. Purge the cache after turning slice on. Declare the option with the [Terraform&nbsp;provider](/developer-tools/terraform/overview) v2.</p>

<p>A new resource without `slice` leaves the option unset. After the option is saved, keep the object in the configuration. Setting `slice` to `null`, or removing the `options` block, leaves the saved `enabled` and `value` in place. A REST API call removes the option by sending JSON `null`.</p>

<p>Slice cannot be enabled in the same configuration as gzip, Brotli, or fetch compressed. Each pairing returns HTTP 400, and the error names those two options.</p>

## Turn slice on

<p>Set `enabled` and `value` to `true`. Both fields are required. After `terraform apply`, Gcore CDN fetches files larger than 10 MB in parts no larger than 10 MB and caches each part. On the resource, the option applies to every file.</p>

```hcl
resource "gcore_cdn_origin_group" "example" {
  name = "my-origin-group"

  sources = [
    {
      source  = "example.com"
      enabled = true
    }
  ]
}

resource "gcore_cdn_resource" "example" {
  cname           = "cdn.example.com"
  origin_group    = gcore_cdn_origin_group.example.id
  origin_protocol = "HTTPS"

  options = {
    slice = {
      enabled = true
      value   = true
    }
  }
}
```
