# Cloud Containers and Cloud Functions closed to new customers

Customer change: Cloud Containers and Cloud Functions are closed to new customers and planned for deprecation in their current form. From November 16, 2026, a region accepts the service only for customers with recorded usage of that service in the region during the preceding 60 days.
Affected users: New Cloud customers, and existing customers with no container or function usage in a region during the 60 days before November 16, 2026
Release evidence: Production Cloud API on 2026-11-18. Listing regions for product containers returned "The feature is not available for the account." Listing containers and functions in Luxembourg-2, Luxembourg, Amsterdam, and London-2 returned "The feature is not available in the region." The November 16 cutoff is the date named by the service owner for DOC-2941.
