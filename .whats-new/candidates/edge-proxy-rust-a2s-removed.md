# Rust Game A2S Caching removed from Edge Proxy

Customer change: The Edge Proxy application list no longer includes Rust Game A2S Caching. A new protected server cannot select that profile.
Affected users: Customers creating an Edge Proxy protected server.
Release evidence: On 2026-11-18 the production Customer Portal Add server wizard listed 15 application cards and none was Rust. DP-5135 was resolved on 2026-11-16 after the template change was verified on production.
