# Monthly billing for new virtual servers

Customer change: A newly ordered virtual server is billed monthly. A server ordered on the previous billing model stays on daily billing and is not moved to the monthly model.
Affected users: Customers who order a new virtual server, and customers who still have a server on the previous billing model
Release evidence: Hosting support (Raphaele Caixeta, 2026-10-26) reported that new VPS orders are charged monthly and that customers are disputing the charge because the docs still describe daily billing. The support wiki still has no launch date.
Open verification: The date monthly billing started for new orders.
