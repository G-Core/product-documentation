# Cost Report usage mode

Customer change: Cost Report replaces the Total, Hours, and Gb-hours chart control with Cost and Usage. Usage shows volume for one unit, including when the cost is zero.
Affected users: Cloud customers opening Cost Report.
Release evidence: The production Customer Portal showed the control on 2026-11-24. Labels are Cost, Usage, Total usage, Top usage driver, Daily average, Usage over time, and Top usage drivers. Group by remains Region, Type, Flavor, and Project.
