Gcore Managed DNS is an authoritative DNS service that routes domain traffic through Gcore's global Anycast network, directing end users to the nearest edge location for fast DNS resolution. Domain records are managed through the [Gcore Customer Portal](https://portal.gcore.com) or [REST&nbsp;API](/api-reference/dns).

Beyond standard resolution, Managed DNS supports weight-based and geographic traffic balancing, health checks that remove unhealthy endpoints from DNS responses, and DNSSEC signing for zone integrity. Records can be managed in non-advanced mode for single entries or in advanced mode for RRsets that combine balancing, geo-routing, and health check rules.

The section covers:

- **Overview** — what Managed DNS is, how it works, plan-level feature differences, and a glossary of terms used throughout the documentation
- **DNS zones** — create a zone, delegate it to Gcore name servers, and manage zone-level settings from a single page
- **Records** — eleven record types managed in non-advanced or advanced mode; includes import and export, specialized record types for email, PTR, and HTTPS, as well as advanced options for geo-routing, failover, and CDN integration
- **DNSSEC** — cryptographic signatures for zone records to protect DNS responses from tampering during the resolving process
- **Integrations** — OctoDNS for GitOps-style zone management, Certbot for Let's Encrypt certificate automation, and Terraform for infrastructure-as-code DNS workflows
