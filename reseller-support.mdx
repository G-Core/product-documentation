The [Admin Portal](https://admin.gcore.top/) is where resellers manage customer accounts, configure branding, and control which Gcore products appear in each customer's [Gcore Customer Portal](https://portal.gcore.com).

This program differs from the [reseller discount](/hosting/become-reseller-and-resell-our-services) program, which provides a discount on Virtual Server and Dedicated Server purchases instead of Admin Portal access.

The section covers:

- New interface: overview of the dashboard for managing accounts and sellers, viewing reports, and configuring branding and product visibility settings.
- Getting started: first steps after becoming a Gcore reseller.
- CDN management: customer CDN resource details, activity logs, origin groups, and feature activation.
- Streaming management: activate Streaming, check status, and manage features.
- Storage management: activate Storage and configure statuses.
- FastEdge management: manage customers' HTTP and CDN FastEdge applications and templates.
- Product statuses: overview of product billing statuses.
- API: reseller API documentation.
- Manuals: detailed guides for managing accounts and sellers, configuring branding and SSO authorization, and managing product visibility.
