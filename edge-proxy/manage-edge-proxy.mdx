Use the **Protected IPs** page to enable, disable, reconfigure, or delete a server without reprovisioning it.

## Protected IPs

Navigate to **Security → Edge Proxy → Protected IPs** to view all configured servers.

Each server card shows:

- **Server name** with a toggle to enable or disable protection
- **Status** — **Online** (protection active), **Stopped** (protection paused), or **Processing** (activation in progress)
- **Proxy IP** — the public IP that clients connect to
- **Origin** — the origin server IP (masked in the list view)
- **Applications** — the game protection profiles and configured ports

### Enable and disable protection

Use the toggle next to the server name to pause or resume protection without deleting the server.

- Toggle **on** — starts activation. The card shows **Processing (~3 min)** while Gcore provisions the proxy. Once complete, status changes to **Online** and traffic routes through the proxy IP.
- Toggle **off** — protection pauses immediately. Status changes to **Stopped**. The proxy IP remains assigned but stops forwarding traffic.

### Edit a server

Click **Edit protection** on the server card to open the **Edit server** panel.

<Frame>![Edit server panel showing server name, origin IP, application with port and proxy protocol configuration](/images/docs/edge-proxy/manage-edge-proxy/manage-edge-proxy-image1.png)</Frame>

The panel supports the following changes:

- **Server name** — rename the server.
- **Origin IP** — update the origin server address.
- **Applications** — add or remove application profiles. Click **Add application** to open an inline selection list and select a profile. To remove an existing application, delete all its ports — the application is removed from the server when **Save changes** is clicked.
- **Ports** — for each application, enter the port number and select the protocol (TCP or UDP). Click **Add port** to add more ports to an application.
- **Proxy protocol** — per-port setting that controls PROXY protocol header injection (visible when **Simple mode** is enabled in the port configuration area):
  - **Off** — no PROXY protocol header is added.
  - **V1** — adds a PROXY protocol v1 (text-based) header to each forwarded connection.
  - **V2** — adds a PROXY protocol v2 (binary) header to each forwarded connection.

Click **Save changes**.

### Delete a server

Click **Delete server** inside the edit panel. A confirmation dialog appears with the server name and the message "This will permanently remove [name] and all its application configurations." Click **Delete** to confirm.

Alternatively, click **Delete protection** on the server card in the Protected IPs list and confirm in the same dialog.

## Monitor traffic

Traffic Overview (**Security → Edge Proxy → Traffic Overview**) displays aggregated traffic across all active servers.

<Frame>![Traffic Overview showing MAX INBOUND, MAX BLOCKED, MAX CLEAN, 95TH PERCENTILE PASSED metrics and chart area](/images/docs/edge-proxy/manage-edge-proxy/manage-edge-proxy-image2.png)</Frame>

### Metrics

The page shows four metrics for packets (pps) and bits (bps):

| Metric | Description |
|--------|-------------|
| **MAX INBOUND** | Maximum total traffic received at the Edge Proxy endpoint |
| **MAX BLOCKED** | Maximum traffic identified as malicious and dropped |
| **MAX CLEAN** | Maximum clean traffic forwarded to the origin server |
| **95TH PERCENTILE PASSED** | 95th percentile of traffic forwarded during the selected period |

### Charts

The page includes two charts:

- **Packets (pps)** — traffic measured in packets per second
- **Bits (bps)** — traffic measured in bits per second

Each chart plots three series:

- **Input** — all traffic received at the Edge Proxy endpoint
- **Drop** — traffic blocked by the DDoS filter
- **Pass** — clean traffic forwarded to the origin server

Click a series label to show or hide it. Click and drag on the chart to zoom into a time interval. Click **Reset zoom** to return to the full view.

### Time range

Use the dropdown to select a preset range from one hour to three months. Set a custom range using the date fields next to the dropdown.
