Edge Proxy applies a filtering profile to each application on a protected server.

The profiles are the cards on the **Applications** step. In the [Gcore Customer Portal](https://portal.gcore.com/), open **Security → Edge Proxy → Protected servers**, click **Add server**, and continue to **Applications**.

<Frame>![Applications step with the search field and application cards](/images/docs/edge-proxy/supported-applications/supported-applications-image1.png)</Frame>

Use **Type to search** to filter the cards. Select every profile that matches traffic on the server. On the next step, set a port and choose **TCP** or **UDP** for each selected profile.

## Available profiles

Names and order match the Applications step.

| Profile | Traffic / behavior |
| --- | --- |
| Minecraft Protection | Protocol-aware protection for Minecraft (Java and Bedrock) traffic with TCP and UDP support. Mitigates handshake/login floods, ping/status abuse, and volumetric attacks while allowing legitimate client connections. |
| Garry's Mod Protection | Protocol-aware protection for Garry's Mod traffic. Mitigates UDP floods, query abuse, and malformed packet patterns while allowing normal gameplay traffic. |
| Counter-Strike 1.6 | Protocol-aware protection for Counter-Strike 1.6 (GoldSrc) traffic. Mitigates UDP floods, query abuse, and malformed packet patterns while allowing normal gameplay traffic. |
| Counter-Strike Go | Protocol-aware protection for Counter-Strike: GO (Source) traffic. Mitigates A2S query floods, connection floods, and high-PPS UDP attacks while allowing legitimate players and server queries. |
| Counter-Strike 2 | Protocol-aware protection for Counter-Strike 2 traffic. Mitigates UDP floods, query abuse, and abnormal packet patterns while allowing normal gameplay sessions. |
| FiveM TCP | Protocol-aware protection for FiveM TCP traffic. Mitigates connection floods and handshake abuse while allowing legitimate sessions. |
| FiveM UDP | Protocol-aware protection for FiveM UDP traffic. Mitigates high-PPS floods and abnormal packet patterns while allowing legitimate gameplay traffic. |
| San-Andreas Multiplayer | Protocol-aware protection for San Andreas Multiplayer (SA-MP) traffic. Mitigates connect floods, query abuse, and malformed UDP packets while allowing legitimate player connections. |
| Teamspeak 3 Voice Chat | Protocol-aware protection for TeamSpeak 3 traffic. Mitigates UDP floods and connection abuse while allowing stable voice sessions. |
| Rust Game A2S Caching | Protocol-aware protection for Rust Steam A2S queries. Enables query response caching to mitigate A2S flood patterns and reduce origin load. |
| Battlefield 2 Query Caching | Protocol-aware protection for Battlefield 2 server queries. Enables query response caching to mitigate server-browser query floods and reduce origin load. |
| Battlefield 2 Game | Protocol-aware protection for Battlefield 2 gameplay traffic. Mitigates UDP floods and malformed packet patterns while allowing legitimate sessions. |
| Unity Engine Unet | Protocol-aware protection for Unity UNET traffic. Mitigates malformed packets and high-PPS flood patterns while allowing legitimate game sessions. |
| Unity Engine UTP | Protocol-aware protection for Unity Transport Protocol (UTP) traffic. Mitigates UDP floods and abnormal packet patterns while allowing real-time traffic. |
| Generic TCP Server | Generic TCP server protection |
| General UDP Countermeasure | A dynamic DDoS mitigation mechanism that activates automatically when UDP traffic exceeds a configured threshold. |
