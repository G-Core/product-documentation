Edge Proxy applies a filtering profile to each application on a protected server.

The profiles are the cards on the **Applications** step. In the [Gcore Customer Portal](https://portal.gcore.com/), open **Security → Edge Proxy → Protected servers**, click **Add server**, and continue to **Applications**.

<Frame>![Applications step with the search field and application cards](/images/docs/edge-proxy/supported-applications/supported-applications-image1.png)</Frame>

Use **Type to search** to filter the cards. Select every profile that matches traffic on the server. On the next step, set a port and choose **TCP** or **UDP** for each selected profile.

## Available profiles

Each card carries a product description. The names match the Applications step.

| Profile | Use |
| --- | --- |
| Minecraft Protection | Filtering for Minecraft Java and Bedrock traffic on TCP and UDP. |
| Garry's Mod Protection | Filtering for Garry's Mod traffic. |
| Counter-Strike 1.6 | Filtering for Counter-Strike 1.6 (GoldSrc) traffic. |
| Counter-Strike Go | Filtering for Counter-Strike: Global Offensive (Source) traffic, including A2S queries. |
| Counter-Strike 2 | Filtering for Counter-Strike 2 traffic. |
| FiveM TCP | Filtering for FiveM TCP traffic. |
| FiveM UDP | Filtering for FiveM UDP traffic. |
| San-Andreas Multiplayer | Filtering for San Andreas Multiplayer (SA-MP) traffic. |
| Teamspeak 3 Voice Chat | Filtering for TeamSpeak 3 voice traffic. |
| Rust Game A2S Caching | Caches Rust Steam A2S query responses so query floods do not reach the origin. |
| Battlefield 2 Query Caching | Caches Battlefield 2 server-browser query responses so query floods do not reach the origin. |
| Battlefield 2 Game | Filtering for Battlefield 2 gameplay traffic. |
| Unity Engine Unet | Filtering for Unity UNET traffic. |
| Unity Engine UTP | Filtering for Unity Transport (UTP) traffic. |
| Generic TCP Server | General protection for TCP server traffic. |
| General UDP Countermeasure | Activates when UDP traffic exceeds a configured threshold. |
