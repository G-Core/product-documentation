Edge Proxy applies a filtering profile to each application on a protected server. Select the profiles that match server traffic during [Setup&nbsp;and&nbsp;configuration](/edge-proxy/setup-and-configuration).

<Frame>![Applications step with the search field and application cards](/images/docs/edge-proxy/supported-applications/supported-applications-image1.png)</Frame>

## Available profiles

| Profile | Traffic / behavior |
| --- | --- |
| Minecraft Protection | Java and Bedrock traffic with TCP and UDP support. Mitigates handshake/login floods, ping/status abuse, and volumetric attacks while allowing legitimate client connections. |
| Garry's Mod Protection | |
| Counter-Strike 1.6 | GoldSrc traffic |
| Counter-Strike Go | Source traffic. Mitigates A2S query floods, connection floods, and high-PPS UDP attacks while allowing legitimate players and server queries. |
| Counter-Strike 2 | |
| FiveM TCP | Mitigates connection floods and handshake abuse while allowing legitimate sessions. |
| FiveM UDP | Mitigates high-PPS floods and abnormal packet patterns while allowing legitimate gameplay traffic. |
| San-Andreas Multiplayer | SA-MP traffic. Mitigates connect floods, query abuse, and malformed UDP packets while allowing legitimate player connections. |
| Teamspeak 3 Voice Chat | Mitigates UDP floods and connection abuse while allowing stable voice sessions. |
| Rust Game A2S Caching | Enables query response caching to mitigate A2S flood patterns and reduce origin load. |
| Battlefield 2 Query Caching | Enables query response caching to mitigate server-browser query floods and reduce origin load. |
| Battlefield 2 Game | Gameplay traffic |
| Unity Engine Unet | Mitigates malformed packets and high-PPS flood patterns while allowing legitimate game sessions. |
| Unity Engine UTP | Unity Transport Protocol (UTP) traffic |
| Generic TCP Server | |
| General UDP Countermeasure | Activates automatically when UDP traffic exceeds a configured threshold. |
