Gcore DDoS Protection is a network-level security service for Dedicated Servers. Two protection modes are available: Basic (free) and Advanced (paid).

<Warning>
If you want to test DDoS protection against your own protected IP addresses, contact [Gcore Support](/hosting/contact-our-technical-support) or your account manager in advance. Each request is reviewed individually, and testing is permitted only after written approval from Gcore. Unannounced tests are treated as real attacks.
</Warning>

## Protection modes

Basic Protection is enabled by default. When an attack triggers IP blocking, the targeted address becomes unreachable, including for legitimate traffic, for several hours.

Advanced Protection routes traffic through the Threat Mitigation System (TMS) at all times, even when no attack is underway. TMS filters malicious traffic and forwards legitimate traffic to the server, keeping it reachable during attacks. An access control list (ACL) can be configured for TMS.

| | **Always-on (Advanced protection)** | **Basic protection** |
|---|---|---|
| **Payment** | Paid | Free |
| **Maximum attack detection time** | 5 seconds | 3 minutes |
| **Types of attacks** | • Standard amplification attacks <br/> • IP spoofing attacks <br/> • Flow and volumetric attacks (L3) <br/> • Connection-based attacks (L4) <br/> • Attacks targeting L5-L7 | • Standard amplification attacks <br/> • IP spoofing attacks |
| **Recommended for** | • Frequent attacks <br/> • Application layer (L7) attacks <br/> • The server hosts a critical business application | • Rare attacks <br/> • The server does not host critical business applications |

## Billing

Advanced Protection pricing depends on the protection layers, bandwidth, and server location:

  * OSI layers to be protected. Two protection options are available: L3-L4 and L3-L7. L3-L4 costs less, and always-on protection is available with either option.
  * The bandwidth that will be used by TMS to send traffic to the server. Several options are available: 1 Mbps, 10 Mbps, 100 Mbps, 200 Mbps, 500 Mbps, 1 Gbps, 2 Gbps, 10 Gbps. The lower the bandwidth, the lower the plan price.
  * The region where the server is located. Prices vary by location — contact [technical&nbsp;support](/hosting/contact-our-technical-support) for pricing in a specific data center.
