[Gcore&nbsp;CDN](https://gcore.com/cdn) is a distributed content delivery network that speeds up website loading in users' browsers, regardless of how far they are from the source server.

## Getting started

Set up a CDN resource and understand how the service is billed:

- [Getting&nbsp;started](/cdn/getting-started/create-a-cdn-resource/overview) — create and integrate a CDN resource with a website, configure the source site to avoid conflicts with the CDN
- [CDN&nbsp;resources&nbsp;interface](/cdn/about-cdn-resources-interface-how-it-is-arranged) — understand how the CDN resource list and its settings are arranged in the [Gcore&nbsp;Customer&nbsp;Portal](https://portal.gcore.com)
- [Billing](/cdn/how-the-cdn-service-and-its-additional-options-are-billed) — how service costs are determined, how to pay for additional features

## Configure a CDN resource

Fine-tune how a CDN resource fetches, caches, and secures content:

- [CDN&nbsp;resource&nbsp;options](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) — configuration of various CDN resource options, including caching, security, HTTP headers, CORS, optimization for delivering large files and images
- [Origin&nbsp;group](/cdn/add-an-origin-group) — add and configure a group of origin websites from which the CDN resource will retrieve content
- [IP&nbsp;configuration&nbsp;options](/cdn/ip-configuration-options/byoip) — bring an external IP address or use a dedicated IP for a CDN resource
- [SSL&nbsp;certificates](/cdn/ssl-certificates/add-an-ssl-certificate-to-deliver-content-over-https) — add an SSL certificate, issue a free Let's Encrypt certificate

## Manage and monitor content

Control cached content and track how a CDN resource performs:

- [Purge](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all) — clear the CDN resource cache by specifying the URL, a regular expression, or the CDN resource whose entire cache will be cleared
- [Prefetch](/cdn/load-the-content-to-cdn-before-users-request-it) — preload content onto CDN servers
- [Logs](/cdn/logs/logs-uploader) — view and download free logs, enable the paid Raw Logs option for more detailed information
- [Reports](/cdn/view-statistics-of-a-cdn-resource) — statistics, including traffic volume, response codes, cacheable traffic percentage

## Video delivery

Unlike static content, live and on-demand video needs delivery formats and security options of its own:

- [Video&nbsp;CDN](/cdn/video-cdn/video-cdn-overview) — deliver live and on-demand video over CDN with CMCD, HLS, DASH, multi-codec support, and video-specific secure tokens
