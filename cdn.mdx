Gcore CDN delivers content from an origin to end users through Gcore edge servers, under the customer's own domain.

A CDN resource links one or more domains to the origin they are served from and holds the delivery settings. Domains that need different settings are separate resources. The [delivery&nbsp;model](/cdn/how-cdn-works) traces a request from the end user through the edge cache to the origin.

<Card title="Create a CDN resource">
Start with a [standard&nbsp;resource](/cdn/getting-started/create-a-cdn-resource/overview) to serve a website or files through Gcore CDN: add the origin that holds the files and the domain to serve them from, then point the domain to the CDN.
</Card>

You can also use a CDN resource to deliver video with [Video&nbsp;CDN](/cdn/video-cdn/video-cdn-overview), as long as the content is already prepared for playback.

## Delivery settings

These areas decide where content comes from, how it is cached and delivered, and who can access it.

<CardGroup cols={2}>

<Card title="Origins">
An [origin&nbsp;group](/cdn/add-an-origin-group) points the CDN at the server, bucket, or FastEdge HTTP application that holds the files, and can combine several origins. To reduce the load on that origin, [Origin&nbsp;Shielding](/cdn/cdn-resource-options/general/enable-and-configure-origin-shielding) adds a cache layer in front of it.
</Card>

<Card title="Cache">
Cached files stay on the CDN for the [cache&nbsp;lifetime](/cdn/cdn-resource-options/cache/specify-cache-lifetime-on-a-cdn-resource-or-origin). A file can enter the cache earlier with [Prefetch](/cdn/load-the-content-to-cdn-before-users-request-it), which loads it before the first request, and leave earlier with [Purge](/cdn/clear-cdn-resource-cache-by-url-pattern-or-all), which removes it before that lifetime ends.
</Card>

<Card title="Secure connections">
Enable HTTPS for end users by adding an [SSL&nbsp;certificate](/cdn/ssl-certificates/add-an-ssl-certificate-to-deliver-content-over-https). You can also select the [origin&nbsp;pull&nbsp;protocol](/cdn/cdn-resource-options/general/specify-an-origin-and-the-origin-pull-protocol) the CDN uses to connect to your server over HTTP or HTTPS.
</Card>

<Card title="Access and security">
[Access&nbsp;policies](/cdn/cdn-resource-options/security/control-access-to-the-content-with-country-referrer-ip-and-user-agents-policies) and [secure&nbsp;token](/cdn/cdn-resource-options/security/use-a-secure-token/about-secure-token) decide who can request files, and [WAAP](/cdn/cdn-resource-options/cdn-security/protect-cdn-resources-with-waap) can block malicious HTTP requests before they reach the origin.
</Card>

<Card title="Per-file settings">
Use [Rules](/cdn/cdn-resource-options/rules-for-particular-files/create-a-rule-manually-or-from-a-template-to-configure-settings-for-particular-files) to control how specific files are delivered. For example, images can be cached longer than HTML pages.
</Card>

<Card title="Image optimization">
Make images load faster with [Image&nbsp;Stack](/cdn/cdn-resource-options/image-optimization-paid/about-image-stack), which automatically resizes and converts them while the originals stay unchanged.
</Card>

</CardGroup>

## Monitoring and logs

Monitor CDN performance, analyze traffic, and investigate individual requests using reports and logs.

- [Reports](/cdn/view-statistics-of-a-cdn-resource): traffic, response codes, and cache performance in the Customer Portal.
- [Grafana](/cdn/grafana/view-cdn-statistics-in-grafana): the same kind of metrics in Grafana, outside the Customer Portal.
- [Log&nbsp;viewer](/cdn/logs/log-viewer-view-and-download-cdn-resource-logs): requests from the last three days.
- [Logs&nbsp;Uploader](/cdn/logs/logs-uploader): export of request logs to external storage.

## Integrations and advanced options

- [FastEdge](/cdn/getting-started/integrate-cdn-with-fastedge): custom code that runs on requests and responses inside the CDN.
- [Terraform](/cdn/terraform/manage-cdn-via-terraform-v2): CDN resources, origin groups, and settings managed as code.
- [CMS&nbsp;integration&nbsp;guides](/cdn/getting-started/integrate-cdn-with-cms): connecting common CMS, ecommerce, and storage systems to a resource.
- [Dedicated&nbsp;IP](/cdn/ip-configuration-options/dedicated-ip) and [BYOIP](/cdn/ip-configuration-options/byoip): exclusive addresses instead of shared ones, either reserved by Gcore or the customer's own prefix.
